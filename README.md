# pzfc

一个以"去掉全局粘合（GLU₀）并度量它的失败"为目标的数学基础体系：带扩张的集合论底座，以及建在它上面的概率层与过程层。

**底座（B，`55`）**：
- 本体系描述一族集合宇宙（世界）及其扩张。
- 每个世界内部都是 ZFC；扩张只增加集合。
- **不假定所有世界能合成一个**。
- 在一切扩张下不变的陈述是全局的数学：恰好是可数核，由 M4 固定。
- 随世界而变的是局部的数学：基数、CH、选择给出的对象、完成的无穷总体。

**两层**：
- B（M1–M4）承担最初的目标；
- B⁺ = B + M4⁺（L(ℝ) 的绝对性）是标准的加强（`106`）。
- **强度**：B⁻ = M1–M3 只比 ZFC 多"有足够多的传递模型"；B 与无穷多个强基数等一致；B⁺ 更强。大基数强度全部来自 M4（`122 §1`）。

**概率与过程（`64`）**：
- 概率以定律（由可数数据给出的测度）为基本对象，样本空间是局部的；
- 部分可交换的过程的隐藏参数恰好是比率，比率恰好在同步没有特征尺度时存在（`120`）。

## 当前状态（第七十一轮；完成度见 `notes/124` §4；英文预印本见 `paper/`）

- **底座**：
  - B + M2a′ + M4 有模型，一致性强度已定位；
  - M4 ⟺ 每个世界满足两步投影泛型绝对性，推出 sharp 与投影可测，不推出 PD；
  - M4⁺ ⟹ AD^{L(ℝ)}（`103`、`106`）。
- **概率与过程**：
  - 比率的相变（ρ 有正下界 ⟺ 隐藏比率）已证；
  - 刚性：凹包络、瓶颈、段内比值有界的任意窗口、一切独立同分布的随机窗口、带重置尖峰的窗口、多链（路与树；三链的一切同步图）都已证（`120`、`123`）。

  - 命运窗口即由世界实现的测度扩张（`105`）；
  - Q\*（先 Cohen 再随机）否定；

  - 汇合高度有精确值：两个世界所含信息之和的第一个 ZFC-高度（`119`）。
- **多宇宙模态逻辑**：带 M4 的 D 在冻结与 Σ₁ 片段上是 S4.2，一般情形开放（`104`）。
