# 实验索引

数值检验脚本，都是独立的 Python 文件（依赖 numpy；`cone_harmonic.py` 还需要 scipy）。
- 运行：`python -u experiments/<脚本>`；
- 输出中有中文时，加 `PYTHONIOENCODING=utf-8`。

每个脚本对应的笔记与表格：

| 脚本 | 检验什么 | 笔记 | 结论 |
|---|---|---|---|
| `rigidity_paths.py` | 稀疏同步下分量之内的隐藏比率（极端中心线性化） | `73` | 稀疏：连续比率；稠密：刚性 |
| `birkhoff_diameter.py` | 检查点核的 Birkhoff 射影直径 | `78` | 几何同步收敛到正数；多项式同步趋于 0 |
| `rigidity_growth.py` | 刚性与同步间隔的增长率（k²、k³、1.5^k） | `83` | 相变在 ρ = 间隔/时间 → 0 处 |
| `plateau_mixing.py` | 平台上的混合长度 m(W) | `93` | m(W) = O(W) |
| `ratio_mixing.py` | 被杀死的 D-游走的比值距离 | `94` | 缓变与宽窗口趋于 0，尺度不变收敛到正数 |
| `sandwich_check.py` | 三段夹逼的常数（f(k) = k） | `97` | 进入、离开、中段的比值有界 |
| `corner_blocks.py` | 宽窗口的块上的角点交叉比 | `98` | 角点直径有界 |
| `irregular_windows.py` | 随机跳动、随机均匀、振荡窗口的角点直径 | `110`–`112` | 都刚性 |
| `multichain_blocks.py` | 三链路状同步、尺度相当时的块直径（完整的 Hilbert 度量） | `112 §1.3` | K → 2K 的直径有界 |
| `boundary_layer.py` | 顶部的相对存活与有效边界层 | `113 §1.4` | 稀疏接触时层 ≍ W^{2/3}（Airy） |
| `cone_harmonic.py` | 锥中采样链的调和函数误差与逃逸概率（稀疏线性方程组精确求解） | `116 §2.3` | 60° 角误差恰为 0；120° 角误差 ≍ 1/\|x\| |
| `entrance_ratio.py` | 进入比 min_x P(存活，末端∈S)/P(存活) | `116 §1.5` | 三种窗口对 K 一致有界（约 0.3–0.5） |
| `multiscale_windows.py` | 多尺度分段、比值有界的窗口的角点直径 | `117 §3` | 刚性 |
| `spike_windows.py` | 带任意高尖峰的窗口（段内比值无界）的角点直径 | `123 §2` | 刚性，尖峰处收缩更快（重置） |
| `multichain_cycle.py` | 三链三角形同步（六边形窗口）的块直径 | `123 §3.1` | 刚性 |
| `multichain4.py` | 四链路状同步（三维窗口盒，含混合角）的块直径 | `123 §3.3` | K → 4K 有界，刚性 |
| `demo.py` | 第一轮的应用层工具（障碍不变量），已降级 | `00`–`04` | — |

**共同的模型**：检查点链 D_{k+1} = D_k + W_{k+1} − NegBin(W_{k+1}, ½)，在 [1, W_{k+1}] 之外杀死（`93`、`97`），间隔等于窗口。

**刚性的数值判据**：
- 块核 M_{K→L} 的 Birkhoff 直径 Δ（一维时等于四个角点的交叉比，`94`）；
- 块长加倍后 Δ 是否一致有界并趋于 0。
