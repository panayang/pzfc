# 69 · 一般独立关系下的表示：无穷处的分量与分量之内的刚性

> 第四十六轮，第一个开放问题（`65 §5`、`64 §5` 第 1 条）。
>
> 形式化：`lean/Traces.lean`，5 条，不依赖 mathlib。

---

## 0. 路线检查

- **原则在推动的**：
  - `65` 的结论是：部分可交换 = 迹 + 迹之内新鲜的次序。
  - 按类时，新鲜的次序就是独立同分布的日程，隐藏的参数是日程的比率。
  - 这里问：对一般的独立关系，隐藏的参数在哪里、有多少？
- **会拉着走的**：
  - 分级图上的中心测度（Vershik–Kerov）；
  - 无穷迹的分解（Diekert 等）；
  - Perron–Frobenius 与 Birkhoff 收缩。
  只作证明的工具。
- **四种情形**：只处理"之前问了什么"（次序）。
- **是否回答 `00 §7`**：回答"与次序无关的隐藏全局参数"究竟有多少个。

## 1. 设定

- **字母与关系**：有限字母集 L，独立关系 I（对称、非自反），依赖关系 D 是它的补（自反）。
- **一个无穷字的堆**：
  - 元素是字母的各次出现；
  - 两次出现，若字母互相依赖且前者在前，则前者在下；再取传递闭包。
- **堆的基本性质**：
  - 每个元素下面只有有限个元素；
  - 同一字母的各次出现构成一条链。
  - 无穷迹就是堆（在同构之下）。
- **迹可交换**：P(X↾n = w) 只依赖于 w 的迹（`65 §2`）。
- **线性化**：给定无穷迹 τ，X 是 τ 的一个线性化。
  - 线性化是**中心的**，若每个前段的概率只依赖于它所到达的理想（`65 §5`）；
  - 线性化是**穷尽的**，若 τ 的每个元素迟早出现。

## 2. 约化：依赖图的连通分量给出日程

记 K₁, …, K_r 为图 (L, D) 的连通分量。不同分量的字母互相独立。

**定理 1**（约化）：X 对 I 迹可交换，当且仅当以下两条同时成立：
1. X 是 `65` 定理 4 的形式，其中类 = 依赖图的分量。也就是说，给定各分量的流与比率 π，分量之间按独立同分布的日程交错。
2. 每条分量的流 S_K，在"对调流中相邻的两个 I-独立字母"之下，联合定律不变。

*证明*：
- 对 I 迹可交换，蕴含对"不同分量"迹可交换：独立的对变少，不变性保持（`invariant_mono`、`invariant_classes`）。再由 `65` 定理 4，得到第 1 条。
- 第 2 条：流中相邻的两个字母，在 X 中可能被其他分量的字母隔开，而那些字母与两者都独立。可以先用 I-交换把它们移开（`slide`），再对调这两个字母，然后移回。每一步都是 I-交换。∎

**所以一般情形约化到依赖图连通的字母集。**

## 3. 没有最大元

**定理 2**：迹可交换的过程，它的无穷迹几乎必然没有最大元。等价地，每个元素上面都有无穷多个元素。

*证明*：
1. **延迟映射保持定律**。令 T_N 为"位置 N 与 N+1 上的字母独立时就对调它们"。迹可交换，所以 T_N 保持定律。
2. **最大元可以被推后一格**。设位置 N 上是 τ 的一个最大元 m。
   - 位置 N+1 上的元素不在 m 之上（m 是最大元），也不在 m 之下（它更晚出现），所以与 m 不可比，从而字母独立。
   - T_N 把 m 移到位置 N+1，τ 不变。
   - 于是 P(E_N) ≤ P(E_{N+1})，其中 E_N 是"位置 N 上是一个最大元"。
3. **求和得出矛盾**。
   - Σ_N P(E_N) 是最大元个数的期望。
   - 最大元两两不可比，所以它们的字母两两独立且互不相同，个数不超过 |L|。
   - 一个不减的数列，和有限，只能全为 0。∎

有限的形式（`slide`、`delay`）：一个字母，若它后面的字母都与它独立，把它移到末尾不改变任何交换不变的权重。所以它的位置本身不带权重；在无穷的过程中，这迫使概率为 0。

**推论**：在 `65` 的按类情形中，"出现至少一次、但只出现有限多次"的类几乎必然不存在。它是定理 2 的特例：这样一类的最后一次出现就是最大元。

## 4. 无穷处的分量：隐藏的比率住在哪里

**记号**：
- alph_∞(τ) 是在 τ 中出现无穷多次的字母；
- C₁, …, C_k 是 D 限制在 alph_∞(τ) 上的连通分量；
- τ_i 是 C_i 中字母的一切出现。

**三个事实**（证明都是有限的组合）：
1. **分量之内有限不可比**：τ_i 的每个元素，与 τ_i 中除有限个以外的一切元素可比。
   - 与它依赖的字母的出现，只有有限个在它下面；
   - 沿连通性传递下去，τ_i 中除有限个以外的元素都在它上面。
2. **分量之间，在有限处之后互不相干**：
   - 只出现有限次的字母，它们的一切出现落在一个有限理想 J₀ 中；
   - 在 J₀ 之外，不同 τ_i 的元素互不可比：连接它们的依赖链必须经过有限字母，而那会把起点拉进 J₀。
3. **每个元素都挂在某个分量上**：由定理 2，每个元素上面有无穷多个元素，所以它在某个 τ_i 的几乎一切元素之下。

**定理 3**（隐藏的比率）：给定 τ，τ 的每个中心的、穷尽的线性化，都是下面这种线性化的混合：
- 取比率 π = (π₁, …, π_k)，每个分量都 > 0，和为 1；
- 在有限时间之后，各分量按比率 π 的独立同分布日程交错；
- 每个分量之内，是它自己的一个中心线性化。

若每个分量都是刚性的（§5），则极端的线性化恰好与开单纯形中的点 π 一一对应。

*证明*：
- **分解**。J₀ 完成之后，剩下的是各分量的不交并。在其中：
  - 只重排日程的前 n 项、保持每个分量之内的次序，到达的理想不变；
  - 所以给定各分量之内的线性化，日程是可交换的。
- **比率**。由 de Finetti 定理，日程是比率为 π 的独立同分布。穷尽性迫使每个 π_i > 0。
- **分量之内**。每个分量之内的线性化也是中心的。
- **每个 π 都出现**（刚性时）。在"完成 J₀ 的首个理想"上，用乘积给出调和函数，再沿首达时刻向前延拓。它处处为正，并且是中心的。∎

**读法**：
- 在迹 τ 之外，隐藏的参数恰好是**无穷处每个依赖分量的一个比率**，共 k − 1 个自由坐标。
- 连接字母的作用：
  - 依赖图本身连通，但连接字母只出现有限次时，最后一个连接字母之后，比率重新出现；
  - 连接字母出现无穷多次时，没有比率。

## 5. 分量之内的刚性

**定义**：一个分量称为**刚性的**，若它恰有一个中心的、穷尽的线性化。

**定理 4**（完全切口）：设 τ_i 有无穷多个完全切口：理想 J，使得 J 外的每个元素都在 J 内每个元素之上。则 τ_i 是刚性的，唯一的线性化是：
- 相邻切口之间的有限段，各自取均匀的线性扩张；
- 各段彼此独立。

特别地，若分量中某个无穷出现的字母与分量中一切字母都依赖，它的每次出现都给出一个完全切口。

*证明*：
- 每个线性化都依次经过各个完全切口。
- 由中心性，到达同一个切口的一切路径等可能，于是各段均匀且彼此独立。∎

**定理 5**（有界的不可比）：若存在 B，使 τ_i 的每个元素至多与 B 个元素不可比，则 τ_i 是刚性的。

*证明*：
1. **小理想含在大理想中**。
   - 设元素 e 属于大小为 n 的理想 J。不含 e 的理想只能由 e 之下的元素与不可比的元素组成，大小 ≤ n − 1 + B。
   - 所以每个大小 ≥ n + B 的理想都包含 J。
2. **转移矩阵严格为正**。
   - 从大小为 n 的理想到大小为 n + B 的理想，路径数就是差集的线性扩张数，在 1 与 B! 之间。
   - 所以相隔 B 步的转移矩阵严格为正，元素之比有界。
3. **Birkhoff 收缩**。
   - 这样的矩阵在正锥的 Hilbert 射影度量下一致地收缩，收缩系数 ≤ tanh(log(B!)/2) < 1。
   - 调和函数在每一层的方向于是唯一确定；归一化之后，调和函数唯一。
   - 存在性来自紧致性；穷尽性来自第 1 步——每个元素 e 至迟在第 |↓e| + B 步出现。∎

**两个例子**：
- **没有完全切口、但不可比有界**：依赖图为路 x – p – q – y，字为 (x y p q)^∞。它的堆没有任何完全切口（逐一检验每个候选理想即可），但每个元素至多与 3 个元素不可比，所以由定理 5 是刚性的。
- **开放的情形**：同一个依赖图，字为 ∏_k (x^k y^k p q)。
  - 不可比无界，也没有完全切口。
  - 同步点把 x 与 y 的进度之差限制在次线性的范围内，所以猜想它仍是刚性的。
  - 一般的刚性问题——有限不可比是否总蕴含刚性——是开放的。

## 6. 汇总：一般独立关系下的表示

> **迹可交换的过程 = 隐藏的迹 τ + 无穷处每个依赖分量的比率 π + 新鲜的部分。**
>
> 新鲜的部分是：
> - 分量之间的独立同分布日程；
> - 分量之内的中心线性化。在完全切口或有界不可比的条件下，它是唯一的，由切口之间的均匀洗牌组成。

| 独立关系 | 无穷处的分量 | τ 之外的隐藏参数 | 新鲜的部分 |
|---|---|---|---|
| 一切不同字母独立（全可交换） | 每个无穷出现的字母 | 各字母的比率（de Finetti） | 日程 |
| 按类（`65`） | 每个无穷出现的类 | 各类的比率 | 类之间的日程 |
| 没有独立（I 为空） | 一个（堆是一条链） | 无 | 无：字就是迹 |
| 依赖图连通，有一个与一切依赖的无穷字母 | 一个 | 无 | 切口之间的均匀洗牌 |
| 依赖图连通，连接字母只出现有限次 | 多个 | 最后一个连接字母之后的比率 | 日程 + 分量之内的洗牌 |

**一句话**：隐藏的参数住在"依赖图在无穷处的分量"上，每个分量一个比率；在分量之内，次序被迹决定，只剩局部的均匀洗牌（在两个充分条件下已证，一般情形开放）。

## 7. 已知的与这里的

**已知的，只作指导**：
- 分级图上的中心测度与遍历方法（Vershik–Kerov）；
- 无穷迹按"无穷处的字母"分解（Diekert 等）；
- 迹幺半群上的 Bernoulli 测度（Abbes–Mairesse）：那是随机无穷迹的定律，与这里"给定迹之后的线性化"是不同的问题；
- Birkhoff 的射影收缩定理。

**这里的**：
1. 定理 1：依赖图的分量给出日程，一般情形约化到连通的字母集。
2. 定理 2：迹几乎必然没有最大元。这是对一切独立关系成立的必要条件；尚未查到文献（待核验）。
3. 定理 3：比率恰好住在无穷处的分量上。
4. 定理 4、5：两种刚性判据。
5. 一个开放的检验例子。

**如实的判断**：
- 定理 1–5 的证明都不长。
- 它们合起来回答了 `65 §5` 的问题，只差一处：一般的刚性。
