# 97 · 缓变窗口的刚性：解析证明

> 第五十三轮，第一块（`94 §4` 的第一个问题；`93`、`78`）。
>
> **范围**：概率论（过程层），主线。

---

## 0. 路线检查

- **原则在推动的**：`93`、`94` 把"ρ → 0 时次序是否完全由迹决定"化成了一个被杀死的一维游走的问题，并在数值上确定。这里给出缓变窗口一侧的完整证明。
- **会拉着走的**：随机游走的破产估计、局部极限定理、指数倾斜、Birkhoff 收缩。只作工具；引用的经典定理只有两条（§1.4），其余都在本篇证明。
- **是否回答 `00 §7`**：回答"次序是否完全由迹决定"——在缓变的同步下，是。
- **一处新的简化**：证明不需要 `94` 的全正性。关键是把检查点链放回"X 的时间"里：那里它是一个独立同分布的游走，只在检查点上受约束，而**窗口的宽度恰好等于上一段的时长**（§1.2）。

## 1. 设定

### 1.1 记号（同 `93 §1`）

- 窗口 W_k = f(k) + 1，P_k = Σ_{l≤k} W_l。
- 检查点链 D_k ∈ [1, W_k]，一步核
  > q_k(d, d′) = P(Y = W_{k+1} − (d′ − d))，d′ ∈ [1, W_{k+1}]，Y ~ 负二项(W_{k+1}, ½)，
  
  即 P(Y = y) = C(W_{k+1} − 1 + y, y) 2^{−(W_{k+1}+y)}。
- M_{K→L} = q_K q_{K+1} ⋯ q_{L−1}。它与 `78` 的路径计数矩阵只差对角的规范变换（`93` 定理 1），所以 Birkhoff 直径 Δ 相同。
- **判据**（`78` 定理 2 与推论）：若有无穷多个互不重叠的层区间 [K_n, L_n]，使 Δ(M_{K_n→L_n}) ≤ C*（C* 与 n 无关），则刚性。

### 1.2 X 的时间：一个只在检查点受约束的游走

**引理 1**（嵌入）：令 G₁, G₂, … 独立，都服从 {0, 1, 2, …} 上的几何分布 P(G = g) = 2^{−g−1}；令 ζ_i = 1 − G_i，D(i) = D(0) + Σ_{j≤i} ζ_j。则
> M_{K→L}(d, u) = P_d( D(P_ℓ − P_K) ∈ [1, W_ℓ]，K < ℓ ≤ L；D(P_L − P_K) = u )。

*证明*：G_j 是第 j 个 x 之前紧挨着的 y 的个数。W 个独立的 G 之和服从负二项(W, ½)，所以相邻两个检查点之间 D 的增量 W_{k+1} − Y 恰是 W_{k+1} 个 ζ 之和。约束只在检查点上。∎

**性质**：
- E ζ = 0，Var ζ = 2，ζ ≤ 1。游走向上**不跳跃**（每步至多 +1），向下的跳跃是几何分布，**无记忆**。
- 第 ℓ 个检查点的窗口 [1, W_ℓ] 的宽度，等于它前面一段的时长 W_ℓ = P_ℓ − P_{ℓ−1}。
  - 缓变窗口（f(k) = k）：窗口 ≈ √(2 × 时间)，与扩散同阶，是一个抛物形的区域；
  - 宽窗口：窗口远大于扩散的尺度；
  - 尺度不变：窗口与时间成比例。这正是 ρ 的含义。
- **反向**：把一段路径倒过来读，得到增量为 −ζ 的游走（向下不跳跃），受同样的检查点约束。于是
  > Σ_b P_b( 这一段存活，终点 = z ) = P̂_z( 反向的这一段存活 )。

  等式两边都只依赖检查点上的值（起点不受约束的那一段，两边都不加约束）。

### 1.3 游走的类

下面的引理对一类游走一致地成立。**类  𝒢**：整数值的独立增量，每个增量的分布属于以下之一：
- ζ 的指数倾斜 ζ_λ：P(ζ_λ = z) ∝ e^{λz} P(ζ = z)，|λ| ≤ λ₀；
- −ζ_λ。

取 λ₀ = ⅒。倾斜后的 ζ_λ 仍然向上不跳跃，向下的跳跃仍是几何分布，参数为 e^{−λ}/2 ≤ 0.56。所以对类中的一切增量，以下常数一致：
- 方差在 [σ₋², σ₊²] 中，σ₋² > 0；
- **越界量**有界：从任一水平之上首次跳到水平之下时，跳过的量 U 满足 E U² ≤ c_o；向上越过时同样。这是因为一侧不跳跃，另一侧是无记忆的几何分布。
- ζ_λ 的均值 m(λ) = Λ′(λ)，其中 Λ(λ) = log E e^{λζ} = λ − log(2 − e^{−λ})。有 Λ′(0) = 0，Λ″(0) = 2，并且在 |λ| ≤ λ₀ 上 |Λ′(λ)| ≥ |λ|。

对类中的游走，记 D̃(i) = D(i) − Σ_{j≤i} E ζ_j 为去掉漂移的游走，它是鞅；D̃(i)² − Σ_{j≤i} Var ζ_j 也是鞅。

### 1.4 引用的两条经典定理

1. **Kolmogorov 极大不等式**：P( max_{i≤t} |D̃(i) − D̃(0)| ≥ R ) ≤ σ₊² t / R²。
2. **一致的局部极限定理**（独立、整数值、非同分布，属于一个紧的非周期分布族，三阶矩一致有界；例如 Petrov，*Sums of Independent Random Variables*，第七章）：存在 C_L、以及对每个 κ 存在 c_L(κ) > 0 与 t₀(κ)，使得对一切 t ≥ t₀：
   - sup_z P(D(t) = z) ≤ C_L / √t；
   - 若 |z − E D(t)| ≤ κ√t，则 P(D(t) = z) ≥ c_L(κ) / √t。

   类 𝒢 是紧的非周期族：ζ 取 1、0、−1 等值，跨度为 1。

## 2. 四个一维的引理

以下 D 是类 𝒢 中的游走，并且**零均值**：每步 E ζ_j = 0。有漂移的情形在 §4 用倾斜化回这里。常数 C、c 只依赖于类 𝒢 与所列的参数。

### 2.1 连续监视下的破产上界

**引理 2**：设 x ≥ 0，τ₀ = min{i : D(i) ≤ 0}。则对一切 n ≥ 1，
> P_x(τ₀ > n) ≤ C₁ (x + 1) / √n。

*证明*：
- 若 x ≥ √n，右边 ≥ 1（取 C₁ ≥ 1），无需证明。设 x < √n，令 H = √n。
- 令 τ_H = min{i : D(i) ≥ H}，τ = τ₀ ∧ τ_H。游走在带形中出界的时间有有限的期望，所以可以用可选停止。
- **向上出界的概率**。由 E D(τ) = x，并且 D(τ₀) ≥ −U（U 是向下的越界量），得到
  > H · P(τ_H < τ₀) − E U ≤ x，所以 P(τ_H < τ₀) ≤ (x + √c_o) / H。
- **出界的时间**。由 E D(τ)² = x² + E Σ_{j<τ} Var ζ_j ≥ σ₋² E τ，得到
  > σ₋² E τ ≤ (H + √c_o)² · P(τ_H < τ₀) + c_o ≤ C (H(x + 1) + 1)。
  
  所以 P(τ > n) ≤ E τ / n ≤ C (x + 1) / √n + C / n。
- **合起来**：P(τ₀ > n) ≤ P(τ_H < τ₀) + P(τ > n) ≤ C₁ (x + 1) / √n。∎

**注**：同一计算给出一个出界时间的界，后面要用：
> 从 x ∈ (0, H) 出发，E_x τ ≤ C₂ (H x + 1)。（✱）

### 2.2 只在检查点上监视的破产上界

**设定**：
- 检查点时刻 0 = T₀ < T₁ < T₂ < …，相邻间隔 ≤ G·W；
- 约束：在每个检查点 T_ℓ（ℓ ≥ 1），D(T_ℓ) ≥ 0；
- 记 s_t(x) 为从 D(0) = x 出发、在一切 T_ℓ ≤ t 处都满足约束的概率。

**引理 3**：存在 C_B = C_B(G)，使对一切 W ≥ 1、t ≥ W 与 x ≥ 0，
> s_t(x) ≤ C_B (x + √W) / √t。

*证明*：
1. **取一个下探的水平**。令 y = A√W，A 待定；σ = min{i : D(i) ≤ −y}。
2. **不下探的部分**。由引理 2（把水平平移 y），P_x(σ > t/2) ≤ C₁ √2 (x + y + 1) / √t。
3. **下探之后必须回升**。在 {σ ≤ t/2} 上，令 c 为 σ 之后的第一个检查点，c − σ ≤ GW。存活要求 D(c) ≥ 0，即在 GW 步之内回升至少 y。
   - 记 R = max_{j≤GW} (D(σ + j) − D(σ))。由 Doob 的 L² 不等式，E R² ≤ 4σ₊² G W。
   - 回升之后，还要在剩下的时间（至少 t/4，只要 t ≥ 4GW）里存活，起点是 D(c) ≤ R − y。
4. **递推**。令 S(t) = sup{ s_{t′}(z) √t′ / (z + √W) : W ≤ t′ ≤ t，z ≥ 0 }。它有限（因为 s ≤ 1）。由第 3 步与强 Markov 性质：
   > P_x(存活，σ ≤ t/2) ≤ E[ s_{t/4}(R − y)；R ≥ y ] ≤ (2S(t)/√t) · E[ (R − y + √W) 1_{R≥y} ]。
   
   又 (R − y)⁺ ≤ R²/(4y)，所以
   > E[(R − y)⁺] + √W · P(R ≥ y) ≤ σ₊²G√W / A + 4σ₊²G√W / A² ≤ 5σ₊²G √W / A（A ≥ 1）。
5. **合起来**：对 t ≥ 4GW，
   > s_t(x) ≤ [ C₁√2 (A + 2) + S(t) · 10σ₊²G / A ] · (x + √W) / √t。
   
   对 W ≤ t < 4GW，平凡地有 s_t(x) ≤ 1 ≤ 2√G (x + √W)/√t。
6. **取 A = 20σ₊²G**，得到 S(t) ≤ max{ 2√G, C₁√2(A + 2) + S(t)/2 }，从而 S(t) ≤ max{2√G, 2C₁√2(A + 2)} =: C_B。∎

**读法**：只在检查点上被杀死，与连续地被杀死相比，只是把起点抬高了一个检查点间隔的扩散距离 √W。

### 2.3 钉住终点的局部下界

**引理 4**：对每个 κ，存在 k₀(κ) > 0 与 c₄(κ) > 0，使得：若 t ≥ t₀(κ)，t ≤ k₀ R²，且 |b − a| ≤ κ√t，则
> P_a( D(t) = b，并且 max_{i≤t} |D(i) − a| < R ) ≥ c₄ / √t。

*证明*：
- 由局部极限定理，P_a(D(t) = b) ≥ c_L(κ)/√t。
- 减去"越出 R"的部分。令 η 为首次 |D(i) − a| ≥ R 的时刻。
  - **若 η ≤ t/2**：由强 Markov 性质，剩下至少 t/2 步，落在 b 的概率 ≤ C_L √2 / √t。
  - **若越出发生在后半段**：把路径倒过来读。反向的游走从 b 出发，在 t/2 步内越出以 b 为中心、半径 R − κ√t ≥ R/2 的区间（设 k₀ ≤ 1/(4κ²)）；之后的点概率同样 ≤ C_L√2/√t。
  - 两种情形的概率都由 Kolmogorov 不等式控制：越出的概率 ≤ 4σ₊² t / R² ≤ 4σ₊² k₀。
- 所以 P_a(D(t) = b，越出) ≤ 2 · C_L √2/√t · 4σ₊² k₀。取 k₀ 使这 ≤ c_L(κ)/(2√t)，得 c₄ = c_L(κ)/2。∎

### 2.4 沿直线的输运

**引理 5**（沿直线的管）：给定 Θ ≥ 1 与 Γ ≥ 1。存在 c₅ = c₅(Θ, Γ) > 0，使得对一切 W ≥ W₀(Θ, Γ)、W² ≤ t ≤ ΘW²，以及整数 a、b，只要 |a − b| ≤ ΓW，就有
> P_a( 对一切 i ≤ t，|D(i) − ℓ(i)| < W/8，并且 D(t) = b ) ≥ c₅ / W，

其中 ℓ(i) = a + (b − a) i / t 是从 (0, a) 到 (t, b) 的直线。

*证明*：
- 把 [0, t] 分成 n 段，每段长 t/n，取 n ≥ max{ 256Θ/k₀(3)，Γ² }。于是：
  - √(t/n) ≤ W/16，并且 t/n ≤ k₀(3) (W/16)²；
  - √(t/n) ≥ W/√n，所以每段中直线的升降 |b − a|/n ≤ ΓW/n ≤ √(t/n)。
- 取 z₀ = a，z_n = b；中间的 z_j 取在 ℓ(jt/n) 周围、宽 ½√(t/n) 的整数窗中。相邻两点之差 ≤ 2√(t/n)。
- 每段用引理 4（κ = 3，R = W/16）：段内偏离段起点不超过 W/16。所以
  > |D(i) − ℓ(i)| ≤ W/16 + √(t/n) + ½√(t/n) < W/8。
- 由 Markov 性质相乘，并对中间点求和：
  > P ≥ (c₄/√(t/n))^n · (½√(t/n))^{n−1} = c₄^n 2^{−(n−1)} √n / √t ≥ c₅ / W。∎

**用法**：若管 {|x − ℓ(i)| < W/8} 在每个检查点处都落在允许的窗口之内，那么管中的路径都存活。于是，对终点在一个区间 J 中求和，得到
> P_a( 存活，D(t) ∈ J ) ≥ c₅ |J| / W。

## 3. 三段夹逼：直径的一个一般上界

**引理 6**（三段夹逼）：设 M = A Q C 是三个非负矩阵之积，S 是 Q 的一个行指标集，V 是 Q 的一个列指标集。设
1. **进入**：对一切行 d，A(d, S) ≥ ε · A(d, ·)；
2. **离开**：对一切列 u，C(V, u) ≥ ε · C(·, u)；
3. **中段**：min_{s∈S, v∈V} Q(s, v) ≥ β₋，并且 max_{s,v} Q(s, v) ≤ β₊。

其中 A(d, ·) 是行和，C(·, u) 是列和。则
> Δ(M) ≤ 2 log( β₊ / (ε² β₋) )。

*证明*：记 a(d) = A(d, ·)，b(u) = C(·, u)。
- 下界：M(d, u) ≥ Σ_{s∈S, v∈V} A(d, s) Q(s, v) C(v, u) ≥ A(d, S) β₋ C(V, u) ≥ ε² β₋ a(d) b(u)。
- 上界：M(d, u) = Σ_{s,v} A(d, s) Q(s, v) C(v, u) ≤ β₊ a(d) b(u)。
- 所以每个交叉比 M(d,u)M(d′,u′) / (M(d′,u)M(d,u′)) ≤ (β₊/(ε²β₋))²。∎

**读法**：
- 刚性要证明的是"远处看不出起点"。
- 引理 6 把它拆成三件事：
  - 从任何起点出发，存活的路径以正的比例进入内部；
  - 反过来读也一样；
  - 内部到内部的路径数彼此可比。
- 前两件是**边界**的事，第三件是**内部**的事。内部由引理 5 给出；边界由引理 3 与 §4 的倾斜给出。

## 4. 倾斜：把移动的上界变成固定的

**问题**：在缓变的窗口中，下界固定在 1，上界 W_ℓ 随时间移动。
- 对 f(k) = k，一段扩散时间 ΘW² 之内，上界移动 ≈ ΘW，远大于 √W。
- 所以不能把上界当作固定的：引理 3 的精度是 √W。

**办法**：在检查点之间用常数的指数倾斜，使游走的漂移跟着上界走。倾斜只在检查点处改变参数，而检查点上的 D 是有界的。所以倾斜的代价是一个有界的因子，外加一个对角的规范变换——后者不改变直径。

**假设（SV，缓变窗口）**：存在常数 C₀ 与函数 ω : [0, ∞) → [1, ∞)，满足
1. ω 不减、是凹的，并且 0 ≤ ω′(P) ≤ C₀ / ω(P)；
2. |W_ℓ − ω(P_ℓ)| ≤ C₀ √W_ℓ 对一切 ℓ 成立；
3. W_ℓ 不减，并且 → ∞。

**说明**：
- 由第 1 条，(ω²)′ ≤ 2C₀，所以 W_ℓ² = O(P_ℓ)：窗口至多与扩散同阶。这正是"缓变"。
- **例子**：f(k) = ⌊c k^α⌋，0 < α ≤ 1。取 ω 为 c k^α + 1 在 P 上的插值：
  - 它是凹的；
  - ω′ = dW/dP ≈ α / k ≤ C₀ / (c k^α)，因为 α ≤ 1；
  - 取整的误差 ≤ 1。
- 在一段 X-时间 ΘW² 之内（W = W_K），窗口留在 [W, C(Θ, C₀) W] 中，因为 ω² 至多增加 2C₀ΘW²。

**引理 7**（倾斜的代价）：在一段 X-时间 [0, t] 上，设检查点为 T₀ = 0 < T₁ < … < T_n = t。在第 ℓ 段（T_{ℓ−1}, T_ℓ] 上取常数 λ_ℓ，使
> Λ′(λ_ℓ) = m_ℓ := (ω(P_K + T_ℓ) − ω(P_K + T_{ℓ−1})) / (T_ℓ − T_{ℓ−1})，

即段内的漂移等于 ω 在这一段上的平均斜率。记 Q 为按 λ_ℓ 倾斜之后的测度。则：
1. |λ_ℓ| ≤ |m_ℓ| ≤ C₀ / W，并且 λ_ℓ 关于 ℓ 单调。
2. 在"一切检查点上 D ∈ [1, C W]"的事件上，
   > dP/dQ = κ_t · exp( −λ_n D(t) + λ₁ D(0) + Σ_{ℓ=1}^{n−1} (λ_{ℓ+1} − λ_ℓ) D(T_ℓ) )，
   
   其中 κ_t = exp(Σ_ℓ (T_ℓ − T_{ℓ−1}) Λ(λ_ℓ)) 是常数。指数中的三项之和的绝对值 ≤ 2C₀C + 2C₀C = 4C₀C。
3. 对停时 τ 截断时同样成立，只要 D(τ) ∈ [1, CW]。

*证明*：
- 第 1 条：由 §1.3，|Λ′(λ)| ≥ |λ|；m_ℓ 是 ω′ 的平均，ω′ 单调，所以 m_ℓ 单调，λ_ℓ 也单调。
- 第 2 条：似然比是 exp(Σ_ℓ λ_ℓ (D(T_ℓ) − D(T_{ℓ−1})) − Σ_ℓ (T_ℓ − T_{ℓ−1}) Λ(λ_ℓ)) 的倒数。按分部求和重排。
  - 由单调性，Σ |λ_{ℓ+1} − λ_ℓ| = |λ_n − λ₁| ≤ 2C₀/W；
  - 所以中间的和 ≤ 2C₀/W · CW；两端的项同样。∎

**推论**：在倾斜的测度 Q 下，令
> Ũ(i) = ω̃(i) − D(i)，其中 ω̃ 是 W_K 加上 ω 在检查点之间的线性插值的增量。

则：
- Ũ 的增量零均值，属于类 𝒢（反号）；
- 上界约束 D(T_ℓ) ≤ W_{K+ℓ} 变成 Ũ(T_ℓ) ≥ β_ℓ，其中 |β_ℓ| ≤ 2C₀√(CW)。

所以在 Q 下，**到上界的距离**是一个零均值的游走，受一个几乎固定的下界约束（摆动 O(√W)）。引理 2、3 对它成立：摆动的界可以并入 √W 那一项。

## 5. 进入与离开

**块的取法**：给定 K，记 W = W_K。取层 m₁ < m₂ < L，分别是使 X-时间 P_{m₁} − P_K ≥ ΘW²、P_{m₂} − P_{m₁} ≥ W²、P_L − P_{m₂} ≥ ΘW² 的最小的层。Θ 在下面选定，只依赖于 C₀。

在 [K, L] 上，由假设 SV：
- 窗口 W_ℓ ∈ [W, ΓW]，Γ = Γ(Θ, C₀)；
- 检查点间隔 ≤ ΓW。

令 **S = V = [W/4, W/2]**，A = M_{K→m₁}，Q = M_{m₁→m₂}，C = M_{m₂→L}。

**引理 8**（进入）：存在 Θ = Θ(C₀) 与 ε = ε(C₀) > 0，使得对一切足够大的 K 与一切 d ∈ [1, W]：
> A(d, S) ≥ ε · A(d, ·)。

*证明*：记 t_A = P_{m₁} − P_K ∈ [ΘW², ΘW² + ΓW]。分两种情形。

**(a) 下半：d ≤ W/2。**

- **上界**。去掉上界约束只会增大概率。由引理 3（约束 D − 1 ≥ 0，G = Γ）：
  > A(d, ·) ≤ C_B (d + √W) / √t_A ≤ C_B (d + √W) / (√Θ W)。
- **下界**，分三步。
  1. **抬离边界**。若 d < √W：第一个检查点间隔 g₁ ∈ [W, ΓW]。由局部极限定理（κ = 2），
     > P( D(T₁) ∈ [√W, 2√W] ) ≥ √W · c_L(2) / √(ΓW) =: c_b。
     
     若 d ≥ √W，这一步略去。记此时的高度为 d₀ ≥ √W。
  2. **升到 H = W/4**。设 d₀ < H（否则略去）。令 τ 为首次到达 ≥ H 或 ≤ 0 的时刻。
     - 游走向上不跳跃，所以到达时恰好是 H。由 d₀ = E D(τ) ≤ H · P(先到 H)，得 P(先到 H) ≥ d₀/H = 4d₀/W。
     - 由（✱），E τ ≤ C₂(H d₀ + 1)，所以 P(τ > t_A/4) ≤ 4C₂(W d₀/4 + 1)/(ΘW²) ≤ 2C₂ d₀/(ΘW)。
     - 取 Θ ≥ C₂，得 P(τ ≤ t_A/4，先到 H) ≥ 2d₀/W。
     - 这段路径在 (0, H] 中，每个检查点都满足 1 ≤ D ≤ W。
  3. **沿直线落进 S**。从 a = D(τ) = H（或 a = d ∈ [W/4, W/2]）出发，剩余时间 r ∈ [t_A/2, t_A] ⊂ [W², 2ΘW²]。
     - 对 b ∈ S，从 a 到 b 的直线在 [W/4, W/2] 中，所以宽 W/8 的管在 [W/8, 5W/8] ⊂ [1, W] 中。
     - 由引理 5，P ≥ c₅ |S| / W = c₅/4。
- **合起来**：A(d, S) ≥ c_b · (2√W/W) · c₅/4（d < √W 时），或 ≥ (2d/W) · c₅/4（d ≥ √W 时）。两者都 ≥ c′ (d + √W)/W。
- 所以 A(d, S) / A(d, ·) ≥ c′√Θ / C_B。

**(b) 上半：d > W/2。**

- 用引理 7 的倾斜 Q（在块 [K, m₁] 上），以及到上界的距离 Ũ，Ũ(0) = x := W − d ∈ [0, W/2)。
- **倾斜的代价**。在块上，窗口 ≤ ΓW，并且 κ_t ≤ exp(t_A · max Λ(λ_ℓ)) ≤ exp(C Θ C₀²)，因为 Λ(λ) ≤ 2λ² 且 |λ| ≤ C₀/W。所以在一切检查点都在窗口中、且停止处 D ∈ [1, ΓW] 的事件上：
  > e^{−K₁} ≤ dP/dQ ≤ e^{K₁}，K₁ = K₁(Θ, C₀)。
- **上界**。
  > A(d, ·) ≤ e^{K₁} Q( Ũ(T_ℓ) ≥ −b√W 对一切 ℓ ) ≤ e^{K₁} C_B (x + (b + 1)√W) / √t_A，
  
  其中 b√W 是 §4 推论中障碍的摆动。这里用了引理 3（把水平平移 b√W）。
- **下界**。在 Q 下，Ũ 是零均值的，重复 (a) 的三步：
  1. 抬到 Ũ ∈ [2(b+1)√W, 3(b+1)√W]：概率 ≥ c_b′；
  2. 在 t_A/4 之内先升到 Ũ ≥ H = W/4，而不降到 (b+1)√W 以下：概率 ≥ 2ũ₀/W。
     - 向上的越界是几何的，均值有界；
     - 这一段 D = ω̃ − Ũ 在 [W/2 − W/4 − O(1), W] 中，两个约束都满足。
  
  这两步在 Q 下计算，换回 P 只差因子 e^{±K₁}。
  3. 此时 a = D(τ) ≤ ω̃(τ) − W/4。在 P 下，沿直线从 a 到 b ∈ S。
     - 管的上沿 ≤ a + W/8 < ω̃(τ) − W/8。由于 ω 不减，它低于此后一切检查点的上界 ω − b√W。
     - 管的下沿 ≥ W/8。
     - 所以管中的路径都存活。由引理 5（Γ 取为窗口比），概率 ≥ c₅/4。
- 合起来，A(d, S)/A(d, ·) ≥ ε′(Θ, C₀) > 0。∎

**引理 9**（离开）：对一切 u ∈ [1, W_L]，C(V, u) ≥ ε · C(·, u)。

*证明*：
- C(·, u) 与 C(V, u) 是**反向的**游走（增量 −ζ，属于类 𝒢）从 u 出发、倒着经过同样的检查点时：
  - 存活的概率；
  - 存活并终于 V 的概率。
- 于是重复引理 8 的证明。唯一的不同：倒着走时上界随时间**下降**。
  - (a) 中的管在 [W/8, 5W/8] 中，而 W_ℓ ≥ W，所以不受影响；
  - (b) 中，管的上沿是从 a + W/8 到 b + W/8 的直线；上界 ω(P_L − s) 作为 s 的函数是凹的（ω 凹，P_L − s 线性）。凹函数在两端都高于一条直线，所以处处高于它。两端的检验与 (b) 相同。
- 倾斜的漂移跟着下降的上界走，引理 7 照样适用：单调性在倒转下保持。∎

**引理 10**（中段）：
> min_{s∈S, v∈V} Q(s, v) ≥ c₅ / W，max_{s, v} Q(s, v) ≤ C_L / W。

*证明*：
- 下界：由引理 5（Γ = 1）。s、v ∈ [W/4, W/2]，管在 [W/8, 5W/8] 中。
- 上界：去掉一切约束，由局部极限定理，点概率 ≤ C_L/√(P_{m₂} − P_{m₁}) ≤ C_L/W。∎

## 6. 定理

**定理 1**（缓变窗口的刚性）：设窗口满足假设 SV（§4）。则对一切足够大的 K，
> Δ(M_{K→L(K)}) ≤ C* := 2 log( C_L / (ε² c₅) )。

其中 L(K) 如 §5 所取；C* 只依赖于 C₀。所以相应的堆是**刚性的**：中心线性化唯一，没有比率之外的隐藏参数。

*证明*：
- 由引理 8、9、10 与引理 6，得到直径的界。
- 取 K₁ 足够大，K_{n+1} = L(K_n)，得到无穷多个互不重叠的块。由 `78` 推论，刚性。∎

**推论**：f(k) = ⌊c k^α⌋（0 < α ≤ 1，c > 0）时刚性。这包括 `73`、`78`、`94` 的主要例子 f(k) = k。

## 9. 已知的与这里的

**已知的，只作指导**：
- 随机游走的破产估计与局部极限定理；
- 指数倾斜（Cramér 变换）；
