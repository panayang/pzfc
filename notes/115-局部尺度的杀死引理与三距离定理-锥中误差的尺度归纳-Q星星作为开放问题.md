## 0. 路线检查

- **原则在推动的**：
  - 刚性只在乎每个时刻附近的局部边界层（`111`、`114`）；
  - 调和函数的误差对尺度可和（`114 §2`）。
- **会拉着走的**：三距离定理（Steinhaus、Slater），只作工具。它把 `114` 中"短区间等分布"的数论问题换成一个初等的组合事实。
- **结论先说**：
  1. **不规则窗口**（§1）：
     - 引理 S 推广到随时间缓变的局部尺度 ℓ(s)（引理 S′）；
     - 振荡的例子：在局部，零点处的对齐值是模 1 的等差数列，由 Slater 的回归时间定理（三距离定理的回归版本），每个时刻都有满足局部条件的尺度 ℓ(s)（命题 1，概要）；
     - 不再需要短区间的等分布。
  2. **多链**（§2）：
     - 三阶项的真实量级是 c·|y|^{p−3}，而不是 `114` 中写的 c^{3/2}|y|^{p−3}：步长是 c 个独立单步之和，三阶累积量按 c 增长；
     - 用环带分解与尺度归纳，调和函数的相对误差 ≲ √c/|x|（引理 G）；
     - 不需要修正函数 h̃。引理 W′ 的证明到此完整（常数未逐一写出）。
  3. **Q\*\***（§3）：再研究一轮，没有决定性的进展。按用户的决定，作为**开放问题**正式陈述，并列出已知的化约、已排除的途径和能判定它的东西。

## 1. 不规则窗口：局部尺度

> **已被 `116` 取代**：进入比中的短时存活因子可以约去（`116` 引理 E\*），所以下条件（KL）、局部尺度与三距离定理都不需要；振荡窗口直接用全局尺度 W^{0.7}。本节保留作记录。

### 1.1 引理 S′

设定同 `114 §1`。

**局部条件**：对块中每个时刻 s，有尺度 ℓ(s) ∈ [√W, ηW]，使：
- （KU）在时刻 s 以尺度 ℓ(s) 成立（只要求从 s 开始的一段）；
- （KL）在时刻 s 以尺度 ℓ(s)/C 成立。

**缓变条件（H）**：对 s < s′，
> ℓ(s′) ≤ C_H (ℓ(s) + √((s′ − s)W))。

也就是说，局部尺度增长不能快于扩散。对倒转的时间同样要求。

**引理 S′**：在局部条件与（H）之下（Θ 取大），Δ(M_{块}) ≤ C′。

*证明*：同 `114` 引理 S，只有两处改动。
1. **第 1 步**（从时刻 s、深度 δ 出发的上界 C(δ + ℓ(s))/W）：
   - 路径回到包络附近的时刻 s′ 满足 s′ − s ≍ δ²/W（尾部按扩散衰减）；
   - 由（H），ℓ(s′) ≤ C_H(ℓ(s) + C δ)；
   - 对回到包络的时刻取平均，尾部的贡献可和。
2. **第 3 步**（从包络之上出发）：
   - 分子与分母都在到达包络的随机时刻 τ 取值；
   - 上界是 E[1{τ 时存活}·(ℓ(τ) + 越过量)]/W，下界是 E[1{τ 时存活}·ℓ(τ)/C]/W；
   - 两者之比 ≥ 1/(C·常数)，与 ℓ(τ) 的值无关。这是局部尺度可以变化的原因。
- 其余不变。∎

### 1.2 振荡的例子

W_k = k(1 + ½|sin k^{0.7}|)，包络 ω_k = k。

**零点处的对齐**：零点 k₀(n) = (nπ)^{10/7}，间距 Z ≍ 4.5W^{0.3}。第 n 个零点处，离它最近的检查点的超出量是
> u_n ≈ 0.35 W^{0.7} · δ_n，δ_n := ‖k₀(n)‖（到最近整数的距离）。

**局部线性化**：在 N 个相邻的零点上，
> k₀(n₀ + t) = k₀(n₀) + β t + O(f″ N²)，β = f′(n₀)，f″ ≍ W^{−0.4}。

- 局部尺度 ℓ(s) ≤ cW^{0.7}，因为每个零点处都有 u_n ≤ 0.18W^{0.7}，所以（KU）在 W^{0.7} 上总成立。
- 这对应的零点个数 N ≲ W^{0.1}，于是 f″N² ≲ W^{−0.2}。而所需的分辨率 ε ≥ √W/W^{0.7} = W^{−0.2}。二次项与分辨率同阶，只影响常数。
- 所以在每个局部，δ_n 由一个模 1 的等差数列 a + tβ 给出。

**Slater 的回归时间定理**（三距离定理的回归版本）：对旋转 x ↦ x + β，一个区间的相继回归时间至多取三个值 g₁ < g₂ < g₃，并且 g₃ = g₁ + g₂。

**命题 1**（概要）：振荡的例子在每个时刻 s 都有满足局部条件的尺度 ℓ(s)，并且（H）成立。因此它刚性（在引理 S′ 之上）。

*证明概要*：取 β 的一个有理逼近 a′/q，满足 |β − a′/q| ≤ 1/(qN)（Dirichlet）。在 N 个零点的时间内，对齐值聚集在 q 个等距的点附近，并以 ≤ 1/N 的量缓慢漂移。令 δ_min(s) 为这 q 个点到 0 的最小距离，u₀(s) := 0.35W^{0.7} δ_min(s)。
1. **局部的墙**：
   - 高度 < u₀(s) 的路径在这段时间内不被杀死；
   - 高度 ≥ u₀(s) + O(W^{0.7}/N) 的路径每 q 个零点至少被杀死一次（回归时间 ≤ g₃ ≤ 2q）。
2. **取尺度**：令 ℓ(s) := max(u₀(s), A√(qZW))。
   - （KU）：高度 ≥ ℓ 的路径在 ℓ²/W ≥ A²qZ 个检查点内至少遇到 A² 个杀死点。
   - （KL）：若 u₀ ≥ ℓ/C，则尺度 ℓ/C 之下没有杀死。否则 ℓ = A√(qZW)，在 (ℓ/C)²/W 个检查点内至多有 A²/C² + 1 个杀死点，每个的杀死概率 ≤ ½，而存活权重的因子由 Harris–FKG 至少是乘积。所以 c₀ ≥ 2^{−(A²/C²+1)}。
3. **缓变条件（H）**：
   - q 只在 β 跨过 Dirichlet 逼近的阈值时改变，而 β 的变化率是 f″ ≍ W^{−0.4} 每个零点；
   - u₀ 的漂移速度 ≤ 0.35W^{0.7}/(qN) 每个零点。
   - 在 s′ − s ≲ W^{0.4} 个检查点内，漂移量 ≲ √((s′ − s)W)。更长的间隔上，ℓ ≤ cW^{0.7} ≤ √((s′ − s)W) 自动成立。
   - q 改变时 ℓ 的跳跃不超过 √q 的比值，也由同样的扩散界控制。
   - 这一步的常数没有追踪。∎

**读法**：
- 振荡窗口的有效边界层在 A√(qZW) 与 W^{0.7} 之间变化，由 β = f′(n₀) 的有理逼近结构决定：
  - β 远离小分母的有理数时，q 大，层接近 W^{2/3}（`113` 的软墙）；
  - β 接近小分母的有理数时，层变大到 W^{0.7}。
- 刚性不在乎层在哪里，只在乎每个时刻的上下条件同阶，并且层不突然变大。

## 2. 多链：锥中误差的尺度归纳

记号：c = g_k（步长的方差尺度），单位取 √c = 1 时 |y| 以 √c 计。

**三阶项的量级（更正 `114 §2` 第 1 步）**：
- 第 k 步是 c 个零均值独立单步之和，所以 E[ξ^{⊗3}] = c·κ₃（三阶累积量可加），而不是 c^{3/2}。
- 于是
  > |E h(y + ξ) − h(y)| ≤ C (c |y|^{p−3} + c² |y|^{p−4})。
- 在 √c = 1 的单位中，误差是 e(y) ≲ |y|^{p−3}。

**引理 G**（尺度归纳）：在锥 ∩ 球 B_R 中，对 |x| ≥ A，
> | E_x[h(Y_T)] − h(x) | ≤ C V(x) / |x|，

其中 T 是离开锥 ∩ B_R 的时刻，V(x) = (|x| + 1)^{p−1}(d(x) + 1)。

*证明*：
- E_x[h(Y_T)] − h(x) = E_x[Σ_{k<T} (E h(Y_k + ξ) − h(Y_k))]，其绝对值 ≤ Σ_i G(x, A_i)·sup_{A_i} e。其中 A_i 是环带 { 2^i ≤ |y| < 2^{i+1} }，G(x, A_i) 是在其中停留的期望步数。
- **环带中的停留时间**：
  - 从 A_i 中的点出发，离开 B_{2^{i+2}} ∩ 锥的期望步数 ≤ C4^i；
  - 从 |w| = 2^{i+2} 回到 A_i 之前，以 ≥ c 的概率被杀死（不变原理，锥的形状与尺度无关）。
  - 所以 sup_{z ∈ A_i} G(z, A_i) ≤ C4^i/c。
- **到达环带的概率**：
  - 对 2^i ≥ 2|x|，P_x(到达 A_i) ≤ C V(x)/2^{ip}。这是尺度 2^i 上的上界，由归纳假设（较小尺度的误差已控制）与 h 的可选停止得到。
  - 对 2^i < 2|x| 的环带（离 x 近的部分）：停留时间 ≤ C(d(x) + 1)|x|（到边的一维时间），而 e ≲ |x|^{p−3}。
- **求和**：
  > Σ_{2^i ≥ 2|x|} C V(x) 2^{−ip} · 4^i · 2^{i(p−3)} + C(d + 1)|x|·|x|^{p−3} ≤ C V(x)/|x|。
  - 第一项是几何级数；第二项等于 V(x)/|x|。
- 归纳：尺度 2^i 上的上界所需的误差，只来自 < 2^i 的尺度，而它们的和 ≤ C V/2^{i₀}，被主项吸收。∎

**结论**：
- 对 |x| ≥ A√c，h(Y) 在离开锥 ∩ B_R 之前是一个相对误差 ≤ C√c/|x| 的鞅。
- 这正是引理 W′ 的第 1、2 条所需要的。贴边的层（`114 §2` 第 2 步）与尖端（第 3 步）不变。
- 到此，引理 W′ 与多链尺度相当的刚性（`112` 定理 1）在证明结构上完整，剩下的只是常数。

## 3. Q\*\* 作为开放问题

### 3.1 陈述

**开放问题 Q\*\***：设 m 在 v 上 Mathias 泛型，r 在 v[m] 上随机。在 v[m][r] 中，ℝ^{v[r]} 是否外测度为正？

**等价形式**（`113` 定理 3）：设 U 是 v 上 P(ω)/fin 的泛型超滤子，V′ = v[U]，r 在 V′ 上随机，F 是 U 在 V′[r] 中生成的滤子。在 V′[r] 中，Mathias–Prikry 强迫 M_F 是否保持地面实数的外测度为正？

**意义**（`105`、`107`）：
- 若 Q\*\* 成立，那么"先 Mathias、再随机"实现了一个 Szpilrajn 型的测度扩张：它消灭 v，但保留 v 的随机扩张。
- 这给出命运窗口内部的一个严格中间值。

### 3.2 已知的

| 结果 | 出处 | 方向 |
|---|---|---|
| 常数型的实数（沿 m 最终常数）全部零测 | `109` 定理 1 | 限制了 Q\*\* 的见证 |
| 以地面函数为界的小集合连 ℝ^v 都覆盖不了；覆盖必须用由 m 给出的快速区间 | `109` 定理 2 | 支持 Q\*\* |
| v[m][r] 中没有按区间猜中地面序列的实数（没有 Cohen 实数） | `107` | 支持 Q\*\* |
| Kakutani–Fubini：r∘g 族在每个固定的 m′ 处的截面零测 | `110` 定理 3 | 化约 |
| Q\*\* 不成立 ⟹ 存在 Ramsey-余贫乏 × 𝒦-零测的 Borel 集 | `112` 命题 3 | 必要条件 |
| ⟺ M_F 保持外测度 | `113` 定理 3 | 等价 |
| Q_𝒦（v[m] 中有 ν ∈ 𝒦 使 ν*(H^v) > 0）⟹ Q\*\* | `113` 定理 4 | 充分条件 |
| 由 m 的有界元组构造的 ν 不满足 Q_𝒦 | `113` 命题 5 | 排除 |
| 地面的 ν 不满足 Q_𝒦 | `114` 命题 6 | 排除 |

### 3.3 已排除的途径

1. **"先随机、再 Mathias"**：对 v[g] 上的 Mathias 实数，g 沿它的比特最终为常数，所以 g 不是随机的（EvConst）。
2. **Galvin–Prikry + 测度的 Fubini**：Ramsey 与测度之间没有 Fubini 定理（奇偶性反例，`112`）。
3. **有限染色**：由 m 的元组构造的测度可以躲过一切有限染色，但仍被"全有或全无"排除（`113` 命题 5）。
4. **文献**：Hrušák–Minami 2014 刻画了 M_F 不加入控制实数与不加入最终不同实数的滤子，没有涉及测度的保持。
5. **这一轮检查过的**：
   - 用 M_F 的σ-中心性：它不决定测度保持（Cohen 强迫也是σ-中心的）；
   - 用 Laver 性质：Mathias 本身有 Laver 性质，却使地面实数零测，所以 Laver 性质也不决定。

### 3.4 什么能判定它

- **证明 Q\*\***：
  - 在 v[m] 中构造一个依赖于 m 的整个前段、元数无界的测度 ν ∈ 𝒦，使 ν*(H^v) > 0；
  - 或者对 M_F 找到一个保持外测度的组合判据（Katětov 序型），并验证 F 满足它。
- **否定 Q\*\***：构造一个满足 `112` 命题 3 的 Borel 集，并验证它具有 ψ 形式。它必须利用依赖 m 的整个前段的信息。
- **判断**：这是一个具体的强迫问题，不是基础的缺口。
  - 无论答案如何，都不改变底座 B 与两层的任何定理；
  - 它只决定命运窗口内部是否有这一种特定的中间值。
  - 命运窗口"外部"的二分（`75`），以及窗口作为由世界实现的测度扩张的一般理论（`105`），都与它无关。
