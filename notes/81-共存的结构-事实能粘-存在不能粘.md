# 81 · 共存的结构：事实能粘，存在不能粘

> 第四十八轮，第四个问题（`77 §5` 第 4 条；`74 §6`）。

---

## 0. 路线检查

- **原则在推动的**：`74` 证明汇合独立于 B，有的模型中有永不共存的集合。这里问：
  - 哪些"共存模式"可以实现？
  - 它与语境性是什么关系？
- **会拉着走的**：多宇宙模型的构造（`74`）；语境场景（`43`、`65`）。只作对照。
- **四种情形**：本篇处理对象层面的"同时"——哪些集合能在同一个世界中。
- **是否回答 `00 §7`**：回答对象层面"全局模型不存在"是什么形状。

## 1. 共存模式

**定义**：
- 给定集合 a₁, …, a_n。它们的**共存模式**是这样一族下标集合 F ⊆ {1, …, n}：{a_i : i ∈ F} 同在某个世界中。
- 它向下封闭，并含一切单点（M1）；也就是说，它是一个单纯复形。

**定理 1**（一切复形都可实现）：
- 设 c₁, …, c_n 是在世界 w 上互为泛型的 Cohen 实数，K 是 {1, …, n} 上任一含一切单点的单纯复形。
- 则有 B 的一个模型，其中 {c_i : i ∈ F} 同在某个世界 ⟺ F ∈ K。

*证明*：取一切从 w 可达、并且"所含的 c 的下标集属于 K"的世界。
- **M3a**：对这样的世界 u 与 P ∈ u，使 u[G] 多含某个 c_j 的泛型 G 只组成贫乏集，可以避开（同 `74` 定理 1）。于是下标集不变，仍属于 K。
- **M3b**：高度扩张不加实数。
- **M4**：沿用外层。
- 对 F ∈ K，w[c_F] 在族中。∎

**定理 2**（唯一的约束：可定义性的封闭）：
- 若 b 在每个含有 a 的世界中都可由 a 定义——例如 b = f(a)，f 是编码在可数核中的 Borel 函数——则每个含 a 的世界也含 b。
- 所以一般对象的共存模式，必须对这种可定义性封闭。
- 互为泛型的对象之间没有这种关系，所以一切复形都可出现。

## 2. 事实能粘，存在不能粘

**定理 3**：
- 关于有限个集合的事实，在含有它们的一切世界中都相同：
  - Δ₀ 的事实是全局的；
  - 关于实数的可数核事实：在定理 1 的模型中，含有 c_F 的世界都扩张 w[c_F]（中间模型定理），所以由 M4 与 w[c_F] 一致。
- 所以各个面（F ∈ K）上的局部事实，总被这些集合本身同时满足。
- 失败的只有**共同的存在**：没有一个世界含有整个组。

**推论**（没有全局的配对）：在定理 1 的模型中，若 {1, 2} ∉ K，则集合 {c₁, c₂} **不存在**——任何含有它的世界都会同时含有 c₁ 与 c₂。所以：
- B 不证明全局的配对公理。
- 集合这一类，连同全局的 ∈，满足外延与基础，也对并封闭；但配对只在世界之内成立，幂集也只在世界之内。

## 3. 与语境性的对偶

| | 值的层次（语境性，`65`、`68`） | 对象的层次（不共存） |
|---|---|---|
| 跨语境的同一 | **失败**：没有共享的记录；每个语境有自己的样本 | **成立**：对象是全局的集合 |
| 共同的世界 | **存在**：新鲜的样本总能放进同一个世界 | **失败**：没有世界含有全部对象 |
| 局部数据能否粘合 | **不能**：定律没有全局定律（η > 0） | **能**：事实在全局成立 |
| 由什么决定 | 定律，有限的、算术的，被强制 | B 不决定：可以实现任何复形 |

**一句话**：
- 语境性是"共存而不共享"；
- 对象层面的不共存是"共享而不共存"。

两者是全局模型不存在的两种相反的方式。

## 4. 对体系的意义

- B 的全局结构现在可以精确地说出来：
  - 一个全局的集合类，带着全局的 ∈，每个集合都在某个世界中；
  - 局部是 ZFC；
  - 可数核绝对（M4）；
  - 全局的事实（Δ₀、可数核）总是一致的；
  - 集合的**共存**——从而配对、乘积这类构造——只在世界之内。
- 所以 B 去掉的 GLU₀，在对象层面恰好是**配对的全局性**："任何两个集合都在一个共同的整体中"。

## 5. 已知的与这里的

**已知的，只作指导**：
- 用可数模型与泛型滤子构造多宇宙模型的技术；
- 语境场景的超图表示（Abramsky–Brandenburger）。

**这里的**：
1. 一切单纯复形都可作为共存模式实现（定理 1），唯一的约束是可定义性的封闭（定理 2）。
2. 事实能粘，存在不能粘（定理 3）；由此 B 没有全局的配对。
3. 与语境性的对偶：共存而不共享，对照共享而不共存。
