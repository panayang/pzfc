## 0. B 为什么没动根：Kolmogorov 在 B 里原样不变

你问：以测度为先的底座里，Kolmogorov 怎么处理？
- 回答是：**原样不变**。B（ZF + DC + LM + PSP）里，概率空间仍是一个点的集合 Ω；事件是 Ω 的子集；随机变量是 Ω 上的函数。
- B 只改了一件事：Ω 的每个子集都有测度。
- 所以 B 是"每个点集都可测的点的世界"，不是"以测量为先的世界"。它没有动开头所说的那个根：**先有一个装着一切结果的全局对象，测量只是去读它。**

## 1. 需求（重读开头）

1. **以测量为核心**：用测量的语言表述逻辑结构；"子集"只在某种意义上成立；与集合论是"底层与顶层"的关系。
2. **能回到**：在某些情况下回到 ZFC 与标准测度论。
3. **更广**：能描述墙外的东西——开头那段话里"突破之后无法描述"的东西。
4. **判定**：对 ZFC 判定不了的问题，给出解释，并在可能时给出判定。
5. **可解释**：公理本身要能用测量的话读懂。

开头的四个倾向（线性时间、绝对因果、还原论、目标拟合）要在底座上消失，而不是在旁边加院子（`41 §2` 的教训）。

## 2. 第一原理：问一次，再问一次

只用"问"和"回答"来想。

- 对一个东西问一个问题，得到一个回答。
- **再问一次，会得到什么？** 只有两种情形：
  - **一定得到同样的回答。** 这时回答可以写下来，以后不必再问，只要读写下的东西；也可以抄很多份，拿去和别的回答并排。称这样的回答为**记录**。
  - **可能得到不同的回答。** 这时单次的回答不能代表这个东西；稳定的只是回答的**统计**——问很多次时各回答出现的比例。称这样的东西为**来源**，称它的回答统计为它的**规律**。
- 记录是来源的特殊情形：规律集中在一个回答上的来源。
- **记录化**（测量）：从来源取一个回答，并把它写下来。写下的是一个记录；来源本身不因此变成记录。

这里只有一个区分——**回答能否复读**。它比"真与假""点与集合""确定与随机"都更靠前：
- 真假是能复读的二值回答；
- 点是一族能一起复读的回答；
- 随机是不能复读、但统计能复读。

## 3. 一个共同的根：一切回答都是记录

经典基础共同的前提是：**每个回答都是记录**——问过一次，就永远可以原样重读、复制、并排。

| 经典的东西 | 这个前提在其中的形态 |
|---|---|
| Kolmogorov | 一个样本点 ω 记下了一切问题的回答；随机变量是对这份记录的读法。所以同一个随机变量出现两次，就是同一个值：X + X = 2X |
| ZFC | 集合是完成的记录：外延说记录相同则同一；幂集说一切可能的记录已经作为一个完成的总体存在；宇宙 V 是总记录 |
| 图灵 | 格局是一份记录；下一步是这份记录的函数 |
| 线性时间 | 记录沿一条线累积，写下就不再变 |
| 绝对因果 | 下一个记录是已有记录的函数——函数可以作用在抄来的记录上，想用几次用几次 |
| 还原论 | 整体的记录由部分的记录拼成：部分的回答可以抄出来，再组合 |
| 目标拟合 | 一切评价都能抄到同一把尺子上比较 |

第一轮的三个旋钮（`01 §1`）也是这一个前提的三个面：
- **锐**：单个回答能复读；
- **粘合**：一切回答能一起复读——有一份总记录；
- **良基**：记录由记录分阶段写成（§4）。

`01 §5` 曾有一句猜想："ZFC 是关于可复制对象的理论"，当时用的是范畴论的说法，没有展开。这里把它当作根，用直白的话展开：**被复制的是回答。**

**B 的位置**：B 仍然假定一切回答都是记录，只是限制了"一切回答能被一个选取者一起写下"（去掉 AC）。所以 Kolmogorov 在 B 里不变。

## 4. 复读的代价：悖论与分阶段

- **Russell 的推导把同一个回答用了两次。**
  - 设 R 是一切不属于自身者。假设"R 属于 R"。
  - 由 R 的定义，得到"R 不属于 R"；再拿原来的假设和它对质，才得到矛盾。
  - 假设在这里被读了两次。否定它之后得到的结论，又被读了两次。
- **不许复读时，这个推导就断了。** 已知：在不许重复使用前提的逻辑里，"每个问题都定义一个东西"（朴素概括）是协调的（Grishin；待核验）。
- **读法。**
  - 经典集合论必须分阶段形成集合——累积层谱，构造上的线性时间。原因是它同时要三样东西：
    - 一切回答可以复读；
    - 回答是二值的；
    - 问题可以随便问。
  - 三样同时要，就会矛盾；分阶段是为此付的代价。
  - 所以**基础里的"线性时间"不是一个独立的偏好，而是"一切回答都是记录"的代价。**
- 还有一条待核验的已知结果：在不许复读的逻辑里，外延公理会把复读带回来（Grishin）。如果成立，它说的正是：**按记录认同（还原论），就必须允许复读。**

## 5. 一条轴：哪些回答算记录

各种基础在这里只有一个差别：**记录的界线画在哪里。**

| 位置 | 哪些回答是记录 | 无穷的总体是什么 |
|---|---|---|
| 经典（ZFC + Kolmogorov） | 一切回答，包括对无穷多个问题的回答；一切可能的记录已经作为总体存在（幂集） | 完成的记录的集合 |
| B（ZF + DC + LM + PSP） | 同上，只是没有全局的选取者 | 同上；这些集合都可测 |
| 构造主义（Brouwer） | 只有有限的程序给出的回答；无穷的东西是程序 | 程序；断言的逻辑随之改变 |
| **本篇的底座** | 有限的回答，以及记录化做出来的回答 | **来源**：一个无穷的总体是一个规律，不是一张写完的表 |

最后一行与构造主义的分别在逻辑：
- 本篇的断言都是关于记录或关于规律的；规律本身能复读——问很多次，比例是稳定的（二阶的记录）。
- 所以**断言层的逻辑仍然是经典的**，变的只是对象：对象可以是来源，而来源的单次回答不是记录。
- 这回答了 `11 §4` 的分岔：
  - 构造主义改的是断言；
  - B 改的是对象，但对象仍是点；
  - 这里改的是对象，而且对象不必是点。

## 6. 底座（草案）

**两种东西，一个动作**：来源、记录；记录化。记录是来源的特殊情形。

用测量的话写，每一条都能直接读懂：

- **S1 问题有规律。** 对来源问一个可以问的问题，回答有一个规律：各回答的概率。
  - 测量是全面的：凡是可以问的，都有概率。
- **S2 同一是统计的。** 两个来源是同一个，当且仅当一切问题——包括在同一语境中一起问的问题——的规律都相同。
  - 按统计认同，不按记录认同。
- **S3 记录是能复读的。** 一个来源是记录，当且仅当对它的每个问题问两次，一定得到同样的回答；也就是每个规律都集中在一个回答上。
- **S4 联合要语境。** 几个来源只能作为一个联合来源的部分被一起问。
  - 联合来源决定各部分的规律；各部分不决定联合（它们之间的关联是另外的数据）。
  - 没有一个把一切来源都作为部分的来源——没有全局语境。
- **S5 记录化未必可行。** 记录化按规律取出一个记录。一个来源可以有规律而没有记录：它的每个问题都有概率，却没有任何一份记录同时回答它的一切问题。
- **S6 记录是做出来的。** 每个记录要么是有限的，要么由记录化做出，要么由记录经集合运算做出。
  - 没有"一切可能的记录"这样一个现成的总体。
- **S7 记录的世界分阶段形成。** 记录能复读，所以按 §4，要分阶段：配对、并、按可以问的问题分离、替换、无穷，照常成立。
- **S8 无穷的总体是来源。** 例如"ω 的一切子集"是一个来源：逐个问"n 在不在里面"的规律（如公平的硬币），而不是一张写完的表。

## 7. 回到经典；Kolmogorov 怎么处理

- **Kolmogorov**：
  - 一个联合来源，再加上对它的一次完整记录化；
  - 样本空间 Ω 就是这个联合来源的记录的全体，事件是可以问的问题，P 是规律；
  - **Kolmogorov 是从记录一侧描述一个"能被一起记下"的来源族。**
  - 联合不存在的来源族、有规律而无记录的来源，都没有 Kolmogorov 描述；它们在这里照样是对象。
  - B 里 Ω 总是一个点集；这里 Ω 只在能记下时才有。这就是本篇与 B 的差别。
- **ZFC**：加一条理想化公理 I——**一切来源都已被完整记下，一切可能的记录作为总体存在**，再加上全局的选取者（AC）。
  - 加上 I，一切回答都成了记录，底座就塌缩成经典的世界。
  - 所以 ZFC = 底座 + "一切回答都是记录"。
- 标准测度论在两者之间：记录的世界里，规律住在可以问的问题上。

## 8. 墙外的东西在这里怎样说

只陈述结构，不推测具体系统。

1. **有规律而无记录。**
   - 一双袜子在交换的对称下：选不出一只，但"随机的一只"是整体的对象，各 1/2（`RandomChoice`，第二十一轮）。
   - 无穷多双时（Russell 的原例）：逐双独立的联合规律存在；但没有选择公理时，可以没有一份记录同时回答"每一双取哪只"。
   - 经典里这叫"选择失败"，像一个缺陷；这里它是一个普通的、有名字的情形：S5 所说的"记录化未必可行"。
2. **单次不能复读，统计能复读。**
   - 来源的身份是规律（S2）。问很多次，比例稳定，所以关于规律的断言本身是记录（§5）。
   - "复读缺陷"度量一个来源离记录有多远：对同一个问题独立问两次，回答不同的概率。它为 0，当且仅当是记录（§10）。
3. **整体不由部分决定。**
   - 两个来源的规律都给定时，它们的联合仍然可以不同（§10）；关联是另外的数据（S4）。
   - 还原论的失效在这里不是例外，而是一般情形；只有当部分都是记录时，整体才由部分决定。
4. **时间是记录化的先后。**
   - 来源没有时间；记录有：一个记录化用到了哪些已有的记录，就排在它们之后。这样得到的先后一般只是偏序。
   - 线性时间是"一切记录化都在同一个语境里、排成一条链"的情形。
   - 物理的"预测演化还是结构"，在这里的形态是：演化是预测一条链上的下一个记录；结构是规律与联合来源本身，没有时间。这不是对物理的回答，只是这个问题在这种语言里的样子。
5. **尺寸不止一把尺子。**
   - 配对（基数）比较的是记录；对来源，自然的尺寸是**信息**：它能回答多少个独立的二值问题。
   - 例：奇数位全为 0 的 0-1 序列，与全体序列一样多（可以配对）；但它只回答一半的问题，信息是一半（维数 1/2）。1 的比例为 p 的序列，维数是 −p log₂ p − (1−p) log₂(1−p)（Eggleston，已知）。
   - 所以在"可数"与"连续统"之间，配对看不见任何东西，信息却看见一整段尺寸。"没有中间大小"（CH 的 Cantor 形式）说的，首先是**配对这把尺子很粗**。
6. **评价没有唯一的尺子。**
   - 比较两个来源，是比较它们的规律；单一标量，是把一切评价都记到同一把尺子上（§3 的目标拟合）。

## 9. 判定了什么（如实）

- **底座上判定的**：
  - 凡可以问的问题都有概率（S1），没有不可测的问题；
  - 连续统作为来源，规律在对称下唯一（`12`：公平的硬币）。
- **经典的 CH（2^ℵ₀ = ℵ₁）**：
  - 它问的是连续统的**全部记录**排在序数尺子上的位置，要用到理想化公理 I（§7）；
  - 底座里没有这个总体，所以它不是关于底座的问题。这是**解释，不是判定**。
  - 它的 Cantor 形式——可以问的子集按配对要么可数、要么与连续统一样多——对 Borel 与解析集是已知的 ZFC 定理（Alexandrov–Hausdorff、Suslin）；**没有新判定**。
- **真正的判定从哪里来**：
  - 把 S6 加强为"一切实数的记录集都是由来源做出的"。
  - 猜想：由此可推出记录的世界里：
    - 一切实数集都可测，实数不能排成良序；
    - 于是 2^ℵ₀ 不是任何 ℵ，Cantor 形式的 CH 对一切集合成立。
  - 结论的形状与 Solovay 模型一致，所需的一致性强度也应当相同（一个不可达基数），**待证**。
  - 那时底座不再保守，但不保守的理由是一条可以读懂的原则："没有未经记录化的记录"。
  - 与 B 的区别：B 把可测性直接写成公理；这里它是"记录都是做出来的"的推论（若猜想成立）。
- 所以现在有两个版本：
  - **弱底座**：S1–S8，与 I 相容，经典作为理想化的完成；
  - **强底座**：S6 加强，判定一批经典问题，不保守。

## 10. 形式化尝试：`lean/Records.lean`（11 条，不依赖 mathlib）

最小的模型：一个有限的来源是一只**罐子**——一串结果，每次有放回地均匀摸一个。独立问两次，就是一切有序对。

| 定理 | 内容 |
|---|---|
| `record_iff_twice_copied` | 一个来源是记录，当且仅当"独立问两次"得到的每一对，都可能来自"问一次再抄一份" |
| `defect_eq_zero` | 复读缺陷（独立两次回答不同的对数）为 0，当且仅当是记录 |
| `first_reading`、`second_reading` | 问两次时，每一次单独看，都有来源原来的规律：统计经得起复读 |
| `read_twice_sum`、`copy_sum` | 0 与 1 各半的来源：问两次再相加，可以得到 1；问一次再加倍，永远得不到 1。X + X 不是 2X |
| `same_parts`、`different_wholes` | 两个联合来源，部分的规律完全相同，整体不同（一个总相同，一个总不同） |
| `records_fix_whole` | 部分都是记录时，整体由部分决定 |
| `mem_pairs`、`mem_copied` | 引理 |

公理剖面：
- 10 条不依赖选择：5 条不依赖任何公理，其余只依赖 `propext`（或再加 `Quot.sound`）；
- `defect_eq_zero` 经由核心库的计数引理 `List.countP_eq_zero` 用到了经典公理；与之等价的 `record_iff_twice_copied` 不用选择。

**如实说明**：这些都是简单的事实。它们的作用是检查本篇的切法是否一致：记录 = 能复读 = 复制与复读不可分辨；统计能复读；还原论恰在部分都是记录时成立。它们不是底座本身的定理——底座（S1–S8）还没有写成形式系统。

## 11. 已知的与这里的

**已知的，只作指导**（都待核验）：
- 不许重复使用前提时朴素概括协调；外延带回复读（Grishin）。
- 概率程序中"抽样两次"与"抽样一次再复制"的区别。
- `01 §5` 引用过的：可复制的对象就是经典的对象（Markov 范畴）。
- Solovay 模型；Alexandrov–Hausdorff、Suslin 的完美集定理；Eggleston 的频率集维数。
- Brouwer 的选择序列、以"随机"为原语的公理化（van Lambalgen）；Simpson 关于没有点的随机子空间的结果。

**这里的**：
1. **诊断**：一个根——"一切回答都是记录"。
   - 四个倾向、三个旋钮、三种形式化（Kolmogorov、ZFC、图灵）都是它的面。
   - 基础里的线性时间（分阶段）是它的代价（§4）。
2. **一条轴**："记录的界线画在哪里"。经典、B、构造主义都落在这条轴上，本篇的底座也在上面（§5）。
3. **底座的切法**：
   - 断言是经典的（关于记录与规律）；对象可以是来源（不必是点）；
   - 无穷的总体是来源；记录是做出来的；
   - Kolmogorov 是从记录一侧对"能被一起记下"的来源族的描述（§7）。

## 12. 开放的问题

1. **"可以问的问题"是什么？** 这是底座的核心定义，也是 `11` 的 P3（有限性）要落地的地方。候选：由有限多个回答决定，或者是它们的可数极限。但这会不会把底座悄悄变回"Borel 集上的经典测度论"？
2. **一致性与强度。**
   - 弱底座要一个模型；如果模型能在 ZFC 里直接定义，弱底座就是保守的。
   - 强底座（§9）的猜想要证明，并确定所需的强度。
3. **按统计认同会不会带回复读？** Grishin 的结果（外延带回复读）若成立，S2（按统计认同）就要检查：来源的同一是统计的，记录的同一是外延的，两者要分开。
4. **失败的度量。**
