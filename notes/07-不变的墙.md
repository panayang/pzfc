# 07 · 不变的墙：换基础只改变它们的形状

> **第三轮注**：§4 的不可克隆、§5 证伪条件中的不确定性关系属物理挪用，删除。Lawvere、等变性、Kripke 与复仇、去收缩、NF 保留。

> 第一轮的口气像是新基础可以拆墙。有一类墙拆不掉——它们是定理，在任何足够强的基础里都成立。
> 能做的只是**选择它在哪里重现**。这一篇把这件事做精确，形式化在 `lean/Invariants.lean`。

## 1. Lawvere 不动点定理

> 若 $\varphi: A\to Y^A$ 是（弱）点满射——每个 $g:A\to Y$ 都等于某个 $\varphi(a)$——则 $Y$ 的**每个**自映射都有不动点。

逆否：**只要 $Y$ 上存在一个无不动点的自映射，就不存在这样的 $\varphi$。**

Cantor、Russell、Gödel 不完全、Tarski 不可定义、停机问题都是它的实例（Yanofsky 2003 做了统一整理）。
取 $Y=\{0,1\}$，否定 $\neg$ 交换 0 与 1，无不动点 ⟹ 没有"所有谓词的枚举"。取 $A$ 为集合宇宙、$\varphi(y)(x)=[x\in y]$，这就是 Russell。

**关键：定理量化的是"所有被允许的自映射"。** 墙的形状取决于两件事：

1. 真值对象 $Y$ 是什么（Λ 轴）；
2. 哪些映射被允许（连续的？单调的？全部？）。

若在某个范畴里 $Y$ 的每个被允许的自映射都有不动点，**对角线就不再产出矛盾，只产出不动点**。

## 2. 墙移动了，但没有消失——三个例子

### 例 A：Kripke 的真理论与"复仇"

Tarski：语言不能定义自己的真谓词。Kripke（1975）的做法：真值取三值 $\{\bot,0,1\}$（$\bot$ = 无根据），
只用在**信息序**上单调的算子（强 Kleene）。平坦三元域上**每个单调自映射都有不动点**（Knaster–Tarski 的最小情形），
所以 Lawvere 无从下手——说谎者句取值 $\bot$，没有矛盾。

然后墙回来了：要在语言内部说"说谎者是**无根据的**"或"说谎者**不是真的**"，
需要算子 $N$：$N(1)=0,\ N(0)=1,\ N(\bot)=1$。它**不单调**，而且**没有不动点**——Lawvere 再次成立。
这就是哲学文献里的**复仇悖论**：你一旦能谈论自己用来躲避悖论的那个范畴，悖论就回来。

`lean/Invariants.lean` 里三件事都证了：单调映射必有不动点；Kleene 否定取 $\bot$ 为不动点；$N$ 无不动点。
**这是"墙守恒"最干净的形式化**：躲开对角线的代价，是语言不能完整谈论自己。

### 例 B：去掉收缩——朴素概括回来了，代价是计算缩水

Russell 的推导把假设 $R\in R$ 用了两次。去掉收缩规则，推导断掉。

- **Łukasiewicz 无穷值逻辑**（本身无收缩）：朴素概括据称协调（White 1979）；Russell 集的隶属度是 $\tfrac12$。
  但其中的算术据称是 ω-不协调的，存在非标准自然数（Hájek 2005，Yatabe 2007）。〔待核验，见 `99`〕
- **Terui 的 Light Affine Set Theory**（2004）：light 仿射逻辑之上的**朴素**集合论，协调；
  其中可证全函数**恰好**是多项式时间函数。

读法：Russell 没有消失。它从"$R$ 处的矛盾"搬到了"自然数不标准"或"计算只剩 PTIME"。
**你用复制换来了概括；复制正是无界计算的燃料**（隐式计算复杂性：限制 `!` 的强度 ⟺ 限制复杂度类）。

### 例 C：NF——换一种挡法，AC 被判定为假

Quine 的 NF 用**分层**（一种类型对称）代替大小限制，于是存在全集。Specker（1953）：**NF ⊢ ¬AC**。
这是"不同的概括原则判定了一个 ZFC 独立的命题"的真实例子。NF 的协调性长期悬而未决，据我所知近年已由 Holmes 证明并在 Lean 中形式化〔待核验〕。

## 3. 第二个不变式：等变性

> 群 $G$ 作用于 $X$；$S$ 是 $G$-不变的，且 $S$ 中没有 $G$-不动点。则不存在 $G$-等变的选择 $c$ 使 $c(S)\in S$。

证明一行：$c(S)=c(gS)=g\,c(S)$ 对所有 $g$ 成立，所以 $c(S)$ 是不动点，矛盾。

实例：

- Fraenkel–Mostowski 置换模型中 AC 失效；
- Angluin（1980）：匿名对称网络中不存在确定性的领导者选举；
- Choiceless Polynomial Time 不能任意选取；
- 原子上的图灵机：确定性机器选不出原子，于是弱于非确定性机器（`08`）。

**同一个一行引理，四个领域。** 反面也成立（也已形式化）：**全序打破一切非平凡对称**。
所以"选择"与"序"是同一种资源——对称破缺。这就是 `06` 中 Χ ↔ Τ 的最小形态。

## 4. 其他候选

- **粘合障碍**（Čech 上同调）：Bell、Kochen–Specker；社会选择的拓扑版本（Chichilnisky；Baryshnikov 用同调重证 Arrow）。
- **不可克隆**：紧闭范畴中若对角映射是自然的，范畴退化（Abramsky）。

## 5. 猜想：L\* 的墙都是"无自然截面" 〔猜想，C→B 级〕

上面每一堵墙都是某个满足自然性条件的截面 / 变换不存在：

| 墙 | 缺失的是 | 自然性条件 |
|---|---|---|
| Lawvere | 点满射 | 与对角线相容 |
| 等变性 | 选择函数 | 与对称相容 |
| 粘合 | 全局截面 | 与限制相容 |
| 不可克隆 | 复制映射 | 与所有态射相容 |

**若成立**：基础的选择 = 选择强加哪些自然性条件；L\* 清单告诉你每个选择的代价。
**证伪条件**：(a) 找到一堵不具此形式的不变墙——最可疑的是**不确定性关系**，它是不等式而非不存在性；
(b) 找到一个不是不变量的自然性障碍。

## 6. "守恒"——只是直觉 〔C 级〕

每个例子里，墙在一处被拆，就在另一处重现：Russell → 非标准数 / PTIME / 复仇；AC → 不可测集；
¬AC + 全可测 → 需要不可达基数（Solovay / Shelah）；全集 → ¬AC。
是否存在一个被守恒的**量**（一致性强度？证明论序数？）——我没有找到，不同例子的代价不在同一个尺度上。
所以这只是启发式：**一个声称不付任何代价的新基础，几乎可以肯定是错的。** 这条被写进检验协议（`09 §3`，T4）。
