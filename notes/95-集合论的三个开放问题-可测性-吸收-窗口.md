## 1. M4 推出投影可测

**附加的公理 M2a′（中间世界）**：若 w ≼ w[G]，v 是介于 w 与 w[G] 之间的 ZFC 模型，则 v 是世界。
- 在一切预期的模型中它都成立：泛型扩张的中间模型本身是泛型扩张。
- 下面的论证需要它。

**定理 1**：在 B + M2a′ 中，每个世界里，以实数为参数的每个投影集都 Lebesgue 可测，并且有 Baire 性质。

*证明*（可测）：设 A = {x : φ(x, a)}，a 是实数。
1. **取 Boolean 值**。在 w 的随机代数中，取 φ(ṙ, a) 的 Boolean 值，它是一个 Borel 码 b。
2. **坍缩连续统**。取 G 在 w 上对 Coll(ω, (2^ω)^w) 泛型（M3a）。在 w[G] 中：
   - ℝ^w 可数，所以 w 编码的一切零测集之并是零测集；
   - 对每个在 w 上随机的 x ∈ ℝ^{w[G]}：w[x] 是中间世界（M2a′），并且 w[x] ≼ w[G]；
   - 由强迫定理，w[x] ⊨ φ(x, a) ⟺ x ∈ b；由 M4，w[G] ⊨ φ(x, a) ⟺ w[x] ⊨ φ(x, a)。
3. **在 w[G] 中得到零测**。所以在 w[G] 中，A 与 b 的对称差含在"非随机的实数"之中，是零测集。
4. **带回 w**。"A △ b 零测"是以 a、b 为参数的投影陈述，由 M4 在 w 中成立。∎

Baire 性质的证明相同：用 Cohen 实数代替随机实数，用贫乏代替零测。

**推论**：
- `79` 定理 2 与 `55 §3.7` 中的"待核验出处"解除，在 B + M2a′ 中成为定理：由实数可定义的记录，对局部点集的测度全有或全无。
- 这是"生成绝对性推出正则性"的标准论证；在这里，它是底座的一个定理。

## 2. 吸收：在自然的解释中，世界总能在更高处汇合

**设定**：
- **丰富的解释**：外层宇宙中，一切由步骤可达的可数传递模型都是世界。
- 设 w 有一个高度扩张 N，N 中有一个大于 o(w) 的 Woodin 基数 δ，并且 N 在外层中可迭代。

**定理 2**（吸收）：在上述条件下，对 w 中任何偏序 P、Q，以及 w 上的任何泛型 G、H，世界 w[G] 与 w[H] 有共同的扩张。它的高度大于 o(w)。

*证明*：
1. **泛型迭代**（Woodin）。
   - G、H 是可数的，由实数编码；设 z 编码 (G, H)。
   - 对 N 作泛型迭代，只用临界点大于 o(w) 的扩张子，得到迭代像 N*。于是 V_{o(w)}^{N*} = w，并且 z 在 N* 上对扩张子代数泛型。
2. **共同的扩张**。取 N*[K] ∋ z，于是 G, H ∈ N*[K]。
3. **从 w[G] 到 N*[K]**。
   - P ∈ V_{o(w)}，P 的稠密子集都在 w 中，所以 G 在 N* 上也泛型。
   - w[G] = V_{o(w)}^{N*[G]}，所以 w[G] ≼ N*[G]，这是一个高度步骤。
   - N*[G] 是 N* 与 N*[K] 之间的中间模型，所以 N*[G] ≼ N*[K]，这是一个宽度步骤。
4. 对 H 同理。∎

**读法**：
- 在自然的解释中，世界层次上"粘不起来"只是**同高**的现象：
  - Mostowski 型的一对不能同高汇合（`71`）；
  - 但在大基数之下，在迭代像的高度上总能汇合。
- 汇合高度（`71`）于是有了上界（迭代像的高度），以及下界（联合 Church–Kleene 序数）。
- 与 `74` 合起来：
  - **作为公理系统**，B 不判定汇合；有稀疏的模型，其中有永不共存的集合。
  - **在自然的、带 Woodin 基数的解释中**，有共同基底的世界总能在更高处汇合。由 `86`，这时在每个连通的部分内，全局的集合就是一个 T₀ 宇宙。
- 所以 `58`、`59` 的判断——B 残留的汇合是"隐含的现实主义"，其极限是 T₀——在自然的解释中直接成立。B 的"不假定汇合"是公理层面的开放，不是对自然模型的否认。

## 3. 命运窗口的内部

- 由定理 1，内部的值不能来自任何由实数可定义的记录（投影的强迫成员集是可测的）。
- 若把 M4 加强为 L(ℝ) 的生成绝对性（M4⁺），同一论证给出：每个世界中 L(ℝ) 的一切实数集都可测。那时内部的值只能来自以 L(ℝ) 之外的参数（真正依赖选择的对象）定义的记录。
- 这是否能实现，仍然开放。它的形状现在很清楚：
  - 需要一个依赖选择的、不可定义的参数；
  - 需要在 ℝ^w 存活的同时，决定一个饱和的不可测集（`89` 定理 1）。

## 4. 集合论问题的状态

| 问题 | 状态 |
|---|---|
| M4 ⟹ 投影可测、有 Baire 性质 | 已证（B + M2a′，定理 1） |
| 丰富解释中的吸收 | 已证：在有 Woodin 基数的高度扩张的条件下，在更高处汇合（定理 2） |
| 汇合高度 | 下界：联合 Church–Kleene 序数（`71`）；上界：迭代像的高度（定理 2）；精确值开放 |
| 命运窗口的内部 | 开放；只能来自依赖选择的参数（§3） |
