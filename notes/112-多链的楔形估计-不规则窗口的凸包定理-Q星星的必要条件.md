## 0. 路线检查

- **原则在推动的**：
  - 刚性只在乎约束最紧的检查点（`111`）；
  - 进入条件可以向后继承（`110 §3`）；
  - 两个坐标过程的独立性（`109` 引理 3）。
- **会拉着走的**：锥中随机游走（Denisov–Wachtel）的调和函数方法；Galvin–Prikry 定理。只作工具。
- **结论先说**：
  1. **多链的尺度相当情形**（§1）：安全盒 + 边的一维估计 + 60°/120° 楔形的调和函数估计，给出进入引理，从而给出刚性（定理 1）。
     - 楔形估计的"只在检查点杀死"的形式沿用 `97` 引理 3 的下探—回升论证，写了关键步骤。
  2. **不规则窗口**（§2）：
     - **凸包定理**（定理 2）推广了下包络定理：凡是与自己的下凸包"经常接触"的窗口都刚性，包络不必是凹的；
     - 数值上，连剩下的情形（连续随机的窗口、振荡而很少接触凸包的窗口）也都刚性。
  3. **Q\*\***（§3）：用 Galvin–Prikry 与 Kakutani 定理，得到 Q\*\* 不成立的一个必要条件（引理 3a、命题 3）：存在一个 Borel 集，它的截面一边 Ramsey-余贫乏，另一边对整个 Kakutani 类零测。最自然的候选（奇偶性型）由此被排除。

## 1. 多链：尺度相当时的进入引理

**设定**：三条链的路 1 – 2 – 3，差 D¹ = x₁ − x₂、D² = x₂ − x₃。在一个块上，两条边都是缓变的（`97` 的假设 SV），窗口 W¹、W² 同阶（≍ W），块长 ΘW²。

### 1.1 安全盒

在块上令 W^i_min 为第 i 条边窗口的最小值。则
> R := [1, W¹_min] × [1, W²_min]

在一切检查点处都被允许：每条边的约束只涉及自己的坐标。

- 取 S = V = [W¹_min/4, W¹_min/2] × [W²_min/4, W²_min/2]。
- 三段夹逼（`97` 引理 6）对任何非负矩阵成立。
- **中段**（`97` 引理 10 的二维形式）：沿直线的管留在 R 中。二维的局部极限定理给出点概率 ≍ W^{−2}（上界对一切点对，下界对 S × V）。

所以只剩进入与离开。

### 1.2 边与角

- (D¹, D²) 的增量协方差：Var = ⅔、⅔，相关 −½。白化之后，窗口矩形变成平行四边形：
  - (低, 低) 与 (高, 高) 两个角是 60°；
  - (低, 高) 与 (高, 低) 两个角是 120°。
- **边**：远离角时，只有一个面起作用。游走在这个面的法向上的分量是一维的零均值游走，只在检查点受约束，`97` 引理 2–3 与构造性的下界原样适用：
  > 存活 ≍ (δ + √g)/√T，δ 是到面的距离。
- **角**：设角的开口为 α，p = π/α（60° 时 p = 3，120° 时 p = 3/2）。在以角为原点的极坐标（白化后）中，令
  > h(x) = r^p sin(pθ)，0 ≤ θ ≤ α，

  它在锥中调和，在两边为零。

**引理 W**（锥中的逃逸与存活）：设 x 在角 α 的锥中，|x| = r，到最近的边的距离为δ，步长的尺度为 √g（检查点间隔的扩散）。令 ĥ(x) := (r + √g)^{p−1} (δ + √g)。则对 R ≍ W、T ≍ ΘW²：
1. **逃逸的下界**：P_x(在离开锥之前到达 |y| = R/2 的弧，并且此后……) ≥ c ĥ(x)/R^p；
2. **存活的上界**：P_x(在一切检查点处都在锥中，直到时间 T) ≤ C ĥ(x)/R^p。

*证明（关键步骤）*：
1. **下界**：从 x 出发，在检查点处只要求在锥中。
   - 先用常数概率在一个间隔内把距离抬到 δ ≍ √g 的量级（同 `97` 引理 8(a) 的第 1 步）。
   - 然后对连续监视的游走，用可选停止：h(X) 是鞅，外加 O(1) 的误差，因为 h 的三阶导数在 r ≳ √g 时 ≲ r^{p−3}。
   - 在弧上 h ≤ R^p；在两边越界时 h ≥ −C (√g) r^{p−1}（越界量是 O(√g)）。于是到达弧的概率 ≥ (h(x) − 误差)/R^p ≍ ĥ(x)/R^p。
   - 最后一步用 sin(pθ) ≍ δ/r（在边附近）。
2. **上界**：分两步。
   - **连续监视的上界**：同 `97` 引理 2（一维的可选停止），把 h 当作 Lyapunov 函数：
     > P(在锥与球 B_R 中停留 T 时间) ≤ E[出界时间]/T，
     
     而出界时间的期望可以用 |X|² 的鞅控制。于是 P ≤ C h(x)/R^p + C′ ĥ(x)/R^p。
   - **只在检查点监视**：沿用 `97` 引理 3 的下探—回升论证。游走在检查点之间越出锥到深度 A√g 之后，必须在一个间隔内回来，概率 ≤ C/A²；回来之后的起点离锥边 O(√g)。
     - 由 S(t) 的递推得到常数界；二维中唯一的不同是"回来的位置"可能在角附近，而那里 ĥ 的因子 (r + √g)^{p−1} 仍然有界于 ĥ 在 √g 尺度上的值。∎
- **移动的边**：上边随时间增长。在涉及上边的角附近，用 `97` 引理 7 的倾斜，取二维的倾斜向量，使平均漂移与角的移动一致（下边固定时只沿一个坐标方向漂移）。代价仍是有界的因子。

**引理 E₂**（二维进入）：对一切起点 x，P_x(存活，末端 ∈ S) ≥ ε P_x(存活)。

*证明*：
- **上界**：由引理 W 与边的一维估计，P_x(存活) ≤ C ĥ(x)/W^{p(x)}。其中 ĥ 与 p 由 x 所在的区域决定：内部、靠近一条边、靠近一个角。
- **下界**：
  - 先逃逸到离一切边都 ≥ W/8 的区域，概率 ≥ c ĥ(x)/W^{p(x)}（引理 W 的第 1 条，或边的一维构造）；
  - 再沿安全盒中的管走到 S，概率 ≥ c(Θ)。
- 比值 ≥ c(Θ)/C。∎

**定理 1**（多链尺度相当时的刚性）：设三条链的路状同步中，两条边在无穷多个块上都满足缓变假设 SV，窗口同阶。则刚性。
- 对 m 条链的路或树，平行多面体的每个角是一个锥，它的主特征函数在球面截口上给出指数 p；同样的论证适用。

*证明*：由引理 E₂ 及其倒转、中段估计与三段夹逼，得到有界的直径。由 `78` 推论得到刚性。∎

### 1.3 数值（`experiments/multichain_blocks.py`）

**设定**：
- X-时间中每步以 ⅓ 推进一条链，(D¹, D²) 的增量为 (1,0)、(−1,1)、(0,−1)。
- D¹ + 2D² (mod 3) 每步加 1，所以游走活在一个陪集上；起点取同一陪集。
- 第 k 个检查点的间隔为 k 步，要求 (D¹, D²) ∈ [1, W¹_k] × [1, W²_k]。
- 表中是块核 M_{K→L} 的 Hilbert 射影直径（完整的 Hilbert 度量；二维中没有全正性，不能只看角点）。

| 窗口 | K | L = K+5 | 2K | 3K | 4K |
|---|---|---|---|---|---|
| W¹ = W² = k | 8 | 4.51 | 1.70 | 0.25 | 0.058 |
| 同上 | 14 | 10.83 | 1.37 | 0.17 | 0.035 |
| W¹ = k，W² = k/2 | 8 | 1.40 | 0.44 | 0.046 | 0.008 |
| 同上 | 14 | 4.25 | 0.39 | 0.033 | 0.005 |

**读法**：
- 块长 ≍ W²（K → 2K）时，直径有界，并且不随 K 增大。这正是定理 1 的证明所给出的形式（有界直径的块）。
- 60° 与 120° 的角没有造成额外的畸变。

**如实的分级**：
- 引理 W 的连续监视部分是标准的（锥中调和函数的可选停止）。
- 只在检查点监视的部分，以及移动的边上的二维倾斜，只写了关键步骤。

## 2. 不规则窗口：凸包定理

### 2.1 凸包

对任何窗口序列，在一个块上取点列 (P_ℓ, W_ℓ) 的**下凸包** ĥ。它满足：
- 是分段线性的凸函数，斜率单调递增；
- ĥ ≤ W 处处成立，并在凸包的顶点处相等。

**定理 2**（凸包定理，缓变情形）：设在无穷多个块上：
1. W_ℓ ≤ ΓW，并且 W_ℓ ≥ W（W 为块上的最小窗口）；
2. 下凸包 ĥ 的斜率的绝对值 ≤ C₀/W；
3. **接触集** 𝒜 = { ℓ : W_ℓ ≤ ĥ(P_ℓ) + C₀√W } 中相邻检查点的间隔 ≤ GW。

则堆刚性。

*证明*：同 `111` 定理 1，只有两处不同。
- **倾斜**：沿 ĥ 做分段倾斜，参数只在凸包的顶点处改变。斜率单调，所以 `97` 引理 7 的总变差界成立。
- **倒转时的管**：在倾斜的共动坐标中构造。这样不再需要包络的凹性（`97` 引理 9 用凹性只是为了在不倾斜的测度中比较一条直线与上界）。
- 其余：上界只用接触集的约束，下界用凸包（它 ≤ 一切窗口）。∎

**读法**：
- 下凸包对任何序列都存在，所以定理 2 唯一的条件是：**窗口与自己的下凸包接触得足够频繁**（间隔 ≤ GW）。
- 这推广了 `111` 定理 1：那里要求包络是凹的正则函数。

### 2.2 剩下的情形

窗口在下凸包之上以 √W 到 W 之间的幅度波动，并且很少接触凸包。例如：
- 每个窗口在 [k, 3k] 中连续均匀随机：接触的频率约为 √W/W，间隔约为 √W 个检查点，远大于 G；
- 以 W/4 的幅度振荡、偶尔接触的窗口。

**困难的精确位置**：
- 从凸包附近出发的存活概率，由此后"接近接触"的约束的整个剖面决定。
- 上界与下界的量级（边界层的 √g 与稀疏接触时的 √τ_c）之间，存在一个由剖面决定的中间尺度。
- **有效边界层的尺度**（启发式，以 k·U_k 为例）：
  - 连续 j 个检查点中，窗口高出凸包的最小值约为 W/j。
  - 离顶部距离 x 的游走，在它扩散 x 所需的 x²/W 个检查点内，遇到的最紧约束约高出凸包 W²/x²。
  - 这个约束起作用，当且仅当 W²/x² ≲ x，即 x ≳ W^{2/3}。
  - 所以有效边界层是 W^{2/3}，而不是 √W。
  - 预测：从顶部附近出发，存活 ≍ (δ ∨ W^{2/3})/W。上下界若都能在这个尺度上写出，进入引理就与正则情形一样成立。
  - 缺的一步是一个"一个时间单位内的 Harnack 型"估计：在存活的路径中，至少有一个固定的比例在 W² 量级的时间内离开顶部的层。
- Holley 的两个方向在这里互相抵消：
  - 上约束（Y = ĥ − D ≥ −e）把路径推向内部；
  - 下约束把路径推向顶部；
  - 两个单边的条件化都不能控制内部的质量。

## 3. Q\*\*：Ramsey-余贫乏与 Kakutani 类

记号同 `111 §7.1`：
- H = ∏_n B_n，B_n 是 r 的位置中互不相交的有限块，并设 Σ_n 1/|B_n| < ∞；
- ψ(m′, g) = μ{ r′ ∈ P(m′) : r′∘g ∈ N_{Φ(m′, r′)} }，Z = { (m′, g) : ψ(m′, g) > 0 }。

**Kakutani 类**：令 𝒦 为 H 上的乘积测度 ν = ⊗ν_n 的全体，满足 Σ_n Σ_{b ∈ B_n} ν_n(b)² < ∞。均匀测度 λ ∈ 𝒦。

**引理 3a**（ψ 形式的截面是 𝒦-零测的）：对一切 m′ 与一切 ν ∈ 𝒦，ν(Z^{m′}) = 0。

*证明*：
1. 固定 r′，令 p_n(r′) = ν_n{ b : r′(b) = 1 }。在 g ~ ν 之下，r′∘g 的分布是 ⊗ Bernoulli(p_n(r′))。
2. 对均匀的 r′，E[p_n] = ½，并且 E[(p_n − ½)²] = ¼ Σ_b ν_n(b)²。所以 Σ_n (p_n − ½)² < ∞ 几乎必然成立。由 Kakutani，r′∘g 的分布等价于 λ。
3. 于是对几乎一切 r′，P_{g~ν}(r′∘g ∈ N_{Φ(m′, r′)}) = 0。由 Fubini，∫ ψ(m′, g) dν(g) = 0，即 ν(Z^{m′}) = 0。
   - 若 P(m′) 不是均匀测度而是与之等价的测度，结论不变。∎

**命题 3**（Q\*\* 的一个必要条件）：若 Q\*\* 不成立（ℝ^{v[r]} 在 v[m][r] 中零测），则存在 Mathias 条件 p₀ 与 v 中的 Borel 集 Z ⊆ [ω]^ω × H，满足：
1. 对一切 m′，截面 Z^{m′} 是 𝒦-零测的；
2. 对一切 g ∈ H，截面 Z_g = { m′ : (m′, g) ∈ Z } 在 p₀ 之下是 Ramsey-余贫乏的：每个 (t, B) ≤ p₀ 都有 B′ ⊆ B，使 [t, B′] ⊆ Z_g。

*证明*：
- 取 `111 §7.1` 的 Z。第 1 条就是引理 3a。
- Q\*\* 不成立时，对一切地面的 g，有 m ∈ Z_g。
  - 理由：r 在 v[m] 上随机，而 { r′ : r′∘g ∈ N_{Φ(m, r′)} } 编码在 v[m] 中并含有 r，所以它的测度 > 0。
- 取一个迫使"对一切地面的 g，m ∈ Z_g"的条件 p₀。由 Galvin–Prikry（Borel 集完全 Ramsey），p₀ ⊩ m ∈ Z_g 等价于 Z_g 在 p₀ 之下 Ramsey-余贫乏。
- 这是 v 中关于 g 的一个 Π¹₂ 陈述；它对一切 g ∈ H ∩ v 成立。在 v 中"对一切 g"就是全称陈述本身，所以对一切 g ∈ H 成立（Shoenfield）。∎

**奇偶性型的集合被排除**：令 Y_par = { (m′, g) : g(m′_i) 的奇偶性对大的 i 为常数 }。
- 它的 g-截面在任何条件下都 Ramsey-余贫乏（一维的 Ramsey），它的 m′-截面 λ-零测。
- 但它的 m′-截面不是 𝒦-零测的。取 ν_n 为 B_n 中偶数元素上的均匀测度（n ∈ m′），其余 n 取 B_n 上的均匀测度。则 ν ∈ 𝒦（因为 Σ 2/|B_n| < ∞），并且 ν(Y_par^{m′}) = 1。
- 所以 Y_par 不满足命题 3 的第 1 条。

> **更正（`113 §3.1`）**：下面的构造只给出**一个** ν 使 H^v 为 ν-零测，而命题 3 需要对一切 ν ∈ 𝒦。所以"地面参数在 v[m] 中是 𝒦-零测的"这一句撤回。正确的状态见 `113` 定理 4 与命题 5。

**这不是一个容易的矛盾**（已更正，见上）：第 1 条中的 𝒦-零测是在每个固定的 m′ 处；在 v[m] 中，地面的 H ∩ v 本身就是 𝒦-零测的。
- 构造：交替地取 C_{m_{2i}} = B 中的偶数、C_{m_{2i+1}} = B 中的奇数，其余的 C_n = ∅；令 ν_n 为 B_n ∖ C_n 上的均匀测度。
- 每个地面的 g 的奇偶性沿 m 最终为常数，所以 g(n) ∈ C_n 对无穷多个 n 成立，而这个集合是 ν-零测的。
- 所以"对 Mathias 的 m 覆盖一切地面参数"与"每个截面 𝒦-零测"不直接矛盾。

**所以 Q\*\* 的剩余问题是**：满足命题 3 的第 1、2 条的 Borel 集是否存在（并且具有 ψ 的形式）。
- 直观上，预言 r′ 在 g(n) 处的比特，需要知道 g(n) 本身（不只是它的奇偶性之类的有限信息）；
- 而 Mathias 实数沿 m 只能把地面函数压缩到"有限多个值之一"（Ramsey）。
- 若能证明满足命题 3 的第 1、2 条的 Borel 集不存在（即：对每个 g 都 Ramsey-余贫乏的集合，必有一个截面不是 𝒦-零测的），Q\*\* 就成立。

## 4. 汇总

| 缺口 | 这一轮 | 剩下的 |
|---|---|---|
