## 0. 路线检查

- **原则在推动的**：
  - 刚性只需要无穷多个直径有界的块（`78`、`109` 定理 6）；
  - 一维的块核是全正的，直径由四个角点给出（`98`、`Sandwich.lean`）；
  - 检查点只是对一个独立增量过程的采样（`97`）。
- **会拉着走的**：
  - 锥中随机游走的方法（Denisov–Wachtel）；
  - Mathias 强迫的两步分解 P(ω)/fin ∗ M_U。
  - 都只作工具。
- **结论先说**：
  1. **随机窗口**（§1）：对独立同分布的随机窗口，把刚性化为一个**确定性的软墙问题**（定理 1）。
     - 这包括"很少接触下凸包"的情形（`112 §2.2` 的连续均匀例子）。
     - 化约用到四个工具：角点公式、Markov 不等式、Paley–Zygmund 不等式、共享环境的几何平均不等式（引理 M）。
     - 软墙的边界层是 W^{2/3}（Airy 标度）。数值与这个预测的量级一致。
  2. **多链**（§2）：检查点处的采样链本身就是一个锥中的离散时间游走，它的步长协方差都是同一个 Σ 的标量倍。白化之后每一步都各向同性，所以锥的调和函数对每一步都只差三阶误差。
     - `112` 引理 W 的"只在检查点监视"的问题因此消失，剩下的是把 Denisov–Wachtel 的一致估计推广到"独立、不同分布、各向同性"的步长。
     - 边是开口 π 的角（p = 1），所以边与角用同一个引理。
  3. **Q\*\***（§3）：
     - 更正 `112 §3` 的一处论证；
     - **Q\*\* ⟺ 在随机扩张 V′[r] 中，Mathias–Prikry 强迫 M_F 保持地面实数的外测度**，其中 F 是由 V′ 的 Ramsey 超滤子生成的滤子（定理 3）；
     - 一个**不含随机实数**的充分条件：若 v[m] 中有 𝒦 中的测度使地面参数的外测度为正，则 Q\*\* 成立（定理 4）；
     - 由有界元组构造的测度都不满足这个条件（命题 5），但它们能躲过一切有限染色。

## 1. 随机窗口：化为软墙

### 1.1 设定

- W_j = ⌊ω_j U_j⌋。其中：
  - ω_j 是正则的包络（满足 `97` 的缓变假设 SV，例如 ω_j = j）；
  - U_j 独立同分布，取值于 [1, Γ]，分布任意。
- 检查点链同 `97`：D_{j+1} = D_j + W_{j+1} − NB(W_{j+1}, ½)，在 [1, W_{j+1}] 之外杀死。
- 块取为 [K, 2K]。

### 1.2 退火核是软墙核

令 F_j(h) := P(ω_j U_j < h)。对固定的路径，窗口独立，所以
> E_U[ ∏_j 1{D_j ≤ W_j} ] = ∏_j (1 − F_j(D_j))。

于是**退火核** M̄ := E_U[M] 是一个确定性的、带"软杀死"的核：
- 在 ω_j 之下不杀死；
- 在 ω_j 之上以概率 F_j(h) 杀死；
- 在 Γω_j 之上必然杀死。

M̄ 是全正的，因为它是全正的转移核与对角的正乘子之积。

**软墙的标度**（以 U 在 1 附近有正的密度为例）：
- 在包络之上高度 h 处，F_j ≈ c·h/W。
- 扩散穿过距离 ℓ 需要 ℓ²/W 个检查点，其间的杀死总量约为 (ℓ²/W)(ℓ/W)。
- 令它为 1，得 ℓ ≍ W^{2/3}。
- 更一般地，F(h) ≍ (h/W)^{β+1} 时，ℓ ≍ W^{(β+2)/(β+3)}。它总是 ≪ W。
- F 在 1 处有原子时，就是硬墙，ℓ ≍ √W。

**引理 A**（软墙的块直径）：对上述退火核，Δ(M̄_{K→2K}) ≤ C，常数只依赖于 SV 的常数、Γ 与 F 的形状（对 F 乘以 [¼, 1] 中的常数一致）。

*证明（关键步骤，逐条替换 `97` 的证明）*：
1. **下界**（构造）：
   - 包络之下 F = 0，管的构造与硬墙相同；
   - 从包络之上 ≤ ℓ 的高度出发，在 ℓ²/W 个检查点内以常数概率下到深度 ℓ（这期间的杀死总量有界）；
   - 所以存活 ≥ c(δ + ℓ)/W，其中 δ 是到包络的深度。
2. **上界**（下探—回升，`97` 引理 3 的软墙形式）：
   - 路径位于包络之上 Aℓ 时，在接下来的 ℓ²/W 个检查点中被杀死的概率 ≥ 1 − e^{−cA}；
   - 这个"每次越界付出常数因子"的性质，正是 `97` 引理 3 的递推所需要的。所以存活 ≤ C(δ + ℓ)/W。
3. **倾斜**（`97` 引理 7）：包络 ω 是正则的，所以不变。
4. **中段与离开**：同 `97`。
5. **对系数一致**：F 换成 κF（κ ∈ [¼, 1]）只把 ℓ 乘以 κ^{−1/3}，并把块上的指数改变 O(Θℓ/W) = o(1)。∎

### 1.3 从退火到淬火

**引理 M**（共享环境）：对同一个环境中的 n 条路径 D¹, …, Dⁿ，
> E_U[ ∏_a ∏_j 1{D^a_j ≤ W_j} ] = ∏_j (1 − F_j(max_a D^a_j)) ≤ ∏_a ∏_j (1 − F_j(D^a_j))^{1/n}。

*证明*：1 − F_j(max) ≤ min_a (1 − F_j(D^a_j))，而后者 ≤ 几何平均。∎

于是 E_U[M(x, y)ⁿ] ≤ M̄^{(1/n)}(x, y)ⁿ，其中 M̄^{(1/n)} 是以 1 − (1 − F)^{1/n}（≍ F/n）为杀死概率的软墙核。由引理 A 的一致性，它与 M̄(x, y) 同阶，只差常数。

**定理 1**（随机窗口的刚性）：在 §1.1 的设定下，若引理 A 成立，则堆几乎必然刚性。

*证明*：
1. **四个角**：一维的块核是全正的，所以 Δ(M) = log[ M(t,t) M(b,b) / (M(t,b) M(b,t)) ]（`98`，`Sandwich.lean` 的 `lcr_le_corners`）。
   - t、b 是两端窗口的顶与底。先条件于两端的 U_K、U_{2K}，下面的期望只对块内部的 U 取。
2. **分子**：由 Markov 不等式，P(M(t,t) > C·M̄(t,t)) ≤ 1/C，对 M(b,b) 同样。
3. **分母**：令 X = M(t,b)·M(b,t)。
   - 两个因子都是窗口的增函数，由 Harris–FKG 不等式，E X ≥ M̄(t,b) M̄(b,t)。
   - 由 Cauchy–Schwarz 与引理 M（n = 4），E X² ≤ C (M̄(t,b) M̄(b,t))²。
   - 由 Paley–Zygmund 不等式，P(X ≥ ½ E X) ≥ q > 0，q 与 K 无关。
4. **合起来**：取 C 使 2/C < q/2。则以概率 ≥ q/2，Δ(M_{K→2K}) ≤ Δ-四角(M̄) + log(2C²) ≤ C′（引理 A）。
5. **Borel–Cantelli**：不相交的块 [K_i, 2K_i] 只依赖于各自的 U，因而独立。由 Borel–Cantelli 的第二引理，几乎必然有无穷多个好块。由 `109` 定理 6，刚性。∎

**读法**：
- 对随机窗口，"很少接触下凸包"不是障碍。随机性把硬墙抹成了软墙，而软墙仍然有一个 ≪ W 的边界层。
- 只需要"以正概率好"的块，不需要每个块都好。
- 这也给 `111` 推论 2（Bernoulli 跳动）一个更干净的证明：那时 F 有原子，是硬墙。

### 1.4 数值：顶部的相对存活

**设定**：`experiments/boundary_layer.py` 向后计算存活函数 s_K(x) = P_x(存活到 2K)，起点 K 取为接触点。表中是 s_K(W_K)/max s_K。

| K | 正则 W = k | k·U[1,3]（稀疏接触） | k·(1 + 2B)（稠密接触） |
|---|---|---|---|
| 25 | 0.53 | 0.96 | 0.58 |
| 50 | 0.41 | 0.84 | 0.66 |
| 100 | 0.32 | 0.83 | 0.51 |
| 200 | 0.23 | 0.71 | 0.25 |
| 400 | 0.17 | 0.72 | 0.25 |

**与 Airy 标度的比较**：
- 软墙方程 (σ²/2) s″ = F·s 中，σ² = 2W，F = h/(2W)，所以 ℓ = (2W²)^{1/3}。
- 包络之下的线性延长，在包络之上 1.37ℓ 处为零（Ai(0)/|Ai′(0)| ≈ 1.37）。
- 于是预测顶部的比值 ≈ sin(π·1.37ℓ/(W + 1.37ℓ))：
  - K = 100 时约为 0.75（实测 0.83）；
  - K = 400 时约为 0.56（实测 0.72）。
- 量级与趋势一致。残差来自包络的漂移和离散性。
- 正则的一列按 W^{−1/2} 的方向下降；稀疏接触的一列下降得慢得多，符合 W^{−1/3} 的软墙预测。

**仍然开放**：确定性的、很少接触凸包的窗口（例如 k(1 + ½|sin k^{0.7}|)）。这里没有可以取期望的随机性，数值上也刚性（`112 §2.3`）。

## 2. 多链：采样链是锥中的游走

**观察 1**（采样）：
- 在检查点处采样，(D¹, D²) 是一个离散时间的游走 Y_k。
- 它的第 k 步是 g_k 个独立同分布单步之和，g_k 是检查点间隔。
- "只在检查点杀死"就是"Y 离开平行四边形时杀死"，对 Y 自己的时间是连续监视的。
- 所以 `112` 引理 W 的第 2 步（下探—回升）不需要；需要的是锥中离散游走的一致估计。

**观察 2**（白化后各向同性）：
- 第 k 步的协方差是 g_k Σ，Σ 固定。白化（乘以 Σ^{−1/2}）之后，协方差是 g_k I。
- 所以对锥的调和函数 h = r^p sin(pθ)：
  > E h(y + ξ_k) − h(y) = (g_k/2) Δh(y) + O(E|ξ_k|³ · |D³h|) = O(g^{3/2} |y|^{p−3})（|y| ≥ A√g）。
- 这与步长是否同分布无关。缓变假设保证 g_k ∈ [g/2, 2g]；单步有指数矩，所以一切矩一致有界。

**观察 3**（边是开口 π 的角）：
- 远离角时，边附近是半平面，p = 1，h 就是到边的距离。
- 所以"边的一维估计"与"角的估计"是同一个引理的两个实例。

**观察 4**（角的局部倾斜）：
- 在一个角附近，只看半径 ηW、时间 ηW² 的局部。
- 取倾斜向量 u，使这个角的两条边在共动坐标中都静止：
  - 两边都在移动时，取角的速度；
  - 一边固定时，取沿固定边的方向。
- 边的速度 ≍ 1/W，所以似然比的对数是 O(|u|·ηW + ηW²|u|²) = O(1)。

**引理 W′**（锥中的一致估计）：设 Y 的步长独立，白化后协方差为 g_k I（g_k ∈ [g/2, 2g]），三阶矩一致有界。对开口 α ≤ π 的锥 C，令 p = π/α，τ 为离开 C 的时刻，σ_R 为到达 |y| = R 的时刻，V(x) := (|x| + √g)^{p−1} (d(x) + √g)，其中 d 是到边界的距离。对 R ≤ ηW，有：
1. P_x(σ_R < τ) ≍ V(x)/R^p；
2. E_x[ sin(pθ(Y_{σ_R})) ; σ_R < τ ] ≍ V(x)/R^p，并且以 ≥ c V(x)/R^p 的概率在 θ ∈ [α/4, 3α/4] 处到达；
3. P_x(τ ∧ σ_R > t) ≤ C (R²/t) V(x)/R^p。

*证明的来源*：
- 对独立同分布的步长，这是 Denisov–Wachtel（2015）的一致估计。
- 它们的证明用两样东西：
  - h(Y) 的鞅修正，由观察 2 对各向同性的不同分布步长照样成立；
  - 与布朗运动的强耦合。Sakhanenko 的耦合对独立而不同分布的和成立。
- 所以推广是直接的，但这里没有逐行重写。∎

**由引理 W′ 得进入引理 E₂**（`112 §1.2`）：
- **上界**：从 x 出发的存活 ≤ Σ（在角的球面上到达的位置的分布）× 此后的存活。
  - 由第 2 条，到达位置的 sin(pθ) 的平均 ≍ V(x)/R^p；
  - 此后离边为 d 的点，存活 ≤ C(d + √g)/W（p = 1 的实例）；
  - 第 3 条控制在球内滞留的部分。
- **下界**：第 2 条给出以 ≍ V(x)/R^p 的概率在中间的角度到达，此后走管进入 S。
- 两者同阶，所以比值 ≥ ε。

**分级**：
- 进入引理的结构与每一步的来源都已确定。
- 唯一没有逐行写出的是：Denisov–Wachtel 一致估计对"独立、不同分布、白化后各向同性"的步长的推广。
- 数值（`112 §1.3`）支持结论。

## 3. Q\*\*

### 3.1 更正

`112 §3` 说"地面参数在 v[m] 中本身是 𝒦-零测的"，并用交替奇偶的构造来证明。这个构造只给出**一个** ν ∈ 𝒦 使 H^v 为 ν-零测。

而命题 3 需要的是**对一切** ν ∈ 𝒦 零测。原论证不成立，这一句撤回。正确的状态见定理 4 与命题 5。

### 3.2 化为 Mathias–Prikry 强迫

**定理 3**：令 U 为 v 上 P(ω)/fin 的泛型超滤子，V′ = v[U]。则 v[m][r] = V′[r][m]，其中：
- m 是 M_F 在 V′[r] 上的泛型；
- M_F 是 Mathias–Prikry 强迫，F 是 U 在 V′[r] 中生成的滤子。

因此：
> **Q\*\* ⟺ 在 V′[r] 中，M_F 保持 ℝ^{V′[r]} = ℝ^{v[r]} 的外测度为正。**

*证明*：
1. Mathias 强迫等价于 P(ω)/fin ∗ M_U（已知），U 是 Ramsey 超滤子。
   - P(ω)/fin 是 σ-闭的，所以 V′ 与 v 的实数相同。
   - U = { A ∈ v : m ⊆* A } ∈ v[m]，所以 V′[m] = v[m]。
2. r 在 V′[m] 上随机，所以 r 对 B^{V′} 在 V′[m] 上泛型：
   - V′[m] 中 B^{V′} 的极大反链之并是余零测的；
   - 它的补集是编码在 V′[m] 中的零测集，r 避开它。
   - 由乘积引理，(m, r) 是 M_U × B^{V′} 在 V′ 上的泛型。所以 m 是 M_U 在 V′[r] 上的泛型。
3. 在 V′[r] 中，{ (s, A) : A ∈ U } 在 M_F 中稠密，所以 m 也是 M_F 的泛型。
4. V′[r] 的实数是 f(r)，其中 f 是编码在 V′ 中的 Borel 函数，而 V′ 的编码都在 v 中。所以 ℝ^{V′[r]} = ℝ^{v[r]}。∎

**读法**：
- Q\*\* 是关于一个具体的 Mathias–Prikry 强迫的测度保持问题。
- F 是一个 P-滤子：随机强迫满足可数链条件，所以 V′[r] 中 F 的可数多个元素，被 V′ 中 U 的可数多个元素覆盖，而 U 是 P-点。
- F 不是超滤子：r 分裂 U 的每一个元素。
- 当 F 是超滤子时，M_F 使地面实数零测（EvConst）。Q\*\* 问的是：一个 P-点生成的、被随机实数"打开"的滤子是否仍然如此。

### 3.3 一个不含随机实数的充分条件

**定理 4**：若 v[m] 中有 ν ∈ 𝒦 使 ν*(H^v) > 0，则 Q\*\* 成立。

*证明*：
- 设 Q\*\* 不成立，覆盖为 N_{Φ(m, r)}（Φ ∈ v），并令 Z^m = { g : μ{ r′ : r′∘g ∈ N_{Φ(m, r′)} } > 0 } ∈ v[m]。
- 对每个地面的 g，r 属于集合 { r′ : r′∘g ∈ N_{Φ(m, r′)} }。它编码在 v[m] 中，而 r 在 v[m] 上随机，所以它的测度为正。因此 H^v ⊆ Z^m。
- 另一方面，在 v[m] 中对 ν 与 μ 用 Fubini：
  - p_n(r′) = Σ_{b ∈ B_n} ν_n(b) r′(b) 关于 n 独立，并且 E(p_n − ½)² = ¼ Σ_b ν_n(b)²；
  - 所以几乎一切 r′ 使 Σ_n (p_n − ½)² < ∞，从而 p_n → ½。
  - 由 Kakutani，r′∘g 的分布（g ~ ν）等价于 λ，因而 ν(Z^m) = 0。
- 这与 ν*(H^v) > 0 矛盾。∎

**推广**：
- H 与 r∘g 可以换成任何地面的 Borel 族 (g, r) ↦ f_g(r)。条件是对几乎一切 r′，g ~ ν 之下 f_g(r′) 的分布绝对连续于 λ。
- 对 ν = λ 这不可能，因为地面实数在 v[m] 中 λ-零测。r∘g 的作用是允许 ν 非常奇异（集中在很小的支撑上），而推前测度仍然等价于 λ。

### 3.4 由元组构造的测度

**命题 5**：设 ν ∈ 𝒦 ∩ v[m]，对大的 i，ν_{m_i} 的支撑是
> S_i = { φ_{m_i}(e) : e ∈ E_i }，

其中 E_i 是 m 在 [i/2, i) 中的元素组成的 l 元组的集合（l 固定），φ 是地面的函数，并且对 e 单射。则：
1. 对每个地面的有限染色序列 χ，χ_{m_i} 在 S_i 上最终取同一个常值。所以"沿 m 最终为常数"型的零测集不能使 H^v 零测。
2. 但 H^v 仍然是 ν-零测的。

*证明*：
1. c(a₁, …, a_l, b) := χ_b(φ_b(a₁, …, a_l)) 是 [ω]^{l+1} 的有限染色。
   - Ramsey 超滤子 U 中有它的齐一集，m 几乎包含于这个集合，所以 m 的尾部上一切 (l+1)-元组同色。
   - i/2 最终超过尾部的起点。
2. 对地面的 g，关系 "g(b) = φ_b(a₁, …, a_l)" 也是 [ω]^{l+1} 的二染色，所以在 m 的尾部上要么全成立、要么全不成立。
   - "全成立"与 φ_b 的单射性矛盾：|E_i| ≥ 2 时，g(m_i) 只能等于一个 φ(e)。
   - 所以 g(m_i) ∉ S_i 对大的 i 成立。H^v 包含于 ν-零测集 { g : ∃^∞ i, g(m_i) ∉ S_i }。∎
- 取 l = 2、|E_i| ≍ i²，就有 Σ 1/|S_i| < ∞，所以 ν ∈ 𝒦。

**读法**：
- 要使 H^v 对 ν 不零测，ν 的支撑必须以**依赖于地面实数本身**的方式包含它们的值。
- 而 Ramsey 性质把一切"由 m 的有界元组定出"的信息压成全有或全无。
- 剩下的可能性是：ν_{m_i} 依赖于 m 的整个前段（元数无界）。这正是 Galvin–Prikry 而不是有限 Ramsey 定理管辖的范围。

**剩下的问题（Q_𝒦）**：v[m] 中是否有 ν ∈ 𝒦，使 ν*(H^v) > 0？
- 若有，则 Q\*\* 成立（定理 4）。
- 若没有，Q\*\* 仍未判定：还需要命题 3 的 Borel 集的存在性。
