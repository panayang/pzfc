## 0. 开工自检（对照 `自检清单`）

- **主目标。** 前几轮在"另一些宇宙判定 CH"（Solovay、Brouwer、有效拓扑斯）上花了不少力气。那些不是保守扩展。
  本轮把它们重新定位为**族的成员**，核心回到：一个 ZF(C) 的保守扩展。
- **纯数学。** 用到的是类理论、带原子的集合论、测度论、布尔值模型。词汇：问题、记录、原子、权重、缺陷。
- **二元论。** 两处要盯：
  - "记录 / 非记录"（集合 / 真类）在 NBG 里是截然的。它在给定公理下是被证明的二分（Russell），但也有分级版本（宇宙层级），放进族里作坐标。
  - "保守 / 非保守"是每个扩展各自的性质；族按理论之间的包含与一致性强度排成格，而不是一个开关。
- **应用层。** 把测度论放进来，是因为"回收标准测度论"是既定目标，不是因为它在别处好用。
- **自由坐标。** 值代数 W 仍是参数，没有被推出；核心里只把经典实例（隶属取布尔值、权重取 $[0,\infty]$）作为可定义的例子。
- **过度统一。** §6 用"缺陷为零"统一几种正则性。只有测度与完美集性质已核实确实是内外逼近之差为零；Baire 性质只列为候选。
- **惯性。** "问题 = 类"是一个现成的系统（NBG），要问这是不是在套现成结构。理由不是熟悉，而是 §4 的发现：
  **NBG 与 MK 的分界恰好是 P4（问题能否谈论问题）的谓词性分界，而它正好就是保守性的分界。**
  其他候选原语：布尔值模型可在核心内部定义，放进 §5；拓扑斯与同伦类型论会改变逻辑，放进族。

## 1. 目标的精确形式

- **PZF₀**（核心）：关于纯记录的语句，是 ZF 的保守扩展。
- **PZFC₀ = PZF₀ + AC**：是 ZFC 的保守扩展。
- **族**：PZF₀ 加上沿各坐标的非保守公理（§6）。ZFC 判定不了的命题，在族里被拆开，并按坐标被判定（§7）。

## 2. 语言

单一种类的个体，两个原始关系：

- $x\,\varepsilon\,q$："$x$ 对问题 $q$ 回答是"；
- $\mathrm{Q}(q)$："$q$ 是一个问题"。

派生概念：

- **记录** $\mathrm{Rec}(x) :\Leftrightarrow \exists q\ (x\,\varepsilon\,q)$：出现在某个回答里的个体。集合就是记录。
- **原子** $\mathrm{At}(a) :\Leftrightarrow \neg\mathrm{Q}(a)$。
- **纯记录**：它自己以及它遗传的所有成员都是作为问题的记录（不含原子）。

值代数、分级问题（取值于值代数的函数型问题）、权重，都是记录层面的**可定义**对象。

## 3. 公理

按原理分组，每条给出经典读法。

**P1 可辨性**
- **A1 问题外延**：两个问题若对一切个体回答相同，则相等。（NBG 的类外延）
- **A2 原子**：原子不对任何个体回答是；原子是记录；全体原子构成一个记录。（ZFA）

**P3 完成（哪些问题被完成为记录）**
- **A3 配对**：对记录 $a,b$，问题 $\{a,b\}$ 是记录。
- **A4 并**：记录之记录的并是记录。
- **A5 幂**：一个记录的全部子记录构成一个记录。
- **A6 无穷**：存在一个无穷记录。
- **A7 替换**：记录在函数型问题下的像是记录。
- **A8 分离即完成**：对任意问题 $q$ 与记录 $r$，$q\cap r$ 是记录。
- **A9 良基**：每个非空问题有 $\varepsilon$-极小的回答者。（为保守于 ZF 而保留；反基础公理 AFA 放进族，§6）

**P4 自反（谓词性）**
- **A10 谓词性提问**：对每个量词只取遍记录的公式 $\varphi$，$\{x : \mathrm{Rec}(x)\wedge\varphi(x)\}$ 是一个问题。（NBG 的谓词性概括）

**P2 缝**：不需要新公理。
- 原子两两不能被回答区分，却彼此不同（`answers_do_not_separate_atoms`；一致性由两原子模型 `twoAtoms_*` 给出）。
- 给定原子的置换群与一个正规子群滤子，**对称子宇宙**（遗传对称的记录）是可定义的。其中等变选择失败（`Invariants.no_equivariant_choice`），不变权重是均匀的（`Principles.gap`）。

**W 权重（全部可定义）**
- 由有限特征问题的基生成外权重（Carathéodory 构造）。
- **正则 ⟺ 可加性存活**：有限测度下，$A$ 零可测当且仅当权重在 $\{A,A^c\}$ 上可加，当且仅当缺陷为零（`nullMeasurable_iff_additive`、`defect_eq_zero_iff`）。
- 值代数的迫使、存在是计数的幂等影子（`Grades`、`Weights` §1–4）。

**选择**：不在 PZF₀ 中。PZFC₀ 加上对记录的 AC。

## 4. 保守性

> **定理。** PZF₀ 关于纯记录的语句是 ZF 的保守扩展；PZFC₀ 是 ZFC 的保守扩展。

*证明梗概（模型扩张 + 完备性）。* 设 $V\models\mathrm{ZF}$。
1. 在 $V$ 上以一个原子集 $A$ 递归地建出 $V(A)\models\mathrm{ZFA}$，其纯部分就是 $V$；若 $V\models\mathrm{AC}$，则 $V(A)\models\mathrm{ZFA+AC}$。
2. 用 $V(A)$ 的可定义类（允许参数）扩张它，得到满足 A1、A10 的模型；**不产生新的记录**。
   `Axioms.lean` 的扩张定理给出这一步的语义核心：任何外延的集合结构，扩张为问题宇宙后，记录恰好是原来的集合（`expand_set_record`、`expand_proper_not_record`），隶属不变（`expand_mem`），问题外延成立（`expand_ext`）。
3. 权重与值代数都是可定义的，这一部分是定义性扩张。

于是 ZF 的每个模型都扩张为 PZF₀ 的模型且纯部分不变；由完备性定理，关于纯记录，PZF₀ 证得出的 ZF 都证得出。∎

〔NBG 对 ZF(C) 的保守性：Novák 1950、Shoenfield 1954；带原子的构造：Jech《The Axiom of Choice》第 4 章。已入待核验队列。〕

**保守性的边界恰在 P4。** 若把 A10 放宽为"$\varphi$ 的量词也可取遍问题"（非谓词性概括，即 Morse–Kelley），得到的理论证明 Con(ZF)，从而**不再**保守。
所以"问题能谈论问题到什么程度"就是保守与否的分界——这不是事后贴标签，是 P4 的精确落点。

形式化里有一处需要如实说明：`Axioms.lean` 的扩张用的是**全部**谓词作问题（这是在类型论元层里二阶的构造，相当于 MK 那一侧）。
它演示的是"加入问题不产生新记录"这一核心，并不是 NBG 保守性证明本身；后者需要公式层面的可定义类，没有形式化。

## 5. 回收

**(a) ZF / ZFC**：由 §4，它们就是纯记录片段。

**(b) 标准测度论**：在可数选择（CC）之下，Carathéodory 可测的问题构成 σ-代数，外权重限制在其上可数可加——
即"有限生成的权重仍保持可加的极大问题代数"。没有 CC 时 Lebesgue 测度的可数可加性可能失效（Feferman–Lévy：$\mathbb R$ 可以是可数个可数集之并）。
所以**标准测度论在选择坐标 ≥ CC 处被回收**。

**(c) 经典存在量词**：幂等值代数下的计数（`any_iff_count_pos`）。

**(d) 集合论的概率读法，在核心之内。** 取 $B$ 为测度代数，布尔值宇宙 $V^B$ 在 ZFC 中可定义，因而在 PZFC₀ 的保守核心之内（Scott 的随机变量模型）：
- 实数是随机变量，隶属是事件，真值是概率；
- ZFC 的每条公理概率为 1；
- 由齐性，不带参数的句子概率只能是 0 或 1；带随机参数的句子取中间值。

这正是你最初要的"用概率的语言表述集合论"，而且不离开保守核心。
它与 `16 §4` 的缺陷二分结构相同：**上确界 / 无参数句子处是被证明的二分；分级活在单个对象或带参数的语句上。**

## 6. 坐标族（非保守扩展）

每个坐标是一个有序的公理族，不是开关：

| 坐标 | 族 | 与保守性的关系 |
|---|---|---|
| **C 选择** | 吸收梯子：AC ⟺ 吸收平方 ⟹ 吸收加倍 ⟹ 吸收一点 ⟺ 无穷集都 Dedekind 无穷；以及 CC、DC、BPI… | AC 对 ZF 不保守；全局选择（类良序）对 ZFC 保守（Jensen–Solovay 1965 以类力迫得到，Felgner 1971 首次发表） |
| **R 正则** $\mathrm{Reg}(W,\Gamma)$ | 点类 $\Gamma$ 中每个记录关于权重 $W$ 缺陷为零；$W\in$ {Lebesgue（可加）、基数（幂等，即完美集性质）、范畴（候选）}，$\Gamma\in$ {Σ¹₁、Δ¹₂、射影、全体} | 全体：与 AC 矛盾；Σ¹₃ 可测需不可达基数；射影需 Woodin 基数；缺陷上确界在每层只能是 0 或 1（`16 §4`） |
| **P 非谓词性** | 类概括按其公式复杂度分层，从 NBG 到 MK | NBG 保守；MK 证明 Con(ZF) |
| **F 基础** | 良基；反基础（同一 = 互模拟） | ZFC⁻ + AFA 与 ZFC 等协调；Aczel 模型的良基部分就是原模型，故对良基陈述保守（第七轮核查） |
| **S 对称** | 以对称子宇宙作为宇宙；按子群滤子分级 | 否定原子上的选择 |
| **U 完成的层级** | 记录按 Grothendieck 宇宙分层（"完成到哪一级"）——记录 / 非记录的分级版本 | 需要不可达基数 |
| **L 逻辑** | 直觉主义、Łukasiewicz 等 | 改变逻辑，不是扩展；族的另一支 |

完美集性质作为"基数权重的缺陷为零"：令 $\kappa_*(A)=\sup\{|C| : C\subseteq A \text{ 闭}\}$，$\kappa^*(A)=|A|$。
由于闭集要么可数要么含完美子集，**完美集性质 ⟺ $\kappa_*(A)=\kappa^*(A)$**：与 Lebesgue 的"内测度 = 外测度"是同一形状，只是权重在 W 轴的幂等端。

## 7. CH 在 PZF 中

核心语言里，CH 分成两条：
- **CH_C**：每个不可数的实数记录都与 $\mathbb R$ 等势——基数权重在实数记录上**饱和**；
- **CH_ℵ**：$\mathbb R$ 有序型为 $\omega_1$ 的良序——关于选择给出的标量刻度上的位置。

核心中可证（ZF 层面）：
1. AC ⟹（CH_C ⟺ CH_ℵ）；
2. CH_ℵ ⟹ $\mathbb R$ 可良序 ⟹ 存在 Bernstein 集 ⟹ ¬Reg(Lebesgue, 全体) 且 ¬Reg(基数, 全体)；
3. Reg(基数, 全体) ⟹ CH_C。

**解释。** CH_C 有两条来路：正则性（基数缺陷为零），或选择给出的标量（CH_ℵ）。
ZFC 固定了选择坐标，这就堵死了正则性那条路（对全体集合而言），却没有决定标量的值。所以 ZFC 判定不了 CH：剩下的唯一来路，是一个自由的标量取值。

族里的判定：
- Reg(基数, 全体)（加 DC，需不可达基数）：CH_C 真，CH_ℵ 假；
- ZFC + CH_ℵ：两者都真；
- ZFC + $2^{\aleph_0}=\aleph_2$：两者都假。
