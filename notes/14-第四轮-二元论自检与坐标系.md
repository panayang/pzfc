# 14 · 第四轮：二元论自检，与基础的重查

> 第三轮把几乎每个概念都写成了开关：有缝 / 无缝、有选择 / 无选择、可测 / 不可测、断言层 / 对象层、底层 / 顶层。
> 这一篇逐个找出这些开关，并指出：**纯数学里对每一个都已经有现成的分级结构**。然后用逻辑自己的词汇重写四条原理。

---

## 1. 第三轮的七个开关，与它们的分级替代

| 第三轮的开关 | 实际的分级结构（纯数学） |
|---|---|
| 缝：存在 / 闭合 | 按参数集分级：可定义闭包 dcl(A) ⊆ 代数闭包 acl(A)，差距由 Aut(M/A) 度量；可定义地看，由不可辨关系在 **Borel 可归约性**序中的位置度量（光滑 < E₀ < …） |
| 选择公理：成立 / 不成立 | **选择原理的格**：有限集选择、可数选择、依赖选择、布尔素理想、良序……（Howard–Rubin 整理了数百种及其蕴含关系） |
| 可测 / 不可测 | 内测度与外测度之间的**区间** $[\mu_*(A),\mu^*(A)]$；可测 = 区间退化为一点 |
| 可数可加 / 有限可加 | **κ-可加性**按基数分级；全域上的可数可加测度存在与否与实值可测基数相连（Banach、Ulam 1930） |
| P3 的两种读法（断言层 / 对象层） | 两条**同一刻度**上的坐标：排中律成立到算术层谱的第几层（LPO、WLPO、LLPO、MP 构成一个格；Σ⁰ₙ-排中律），正则性成立到射影层谱的第几层（Σ¹₁ 在 ZFC 中已正则；更高层需要大基数） |
| 不可驳倒层 / 可证实层（两层） | **核（nucleus）/ 拓扑斯的子拓扑斯构成的格**，¬¬ 只是其中一点 |
| 底层（对称）/ 顶层（ZFC） | 介于对称模型与带选择宇宙之间的**中间模型的格**，由子群滤子索引：可以只为某些族补入选择 |

还有一个更深的开关，第三轮完全没察觉：

| 真值：布尔 / Heyting | **值代数**本身是一个坐标。见 §3 与 `15` |

另一个值得单独记下的：第三轮把"选择与正则性的冲突"写成二择一，而实际情形是分级的定理——
**若 $\mathbb R$ 有 Σ¹ₙ 可定义的良序，则存在 Δ¹ₙ 的非正则集**（在 $L$ 中 n = 2）。
选择在哪一层可定义，就在哪一层摧毁正则性。**比较型测量与可加型测量的冲突，是沿着定义复杂度逐层发生的。**

## 2. 重查四条原理

第三轮的 P1–P4 是用"问题与回答"写的。换成逻辑自己的词汇，每条都暴露出一个隐含的开关，而每个开关背后都是一个层谱。

**P1 可辨性相对于可定义性。**
两个元素可区分，当且仅当某个可定义性质区分它们。
- 隐含开关一：**语言是固定的**——一个公式要么在语言里，要么不在。
  分级：逻辑按表达力排成一个序；Lindström 定理说一阶逻辑是满足紧致性与下行 Löwenheim–Skolem 的**极大**逻辑。
  紧致性就是有限特征（P3）。所以 **P3 选定了 P1 的语言**——两条原理不是独立的。
- 隐含开关二：**可区分 / 不可区分**。
  分级：按参数集 A 的类型 tp(a/A)；在一个固定语言里，可区分的"深度"本身是一个过滤（`15 §1`：随深度加细的等价关系链，相等是它们的极限）。

**P2 可计数不蕴含可定义。**
第三轮写的是"计数可以超过辨别"。它在纯数学里有一个经典的名字：
**acl(A) 可以严格大于 dcl(A)**——元素属于某个在 A 上可定义的有限集，却不能被单独定义。
$x^2-2$ 的两个根在 ℚ 上正是如此：知道有两个，说不出哪个是哪个，其对称就是 Galois 群。
- 隐含开关：**同一性本身是命题**（两物要么相等要么不等）。
  分级：同一性的结构层级——命题、集合、广群、高阶广群（HoTT 的截断层级）。
  集合是"每个元素的自同一没有结构"的那一层；广群是缝首次出现的那一层。
- 计数也随之分级：在有对称的地方，自然的计数是**广群基数** $\sum 1/|\mathrm{Aut}(x)|$，取有理数值。
  **分数出现在计数本身之中**，不是后加的测度。

**P3 有限特征。**
每个原子判定只依赖有限多个原子判定的结果；复杂的判定按量词交替的层数分级。
- 隐含开关：**有限 / 无限**。
  分级：算术层谱、Borel 层谱、射影层谱。第三轮证明的"全零检验不能被有限判定"只是第一层（Π⁰₁ 不是 Δ⁰₁）。
- 还有一个被漏掉的维度：**每个问题有有限多个可能回答**（有限分叉）。
  有限分叉 ⟹ 紧致 ⟹ 均匀的归一化权重存在（Cantor 空间）；无限分叉（Baire 空间、ℕ）没有均匀概率。
  所以"能否归一化"也不是开关，而是由分叉结构决定的。

**P4 自反。**
判定可以被编码为对象。
- 隐含开关：**能 / 不能谈论自身**。
  分级：真谓词的 Tarski 层级；Kripke 构造的阶段；谓词性的极限（Feferman–Schütte 序数 Γ₀）；证明论序数与反射层谱。

## 3. 坐标系（不是七个旋钮）

把以上合起来，一个基础不是一个角落，而是一个**剖面**：

- **值代数**——推导后拆成两条独立的轴（`15 §5`）：**E** 事件 / 隶属的代数（布尔 ↔ MV ↔ …），**W** 不交部分的权重如何合成（幂等 ↔ 截断 ↔ 可消）。本节初稿把二者写成了一条，已更正；
- **语言与参数**：受 P3 经 Lindström 约束；
- **同一性的结构层级与对称**：acl/dcl 的差距、截断层级、Borel 可归约性中的位置；
- **定义复杂度上的三条截断线**：排中律到哪一层、选择到哪一层、正则性到哪一层；
- **反射层级**。

ZFC 的剖面：E 与 W 都在幂等端（布尔隶属、存在量词）；一阶语言；集合层级且处处可选（dcl 与 acl 在补入选择后不再有区别）；
排中律与选择在所有层成立，正则性只到 Σ¹₁；反射到 ZFC 自身的强度。

**这不是七个开关的组合，每个坐标本身是一个序或格，而且坐标之间有分级的交换定理**（§1 末尾那条就是一例）。

## 4. 元语言

第二轮指出第一轮"改了对象没改逻辑"。现在的形式化在**不使用任何公理**的构造性类型论里完成（唯一例外 `truncated_saturates` 用了 `propext` 与 `Quot.sound`，二者在任何拓扑斯中成立）——
不假设排中律、不假设选择、不假设函数外延。所以这些结果在上面所有剖面里都成立：
**元层取在坐标系的最弱点，结论才能向任何方向迁移。** 这条今后作为纪律保留。

## 5. 词汇纪律

主线只用逻辑与数学的词：可定义性、参数、类型、自同构、闭包、层谱、复杂度、值代数、幂等、可除、紧致。
"测量"只作为你最初启发的名字出现，不作为术语。

## 6. 推导中的裂缝检查清单

推导中若出现较大的裂缝，按顺序检查：

1. 是否又被某个应用领域的"有效性"牵着走——把某个领域里好用的结构当成了必须；
2. 是否又落入二元论——把一个本应是序或格的东西写成了开关，而没有找出它的坐标轴；
3. 是否把一个自由坐标误当成了原理的推论（或反过来）。

裂缝与处理记录在 `15 §7`。
