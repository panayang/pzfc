## 2. 惯性的六个症状

**(1) 一个轴解释一切。** GLU 先被找到，于是 ML 指标、自回归、物理的循环、ZFC 全被解释成 GLU。
第二轮若换一个"更上游"的轴再做一遍，是同一个错误。所以第二轮组织成**带依赖关系的图**，不设"唯一根源"（`06`）。

**(2) 层级混淆。** 第一轮说"Kolmogorov = Sharp + GLU 是基础层的假设"。但 **ZFC 并不强制 Kolmogorov**：
有限可加概率、不精确概率、博弈论概率（Shafer–Vovk）全都住在 ZFC 里。那是一个**建模约定**，被说成了**基础公理**。
ML 的标量指标同理：ZFC 里做偏序毫无障碍。→ 需要区分三层（§4）。

**(3) 旋钮本身是 0/1 的。** "GLU 成立/不成立"本身就是元层面的 Sharp。
在高阶范畴里，粘合是**数据**而不是命题：粘合方式的空间可以是空、单点、或自带非平凡结构（栈、下降数据、高阶上同调）。
第一轮对对象做了形变，却用经典方式给形变分类。

**(4) 元逻辑没动。** 第一轮用经典一阶元语言写 PZFC 公理——改了对象，没改逻辑。
而你的原话是"以测量为核心的语言去**表述逻辑结构**"：逻辑本身应该从测量中来。
这是第一轮最大的遗漏，而这件事**早有成熟答案**：有限观测的逻辑是几何逻辑 / 拓扑（Vickers），既不是经典逻辑也不是概率。（§3）

**(5) 把不变的墙当成可拆的墙。** 对角线论证（Cantor / Russell / Gödel / Tarski / 停机）在任何合理基础里都存在，
换基础只能**改变它的形状**，不能消除它（`07`）。第一轮的口气像是新基础可以拆墙。

**(6) 过早应用，并且猜了不该猜的。** 第一轮有几段在推测朋友们的具体工作。已删除；`02` 降级为"应用层：启发与检验"。

## 3. "测量"不是一个东西

第一轮默认 测量 → 概率。拆开看，测量至少有六个侧面，**每个侧面强制出不同的数学**：

| 侧面 | 含义 | 强制出的数学 |
|---|---|---|
| **有限观测** | 任何时刻只看到有限多信息 | 拓扑即逻辑（Vickers）；几何逻辑；Brouwer 连续性；直觉主义 |
| **统计重复** | 结果以频率出现 | 概率——但哪一种：von Mises / Kolmogorov / de Finetti / Shafer–Vovk |
| **扰动** | 读取改变对象 | 非笛卡尔结构；线性逻辑；无免费复制 |
| **上下文** | 哪些问题能一起问 | 层；上下文性（第一轮的 GLU） |
| **不可区分** | 无法把两者分开 | 对称；置换模型；nominal 集合；选择失效 |
| **自包含** | 测量者在被测者之中 | 对角线；Lawvere 不动点 |

第一轮只做了第 4 行，外加第 2、3、6 行的碎片。**第 1 行和第 5 行几乎完全漏掉**——而第 1 行恰好是"以测量为核心的逻辑"真正所在的地方。

### 第 1 行的第一个推论不是概率，是排中律的失效

若函数 $f$ 在 $\alpha$ 处的值由 $\alpha$ 的**有限多次观测**决定，则 $f$ 连续（Baire 空间拓扑）。
"所有 $f:\mathbb N^{\mathbb N}\to\mathbb N$ 连续"（Brouwer 弱连续性原理）推出 $\neg\mathsf{LPO}$——即排中律的一个弱形式为假。

所以：**认真对待有限观测，首先失去的是"不可观测命题的排中律"，而不是 0/1 真值。**
这正是 Popper：观测可**证实**（开集），定律只可**证伪**（闭集）；全称定律不是观测，是约束。

再加 Diaconescu 定理（拓扑斯 / IZF 中，AC ⟹ LEM），得到：

$$\text{有限观测} \;\Longrightarrow\; \neg\mathsf{LEM} \;\Longrightarrow\; \neg\mathsf{AC}$$

你说"AC 可以直觉地视为我们对测量的存在的坚信"。这里有一个精确化，而且方向略有不同：
**AC 是相信"每一个区分都能被判定"——包括任何有限测量都判定不了的那些。** ¬AC 不是被规定的，是有限观测**推出**的。

## 4. 三层：L0 基础层 / L1 建模层 / L\* 不变层

- **L0**：基础的公理（逻辑、结构规则、概括、选择……）
- **L1**：在某个基础**之内**的建模约定（Kolmogorov、标量指标、演化方程、线性时间索引）
- **L\***：跨越所有合理基础都成立的约束（对角线、等变性障碍……）

重新归类（只列我能判断的；物理与 ML 的具体情形不猜）：

| 墙 | 主要在哪一层 | 说明 |
|---|---|---|
| 单标量指标 | L1 | 聚合时撞上 Arrow 型障碍（L\*） |
| 自回归 | L1 | 表示选择，不需要换基础 |
| 物理还原论 | L1 为主 | **集合论的还原论（∈ 的良基构造）≠ 物理的还原论（宏观由微观决定）**。第一轮混为一谈 |
| ZFC 的良基性 | L0 | 基础公理本身 |
| 不可测集 / "狭义测度" | L0（AC） | 代价在一致性强度上（Solovay / Shelah，`09`） |
| CH 与独立性 | L0 | 但 Gödel（L\*）保证任何基础都有独立命题 |
| Church–Turing | L0 + L1 + L\* | "函数"是什么是 L0；模型选择是 L1；停机是 L\*（`08`） |

**结论：不是一个问题的多个体现。** 一部分墙可以换公理移动（L0）；很多墙根本不需要新基础（L1）；
还有一部分在任何基础里都会以新形状重现（L\*）。这个项目的价值首先在于**分清哪个是哪个**。

### 那 L0 的改变到底能做 L1 做不到的什么？

在 ZFC 里你可以**选择**只用连续函数（L1 纪律）；在 Brouwer 式基础里你**没有选择**（L0 事实）——
于是"所有函数连续"成为**定理**，而它在 ZFC 里是**假**的。

> **L0 改变把纪律变成必然，从而产出 ZFC 证伪的"免费定理"。** 代价是：被纪律排除的病态对象不再存在。

这给"新基础能证明 ZFC 不能证明的东西"一个准确含义，展开在 `09 §1`。
