# 76 · D 的模态：分叉全在可数核之上

> 第四十七轮，第四个问题（`72 §6` 第 4 条；`60`、`71 §4`）。

---

## 0. 路线检查

- **原则在推动的**：
  - `71` 把 GLU–良基猜想分成两条界线：良基管可能性，ω 的标准性管对象与有限层。
  - D 是这样的变体：保持 ω 标准，但允许非良基的高度增长（顶部扩张），再加上宽度扩张。
  - 问题是：D 的模态逻辑是什么？它的分叉触及体系的哪些部分？
- **会拉着走的**：
  - Hamkins–Woodin 的普遍有限集；
  - Hamkins–Linnebo 的潜在主义表。
  只用它们的结论，并标明待核验之处。
- **四种情形**：不涉及单次提问。
- **是否回答 `00 §7`**：回答"可能性的分叉"是否影响全局的内容。

## 1. D 的两种步骤

- **宽度**：泛型扩张，同 B 的 M2a。D 也采用 M4（可数核的绝对性）。
- **顶部扩张**：M ⊆ N，并且 M 是 N 的秩初段——N 中新增的元素，其秩都不小于 M 的一切序数。
  - N 可以非良基；
  - 但它的 V_ω 就是 M 的，所以自然数是标准的。

## 2. 可数核在一切步骤下不变

**定理 1**：沿 D 的每一步，可数核 H(ω₁) 或者不变，或者初等地扩大。
- 顶部扩张：**完全不变**。
- 宽度扩张：初等地扩大（M4）。

*证明（顶部扩张）*：
1. **实数不变**。新元素的秩不小于 o(M)，所以 N 没有新的实数。
2. **ω₁ 不变**。N 中 ω 上的良序都由 M 的实数编码。它们的序型在 M 中与在 N 中相同，因为 M 是秩初段。所以 ω₁^N = ω₁^M。
3. **可数核不变**。于是 H(ω₁)^N ⊆ V_{ω₁^M}^N = V_{ω₁^M}^M，而后者 = H(ω₁)^M 的所在。∎

**推论（可数核的模态是平凡的）**：
- 对可数核中的一切断言（带可数核中的参数），在 B 与 D 中都有：φ ⟺ □φ ⟺ ◇φ。
- 所以限制在可数核上，模态逻辑是平凡逻辑 Triv。
- **概率层与过程层完全建在可数核中，因而在 B 与 D 的一切世界中相同**：
  - 定律、描述、次序谱；
  - 部分可交换的表示；
  - 语境性的判定。

## 3. 分叉在哪里

- **只有顶部扩张时**：可数模型在顶部扩张下的模态逻辑恰好是 S4（Hamkins–Woodin）。
  - 顶部扩张保持 ω 标准，所以这一分叉发生在 ω 标准、非良基的扩张中。
  - 这一点与 `71 §4` 一致；它对 ω 标准的可数模型成立，待核验。
- **B**（宽度与良基的高度）：S4.2，可能性汇合（`57`）。
- **D**（宽度与顶部扩张）：模态逻辑包含 S4。
  - 要说明 .2 在 D 中不成立，需要一个在宽度扩张下也稳定的分叉见证。普遍有限集是 Σ₂ 定义的，宽度扩张可以改变 Σ₂ 的事实。
  - 这一点未判定，猜想仍是 S4。
- **分叉的见证都在可数核之上**：它们是关于很高层次 V_θ 的断言，即关于完成的总体的断言。

## 4. 结论：D 只改变局部内容的模态

1. **D 的分叉只触及 B 本来就视为局部的内容**。
   - 在 B 中，完成的总体（一切子集、一切阶段）是局部的（`55`、`57`）；
   - D 的分叉恰好发生在关于它们的高层断言上。
2. **D 不改变全局的内容**：
   - 可数核不变（定理 1）；
   - 有限层不变（ω 标准）。
3. **D 不消除对象层面的障碍**：高度障碍依然存在（`71` 定理 2）；汇合依然不被判定（`74`）。
4. **所以 D 是一个只作用于"局部内容的模态"的变体**。至今研究过的墙，都位于：
   - 有限层（Bell）；
   - 可数核（概率与过程）；
   - 局部对象（选择、CH），但那是对象的局部性，不是模态。

   没有一堵墙需要 D。这精确化了 `58` 的判断："B 足够，D 作外层可选。"

## 5. 已知的与这里的

**已知的，只作指导**：
- Hamkins–Woodin：普遍有限集，顶部扩张的模态逻辑是 S4；
- Hamkins–Löwe：强迫的模态逻辑是 S4.2；
- Hamkins–Linnebo：潜在主义表。

**这里的**：
1. 定理 1：顶部扩张使可数核完全不变。
2. 推论：可数核上的模态是平凡的，所以概率层与过程层对 B 与 D 的选择不敏感。
3. 结论：D 的分叉只作用于局部内容的模态，没有一堵已研究的墙需要它。

**如实的判断**：
- 定理 1 是一个简单的观察。
- 它的作用是把 `58`、`60` 中关于 D 的判断变成一个证明：分叉与体系的全局内容无关。
