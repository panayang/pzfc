## 1. 定理 D 的完整证明

**设定**：
- 检查点链（`97`），间隔 g_j ∈ [g, 2g]；
- 平台前后的检查点窗口 ≤ ΓW；
- 平台由若干检查点组成，总的 X-时间为 T ≥ η²W²，平台上的窗口都 ≥ W′_min。
- 记 K := Γ/η，于是平台前后的位置 x, y ≤ ΓW ≤ K√T。

**引理 D1**（半直线的核，`97` 引理 2–5 的组合）：只在检查点处杀死 D < 1 的链，经过 X-时间 T，对 1 ≤ x, y ≤ K√T，
> q_T(x, y) ≍ (x ∨ √g)(y ∨ √g)/T^{3/2}，

常数只依赖于 K。

*证明*：
- **上界**：
  - 在时间 T/2 处分开；
  - 前半段的存活 ≤ C(x ∨ √g)/√T（`97` 引理 3，检查点破产）；
  - 后半段对终点 y 用倒转的链，同样 ≤ C(y ∨ √g)/√T；
  - 中间的点概率 ≤ C/√T（局部极限定理）。
- **下界**：
  - 先以常数概率离开到 √g 的量级（`97` 引理 8(a) 第 1 步）；
  - 再以 ≍ (x ∨ √g)/√T 的概率沿管升到 √T 的量级（`97` 引理 5）；
  - 然后以 ≍ 1/√T 的点概率到达 y 附近的 √T 量级，再倒转下来；
  - 在 x, y ≤ K√T 的范围内，这些量的常数只依赖于 K。∎

**引理 D2**（桥不会走得太高）：对同样的 x, y，
> P_x(存活，终点 y，并且某个检查点处 D > C√T) ≤ ½ q_T(x, y)，

只要 C ≥ C(K)。

*证明*：
- 在首次越过 C√T 的检查点 σ 处分开。
- 到达 C√T 而不被杀死的概率 ≤ C′(x ∨ √g)/(C√T)（一维的破产估计）。
- 从高度 ≥ C√T 出发、在剩下的时间 ≤ T 内到达 y ≤ K√T 并存活：
  - 由 Gaussian 尾与底部的破产因子，≤ C′(y ∨ √g)/√T · T^{−1/2} · exp(−c(C − K)²)。
- 两者之积 ≤ C″ exp(−c(C − K)²)·(x ∨ √g)(y ∨ √g)/T^{3/2}。
- 由引理 D1 的下界，对大的 C 它 ≤ ½ q_T(x, y)。∎

**定理 D**（`123`）：若 T ≥ η²W² 并且 W′_min ≥ C(K)√T，则穿过平台的核 M(x, y)（x、y 分别是平台前后的检查点上的位置）满足 Δ(M) ≤ C′(K)。

*证明*：
- **上界**：忽略平台窗口的上界，只保留底部，M ≤ q_T。
- **下界**：只计在一切平台检查点处 D ≤ C√T 的路径。由于 C√T ≤ W′_min，它们不被平台的上界杀死。由引理 D2，M ≥ ½ q_T。
- 所以 ½ q_T ≤ M ≤ q_T。由引理 D1，q_T 在有界的畸变内是乘积形式 a(x)b(y)，于是 M 也是。它的交叉比 ≤ 4·C_D1⁴，直径有界。∎

**状态**：
- 定理 C（尖峰）是定理 D 的特例（平台只有一个检查点）。
- 两者都在 `97` 的一维引理之上完整。
- `123 §2` 的递归由此成立：比值无界的窗口，只要无穷多次出现"比值有界的段"或"足够高的平台短途"之一，就刚性。
- 剩下的是分形的剖面（`123 §2`）。

## 2. 一般世界的汇合高度

`119` 对形如 L_α[A] 的世界给出了精确值。对一般的可数传递世界 w（高度 α），有如下的夹逼。

**命题 1**：设 w[c]、w[d] 是世界。
1. **下界**：
   > amh(w[c], w[d]) ≥ sup{ zh_{≥α}(A, c ⊕ d) : A ∈ w，A 是序数的集合 }，

   其中 zh_{≥α}(A, z) := min{ β ≥ α : L_β[A, z] ⊨ ZFC }。
2. **上界**：
   - 同高汇合失败时，amh(w[c], w[d]) ≤ min{ β : L_β(w ∪ {c, d}) ⊨ ZFC }；
   - 这里 L_β(X) 是在传递集 X 之上的可构成层级，与 L(ℝ) 的构造相同。
3. **相等**：若 w ⊨ "V = L[A]"（A 是序数的集合），则 amh = zh_{≥α}(A, c ⊕ d)（`119` 定理 1）。

*证明*：
1. 设 M ⊇ w[c] ∪ w[d] 是传递的 ZFC 模型，高度 β。对每个 A ∈ w，A、c、d ∈ M，所以 L^M[A, c, d] = L_β[A, c, d] ⊨ ZFC，从而 β ≥ zh_{≥α}(A, c ⊕ d)。
2. L_β(w ∪ {c, d}) 包含 w 的一切元素，也包含 c、d，所以包含 w[c]、w[d]。
3. 见 `119`。∎

**读法**：
- 下界说：汇合的代价至少是"世界里任何一个序数集合与 c ⊕ d 合起来"的第一个 ZFC-高度。
- 上界说：把整个 w 作为一个对象加进去，一定够。
- 两者之间的差距，来自一个技术上的可能性：共同的扩张 M 可以包含 w 的每个元素，却不把 w 本身作为一个元素。
- 当 w 由一个集合参数生成时，差距消失。

**问题**（留作开放，不影响体系）：下界是否总是被达到？等价地，是否总有高度为下界的 M，它包含 w 的一切元素？
