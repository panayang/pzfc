## 1. 第一层：概率

### 1.1 定义

- **定律**：标准空间上的概率测度，由可数数据给出。
- **描述**（事件）：一个 Borel 码。在 M4 下，也可以是投影的。
- **局部的实现**：世界 w 中的 (Ω^w, Σ^w, P^w)。
- **新鲜的样本**：扩张中、在 w 上对定律随机的点。
- **语境上的定律**：若干语境，每个语境上一个定律，在重叠处相容。它的**实现**是把各语境的样本放进同一个世界的一个耦合。
- **记录**：世界的扩张。
  - **测度型**的记录加入对某个测度典型的点，例如随机实数；
  - **范畴型**的记录加入对贫乏理想典型的点，例如 Cohen 实数。

### 1.2 原则

> **事件是描述，不是点集。**

它不是另加的公理，而是定理 A、B 的推论：
- 点集的测度是暂时的；
- 新鲜样本只能被描述命中。

### 1.3 定理

**A. 描述与点集**
- **A1**：描述的测度在一切扩张中不变；每个局部点集都在某个扩张中零测；不可测是局部的、暂时的（`61 §1`）。
- **A2**：在极限 T₀ 中，选择公理成立，而一切实数的集合都零测：选择与全面的测度共存（`59 §4`）。

**B. 新鲜样本**
- 样本不在它所随机的世界里；
- 新鲜样本几乎必然躲开一切局部点集；只有描述能被命中（`61 §2`；`Askable` §6）。

**C. 独立是扩张**：第二个样本相对于含有第一个样本的世界是新鲜的（`61 §3`）。

**D. 语境上的定律**
- **D1**：有全局定律 ⟺ 有一种实现，使各样本在重叠处以概率 1 一致；一切实现中，一致的最大概率等于非上下文的部分（`61 §4`、`63 §5`；`Records` §6）。
- **D2**：障碍是**有限的**。
  - 存在 η > 0，使任何长度的共享记录表都在某个语境上偏离至少 η；
  - 判定是算术的，在一切世界中相同（`68`；`Exchange` §5）。
- **D3**：语境性与世界能否汇合互相独立（`68`）。

**E. 局部点集的测度命运**
- **E1**（对偶）：
  - 随机型的记录精确保持一切旧点集的外测度，并使旧实数贫乏；
  - Cohen 型的记录使一切旧点集零测，并保持范畴；
  - 旧实数服从零一律：零测，或者满外测度（`67`；`Fate`）。
- **E2**（刻画）：
  - I 型的记录能消灭 A ⟺ A 被一个 Borel 的零测族 I-几乎处处覆盖（`67 §4`）。
  - 若 I 由测度承载，则精确保持（`70 §2`）。
- **E3**（捕获）：
  - 消灭不需要 Cohen 实数：一个不被分裂的集合（Mathias 实数）就消灭一切（`70`；`Kill`）。
  - 一切 Mathias–Prikry 强迫都消灭一切（`84`）。
- **E4**（二值）：
  - 良好的记录（Π¹₁ on Σ¹₁ 的理想型强迫及其有限迭代）使点集测度的命运二值：完整保留，或全部消失（`75`）。
  - 在 B 中，一切由实数可定义的记录都如此；部分失去只能来自以局部选择对象为参数的记录（`79`）。
- **E5**（窗口）：在任何扩张中，局部集合的测度要么随旧实数归零，要么落在它的内外测度之间。测度的不确定性恰好是不可测性（`84`）。

**F. 概率层对自己的运算封闭**：抽样由测度承载，所以依次抽取新鲜样本，保持一切旧点集的外测度（`67 §5`、`70 §2`）。
- 更强地，抽样所实现的测度扩张是平凡的（`105`）。
- **[B⁺]** 描述可以取 L(ℝ) 中的一切定义：由实数可定义的事件都可测，测度全局（`106` R1）；由 L(ℝ) 可定义的记录全有或全无（`106` R2）。
- 一般的扩张所实现的扩张总是可分的、平移不变的，并且沿分支单调（`105` 定理 1–3）。

### 1.4 开放（集合论范围）

- 窗口内部的值能否实现（`84 §3`、`89 §1`、`100`）。已移出主线。
  - `100` 证明了：
    - 窗口即诱导的外测度，它在平移不变的集合上只取 0 与 1；
    - 对测度典型的覆盖码只能覆盖零测集；
    - 若能选择性地消灭一个地面模型的实数，就实现窗口的严格内部。
  - 候选"先 Cohen、再完整的随机"（Q\*）已被否定：在 v 上的 Cohen 实数连同 v 的一切随机扩张的实数一起消灭（`107` 定理 1′）。
  - 新的候选"先 Mathias、再随机"（Q\*\*）不添加猜测实数（`107` 定理 2），开放。
    - 由 Ramsey 性质，v[r] 的实数分为常数型（全体零测）与相异型；以地面函数为界的覆盖连地面实数都覆盖不了。Q\*\* ⟺ 快速的小集合不能覆盖相异型（`109 §1`）。

## 2. 第二层：过程

### 2.1 定义

- **行为**：从提问的历史（谁问、问了什么）到回答（或回答的定律）的函数。
- **四种情形**：再问、谁问、之前问了什么、同时问了什么。记录 = 四种都不变。
- **余下行为、事实、结构、位置**：
  - 事实：对一切余下行为都成立的性质；
  - 结构：余下行为的全体；
  - 位置：此刻是哪一个。
- **可交换**：两次提问按两种次序问完，此后的样子相同。
- **迹**：交换相邻的独立提问所得的等价类。按类时，迹就是各类的流组成的组。
- **次序谱**：同一组提问按各种次序问完之后，行为能变成的一切。
- **中心的线性化**：给定迹，前段的概率只依赖于到达的理想。
- **隐藏比率**：中心线性化中各部分推进的渐近比例。
- **同步比 ρ**：同步间隔与已过时间之比。

### 2.2 定理

**P1. 记录与模型**（`47`；`Circumstances` §1–§3）
- 有记录模型 ⟺ 公共且不被扰动；
- 隐藏状态的模型总存在；最少的隐藏状态数 = 余下行为的个数。

**P2. 事实、结构、任务、评价**
- 事实全同 ⟺ 余下行为全同；给出位置何时是事实的判据（`48`；`Circumstances` §6）。
- 预测是定死每个回答的任务；关系的任务不是预测（`47 §5`）。
- 可以随时重做的评价只看见终局（`53 §1`；`Circumstances` §8）。
- 与次序无关的指标看不出被评价者是否与次序无关（`66 §7`；`Spectrum` §4）。

**P3. 次序**（`62`、`63 §2`、`65 §1`；`Protocols` §2、§6，`Exchange` §1–§2）
- 此后与次序无关 ⟺ 两两可交换；
- 同一迹留下相同的未来；
- 按类可交换时，同迹 ⟺ 各类的流相同。

**P4. 部分可交换的一般表示**
- **P4.1 按类，三种"谁决定读哪条流"**（`65`；`Exchange`）：
  - **过程自己决定**：任意的流，按可交换的日程交错。de Finetti（每类一个字母）与任意过程（一类）是它的两端。
  - **位置决定**：Diaconis–Freedman 的 Markov 链混合。
  - **提问者决定**：迹可交换 ⟺ 类之间不传信；隐藏的全局结构存在 ⟺ GLU。
    - 至多一类有选择时，它总存在；
    - 两类有选择时，它可以不存在（PR 盒）；
    - 所以 de Finetti 与 Bell 是同一个定理的两端。
- **P4.2 一般独立关系**（`69`、`73`；`Traces`）：
  - 依赖图的连通分量给出日程；迹几乎必然没有最大元；
  - 迹可交换的过程 = 隐藏的迹 + 迹的比率边界上的一点 + 新鲜的局部洗牌。
- **P4.3 隐藏比率**（`73`、`83`、`88`）：
  - 存活的比率给出不同的极端中心线性化；
  - **隐藏比率存在 ⟺ liminf ρ > 0**：同步没有特征尺度时，隐藏的频率出现。
- **P4.4 刚性**（`69`、`78`、`93`、`97`、`98`）：
  - 有完全切口，或者不可比有界时，刚性；
  - 刚性 ⟺ 检查点核的 Birkhoff 射影直径趋于 0 ⟺（由全正性）四个角点概率之比趋于 1（`94`）；
  - 平台型的同步是刚性的，即使不可比无界（`93`）；
  - **相变**（`98` 定理 3）：对正则的同步（窗口有凹的光滑包络），刚性 ⟺ ρ → 0。
    - 缓变窗口的一侧（W² = O(P)）是 `97` 定理 1；
    - 宽窗口的一侧（W² ≫ P）是 `98` 定理 2；
    - 不刚性的一侧是 `83`。
  - 所以：**隐藏的参数恰好是比率，而比率恰好在同步没有特征尺度时存在。**
  - **不规则窗口**（`117`）：段内比值有界的任意窗口、一切独立同分布的随机窗口都刚性；多链尺度相当时刚性（`116`）。见 §2.3 与 `120`。
  - **一切凹包络**（`108` 定理 1、2）：只要窗口有凹包络（误差 O(√W)），刚性 ⟺ ρ → 0。包括临界情形（ω ≍ P/log P）与 W²/P 振荡的情形。
  - **多链**（`108` 定理 3、4）：
    - 同步图连通且稠密时，比率唯一；
    - 尺度不变的边给出一个开的比率多面体，隐藏比率的维数 = 它的维数。
- **P4.5 学习**（`88`）：
  - 迹是充分统计量；后验相合；
  - √n 的速率，方差与没有约束时相同。
  - 同步决定比率是否存在，不决定它被学得多精确。

**P5. 次序谱**（`63 §3`、`66`；`Protocols` §7、`Spectrum`）
- 次序谱落在余下行为之内，藏回次序依赖的代价至少是它的大小；可交换 ⟺ 只有一个成员。
- 按类可交换时：
  - 次序谱恰是类内重排之组的像，上界可达；
  - 随机次序下各类内的次序独立，次序熵按类相加；
  - 概率版本对类内的 Kendall 距离是 Lipschitz 的；粗粒化只会缩小次序谱。

**P6. 沿树的学习**（`63 §1`）
- 沿一条路是经典的鞅；未问的分支永不揭示；
- 只有可交换时，极限与提问的策略无关。

**P7. 网络**（`51`；`Network`）
- 公共 + 不干扰 ⟹ 不被扰动；公共而被扰动 ⟹ 干扰。

### 2.3 刚性的最终状态与开放（概率论范围）

最终定理、依赖图与工具见 `120`；中间结论的演变见 `97`–`117` 与 `118 §3.1`。

- **已证**：
  - 凹包络：刚性 ⟺ ρ → 0（`97`、`98`、`108`）；
  - 瓶颈：一步收缩判据（`109` 定理 5）；
  - **段内比值有界的任意窗口刚性**（`117` 定理 2：下 Lipschitz 包络 + 停时版的约去）；
  - 一切独立同分布的随机窗口几乎必然刚性（`117` 推论 2）；
  - 普通窗口之间高于 η²W² 的尖峰是重置，给出好块（`123` 定理 C）；
  - 多链（路与树）：尺度分离、平台、瓶颈、尺度相当都刚性（`109`、`110`、`112`、`116`）；60° 角的精确鞅（`116` 命题 2）；三链的一切同步图（含三角形）刚性（`123 §3`）；m 链的全低角是 Weyl 室，Vandermonde 精确调和。
- **开放**（`118 §2.1`、`120 §6`）：
  - 分形的窗口剖面（单调性猜想；尖峰与高平台已由 `123` 定理 C、D 处理）；
  - m ≥ 4 链混合角在 120° 棱附近的估计细节（`123 §3.3`，结构已给、数值刚性）；
  - 宽窗口下多链刚性的精确形式。

## 3. 与经典的对照

| 经典 | 在 B 上 |
|---|---|
| 概率空间 (Ω, Σ, P) | 定律的一个局部实现 |
| 事件 | 描述（码） |
| 不可测集 | 局部的选择对象；它的测度在扩张中只能落在自己的内外测度之间 |
| 独立 | 扩张：后一个样本相对于前一个是新鲜的 |
| 滤子（信息的时间） | 提问的次序：可交换时是多重集，部分可交换时是迹，否则是树 |
| 可交换序列（de Finetti） | 隐藏的记录被新鲜地读取；"没有选择"时的 GLU |
| Bell 不等式 | "两类都有选择"时 GLU 的失败 |
| Markov 链的混合 | 位置决定读哪条流 |
| 部分可交换的序列 | 迹 + 比率边界上的一点 + 新鲜的洗牌 |
| de Finetti 的频率 | 同步没有特征尺度时的隐藏比率 |
| 状态空间模型 | 按时间个别化；代价是隐藏状态的个数 |
| 单一标量的评价 | 事实的包含关系（偏序）；次序谱 |

## 4. 新在哪里（如实的评估）

- **组成部分**：大多是已知的或初等的。包括强迫法、de Finetti、Diaconis–Freedman、迹、非上下文部分、Birkhoff 收缩、Rényi 的中心极限定理。
- **新的是组织，以及这些陈述**：
  1. 测度属于描述；概率谈论新鲜的样本；独立是扩张。
  2. 局部点集的测度命运：对偶、刻画、二值、窗口；概率层对自己的运算封闭。
  3. 语境性是有限的、算术的，与世界的汇合无关。
  4. de Finetti 与 Bell 是同一个定理的两端。
  5. 部分可交换的一般表示；隐藏比率存在 ⟺ 同步没有特征尺度；在比率存在处，de Finetti 的学习理论原样成立。
  6. 次序谱与藏回去的代价，是经典写法看不见的不变量。
- **还不是**：一条专家不知道的深定理。它是一个新的坐标系：经典的结构在其中各就其位，并且显出了经典看不见的量（次序谱、比率边界、命运窗口）。
