# 60 · D 的初步探索：GLU 与良基

> 按你的计划，第二步：对 D 作初步探索，看 GLU 与良基的关系；若成立，就指出将来遇到新的墙时可以考虑 D。
>
> 形式化：`lean/Modal.lean` §5，5 条。

## 1. 三种增长，三种模态的形状

| 增长 | 两个扩张能否汇合 | 模态 | 依据 |
|---|---|---|---|
| **宽度**（强迫） | 在可能性上总能：乘积强迫 | .2，即 S4.2 | `56 §1.2`；Hamkins–Löwe |
| **高度，在同一个外层宇宙里**（秩初段） | 任意两个扩张可比较：排成一条线 | .3，即 S4.3，并且推出 .2 | 下面的定理；Hamkins–Linnebo |
| **高度，跨越不同的宇宙** | 要么可比较，要么完全粘不起来 | 世界层面分叉 | §1.2 |

### 1.1 定理：线性是汇合的特例（`Modal.lean` §5）

- **.3 对一切赋值成立，当且仅当框架是连通的**：任意两个扩张都可比较（`dot3_iff_connected`）。
- **连通的框架一定汇合**：两个可比较的扩张，较大的那个就是共同的扩张（`confluent_of_connected`）。
- 所以 **.3 推出 .2**（`dot2_of_dot3`）；这个推导是构造性的，不依赖任何公理。

**读法**：
- 高度沿一条线增长，就是构造的**线性时间**——序数的阶段一个接一个。
- 定理说：**线性时间是粘合的特例。** 开头四个倾向中的"线性时间"，在形式上是"存在全局模型"的一种特殊形态。
- 这是 `00` 把两者并列时没有看到的一层关系，现在是一条定理。

### 1.2 高度跨越宇宙时：要么可比较，要么粘不起来

设 N₁、N₂ 都是传递世界 M 的高度扩张（M 是两者的秩初段）。
- 如果它们有一个共同的高度扩张 N，那么 N₁ = V_β^N，N₂ = V_γ^N。因为 β ≤ γ 或 γ ≤ β，两者中一个是另一个的初段。
- 所以**两个高度扩张要么可比较，要么在高度方向上完全不能汇合。**
- 线性恰好对应"一切高度都在同一个外层宇宙里"。

## 2. GLU 与良基：一个有概念基础的猜想

**问题**：可能性什么时候会真正分叉，也就是 .2 失败？
- 宽度的增长：从不（乘积强迫）。
- 高度在同一个宇宙里：从不（线性）。
- 高度跨越宇宙：在世界层面会（§1.2）；在可能性层面，已知只有 S4 的例子（Hamkins–Woodin 的万有有限集）用的是**可以非良基**的可数模型。

**为什么良基可能会迫使汇合**（启发式的论证）：
- 两个传递的世界，它们的序数都是良序，在任何包含它们的宇宙里，都是同一条序数之线的初段，因此可以比较。
- 所以，**良基带来一条共享的线性标尺（序数），一切构造的阶段都能在上面比较**。这正是一个关于构造阶段的全局语境——第 1 轮所说 GLU 的第一层（`22 §1`）。
- 有了共享的标尺，高度就不能真正分叉，只剩宽度的分叉，而宽度的分叉在可能性上总能汇合。
- 非良基的"阶段"不能放到任何良序的标尺上，于是没有共享的标尺，高度才可能真正分叉。

> **猜想（GLU–良基）**：
> - 对由良基（传递）世界组成、在自然的运算（强迫；更高的传递模型）下封闭的系统，可能性汇合（至少 S4.2）。
> - 可能性的真正分叉（只有 S4）需要非良基的增长。
> - 换句话说：**良基就是构造阶段上的全局语境；它本身是一种 GLU。**

**现状**：
- **支持的证据**：
  - Hamkins–Linnebo 表中一切传递系统都至少是 S4.2；
  - 已知的 S4 系统都用到非标准的部分；
  - §2 的启发式论证。
- **没有证明**。关键的开放点：万有有限集的扩张性质，能否总是用传递的高度扩张来实现。若能，猜想就不成立。

**与第 1 轮的关系**：
- `00` 写下"ZFC = 锐 + GLU + 良基"，把三者当作三个旋钮。
- 若猜想成立，其中两个不是独立的：**良基是 GLU 在构造阶段上的形态**，而线性时间（`§1.1`）是它们共同的特例。

## 3. 给将来的一个指引

**B 足够用于现在的目标**（`58`）。但如果将来遇到一堵新的墙，它要求**可能性本身的分叉**，就应当考虑 D，也就是放开增长的良基性。例如：
- 要把"不能调和的永久承诺"写进基础本身，而不只是作为可数核里的对象；
- 或者要一个没有唯一数学实在、连潜在地也没有的底座。

**D 的形状**：
- 一个固定的、良基的可数核（全局，由 M4 固定）；
- 核之上的增长可以非良基，因而可以分叉。

它与第十到十二轮的非良基种类（反基础集合）是同一个方向：在那里，非良基让循环的、按关系认同的对象成为可描述的；在这里，它让数学的可能性可以分叉。

**代价**：
- 世界不再都是传递的，属于关系要相对于世界；
- 失去 .2 与镜像翻译，也就是失去"可能性总能合在一起"的推理（`58 §3`）。

## 4. 形式化：`lean/Modal.lean` §5

| 定理 | 内容 | 公理 |
|---|---|---|
| `connected_of_dot3` | .3 对一切赋值成立 ⟹ 框架连通 | 无 |
| `dot3_of_connected`、`dot3_iff_connected` | 反方向：连通 ⟹ .3（用到排中律，因为 .3 是一个析取式） | 经典 |
| `confluent_of_connected` | 连通 ⟹ 汇合 | 无 |
| `dot2_of_dot3` | .3 ⟹ .2：线性时间是粘合的特例 | 无 |

## 5. 如实说明

- §1 的模态事实都是已知的：S4.3 包含 S4.2，秩潜在主义是线性的。§1.2 的"可比较或粘不起来"是一条初等的观察。
- 属于这里的：
  - 把"线性时间是粘合的特例"作为关于开头四个倾向的一个陈述，并给出构造性的证明；
  - GLU–良基的猜想，以及它的概念基础——良基就是构造阶段上的全局语境。
- 猜想本身没有证明，已列入待核验。
