## 1. 窗口的内部

**设定**：w ≼ w′，ℝ^w 在 w′ 中不零测（所以满外测度）。对 Y ∈ w，记 μ′(Y) = μ*(Y)^{w′}。由 `84`：
- μ′ 在 w 的 Borel 集的迹上与 μ 一致；
- 并且 μ_*(Y)^w ≤ μ′(Y) ≤ μ*(Y)^w。

**定理 1**（内部值的一个充分机制）：
- 设 Y ∈ w 是**饱和的**不可测集：Y 与它的补 ℝ^w ∖ Y 在 w 中都满外测度。
- 若 w′ 中有 Borel 集 B，使 B ∩ ℝ^w = Y（w′"决定"了 Y），则 μ′(Y) = μ(B)，μ′(ℝ^w ∖ Y) = 1 − μ(B)。
- 所以 Y 与它的补至少有一个取窗口内部的值；若 0 < μ(B) < 1，两者都取内部的值。

*证明*：ℝ^w 满外测度，所以 μ′(B ∩ ℝ^w) = μ(B)，补同理。而 μ*(Y)^w + μ*(ℝ^w ∖ Y)^w = 2 > 1。∎

**已排除的**（它们都消灭一切，或精确保持）：
1. 一切由实数可定义的记录（`79` 定理 2）；
2. 一切 Mathias–Prikry 强迫（`84` 定理 1）；
3. "先 Cohen、再随机"之类的迭代：它们的商由实数可定义，同 `79 §2`。

**剩下的形式**：
- 窗口内部的值，需要一个以不可定义的局部参数（例如 Y 本身）为参数的记录；
- 这个记录在 ℝ^w 存活的同时"决定"一个饱和的不可测集。
- 这是强迫法中的一个具体问题，本篇未判定。

**判断（范围）**：
- 对概率层，窗口定理已经足够：
  - 抽样精确保持（`67`）；
  - 由描述给出的集合命运精确（`84`）；
  - 窗口内部只涉及不可测的局部集合，而它们不是事件（`61`）。
- 所以窗口内部的问题**移出主线**，归入集合论的技术问题（待核验清单）。

## 2. 全局配对推不出汇合：构造的闭合

**定理 2**：有 B 的模型满足全局配对（GP），但其中 w[c] 与 w[d] 没有共同的 ≼-扩张。

*构造*：
1. **起点**。从 `74` 的稀疏模型出发。它的世界称为**枝世界**：由 w[c] 或 w[d] 可达，并且不同时含有 c 与 d。
2. **添加世界**。对每一对不共存的集合 a、b，添加一个可数传递模型 X_{a,b}，满足：
   - 它同时含有 a、b、c、d；
   - 它的高度不等于迄今出现过的任何高度（可数多个，可以避开）。
   
   再添加它的扩张树（满足 M3），树中的世界同样含有 c、d，并取新的高度。
3. **封闭**。对新加入的集合重复第 2 步，共进行 ω 次；每一步只有可数多对。
4. **添加的世界不在任何枝世界之上**：
   - 它不是枝世界的宽度扩张：高度不同。
   - 它不是枝世界的高度扩张：它的任何秩初段 V_κ（κ > ω + 1）都同时含有 c 与 d，而枝世界不同时含有两者。
   - 由此归纳，添加树中的任何世界都不 ≼-高于任何枝世界。
5. **结论**。
   - w[c] 与 w[d] 的共同扩张若存在，必同时含有 c、d，所以不是枝世界；它也不在添加树中，因为添加树中的世界不高于枝世界。所以不存在。
   - GP 由第 2、3 步成立。
   - M1–M4 同 `74` 定理 1。∎

**于是 `86` 的三级全局性严格**：B ⊊ B + GP ⊊ B + AM。每一级都独立于前一级。
