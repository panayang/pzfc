# 54 · 这个体系是关于什么的

> **第三十七轮注**：公理体系已改用集合论的语言重写，见 `55`（世界、扩张、绝对、局部）。本篇的内容与之一致，但用语已被取代；对照表见 `55 §6`。

> 你的问题：我们给出的数学模型究竟是关于什么的？描述了什么，又能描述什么？ZFC 很明确是关于集合的，我们呢？
>
> 前面各篇把四层东西混在一起写了：**公理、词汇、定理、读法**。本篇把它们分开，并用同样的三个例子，对照 ZFC 与我们各自怎样描述。

---

## 1. 一句话

- **ZFC 问：有哪些集合？** 它假定对"x 属于 y 吗"这样的问题，回答总是定了的；数学就是在这个前提下研究集合。
- **我们问：哪些回答是不变的？其余的东西，有什么是不变的？**
  - 回答不变，指问第二次、换人来问、之前问过别的、同时问了别的，回答都不变。这样的回答称为**记录**。
  - 数学在这里研究两件事：一是记录；二是那些回答会变的东西——它们身上有什么仍然是记录。

## 2. 四层，分开看

### 第一层：公理——形式上它是关于什么的

| | ZFC | 我们（`50`、`53`） |
|---|---|---|
| 基本对象 | 集合 | **记录**；形式上就是**可数的**集合（T₀） |
| 第二种对象 | 没有 | **记录的世界**：某一时刻已有的全部记录（T₂） |
| 基本关系 | 属于（∈） | 属于，加上 **"由记录化而来"**：一个世界补上新的记录，得到另一个世界（T₂） |
| 关键公理 | 幂集、选择…… | "每份记录都可数"（T₀）；**"记录不被之后的记录化扰动"**（T₂ 的 U） |

**如实说**：
- 在最底一层，我们的对象仍然是集合，只是只收可数的那些。所以 T₀ 本身几乎就是已知的二阶算术。
- 真正新的原语只有一个：**记录化**，也就是记录的世界怎样增长。

所以，形式上：

> **这个体系是关于"记录"与"记录的增长"的理论。**
> - ZFC 描述一个已经完成的集合宇宙；
> - 我们描述一个**不断被补充的记录世界**，以及补充时什么保持不变。

### 第二层：词汇——用记录去描述回答会变的东西

这是日常使用时的主体（`50 §3`）。它们都是**定义**，不是新的公理：

| 词 | 描述什么 | 它身上什么是记录 |
|---|---|---|
| **来源** | 回答每次都可能不同、统计却稳定的东西（硬币、噪声、随机过程） | 它的**规律** |
| **行为** | 回答随情形而变的东西（被读就变的记忆、学习中的系统、因人而异的回答） | 它的**事实**：一切情形下都成立的性质 |
| **结构 / 位置** | 行为在各种情形下的样子的全体 / 此刻是哪一种情形 | 结构是记录；位置只有被记下时才是 |

这一层的意思是：**对回答会变的东西，不去虚构一个隐藏的完整状态，而只谈它身上什么是不变的。**

### 第三层：定理——这套词汇能精确地说什么

例如：
- 可以问的问题恰是可测的问题；
- 事实只看得见结构，看不见位置；
- 为了假装一切回答都是记录，经典的描述必须虚构多少隐藏状态；
- 公共的世界里，读取即更新必然造成干扰。

它们大多是初等的，作用是保证第二层的词**有确切的意义**。

### 第四层：读法——对开头那几堵墙说了什么

这一层只是启发，不承重（`52 §3`）。

## 3. 同样三个例子，两边怎样描述

**例一：一枚硬币抛很多次**

| | ZFC / Kolmogorov | 我们 |
|---|---|---|
| 对象 | 样本空间 Ω = 所有 0-1 序列；第 n 次抛是 Ω 上的函数 | 一个**来源**：只给出"前 n 次各种结果的概率" |
| "第 7 次是正面吗" | 在每个样本点上都有确定的回答 | 不是对象。只有被记下之后才是一份记录 |
| 什么是确定的 | 一切 | **规律**，以及必然的事实，例如"正面的比例趋于 1/2" |
| 结论 | 每个无穷序列都是一个点 | 这个来源**没有**记录（`44`），点是别的来源的记录 |

**例二：一个读取就会改变自己的记忆（例如学习中的系统）**

| | ZFC | 我们 |
|---|---|---|
| 对象 | 一个隐藏状态，加一个转移函数 | 一个**行为** |
| 能说的 | 下一时刻的状态与回答——**预测** | 它的**事实**，例如"存了能读到""读过的受保护"（`48 §3`），即它的**结构** |
| "它此刻能力如何" | 一个状态的函数 | 一个**位置**，不是事实。可以随时重做的评价只能看见它终将成为的样子（`53 §1`） |

**例三：连续统假设 CH**

| | ZFC | 我们 |
|---|---|---|
| 身份 | 一个关于唯一宇宙的陈述，真假未定 | **不是关于记录的陈述**。它问的是理想化的完整总体 |
| 为什么判定不了 | 没有解释 | 它随"换一个宇宙""补充记录"而变——它是位置，不是事实 |
| 关于记录的问题 | 许多也判定不了 | 由 U，它们都不被补充记录所改变。第一层上，这与"能构成的问题都能问（可测）"是同一件事（`53 §3.1`） |

## 4. 描述了什么，还能描述什么

**已经描述了的**：
- 经典数学：
  - 可数的部分就是记录；
  - ZFC 是把一切情形都写进问题之后的理想化（`50 §2`）。
- 不以样本空间为前提的概率：来源、能问的问题、来源的记录（`43`–`45`）。
- 会被问而改变的系统：它的事实、结构、位置，以及评价的限度（`47`、`48`、`53`）。
- 提问者之间：公共、干扰、记录的转交（`51`）。
- 数学世界本身的增长：哪些真理稳定（关于记录的），哪些是位置（例如 CH）（`53`）。

**能描述、但还没做的**：凡是**回答取决于怎样问**的东西。
- 学习与记忆；
- 观察依赖于观察者的描述；
- 一个共同体共享又不断更新的数据。

它们在经典语言里只能写成"一个很大的隐藏状态加一个预测问题"；在这里可以只谈它们身上不变的部分。

**不能描述、或描述得不好的**：
- 不可数的数学（非可分的空间、一般拓扑）只住在理想化的完成里；
- 图灵式的计算还没展开（`52 §5`）。

## 5. 和 ZFC 的关系，一句话

- **ZFC 是这个体系在"假定一切回答都是记录"时的样子。** 把情形都写进问题（个别化），一切就回到 ZFC。
- 反过来，我们的一切定义在 ZFC 里也写得出来。**差别不在能不能写，而在把什么当作对象、把什么当作事实：**
  - ZFC 把每一个回答都当作对象；
  - 我们只把不变的东西当作对象，其余的东西，由它们身上不变的部分来描述。
