## 1. 事实看见结构，看不见位置

**定义**：
- **余下行为**（`47 §3`）：一个行为在某段历史之后还会做的事。
- **不变的事实**：对"它在任何历史之后还会做的事"都成立的性质。

**定理 1**（`sameFacts_iff`）：
> **两个行为的不变事实全同，当且仅当它们的余下行为全同。**

读法：
- 余下行为的全体，是这个行为**可能处于的一切情形**，每一种都连同它此后的全部表现。称它为**结构**。
- 此刻处于其中的哪一个，称为**位置**。
- 不变的事实恰好看见结构，看不见位置。
- **预测 = 结构 + 位置**：知道此刻是哪一个余下行为，就知道此后的一切回答。

**定理 2**（`undisturbed_facts_determine`）：
> **不被扰动的行为，事实定死一切。**

它只有一个余下行为——就是它自己——所以结构和位置是一回事。经典的记录就是这样：**在经典的世界里，"知道结构"和"预测演化"不可区分**，因为根本没有位置可言。

**定理 3**（`flip_facts_not_position`）：
> **两个翻转的记忆事实全同，而它们不同。**

它们有同样的两个余下行为（此刻回答"否"的相位、此刻回答"是"的相位），只是起点不同。在这种会回到原处的结构里，**"现在是哪个相位"不是一个事实**。

**定理 4**（`markB_facts_determine`）：
> **做标记的记忆被它的事实定死。**

一旦做了标记，就回不去（标记后的记忆不被扰动）。所以"尚未标记"的那个余下行为，是唯一还能到达全部余下行为的；它的起点本身就是一个事实。

**定理 5（一般判据，`positionIsFact_iff`）**：
> **位置是一个事实，当且仅当：没有别的余下行为，与它自己能做的事完全一样。**

- 翻转的记忆：另一个相位能做的事和它一样，所以位置不是事实。
- 做标记的记忆：标记之后能做的事变少了，所以位置是事实。
- 不被扰动：只有它自己，所以位置是事实。

## 2. 这对开头的问题意味着什么

**线性时间**：
- 经典的线性时间，是记录**不可撤销地**累积：写下就不再变，历史只增不减。
  - 于是每走一步，"还能做的事"都真的变少，别的余下行为能做的事都不如此刻多；
  - 由定理 5，位置（此刻在历史的哪一点）由事实决定。定理 4 是它最小的例子。
- 一旦结构里有**回复**——系统可以回到与从前能做同样事情的状态，例如重组之后又回到等价的组织——"此刻是哪一点"就不再是事实（定理 3）。
- 所以：**线性时间不是时间本身，而是"扰动不可撤销"时的时间。** 在有回复的结构里，时间不是一个事实，只有结构是。

**物理的"预测演化还是结构"**（只作启发）：
- 结构 = 余下行为的全体 = 不变的事实；演化 = 结构加上位置。
- 在有回复的世界里，位置不能从事实中得到，而只能靠记录（此刻的读数）；在不可撤销的世界里，起点就是事实。
- "预测结构"是一个可以完整陈述的任务（定理 1），它不要求一个全局状态沿一条时间线演化。

**ML 的评价**：
- 系统的事实决定它的结构；快照上的一组回答反映的是位置。
- 对一个会重组、会回到等价状态的记忆，快照上的回答不是它的事实（定理 3 的情形）。

## 3. 一个读取即更新的记忆

比翻转的记忆更像真的记忆：**两格，按最近使用的先后排列**（`Circumstances.lean` §7）。
- 存一个项，它放到最前；满了，就挤掉最久没用的。
- 读一个项：在就回答"在"，并把它移到最前；不在就回答"不在"，什么都不变。

**读取会改变它**：读一次，就改变了之后谁会被挤掉。

已证明：

| 定理 | 内容 | 性质 |
|---|---|---|
| `lru_store_read` | 存了再读，一定在——在任何历史之后 | 不变的事实（关系） |
| `lru_read_protects` | 存 0、存 1、**读 0**、存 2，之后 0 还在——在任何历史之后 | 不变的事实（关系） |
| `lru_no_read_evicts` | 存 0、存 1、存 2（**没有读**），之后 0 不在了——在任何历史之后 | 不变的事实（关系） |
| `lru_disturbed` | 由上面两条：两段历史只差一次读取，之后的回答就不同 | 被扰动：**读取即更新** |
| `lru_read_repeatable` | 同一个项接着再读，回答不变 | 可复读 |
| `lru_snapshot_depends` | 某一时刻读 0 的结果，取决于之前发生了什么 | 快照不是事实 |
| `lru_two` | 连续存两个不同的项之后，内容恰是这两项，与之前无关 | 引理 |

读法：
- **这个记忆的定义性质，就是几条关系的不变事实**：存了能读到；读过的受保护；没读过的会被挤掉。它们在任何历史之后都成立，是公共的、可复读的记录。
- **没有一条是某个快照上的分数。** 某一时刻"读 0 在不在"取决于历史，不是这个记忆的事实。
- 它同时满足"可复读"（再读一次回答不变）与"被扰动"（读取改变以后）——扰动改变的是**别的**、**以后的**回答（与 `47 §4` 做标记的记忆同类）。
- 所以对这样的系统，**评价 = 检查哪些关系的事实成立**，不必压成一个数；这正是 `46 §6` 所说的可信的评价。

**如实说明**：这种缓存是教科书里的东西。这里的要点只在于：它的"读取即更新"可以被精确地陈述，而它的定义自然地就是一组关系的不变事实——不是一个预测目标，也不是一个分数。

## 4. 随机的情形（下一步，未形式化）

- 有随机性时，余下行为换成**给定历史之后，此后回答的条件规律**。
- 于是"再问"与"之前问了什么"分开了：
  - **随机**：条件规律不随历史变；
  - **扰动**：条件规律随历史变。
- 藏回扰动的最少隐藏状态，是不同条件规律的个数。这在计算力学里是已知的"因果态"，只作对照。
- 定理 1 应当照样成立：不变的事实（对每个条件规律都必然的性质）看见的，是条件规律的全体。这要用 mathlib 的概率来写，**待做**。

## 6. 已知的与这里的

**已知的，只作指导**：
- 自动机的余下部分与最小状态；
- 动力系统里的不变量、回复与不可逆；
- 最近使用顺序的缓存；
- 计算力学的因果态。

**这里的**：
1. **事实看见结构，看不见位置**（定理 1），以及位置何时是事实的一般判据（定理 5）。
2. **经典的世界里结构与位置不可区分**（定理 2）；有回复时位置不是事实（定理 3）；扰动不可撤销时起点是事实（定理 4）。
3. **线性时间是"扰动不可撤销"时的时间**：记录只增不减，于是位置由事实决定；有回复时，时间不是事实，只有结构是。
4. **一个读取即更新的记忆**：它的定义性质是几条关系的不变事实；快照上的回答不是它的事实。
