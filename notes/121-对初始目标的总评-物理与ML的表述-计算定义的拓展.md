### 1.2 总的判断

- **诊断变成了理论**：第一轮的诊断——四堵墙是同一堵，那条隐形公理是 GLU₀——现在是一个有模型、有一致性强度、有可读公理的体系 B；它的两层（概率、过程）有真正的新定理。
  - 例如：隐藏比率的相变；刚性对一切比值有界的同步成立（`120`）。
- **新数学在哪里**：
  - 底座本身的数学强度与已知的泛型绝对性理论相同，新的是分类与读法；
  - 概率与过程两层的定理是新的，工具是标准的；
  - 集合论范围留下一个具体的开放问题 Q\*\*（`118`）。
- **与设想的偏差**：
  - 设想是"底层是测量、顶层借用集合的符号"。实际得到的是：
    - **底层是可数的记录（全局）**；
    - **顶层是完成的总体（局部）**；
    - 两者之间由记录化（扩张）连接。
  - 这其实就是设想的一个严格形式：集合的完成总体（幂集、ℝ、选择对象）确实只是"顶层"——它们不是全局对象。只是连接两层的不是概率，而是记录化。
  - 概率在这个体系里是被推出的：定律全局、样本局部（`61`）。
- **应用层**：对物理与 ML，体系给出的是陈述问题的精确形式，不是理论或指标（`52 §3.3` 的判断仍然成立）。§3、§4 把这一点推进一步。

## 2. 统一的形状：全局 = 在一切个别化下不变

三处已证的结论有同一个形状：

| 层 | "选择"是什么 | 在一切选择下不变的（全局的）内容 | 出处 |
|---|---|---|---|
| 底座 | 一个世界（一次记录化的路径） | 可数核的理论（M4）；有限层（ω 标准） | `55`、`72` |
| 过程 | 一个位置（此刻是哪种情形） | 结构：余下行为的全体 | `48`、`49` |
| 部分可交换 | 一个线性化（日程） | 迹 + 隐藏比率（仅当同步没有特征尺度） | `65`、`120` |

**经典的要求都是"作出一个选择"**：
- 一个宇宙（ZFC）；
- 一条时间演化（线性时间 = 个别化的下标，`49`）；
- 一个样本空间（Kolmogorov）；
- 一个标量指标（§4）。

**对"墙"的精确说法**：
- 墙不是某个选择错了，而是把一个选择的内容当成了全局的内容。
- 突破墙之后"变得无法描述"，是因为经典的描述语言只有"一个选择之内"的词汇。
- 体系提供的是**"在一切选择下不变"的词汇**：全局的、结构、迹与比率、偏序。

这给物理、ML、计算三个问题一个共同的提法：**在所要求的那个选择之下，什么是不变的？**

## 3. 理论物理：预测什么

### 3.1 底座能严格说出的

1. **结构与位置**（`48`）：
   - 一个行为的不变事实，恰好决定它可能处于的一切情形的全体（结构），决定不了此刻是哪一个（位置）；
   - 预测 = 结构 + 位置。
   - 所以"预测演化还是预测结构"有一个精确的形式：**演化 = 结构加上一个位置的个别化；结构 = 在一切个别化下不变的部分。**
   - 位置是事实，当且仅当扰动不可撤销（`48 §2`）。在会回到原处的系统中，"此刻是哪一点"不是事实，要求预测它就是要求一个不存在的事实。
2. **隐藏的全局结构 ⟺ GLU**（`65`）：
   - 一族语境上的定律有隐藏变量模型，当且仅当局部的定律能粘成一个全局的定律；
   - de Finetti 与 Bell 是这同一个定理的两端；
   - 它的失败程度 η 是有限的、算术的，在一切世界中相同（`68`）。
   - 已知：Abramsky–Brandenburger 的层论表述。这里新的是它与 de Finetti 是同一定理，以及它与世界的汇合无关。
3. **全局的时间率是涌现的隐藏参数**（`120` T2、T3）：
   - 对在检查点处部分同步的若干条链（时钟），除了因果偏序（迹）之外，唯一的全局参数是相对速率；
   - 它存在，当且仅当同步没有特征尺度（liminf ρ > 0）；
   - ρ → 0 时，相对速率被同步唯一决定（刚性）。
4. **触发器的循环**（`51`）：公共而被扰动 ⟹ 干扰。共享的记录由会改变被读者的提问产生时，提问之间必然互相干扰。

### 3.2 一个新的精确陈述：由理论设计的触发器看不见新鲜的现象

**命题 1**：设 w 是一个世界（"当前的理论"能写出的一切描述），(T_n) 是 w 中编码的一列事件（"触发器"），Σ_n μ(T_n) < ∞。若 x 相对于 w 是新鲜的（在 w 上随机），则 x 只落在有限多个 T_n 中。

*证明*：{y : 有无穷多个 n 使 y ∈ T_n} 由 Borel–Cantelli 是零测的，并且编码在 w 中。随机实数避开 w 编码的一切零测集。∎

- 这是 Solovay 检验（已知）在底座中的读法。
- **读法**：
  - 一个由当前理论设计、只挑选稀有事件（概率可和）的触发器序列，对"相对于这个理论新鲜的"现象，最终是盲的；
  - 只有不依赖理论的、测度为正的采样才能以正的频率抓到它（`61` 定理 B：新鲜的样本躲开一切局部点集，只有描述能被命中）。
- 这把"实验需要理论来训练触发器、理论需要实验来启发"的循环写成一个定理的形状：
  - 循环不是态度问题；
  - 稀有事件的选择性记录只能确认理论已经能描述的东西。
- **边界**：命题 1 只说"可和的稀有触发器"；实际的触发器是否满足它，是物理的问题，不在这里判断。

### 3.3 提示的研究问题

- **P-1**：一个关系主义的理论应当预测什么？体系的回答形状是"在一切个别化下不变的量"。
  - 需要回答的具体问题：对给定的一族提问情形（`47` 的四种），不变量的全体是什么格？
  - 它比"演化方程"少了位置，比"结构"多了哪些东西？
- **P-2**：检验"全局时间率是涌现的"是否能落到一个可以检验的模型上：一组只在事件处同步的时钟，其相对速率的可辨识性 ⟺ ρ → 0。
  - 这是一个概率论的定理，但它的物理读法需要物理学家判断，本项目不做。

## 4. ML：放弃单一标量之后怎样度量

### 4.1 底座能严格说出的

1. **可重做的评价只看见终局**（`53`）：
   - 对不可逆地改变的系统（持续学习），任何时间不变的评价，给出的值与它能变成的任何东西相同；
   - 要看见此刻的能力，就得按时间个别化，而这样的记录不能重做。
   - 这是一个真的取舍，不是方法不够好。
2. **失败的度量是藏回去的代价**（`47`）：
   - 最少隐藏状态 = 余下行为的个数。
   - 这是 Myhill–Nerode 定理在"提问者依赖的行为"上的形态（已知的核心，新的是四种情形的推广）。
3. **次序谱**（`66`）：
   - 一个学习系统对提问次序的依赖，被一个组（类内重排之组的像）精确刻画；
   - 可交换 ⟺ 次序谱只有一个成员；
   - 次序熵按类相加。
   - 这是一个不是标量的、经典看不见的不变量。
4. **学习的精度不依赖同步，隐藏参数的存在依赖同步**（`88`、`120`）：
   - 在隐藏比率存在处，后验相合，√n 速率，方差与无约束时相同。

### 4.2 一个新的精确陈述：标量指标就是一个线性扩张

**设定**：设学习系统的集合为 𝒮，"A 维持了 B 维持的一切事实"定义了一个偏序 ≤（`46 §6`、`47 §5`：评价按事实的包含关系比较）。

**命题 2**（Szpilrajn、Dushnik–Miller，已知的序理论）：
1. 一个标量指标 f : 𝒮 → ℝ **忠实地**表示 ≤（A ≤ B ⟺ f(A) ≤ f(B)），当且仅当 ≤ 是全序，并且满足可分性（Debreu 条件；可数时自动成立）。
2. 每个偏序都是它的全部线性扩张的交（Dushnik–Miller）。所以：
   > **一切与事实相容的排名的共同内容，恰好就是事实的偏序本身。**
3. 忠实地表示 ≤ 所需的标量的最少个数，是 ≤ 的**序维数** dim(≤)（Dushnik–Miller）：
   - A ≤ B ⟺ 对一切 i，f_i(A) ≤ f_i(B)；
   - k 种彼此独立的能力组成的布尔格，序维数恰为 k。

**读法**（这是对 prompt 中"小怪圈"的精确化）：
- **"必须给一个标量"** = 要求选定一个线性扩张。
  - 当 ≤ 不是全序时，这个选择不是由事实决定的；
  - 不同的选择给出不同的排名，而它们的共同内容就是偏序。
- **"有标量就不算智能"** = 注意到那个线性扩张不是全局的事实。
- 两个论点各自正确，连起来成了循环，因为它们都默认"评价 = 一个全局的标量"。
- **出路**（不是指标，而是报告的形式）：报告偏序本身，或者 dim(≤) 个标量。
  - dim(≤) 是任务族的一个不变量，可以先于任何模型计算出来。
  - 单一标量合法，当且仅当 dim(≤) = 1。
- 这与底座的形状一致（§2）：排名是一个选择，偏序是在一切选择下不变的内容。

### 4.3 对"非自回归、无 reward 的记忆组织"的表述

- **自回归**：把一个过程写成"给定全部过去、预测下一个"，就是选定了一个线性的个别化（`49`）。
  - 当被建模的流只是部分可交换时（例如多个相互独立、偶尔同步的来源），线性化引入了一个不属于事实的次序。
- **隐藏参数的精确清单**（`120` T2–T3）：对部分可交换的流，除迹（依赖图给出的偏序）与新鲜的局部洗牌之外，唯一的全局隐藏参数是各分量之间的相对速率，并且只在同步没有特征尺度时存在。
  - 所以一个"以记忆组织为中心"的学习系统，要学的全局结构恰好是：依赖图、分量上的各自的规律、以及（在尺度不变的同步下）速率。
  - 它不需要学一个全局的"下一个"。
- **评价**：
  - 这样的系统可以按 §4.2 的偏序比较：维持了哪些迹上的事实，辨识了哪些速率；
  - 次序谱（`66`）度量它对提问次序的敏感度。
- **边界**：这是**问题的形式**，不是架构或数据集。

### 4.4 提示的研究问题

- **M-1**：对一个具体的任务族，计算事实包含序的序维数。它就是"至少需要几个指标"的答案。
- **M-2**：持续学习的"时间不变 / 按时间个别化"的取舍（`53`），有没有一个中间形式？
  - 候选：按次序谱的轨道个别化，而不是按时间个别化。它只记住"次序的类"，不记住时间。

## 5. 计算的定义：可能的拓展

### 5.1 已有的（`39`）

- Gandy 的机器原则恰是原点处的 GLU：锐的回答、良基、单一全局上下文、局部数据唯一地粘成整体。
- 离开原点，改的是粘合（π：值、形状、对称、上下文），不是机器。于是"计算"分裂为对 π 可解的任务：
  - 对称之下选不出领袖；
  - 集合与计数看得见不同的东西；
  - 硬币打破确定性打不破的对称；
  - 在有限系统上，对象恰是确定性局部计算的分辨极限。
- 这些在分布式计算中都有已知的对应，新的是框架。

### 5.2 拓展一：计算 = 答案沿记录化的稳定

**观察**：三个已知的"可判定"概念，是同一个概念在三个层次上的实例——**一个问题的答案沿一个有向的记录化系统何时稳定**：

| 层次 | 记录化的系统 | "答案稳定"的形式 | 已知的名字 |
|---|---|---|---|
| 有限 | 计算的有限阶段（线性） | 在一个可计算地知道的阶段确定 | Turing 可判定 |
| 有限 | 同上 | 在某个未知的阶段之后不再改变 | 极限可计算（Δ⁰₂），Gold–Putnam 的"极限中学习" |
| 无穷 | 世界的扩张（有向，S4.2） | 从一开始就不随扩张改变 | 泛型绝对性（M4）：可数核是"全局可判定的" |

**Hamkins–Löwe 的按钮与开关**给出第三行的细分：
- **固定的**：可数核的陈述（M4）；
- **按钮**：可以被强迫成永远为真，例如"有一个不在 L 中的实数"；
- **开关**：可以反复翻转，例如 CH。

它们与第一行的算术层级**形状相似**：
- 按钮与 Σ⁰₁ 相似：一旦出现见证，就永远为真；
- 开关与不稳定的问题相似。

但线性的阶段系统中没有"可能"的分叉，模态的区分会退化。这个相似能否成为精确的对应，是 C-1 要确定的。

**提议的定义**（研究计划，不是定理）：

> 设 E 是一个有向的记录化系统（阶段与"补充记录"的关系）。一个问题相对于 E **可计算**，如果它的答案在 E 的每条路径上最终稳定，并且稳定的阶段可以由已有的记录确定。

- 丘奇—图灵论题是 E = "有限计算阶段、ω 标准、线性"的情形。
- 底座 B 给出 E = 世界的扩张，其中：
  - "ZFC 不可判定"读作"沿记录化不稳定"（开关）；
  - 或"稳定但不从一开始"（按钮）。
- **这给出 ZFC 独立性的一个计算的读法**：独立的命题不是"太难算"，而是它的答案**沿记录化不收敛**。M4 说的是可数的问题都从一开始收敛。

**需要做的**：
- **C-1**：对有限阶段的系统，把"按钮/开关"的模态逻辑与算术层级的对应写成定理。
  - 线性阶段应当给出 S4.3；
  - 分叉（非确定的）计算给出 S4.2 或 S4。
- **C-2**：对世界的扩张，把"一切 Σ¹ₙ 句子的稳定类型"分类，看它是否与算术层级有精确的平行。

### 5.3 拓展二：计算 = 最小的藏回去

- 一台机器就是把"对历史的依赖"藏进状态的一种方式。最小的机器的状态数 = 余下行为的个数（`47`；Myhill–Nerode 的推广）。
- **部分可交换时**：
  - 历史只按迹（偏序）计。Zielonka 定理（已知）说：每个正则的迹语言都能由局部的、异步的自动机实现。这是计算中的一个 **GLU 成立的定理**：全局的行为粘成了局部的机制，代价是状态的膨胀。
  - 体系的 `120` 在无穷时间上补上了另一半：在迹之外，唯一不能由局部机制在有限时间内确定的全局参数是相对速率，并且它存在 ⟺ 同步没有特征尺度。
- **拓展的形式**：
  - 计算的"全局内容" = 事件的偏序（迹）+ 速率；
  - 在一切调度（个别化）下不变的只有它们。
  - 一台图灵机是选定了一个调度的描述。
- **C-3（研究问题）**：Zielonka 定理的"代价"（局部状态的膨胀）与 `47` 的"藏回去的代价"之间，是否有一个统一的下界——局部实现一个全局行为的最小代价，由余下迹行为的个数给出？

### 5.4 拓展三：沿 π 的其他参数

`39 §3` 表中未做的两项：
- **形状**：非良基的形状给出无穷的行为（共归纳的计算），它的"原点"是有限的计算；
- **上下文**：没有全局时钟的异步系统，其中的不可能性是否正是"局部存在而没有整体"。

它们与 §5.2、§5.3 合在一起，构成计算定义的三条拓展线：
- 稳定（沿记录化）；
- 藏回去（最小实现）；
- 粘合（π）。
