# 25 · 构造出来的拓展：它们是什么，怎么写

> **第十三轮注**：§5 的"共同核心是 IZF"指的是内层——各个情况在内部满足的理论——不是替换公理体系；保守性在外层。IZF 比 ZFC 弱，IZF + 选择 = ZFC。见 `26`。
>
> **第十四轮注**：§5 把 IZF 写成"家族的写法"的核心，强调放错了位置。IZF 只是各实例在内部共有的剩余，**不是拓展**。拓展是一条公理模式 GLU(π)：经典记录是原点实例，本篇的各个构造是其他实例的对象。见 `27`。
>
> **第十五轮注**：§4–5 把权重只读成"真值上的态"，是过度约简。权重还是局部数据本身的值（"y 以多大权重属于 x"），它是参数 W；π =（W，S，𝒞）。见 `28`。

> 接 `24`。上一篇说：拓展就是换 GLU₀ 的形容词，由一个构造 U(π) 给出。本篇把这些构造逐个做出来，写出每一个满足的公理——也就是换了形容词之后，GLU₀ 实际长什么样。
>
> 形式化：
> - `lean/Shapes.lean` §8：形状的拓展，完整构造。带基点的图按互模拟认同；在这个宇宙里，每个系统恰有一个解，小族可以粘合，Ω = {Ω} 存在，良基树嵌入其中，相等与隶属都被保持和反映。新增 17 条，只用到 `propext`、`Quot.sound`，**不用选择**。
> - `lean/Supports.lean`：对称的拓展里，选择失败，是因为没有一个上下文命名了所有原子。5 条，都不依赖任何公理。
>
> 文献最后核查。

## 0. 自检

- 只做 `24` 的四个参数。每个都给出四样东西：构造；写法（它满足的公理）；经典原点的像；变得可描述的东西。
- **不拼图**：做完后要看四个构造之间是否其实是同一件事。结果是参数比四个少（§5）。
- **不迷失在形式化**：只把最干净的一个（形状）完整做出来；其余只形式化承重的那一步。

## 1. 形状：删去"良基的"

**构造。** 带基点的图——结点、"是……的子结点"的关系、一个基点——按互模拟认同。
隶属的定义：G ∈ H，当且仅当 G 与"H 在其基点的某个子结点处重新取基点"互模拟。

**写法。** GLU₀ 删去"良基的"：
> 记录恰好是小的局部数据的唯一粘合，任意形状；小的族也有非唯一的粘合。

在构造出的宇宙里逐条检查（`Shapes.lean` §8）：

| 条款 | 在构造出的宇宙里 | 定理 |
|---|---|---|
| 唯一 | 变成强外延：互模拟即相等 | `UA.strong` |
| 确定的存在 | 小族可以粘合 | `UA.mem_sum` |
| 形状 | 每个系统恰有一个解（反基础公理 AFA） | `UA.afa` |
| 非唯一的存在 | 核心有选择时成立（未形式化） | — |

标准写法：ZFC⁻ + AFA（Aczel）。

**经典原点。** 良基树嵌入其中，相等与隶属都被保持和反映（`UA.embed_eq_iff`、`UA.embed_mem_iff`）：经典宇宙原样坐在里面。

**变得可描述的。**
- 自属的 Ω = {Ω}（`UA.omega_self`），而且它是环 x = {x} 的唯一解；对照 `quine_not_strong`：只有外延时，这个环有两个解。
- 由有限方程组给出的无限对象。例如 x = {0, y}、y = {1, x} 有唯一解：对象是"解"出来的，不是逐层构造出来的。
- 按关系认同：两个对象相等，当且仅当它们的展开无法区分（互模拟）。

**代价。** ∈-归纳失效。递归只在良基部分可用；一般对象的相等要靠互模拟来证。

**没有用到选择。** 这个拓展只推广了确定的粘合（`24 §3` 条款 1–3），所以整个构造不需要选择。这与 `23 §4`"唯一处，存在免费"一致。

## 2. 对称：局部数据只在某个上下文中给出

**构造。** 在带原子的核心里，取：
- 原子集 A；
- A 上的置换群 G；
- 子群的一个正规滤子 𝓕；

保留遗传对称的集合，即稳定子属于 𝓕 的集合。基本情形是：𝓕 由"固定有限个原子"的子群生成——**有限支撑**。

**写法。** GLU₀ 加上"有支撑的"：
> 记录恰好是小的、良基的、有支撑的局部数据的唯一粘合——原子除外；非唯一的粘合只在某个支撑能给出它时存在。

标准写法（有限支撑）：FM 集合论（Gabbay–Pitts），即 ZFA + 原子无穷 + 每个集合都有有限支撑（待核验）。

**读法：支撑就是上下文。** 一个对象有支撑 E，就是说它在"命名了 E 中原子"的上下文里被给出：不被命名的原子之间怎么置换，都不改变它。
- 原子的全体，支撑是空的：在任何上下文里都给得出。
- 单个原子 a 的支撑是 {a}：要命名它，才给得出它。
- 从每一对原子中选一个的函数，它的支撑必须命名除至多一个之外的所有原子（`Supports.no_choice_outside`）。没有有限的上下文做得到（`Supports.no_finite_context_chooses`）。

Russell 的袜子（`21 §5`、`Socks.lean`）在这里就是原子对：
- 均匀权重的支撑是空的，在任何上下文里都给得出；
- 选取，则要求命名。

**选择的失败，就是缺一个全局上下文。** 原本当作两种不同的不适用：
- 数得出、分不开的个体；
- 没有全局上下文。

在这里它们是同一件事：一个个体不可分辨，就是因为手头没有一个上下文命名它。

**经典原点。** 纯集合（核）。

**分级。** 换滤子，就是换上下文的"大小"：有限支撑、可数支撑……不同的滤子给出不同强度的选择原理（例如可数支撑下依赖选择是否成立，待核验）。这是 `23 §4b`"选择按对称分级"的具体形态。

## 3. 值与上下文：局部数据在一个位形的覆盖上粘合

**构造。** 取 Ω 为完备 Heyting 代数，即一个位形的开集格。
- Ω-名：隶属取值于 Ω 的良基带基点系统。
- [[x ∈ y]]、[[x = y]] ∈ Ω，都是递归定义的。

**写法。** 把 GLU₀ 中的"锐的、全局的"换成"Ω-局部的"：
> 记录恰好是小的、良基的局部数据的唯一粘合；局部数据在 Ω 的覆盖上给出，在各块上相容就粘成唯一的整体。

两个关键性质：
- **混合**，即沿覆盖的确定粘合。给定一个覆盖，以及在各块上给出、在重叠处相容的名，就有粘合出来的名。这是确定的粘合，不用选择。（布尔情形是标准的混合引理；Heyting 情形待核验。）
- **见证的存在**，即极大原理：若 [[∃x φ(x)]] = u，是否有一个名 x 使 [[φ(x)]] = u？
  - Ω 是布尔的：覆盖可以取成互不相交，各块上**选出**的见证可以混合成一个。所以它成立，但要用到核心的选择。
  - Ω 不是布尔的：覆盖一般必须重叠，各块上选出的见证在重叠处未必一致，粘不起来。

标准写法：
- 一般的 Ω：IZF（Grayson、Fourman–Scott）；
- Ω 是完备布尔代数：ZFC（Scott–Solovay–Vopěnka）。

**读法：真值是上下文。** [[φ]] ∈ Ω 就是"φ 在哪些上下文中成立"。所以"真值有程度"与"真值随上下文变化"，是同一件事的两种说法。

**经典原点。** 检验名，即每处都取同一值的常数据。

**变得可描述的。** 真值随上下文变化。Ω 可以没有点，也就是没有全局上下文，而整体的对象照样存在。

## 4. 权重：真值上的态

**构造。** 取 Ω = B 为测度代数，μ 为其上的概率。一个陈述的概率是 Pr(φ) = μ([[φ]])。

**写法。** GLU 本身不变，只是在真值上多了一个态：
- ZFC 的公理，概率为 1；
- 实数是随机变量（Scott）；
- 不带参数的陈述，概率为 0 或 1（齐性）；带随机参数的陈述，取中间值（`17 §5(d)`）。

**经典原点。** μ 是 2 上的点质量。

**所以权重不是宇宙的参数。** 它是 §3 的宇宙在真值上的一个态。`24 §4` 里"值"这一行其实包含两件事：
- 作为真值的代数，归入 §3；
- 真值上的权重，即本节。

## 5. 构造之间：参数比四个少

逐个做出来之后，`24 §4` 的四个参数并不是四样东西：
1. **值（作为真值）与上下文是同一个参数。** 完备 Heyting 代数就是一个位形的开集格；Ω 值宇宙，就是这个位形上的对象所组成的宇宙（Fourman–Scott，待核验）。
2. **对称也是一种上下文结构。** 它的上下文是支撑。置换模型也可以写成某类上下文结构上的模型（Fourman、Freyd；有限支撑时即 nominal 集合，待核验）。
3. **权重是真值上的态**，不是宇宙的参数。

于是宇宙的参数只剩两个：
- **形状 S**；
- **上下文结构 𝒞**，它把对称、真值的程度、局部性都包括在内。

权重是真值上的态。经典原点是（良基，单点）。

| 𝒞 \ S | 良基 | 一切图 |
|---|---|---|
| 单点 | ZFC | ZFC⁻ + AFA（§1，已构造） |
| 有限支撑 | FM 集合论：ZFA + 有限支撑；选择失败 | 带原子的 AFA + 有限支撑（待核验） |
| 完备布尔代数 | ZFC；真值是事件 | 布尔值的 AFA（待核验） |
| 非布尔位形 | IZF；排中律与选择都失效 | IZF 去掉 ∈-归纳、加上 AFA（待核验） |

**共同的核心。** 表中每个宇宙，在内部都满足 IZF（良基一列），或 IZF 的反基础版本（右列）。而 IZF 大致就是：
- GLU₀ 的条款 1–3 加上大小，也就是确定的粘合；
- 用直觉主义逻辑写出来（IZF 用收集公理代替替换）。

各个宇宙的差别只在两件事上：
- 条款 4（非唯一的粘合）回来多少；
- 锐性（排中律）回来多少。

由 Diaconescu，IZF + 选择 = ZFC：条款 4 一回来，锐性也就跟着回来了。按上下文结构看：

| 上下文结构 | 锐性 | 条款 4 |
|---|---|---|
| 单点 | 有 | 有 |
| 完备布尔代数：覆盖可以互不相交，没有对称 | 有 | 有：各块上的见证可以混合 |
| 有限支撑：有对称 | 有 | 只在支撑允许处 |
| 非布尔位形：覆盖必须重叠 | 无 | 无 |

**读法（待证）。** 失去全局上下文之后，选择还能否保留，取决于局部的选择能否沿上下文结构粘起来：
- 覆盖可以不相交、并且没有对称时，能；
- 覆盖必须重叠，或者有对称时，不能。

这三种情形各自是已知的定理：布尔值模型满足选择；置换模型里选择失败；Diaconescu。把它们统一成一条定理，尚未做。

**于是整个家族可以这样写：**
> **IZF（确定的粘合）+ 形状 S + 上下文结构 𝒞；𝒞 决定条款 4 与锐性回来多少；权重是真值上的态。经典原点是 S = 良基、𝒞 = 单点，此时 IZF + 选择 = ZFC。**

## 6. 对照开头那段话

| 倾向 | 落在哪个参数上 | 在构造出的拓展里，变得可描述的 |
|---|---|---|
| 线性时间 | S | 由解方程得到的对象；良基的递归是它的特例（§1，已构造） |
| 还原论 | S；𝒞 | 按关系认同（互模拟）；不被上下文命名的个体（原子） |
| 绝对因果、目标拟合 | 条款 4，由 𝒞 决定回来多少 | 选择只在上下文允许处存在 |
| 绝对状态 | 𝒞 | 真值随上下文变化；没有全局的点，整体的对象照样存在 |

症状"突破之后无法描述"：在这些构造出的宇宙里，每一种不适用的情形都是一个对象，而每个宇宙都含有经典原点。
