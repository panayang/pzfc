  - 概率一侧回答了"与次序无关的全局参数何时存在"；

## 2. 三个体系层面的结论

### 2.1 部分可交换的一般表示，在正则的同步下闭合

- **隐藏参数的完整刻画**：给定迹，一个部分可交换的过程**恰好在**同步没有特征尺度（liminf ρ > 0）时带有隐藏的全局参数；这个参数就是比率，不多也不少（`88`、`98`）。
  - 在它存在处，de Finetti 的学习理论原样成立（`88`）；
  - 在它不存在处，给定迹之后次序是均匀的，不携带信息（`97`、`98`）。
- **对最初的墙**（`00` 的"目标拟合"与"线性时间"）：
  - "按时间线性化的评价是否丢失信息"有一个精确判据：同步是否尺度不变；
  - 丢失的东西是一个可以以 √n 的速率学到的实数，而不是一个无法命名的残差。

### 2.2 不规则只在世界之间

- 由 `95`、`100`：
  - 一切由实数可定义的记录，对局部点集全有或全无；
  - 对测度典型的覆盖码只能覆盖零测集；
  - 部分失去最自然的形式是"选择性地消灭一个较小世界的实数"。
- 所以测度中最不规则的现象若存在，它的参数是**一个世界的全部实数**：不是一个实数，也不是一个可定义的集合，而是世界之间的关系。

### 2.3 M4 压制可能性的分叉

- 由 `101`：M4 使 0# 存在并被一切后继世界认得，于是 L 的理论被冻结；Σ₁ 断言在一个坍缩扩张中汇合。
- 这修正了 `71`、`72` 的"两条界线"图景中的一半：
  - 那里说"良基管可能性"：良基时 S4.2（汇合），非良基的 D 时 S4（分叉）；
  - 现在看到，**非良基的高度本身不产生分叉**。不带 M4 时分叉确实发生（`101` 定理 3）；带 M4 时，最自然的分叉见证全部失效。
  - 所以可能性是否汇合，至少同样取决于**可数核是否固定**（M4）。
- **新的猜想**：D₄（带 M4 的 D）的模态逻辑仍是 S4.2。若成立，"良基"这条界线对可能性不是必要的：在 M4 之下，可数核的固定就足以使可能性汇合。

## 3. 体系闭合还需要什么

按"一个公理系统要闭合，需要什么"来列，不按问题的难度。

### 3.1 必需的（缺了它，体系在逻辑上不完整）

1. **B + M2a′ 的一致性证明，写成一个定理**。
   - 现有的模型（`74` 的稀疏与有向模型、`89` 的全局配对模型、`95` 的丰富解释）分散在各篇中；M2a′ 是后加的。
   - 需要：从一个明确的大基数假设出发（例如：真类多个 Woodin 基数），构造一个满足 M1–M4 + M2a′ 的模型，并写明 M4 的一致性强度。
   - `55 §3.5` 写的"约为无穷多个强基数"尚未核验，列入待核验。
2. **"全局的数学"的外延**。
   - 体系断言：全局 = 可数核的理论。但 B 本身不固定 Th(H(ω₁))：不同的 B 的模型可以有不同的可数核。
   - 需要回答：M4 推出多少？例如，是否推出投影决定性（PD）？若推出，全局的数学就是"PD 下的描述集合论加算术"，这是一个有确定内容的陈述；若不推出，要说明哪些投影命题是全局的而又不被 B 判定。
   - 这是底座的一个**实质缺口**：没有它，"全局的数学"只是一个形式上的类。
3. **"换世界"方法的形式化**（`55 §4.3`、`55 §8`）。在 Lean 中写出 M1–M4 的形状，以及"在扩张中证明、由 M4 带回"的有效性。
   - 这是方法论层面的闭合：体系给数学家的主要工具应当是一条定理，而不只是一段说明。

### 3.2 应当有的（缺了它，某一层有一个明确的洞）

4. **过程层**：
   - `73` 的猜想（刚性 ⟺ 至多一个存活比率）对多于两条链的一般依赖图仍开放；两条链、正则同步的情形由 `98` 定理 3 给出。
   - 相变的临界情形（ρ → 0 但 ω′P/ω → 1）与不规则的窗口仍开放（`98 §7`）。
5. **概率层与底座之间**：命运窗口的内部（`100` 的 Q\*）。它不影响概率层（事件是描述），但它是"测度属于描述"这一原则的边界：若 Q\* 为真，局部点集的测度可以被一次扩张部分地决定。
6. **模态**：D₄ 的模态逻辑（`101 §5`，mantle 候选）。它决定 §2.3 的新猜想。

### 3.3 不需要的

- 汇合高度的精确值（`71`）：它不改变任何层面的结论，只改变一个上界与下界之间的数。
- 非正则窗口的完整分类：定理 3 已覆盖一切自然的例子。

## 4. 有意思的方向（可能由这套体系得出有意思的结论）

1. **次序信息的统计检验**。
   - `98` 定理 3 与 `88` 给出一个可检验的二分：在带同步点的多流数据中（分布式日志、多智能体交互、带检查点的训练日志），
     - 若同步间隔与经过的时间成比例，存在一个可以以 √n 学到的全局比率；
     - 若同步间隔相对于时间可以忽略，给定迹之后次序是均匀的。
   - 这给 `00` 的"目标拟合之墙"一个定量的回答：评价一个按时间线性化的系统时，丢失的信息恰好是这个比率。
   - **可以做的**：写出检验统计量（迹的计数），给出两种情形下的渐近分布（`88` 定理 4 与 `98` 的均匀性），在合成数据上验证。
2. **命运窗口 = 由世界实现的测度扩张**。
   - `100` 定理 1 把扩张对旧点集的作用写成一个夹在内外测度之间的外测度 ν。
   - 自然的问题：哪些这样的 ν 能由世界实现？这是 Łoś–Marczewski 的测度扩张问题的一个"由强迫实现"的版本。
   - 若能刻画，就得到"局部测度的不确定性"的完整描述：一个集合的测度在一切扩张中能取的值的集合。
3. **M4 与可能性的汇合**（§2.3 的猜想）。
   - 若 D₄ 是 S4.2，就得到一个干净的定理："可数核固定 ⟹ 可能性汇合"，不依赖于高度是否良基。
   - 这会简化 `71`、`72` 的两条界线为一条：可数核。这是底座一侧最有价值的结构性问题。
4. **全局数学 = 泛型多宇宙中的不变量**。
   - B 的全局陈述正是在一切扩张下不变的陈述。在带 Woodin 基数的丰富解释中，它们应当与 Woodin 的"泛型多宇宙真理"相关联。
   - 需要检查的是：B 是否由此继承 Woodin 对泛型多宇宙观的批评，即那种真理可以化归为 Ω-逻辑的一个片段。
   - 这是对体系的一个**外部检验**，不是翻译。若成立，就要说明 B 的"全局"与 Ω-逻辑有何不同——例如：B 不假定汇合。

## 5. 下一步的建议（判断）

1. **先补 §3.1 第 2 条**：M4 推出多少。它是底座唯一的实质缺口，而且是一个有确定答案的集合论问题（需要文献核验：泛型绝对性的一致性强度、它与 PD 的关系）。
2. **然后是 §4 第 1 条**：它把概率一侧的闭合变成一个可以用数据检验的陈述，是回答最初那堵墙的最直接的一步。
3. Q\* 与 D₄ 的 .2 列入待核验与开放清单，不进入主线。
