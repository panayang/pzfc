## 1. 记录与 GLU：同一堵墙，从两边看

**GLU 看的是结果**：一族局部数据，是否来自同一个整体对象。
**记录看的是动作**：一个回答，能否再问而不变，能否抄出来与别的回答并排。

两者由一条定理接上（`Records.glues_iff_contextFree`，不依赖任何公理）：
- **一族在各个语境中给出的回答，来自同一个整体对象，当且仅当每个问题的回答是跨语境的记录**：同一个问题，在任何语境里、和任何别的问题一起问，回答都相同。
- 整体对象是唯一的（`glue_unique`）。
- 整体对象就是把这些记录并排放在一起得到的那份**联合记录**。

逐项对照：

| GLU 的成分 | 在记录的说法里 |
|---|---|
| 第一层：存在一个全局语境（V、Ω） | 存在一份总记录 |
| 存在（∃）：相容的局部数据粘得起来 | 回答能抄出来并排：并排得到的就是整体对象 |
| 唯一（!）：整体由局部数据决定 | 一个东西就是它的记录（外延） |
| 形状：良基 | 记录由记录分阶段写成——这是复读的代价（`42 §4`） |
| 值：锐 | 单个回答能复读 |
| 值：权重（Kolmogorov） | 每个来源都是记录的混合：先随机取定一份总记录 ω，之后一切回答都是它的读数 |

最后一行值得单独说：
- 有了整体的联合分布，就可以把它读成"先随机抽一份联合记录，再照着它回答"。有限的情形下，这就是联合分布的定义，已知的 Fine 定理是它在 Bell 情景中的形态。
- 所以 **Kolmogorov 的隐含前提，是"每个来源都是记录的混合"**。这是"一切回答都是记录"在概率里的样子：单次的回答可以不能复读，但只是因为我们不知道抽到了哪份记录。

**为什么说记录更靠前**：
- GLU 说的是"是否粘得起来"；记录说的是**为什么经典里总粘得起来**——因为回答被默认可以复读、复制、并排。
- 它还指出了**换成什么**：不能复读的回答，稳定的是统计；来源的身份是规律，不是记录。GLU 本身不提供这个替代。

## 2. GLU(π) 为什么没动墙：精确的说法

`41 §2` 说 GLU(π) 靠增加对象吸收失败。用记录的话，可以说得更准：
- GLU(π) 改的是**记录什么**——权重、随上下文的值、名字；没有改**回答是不是记录**。
- 种类里的每个对象，都是它全部回答的一份完成的记录：权重本身被当作固定的数据记下了。
- 所以"存在"的一半是同义反复（对象就是那份记录），整个拓展也是保守的：记录的世界本来就能描述任何被记下的东西。

## 3. 回答不是记录的三种方式

失败是一般情形，记录是特殊情形。回答可以在三处不是记录：

1. **再问一次不同**：单次回答不能复读，只有统计能复读。
   - 度量：复读缺陷（`42 §10`）。
   - Kolmogorov 用"背后有一份没看到的记录"来吸收它（§1 最后一行）。
2. **和不同的问题一起问，回答不同**：回答依赖语境，GLU 的存在在语境之间失败（§1 的定理）。
   - 物理中的 Bell、Kochen–Specker 属于这一类（已知，只作指导）。
3. **来源有规律，却没有任何一份记录**：
   - 定义：来源的一份记录，是一个结果，它对来源一切"必然"的问题（概率为 1 的问题）都回答"是"。
   - **没有原子的来源没有记录**（`Askable.no_record`）：
     - 对任何一个结果 x，"不是 x"这个问题的概率都是 1，而 x 回答"否"；
     - 所以没有哪个结果能代表这个来源。
   - **有限的部分总有记录**（`finite_part_has_record`）：只问有限多个问题时，总有一个结果的概率为正。

第 3 条在经典概率里**处处都在**，只是语言把它藏起来了：
- 公平的硬币序列、[0, 1] 上的均匀分布，都没有原子，所以都没有记录。
- Kolmogorov 把它们放在一个点的集合 Ω 上，每个点都是**另一个**来源（集中在这一点上的来源）的记录，而不是这个来源的记录：每个点都落在一个概率为 0 的集合里。
- 所以"有规律而无记录"不是奇怪的新东西，而是一切连续的随机性的常态。经典的语言只允许它以"点的混合"的形式出现。

这也给 P3（有限性）一个精确的位置：
- **记录只在有限处必然存在**；
- 无穷的来源要"被记下"，需要无穷多次有限的记录化，完成以后得到的点也不是这个来源的记录。

## 4. 可以问的问题

**定义**：
- 一个来源带有它的**有限读取**：只看有限多个回答就能判定的问题（对 0-1 序列：只看前几位的问题）。
- 一个问题对这个来源**可以问**，是指：对任意小的误差，都有一个有限读取，它答错的概率小于这个误差。
- 也就是：**问不能被一次问完，但可以用有限的读取，以任意高的可靠性回答。**

**定理**（`Askable.askable_iff`，一般形式；`bits_askable_iff`，0-1 序列）：
- 对任何有限的来源，**可以问的问题恰好是可测的问题**（至多差一个概率为 0 的集合）。
- 证明的两个方向：
  - 可测的都能用有限读取逼近（mathlib 中的逼近定理）；
  - 反过来，误差可求和的有限读取的上极限几乎处处等于这个问题（Borel–Cantelli 的第一半）。
- 这条定理本身是标准的测度论；这里的用法是新的：**可测性不作为公理，它就是"可以问"的意思。**

读法：
- **不可测集是不能问的"问题"**：它是一个点的集合，但没有任何有限的读取能以小的误差回答它。它可以作为记录的集合存在，却不是一个可以问的问题。
- **对记录，一切问题都可以问**（`record_all_askable`）。所以经典的"一切子集都是问题"，正是"一切来源都是记录"的形态。
- "一切集合都可测"（LM）混同了两件事：记录的集合，与可以问的问题。
- 你开头说"'子集'是某一种意义上的"。这里有两种子集：
  - 可以问的问题：以测量为核心的一种，底层；
  - 记录的集合：点的一种，顶层。

## 5. 第一版体系 T₀（弱底座）

**一条原则**：记录由可数多个有限的回答写成——每次记录化是有限的（P3），一份记录是一串这样的动作完成的结果。所以：**一切记录都是可数的。**

T₀ 由五部分组成：
- **记录的世界**：遗传可数集合的理论——ZFC 去掉幂集，再加"每个集合都可数"。
  - 已知它与二阶算术 Z₂ 可以互相翻译（待核验）。
  - 在这里选择成立（可数就能排成一列），线性时间也在：记录本来就沿 ω 一个个累积。**四个倾向住在记录的世界里，这没有问题；墙在于假定一切都在这里。**
- **来源**：一个可数的有限读取代数，带一个规律（有限读取的概率，满足可数可加的相容条件）。
  - 来源的**描述**本身是记录：规律是能复读的统计（`42 §5`）；来源的**回答**不是。
- **可以问的问题**：有限读取在规律的距离下的极限；距离是"两个问题回答不同的概率"。
  - 每个可以问的问题由一串有限读取表示，所以也是记录。
  - 来源放在点的集合上时，它们恰是可测的问题（§4）。
- **来源的记录**：对一切有限读取的一组相容的完整回答，对一切必然的问题都回答"是"。
  - 可以不存在（§3）；有限的部分总有。
- **联合来源**：一个来源，连同把各部分的有限读取嵌进去、保持规律的映射。
  - 部分不决定整体（`42 §10`）。

T₀ 里没有不可数的记录：
- "全体实数"不是记录，它是硬币来源；
- "ω 的一切子集"也是一个来源（`42` 的 S8）。

**回到经典**：
- **Kolmogorov**：
  - 标准空间上的概率测度由可数的数据决定，就是一个 T₀ 的来源；
  - 关于可数运算的经典定理（极限定理、可数生成的条件期望……）都是关于记录的陈述；
  - 在 Z₂ 的范围内，测度论的大部分都能做（反推数学的已知结果，待核验）。
- **ZFC**：
  - 任何一个 ZFC 宇宙，它的遗传可数部分都是 T₀ 的记录世界，来源也相同。
  - **ZFC 是 T₀ 的理想化完成**：把"一个来源的一切记录"也当作记录——不可数的总体成为记录。
- **强度**：T₀ 大约与 Z₂ 相当，比 ZFC 弱得多。它能证明的，ZFC 都能证明（作为关于遗传可数集合的陈述）。

**T₀ 里 CH 是什么**：
- 它不是 T₀ 的陈述，因为 T₀ 里没有不可数的记录。CH 问的是理想化的总记录，**这是消解，不是判定**。
- T₀ 能说的、关于连续统的问题，是两类：
  - **可以从记录构成的**实数集合，也就是可定义的集合，已知叫投影集；
  - 来源本身。
- 恰好在这里，ZFC 的独立性就已经出现了，例如"每个 Σ¹₂ 集合都可测吗"。所以 T₀ 单独太弱，需要原则。

## 6. 强底座 T₁ = T₀ + 两条原则

- **(A) 能构成的就能问。** 凡是能从记录构成的问题，对每个来源都可以问。
  - 读法：没有一个能写出来的问题，能逃过一切测量。
- **(P) 要么列得出，要么承载一个来源。** 凡是能从记录构成的记录集合，要么可数（能列出来），要么包含硬币来源的一份完整拷贝（一个完美集）。
  - 读法：要么能一个个点名，要么里面装得下一整个来源。

**推论**（对可定义的集合，都是已知的集合论，待核验）：
- 由 (A)：
  - 没有能构成的良序把实数排成一列，因为那样会构成一个不可测的集合——**连续统不能被任何写得出的方式排进线性时间**；
  - 也没有能构成的办法，从"只差有限多位"的每一类里各选一个代表（Vitali 的选法不可测）——**写得出的绝对因果在这里失败**。
- 由 (P)：没有能构成的、大小居中的实数集合——Cantor 形式的 CH 对一切能构成的集合成立。
- **(A)、(P) 在可构成宇宙 L 中都不成立**：L 里有一个 Σ¹₂ 的实数良序，以及一个没有完美子集的不可数 Π¹₁ 集合。所以 **T₁ 不能由 ZFC 证明：它判定了 ZFC 判定不了的问题**，而且是真正的判定，不是消解。
- **(A)、(P) 在足够多的大基数下对一切投影集成立**（投影决定性）。所以 **T₁ 与 ZFC + 大基数相容**：它不否定选择公理。选择公理给出的不可测集，不能从可数的记录构成。
- 一致性强度至少是一个不可达基数（Shelah、Solovay 一类的结果，待核验）。

**与 B 的差别**：
- B 对**一切**集合要求可测与完美集性质，于是与选择公理冲突，底座也仍是点。
- T₁ 只对**能构成的**问题要求它们。理由来自记录与问题的区分：不能构成的记录集合，本来就不是问题。所以 T₁ 不必否定选择公理，经典 ZFC 仍是它的理想化完成。

**一个检查，不是新结果**：
- 从测量出发得到的界线——可数的记录与能构成的问题 vs 理想化的总体——恰好落在现代集合论所发现的"规范与不规范"的分界上：
  - 在大基数下，投影集的理论不随强迫法改变；
  - CH 在这条界线之外。
- 我们不是为了得到这条界线才定义 T₀ 的。它自己落在这里，是这套切法站得住的一个独立证据。

## 7. 形式化

**`lean/Records.lean` §6（2 条，不依赖 mathlib）**：
- `glues_iff_contextFree`：一族回答来自同一个整体对象，当且仅当每个问题的回答跨语境不变。不依赖任何公理。
- `glue_unique`：整体对象唯一。只依赖 `Quot.sound`（函数外延）。

**`lean-mathlib/Askable.lean`（9 条，依赖 mathlib 的经典公理）**：

| 定理 | 内容 |
|---|---|
| `askable_of_nullMeasurable`、`nullMeasurable_of_askable`、`askable_iff` | 对任何有限的来源和任何生成可测结构的有限读取环：可以问 ⟺ 可测（至多差零测集） |
| `symmDiff_limsup_subset` | Borel–Cantelli 的那一步：问题与有限读取上极限的差，含于误差的上极限 |
| `bits_askable_iff` | 0-1 序列：用有限多位以任意小误差回答 ⟺ 可测 |
| `no_record` | 没有原子的来源没有记录 |
| `finite_part_has_record` | 有限的部分总有概率为正的结果 |
| `dirac_all_nullMeasurable`、`record_all_askable` | 对记录（集中在一点的来源），一切问题都可以问 |

**如实说明**：
- 这些定理本身都是标准的测度论。它们在这里的作用，是把两个定义钉住：
  - "可以问"的操作定义，恰好给出可测性；
  - "有规律而无记录"在连续的随机性中处处都在。
- T₀、T₁ 还没有写成形式系统；§6 的推论都来自已知的集合论，列入待核验。

## 8. 已知的与这里的

**已知的，只作指导**（待核验）：
- 遗传可数集合与二阶算术的互译；
- 反推数学中测度论的位置；
- 投影决定性推出投影集的正则性（可测、完美集性质）；
- L 中的 Σ¹₂ 良序与没有完美子集的 Π¹₁ 集；
- 大基数下投影理论的绝对性；
- Fine 定理。

**这里的**：
1. **记录与 GLU 的打通**：GLU = "回答是跨语境的记录"，一条定理（§1）。Kolmogorov 的隐含前提是"每个来源都是记录的混合"。
2. **GLU(π) 没动墙的精确原因**：它改了记录什么，没改回答是不是记录（§2）。
3. **三种失败**；"有规律而无记录"是连续随机性的常态（§3）。
4. **"可以问"作为定义**；可测性是它的推论；两种子集（§4）。
5. **T₀ 的切法**：一切记录可数；来源、可以问的问题、来源的记录、联合来源；ZFC 是理想化完成；CH 被消解（§5）。
6. **T₁ 的两条原则**：能构成的就能问；要么列得出、要么承载一个来源。它们判定 ZFC 判定不了的问题，与 ZFC + 大基数相容，并且恰好落在已知的规范界线上（§6）。

## 9. 开放的问题与下一步

1. **把 T₀ 写成形式系统。** 两类对象：记录，与来源的描述。关键是"来源的记录"与"可以问的问题"作为定义，不作为原语。先在 Lean 中写一个有限版本：有限读取的代数、规律、极限。
2. **(A) 与 (P) 的来源。** 它们现在是两条原则。能否由一条更根本的原则推出？
   - 候选："记录的世界相对于来源是小的"——每个能构成的东西，都只用到可数多的信息。
   - 已知的对应是：一切投影集都有正则性，与"每个实数都在一个小的内模型之外有很多随机实数"之间有联系（Solovay 型的刻画，待核验）。这可能正是 (A) 的测量读法：**对每一份记录，几乎所有的来源的读数都与它无关。**
3. **失败的度量**：语境依赖、联合记录的缺失，各自的度量。
4. **记录化与世界的扩张**：给一个没有记录的来源补上一份记录，就是扩大记录的世界（已知的随机实数的强迫法，只作指导）。实数有多少，取决于做了多少次记录化，而不取决于规律——这是 CH 被消解的动态读法，还要写准。
5. **自指**（`11` 的 P4）：还没想清楚，不作断言。
