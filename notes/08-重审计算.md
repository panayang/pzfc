# 08 · 重审"计算"：图灵的前提就是我们的轴

> **第三轮注**：§2 的物理注、§4 中 MIP\* = RE 的"粘合"读法、Q4 属物理挪用，已降级或删除。图灵前提分析保留，并在 `12 §6` 重新锚定到 P2。

> 你说图灵论题本身是公理，可以审视它在新框架下是否还理所应当。
> 第一原理的做法是回到图灵 1936 年的论证本身：他不是凭空断言，他从一组**关于人类计算者的前提**推出了机器模型。
> 那组前提，逐条对上了 `06` 的轴。

---

## 1. 图灵 1936 §9 的前提

| 图灵的前提 | 对应的轴 |
|---|---|
| 符号只有有限多种——否则会有相差任意小的符号，**无法区分** | Χ / Ι：可区分性，图灵**明确**把它当前提 |
| 一次只能观察有界多个格子 | 有限观测 |
| 心智状态有限多种 | 有限观测 |
| 每步只改变被观察的格子 | 局部性 |
| 计算由简单步骤**逐一**组成 | Τ：顺序时间 |
| （隐含）读一个符号不改变它，符号可反复读 | Σ：读取不扰动，可免费复制 |

所以 Church–Turing 论题，按图灵本人的论证方式，是一个**从这些前提出发的表示定理**
（Sieg 的读法；他后来把它写成了公理 + 表示定理，见 §3）。
**CT 不是一条任意的公理，它是一次分析的结论，而那次分析的前提恰恰是本项目要审视的隐含假设。**

于是"CT 在新框架下是否理所应当"变成了一个精确问题：**改动某条前提，表示定理变成什么？**

## 2. Gandy 1980：唯一重组 = 一条粘合公理

Gandy 把图灵的分析推广到**并行**机制（去掉顺序时间），列出四条原则：描述形式、层级有界、**唯一重组**、局部因果。
在这些原则下，Gandy 机器仍只计算图灵可计算函数。

**唯一重组**：一个状态由它有界大小的局部片段、沿重叠处拼合而**唯一**确定。
这就是 Γ 轴——局部数据唯一决定全局。Gandy 定理**依赖**它。

**问题 Q1**：去掉唯一重组（局部片段相容，但全局状态不被它们决定）的 Gandy 机器，计算什么？

一条物理约束：纠缠态恰好违反唯一重组（约化密度矩阵不决定全局态），而量子计算机**不**超出图灵可计算性。
所以"量子式"的重组失败不增加可计算性。是否存在别的失败方式会增加——我不知道。

## 3. Sieg 的公理化——这是要被形变的对象

Sieg（"Church without dogma"，2008 前后）把图灵与 Gandy 的分析写成"可计算动力系统"的公理（有界性 + 局部性），
并证明满足公理的系统可化归为图灵机。

**问题 Q2**：把 Sieg 的每条公理对应到一个轴，逐条放松，看表示定理如何变化。
这是"在新框架下重审 CT"的**可执行**版本，而且它是纯数学。

## 4. 数据点：每个轴改动时，计算怎样变化

| 改动 | 结果 | 文献 |
|---|---|---|
| Σ：收缩受控 | 朴素集合论 LAST 协调，可证全函数**恰为** PTIME；LLL / ELL / SLL 分别对应复杂度类 | Terui 2004；Girard；Lafont |
| Χ：对称、无选择 | 原子上的图灵机：**确定 ≠ 非确定**，在**可计算性**层面 | Bojańczyk–Klin–Lasota–Toruńczyk 2013 |
| Χ：无序结构 | Choiceless PTIME；"是否存在刻画 PTIME 的逻辑"悬而未决 | Blass–Gurevich–Shelah 1999 |
| Τ：给宇宙一个全序 | 最小不动点逻辑**恰好**刻画 PTIME | Immerman 1986；Vardi 1982 |
| Χ + Τ：匿名且异步 | 种群协议稳定计算的谓词**恰为**半线性（Presburger 可定义）⟹ **可判定** | Angluin 等 2006/2007 |
| Χ：加入一个可区分者（leader） | 高概率模拟寄存器机 | Angluin–Aspnes–Eisenstat 2008 |
| Λ：可实现性（构造性） | 内部 CT₀ 成立：每个 $\mathbb N\to\mathbb N$ 函数都可计算 | Hyland 1982（有效拓扑斯） |
| Γ：张量积 vs 交换算子 | MIP\* = RE；Connes 嵌入猜想为假 | Ji–Natarajan–Vidick–Wright–Yuen 2020 |

### 从表里读出的东西

**(a) "有序结构 vs 无序结构"就是"线性时间"问题在有限模型论里的精确形态。**
在有序结构上，逻辑与 PTIME 完美对应；去掉序，对应破裂，而能否修复是该领域的核心公开问题。
你们关于"线性时间认知"的直觉，在这里有一个**现成的、公认困难的数学问题**作为落点。

**(b) 图灵完全性似乎需要"区分 + 排序"。**
匿名 + 异步 ⟹ 恰为 Presburger，可判定，没有停机问题。加一个 leader ⟹（近似）图灵完全。
**停机问题像是"能够区分并排序"的代价。** 〔猜想 Q3，见 §6〕

**(c) 可计算性对很多改动是稳健的，复杂性不是。**
量子、并行、随机：可计算性不变，复杂性改变。Σ 轴改动直接切换复杂度类。
这说明 CT 的稳健性是**相对于图灵前提的稳健性**：在经典角落里所有模型都一致，是因为它们共享同一组前提。

## 5. "函数"是什么——这才是 L0 的问题

在 ZFC 里，函数 = 图（有序对的集合），与"如何算"无关。于是绝大多数 $\mathbb N\to\mathbb N$ 的函数不可计算——
这是基数论证，**ZFC 反驳内部 CT**。

在以有限观测为原语的基础里，函数的值由有限观测决定 ⟹ 连续（Brouwer）；在可实现性模型里 ⟹ 可计算（CT₀）。

| 基础 | 内部 CT |
|---|---|
| ZFC | 可反驳 |
| 有效拓扑斯 | 可证明 |
| Bishop 构造数学 | 独立（与两者都相容） |

所以准确的重审不是"CT 对不对"，而是：**CT 在哪些基础中可证、可驳、独立。**
在以测量为原语的基础里，CT 从一条**外部论题**变成一条**内部定理**——不是因为世界变了，是因为"函数"这个词的意思变了。

## 6. 研究问题

- **Q1** 无唯一重组的 Gandy 机器。
- **Q2** 逐条放松 Sieg 公理的表示定理。
- **Q3** 在一个对称且无序的基础（nominal + 无全局时间）中，把"计算"定义为内部概念，证明其表示定理。
  **猜想**：内部可计算性落在半线性 / Presburger 型，内部停机问题可判定；加入一个 `!`-可复制的区分者后恢复图灵。
  若成立，停机问题就被刻画为"区分与排序"这对资源的代价——这是 L\*（`07`）与 L0 的直接连接。
- **Q4** 物理检验：自然不免费提供 Σ（不可克隆；Landauer：擦除有热力学代价）。
  但物理计算机在资源无界时确实计算所有图灵可计算函数。
  所以一个面向物理的基础必须满足：**有界 `!` ⟹ 复杂度类；无界 `!` ⟹ 恢复图灵。** 隐式计算复杂性的模式恰好如此——这是一个可检验的一致性条件。
