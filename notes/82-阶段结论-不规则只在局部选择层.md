# 82 · 阶段结论：不规则只在局部的选择层

> 收拢第四十八轮（`78`–`81`）。主文件仍是 `55` 与 `64`；前两次阶段结论见 `72`、`77`。

---

## 0. 路线检查

- 四个问题分别落在过程层（刚性）、概率层（部分失去）、模态（D）、对象（共存）上。
- 它们汇到同一个结论：**凡由实数可定义的，都表现得全局而规则；不规则的现象只能来自局部的选择对象。**
- 仍在回答 `00 §7`：全局模型在哪里存在（可定义的层），在哪里不存在（共存、局部的选择对象）。

## 1. 这一轮确立的

1. **刚性的判据**（`78`）：
   - 刚性 ⟺ 检查点核的射影直径 → 0。
   - 一步核有显式公式 C(f(k+1) + f(k) + 1 − t + t′, f(k+1))。
   - 几何同步已证不刚性，数值上直径收敛到正数；多项式同步数值上刚性，证明还差一个具体的不等式。
2. **部分失去的定位**（`79`）：
   - 对一切强迫：部分失去 ⟹ 强迫成员集不可测。
   - 在 B 中，由实数可定义的记录（Suslin ccc 强迫、良好的理想型强迫、它们的迭代与商）都是全有或全无。
   - 部分失去若存在，只能来自以局部选择对象为参数的记录（候选：M_{U∩U′}）。
3. **D 的分叉见证**（`80`）：
   - 相对化到 L，得到强迫不变的按钮；以一个待核验的普遍性为条件，D 不满足 .2。
   - 分叉能改变"对整个宇宙作的定义"的值，甚至是自然数值的定义；不改变有限层与可数核。
4. **共存的结构**（`81`）：
   - 一切单纯复形都可作为共存模式实现；
   - 事实能粘，存在不能粘；B 没有全局的配对；
   - 与语境性对偶：语境性是共存而不共享，不共存是共享而不共存。

## 2. B 的全局结构（再精确一次）

| 层 | 在 B 中 | 例子 |
|---|---|---|
| 有限层 | 全局（ω 标准） | 有限的记录、频率表、语境性的判定 |
| 可数核（由实数可定义的） | 全局，并且在一切扩张下不变（M4；模态平凡） | 定律、描述、迹的有限部分、由实数定义的强迫及其效果 |
| 全局的 ∈ | 外延、基础、对并封闭 | 两个集合之间的 Δ₀ 事实 |
| 共存（配对、乘积、幂集） | 只在世界之内；B 不决定 | 永不共存的集合（`74`、`81`） |
| 局部的选择对象 | 只在世界之内 | 超滤子、Vitali 集、ℝ 的良序、非分层的不可测集 |
| 对整个宇宙的定义 | 随世界而变；在 D 中还可以分叉 | 普遍序列的项（`80`） |

## 3. 这一阶段的原则：不规则只在局部的选择层

**陈述**：在 B 中，以下现象都不能由可定义（由实数）的对象或运算引起：
- 测度的部分失去；
- 局部集合之间的选择性区分；
- 语境性判定的世界依赖；
- 事实的不一致。

它们若出现，只能来自局部的选择对象（或来自世界的共存结构，而那是 B 不决定的自由部分）。

**依据**：
- `79` 定理 1、2：部分失去需要不可测的成员集，而可定义的成员集可测（M4）。
- `81` 定理 3：事实在全局一致。
- `68` 定理 2：语境性是算术的。
- `75`、`76`：可数核上的模态平凡；良好的记录是二值的。

**读法**：
- 经典数学的"病态"——不可测集、选择给出的怪异对象——在 B 中不是被禁止，而是被**定位**了：它们都在局部的选择层。
- 全局的、可描述的部分，比 ZFC 所允许的更规则：一切投影集可测、描述的测度不变、点集测度的命运二值。

## 4. 下一阶段的问题

1. **多项式同步的刚性**：证明 sup_K Δ(M_{K→2K}) < ∞（`78 §3`）。
2. **M_{U∩U′}**：它是否同时消灭 F 未决定的实数？若否，部分失去就存在，而且恰好由局部的选择对象引起（`79 §3`）。
3. **普遍性的 L 版本**：核验 Hamkins–Woodin 的论证在 L_θ 上成立（`80 §2`）。
4. **全局配对与汇合**：若加上"任何两个集合共存"作为公理，它与汇合是什么关系，是否恢复 GLU₀（`81 §4`）？
