## 1. 设定与核心定理

**定义**：
- 字母的集合 L，类的映射 cls : L → C。
  - 不同类的字母称为**独立**；
  - 同类的字母不独立，包括同一个字母与它自己。
- **一步交换**：把相邻的两个独立字母对调。
- **迹**：由一步交换生成的等价类（`TEq`）。
- 字 w 在类 c 上的**流**：w 中属于 c 的字母，按原来的次序排成的序列（`proj`）。
- 字 w 的**日程**：它的字母所属的类依次排成的序列 cls(w)。

**定理 1**（核心，`teq_iff_proj`）：两个字在同一个迹里，当且仅当它们在每个类上的流都相同。
- 所以一个迹就是"每类一条流"组成的组；
- 在迹之内，唯一自由的是各条流如何交错。

**定理 2**（`word_determined`、`weave_spec`、`weave_self`）：
1. 一个字由它的日程与它的流唯一确定。
2. 反过来，给定各类的流，任取一个日程，只要其中每类出现的次数等于该类流的长度，按日程依次读取各流就得到一个字，并且这个字的流恰好是给定的那些。

所以在次数相符的条件下，"字"与"日程和流的组"一一对应。

## 2. 由过程自己决定读哪条流（表示 R1）

**定义**：设 P 是 L^ℕ 上的定律，X 是服从 P 的随机序列。若对每个 n，P(X↾n = w) 只依赖于 w 所在的迹，就称 P 是**迹可交换的**。

**定理 3**（有限形式，`stepInvariant_iff`、`weight_schedule_free`）：
1. P 迹可交换，当且仅当 P(X↾n = w) 只依赖于 w 的流组成的组。
2. 于是，给定前 n 步的各条流，日程在"每类出现次数相同的一切排列"上均匀分布。

**定理 4**（表示）：P 迹可交换，当且仅当存在
- 一个随机的流组 S = (S_c)_{c∈C}，其中 S_c 是 c 类字母的序列，
- 以及 C 上的一个随机定律 π，

使得给定 (S, π) 时：
- 日程 Y = (Y₁, Y₂, …) 独立同分布，分布为 π；
- X 就是按日程 Y 依次读取各条流所得的序列。

(S, π) 的联合定律可以是任意的。

**证明**：

(⇐) 给定 (s, π)，记 k_c 为 w 中 c 类字母的个数。
- 前 n 步等于 w 的概率是 ∏_c π_c^{k_c}，再乘以"每条 proj_c(w) 都是 s_c 的前段"这一条件的示性函数。
- 这个值只依赖于 w 的流，所以由定理 1，它只依赖于 w 的迹。
- 取混合时这一性质保持不变。

(⇒) 分三步。
1. 令 S_c 为 X 中 c 类字母组成的子序列，Y = cls(X)。对 {1,…,n} 的一个置换 σ，定义映射 T_σ：
   - 把前 n 个类标签按 σ 重排；
   - 保持各条流不变；
   - 按新的日程重新读取各条流（定理 2）。
2. T_σ X 与 X 同分布：
   - 对 m ≥ n，T_σ 把长为 m 的柱集 [w′] 映到柱集 [w]，并且 w 与 w′ 的流相同；
   - 由定理 1 与迹可交换，P[w] = P[w′]。
3. 由 X 与 (Y, S) 互相确定（定理 2），得到：
   - 只置换 Y 的前 n 项时，(Y, S) 的联合定律不变；
   - 所以给定 S，Y 的条件定律是可交换的；
   - 由 de Finetti 定理的条件形式，令 π 为 Y 的极限频率，则给定 (S, π)，Y 独立同分布于 π。∎

**附带的结论**：
- 若 π_c > 0，c 类出现无穷多次，S_c 是无穷序列；
- 若 π_c = 0，c 类几乎必然一次也不出现，S_c 为空；
- 所以"出现至少一次、但只出现有限多次"的类，几乎必然不存在。

**特例**：
- 每类只有一个字母：各条流都是常数序列，X = Y，定理 4 就是 **de Finetti 定理**。
- 只有一类：日程是常数，X = S，于是**任意过程**都满足。
- 一般情形：任意的流，按一个可交换的日程交错。

**读法**：
- 各成分的对应：
  - 隐藏的结构 = 各条流 S，加上日程的定律 π；
  - 新鲜的部分 = 给定 π 之后的日程；
  - 位置 = 每条流已经读到了第几个。
- 前 n 步的迹，就是已经揭示出来的那部分结构，即每条流的前段。
- 迹之内的次序是纯粹的新鲜随机：
  - 它只通过各类出现的个数，提供关于 π 的信息；
  - 它不提供关于流的任何信息。
- 所以在这一情形下，`64 §5` 的问题的回答是：**是，迹就是表示的指标**。

## 3. 由提问者决定问什么（表示 R2）：分离总成立，隐藏的结构未必存在

**设定**：
- 提问的集合 E，类的映射 cls : E → C，回答的集合 A（有限，或是标准 Borel 空间）。
- 一个**随机行为**是这样一族定律：
  - 对每个有限的提问序列 l，给出 A^{|l|} 上的一个定律 μ_l；
  - 去掉最后一问时相容，即最后一问不影响之前各问的回答。
- **迹可交换**：l 与 l′ 在同一个迹里时，μ_{l′} 就是把 μ_l 的回答按对应位置重排所得。
- 这就是 §2 的情形，只是把字母换成"（提问，回答）"的对，并按提问分类；`stepInvariant_iff` 对这种字母同样成立。
- 与 §2 的区别：提问由提问者选择，而不是由过程随机产生。

**定理 5**（分离）：随机行为迹可交换，当且仅当存在一族定律 ν，满足：
- 指标是组 (u_c)_c，其中每个 u_c 是一条 c 类的提问序列；
- 缩短任何一个 u_c 时相容；
- 对每个提问序列 l，μ_l = ν_{(proj_c l)_c}。

也就是说，**c 类回答的定律只依赖于 c 类的提问**；其他类问了什么、在什么时候问，都不影响它。

*证明*：
- 由定理 1，同一组 (u_c) 的一切交错都在同一个迹里，所以 ν 的定义是合理的。
- 验证相容性时，取一个把被缩短的那一问放在最后的交错。

**定义**：一个确定的行为称为**类分离的**，若它对 c 类提问的回答只依赖于到此为止的 c 类提问序列。
- 等价地，每个类 c 有一个"隐藏的记录" β_c，它是从 c 类的非空提问序列到 A 的映射；
- c 类的每次回答，都由 β_c 作用在"到这一问为止的 c 类提问序列"上给出。

**定理 6**（隐藏的结构就是 GLU）：一个迹可交换的随机行为是类分离确定行为的混合，当且仅当族 ν 有一个全局延拓。
- 全局延拓是指：一切类的一切提问序列上的一个联合定律，它在每组 (u_c) 上的边缘恰好是 ν_{(u_c)}。
- 这正是 `43 §1` 的 GLU 条件，其中的语境就是"每类一条提问序列"组成的组。

**定理 7**（什么时候成立）：
1. **至多一个类中有选择**（其余每类都只有一种提问）时，总成立。
   - 其余各类的流只构成一个语境，所以有联合定律，记为 Z。
   - 在有选择的那一类的提问树上：给定 Z 与祖先节点的回答，各分支条件独立地取值。
   - 限制到任何一条路，得到的正是原来的定律。
2. **两个类中各有两种提问**时，可以不成立。例子是 PR 盒（`pr_alice`、`pr_bob`、`pr_not_mixture`）：
   - 甲类的提问是 x ∈ {0,1}，乙类的提问是 y ∈ {0,1}；
   - 回答 a、b 满足：a ≠ b 当且仅当 x = y = 1；两种允许的回答对各占一半。
   - 甲的回答的定律与乙被问什么无关，反之亦然。所以两种次序给出同一张表：**两个类可交换**。
   - 但它不是类分离记录的混合：
     - 任意一列类分离的记录（每个记录给出 a₀、a₁、b₀、b₁）中，每个记录在四个语境中至多满足三个（`shared_records_chsh`）；
     - PR 盒在四个语境中全部满足。

**读法**：
- de Finetti 型的表示分两步：
  1. 全局定律存在，即 GLU；
  2. 遍历分解，即在流内部可交换时，对每条流用 de Finetti。
- 第 2 步从不失败。第 1 步只在提问者有选择、并且至少两个类中都有选择时，才可能失败。**这就是 Bell 定理在这里的位置。**
- 用四种情形来说：
  - 可交换处理的是"之前"：类之间的先后无关紧要；
  - 定理 5 说，"同时"问了什么，不影响每一类自己的定律；
  - 定理 7.2 说，"同时"问了什么，却可以决定联合定律，并且不存在与语境无关的联合定律。
- 于是经典概率中"对称的观察背后有一个隐藏的原因"（de Finetti）是 GLU 的一个实例：
  - 当过程自己决定观察什么时，它总成立；
  - 当观察者有选择时，它可以失败。

## 4. 由位置决定读哪条流：Diaconis–Freedman（表示 R3）

- **设定**：
  - 每一步的提问由当前状态决定："i 之后是什么？"；回答是下一个状态。
  - 每个状态 i 对应一条流：历次到达 i 之后的后继，依次排列。
- **已知**（Diaconis–Freedman）：对常返的过程，若有限路径的概率只依赖于初始状态与各种转移出现的次数，它就恰好是 Markov 链的混合。
  - 证明中的关键一步：这个条件等价于每条后继流内部可交换。
- **放进本篇的写法**：
  - 每个状态是一类，每类只有一种提问，所以**没有选择**；定理 7.1 保证全局定律存在。
  - 每条流内部可交换，所以 §3 读法中的第 2 步给出每个状态的转移定律。
- 对应关系：
  - 隐藏的结构 = 转移定律；
  - 位置 = 当前状态；
  - 新鲜的部分 = 每一次转移。

## 5. 一般的独立关系

- 当独立关系不是"按类"的时候，迹不再是一组流。例如 a、b 独立，而 c 与两者都不独立。
- 仍然成立的一般形式：
  - **有限时**：迹可交换，当且仅当给定迹时，它的一切线性化等可能（由定义）。
  - **无穷时**：把 X 的"无穷迹" τ 当作隐藏的结构，则给定 τ：
    - X 是 τ 的一个随机线性化；
    - 这个线性化的前段的概率，只依赖于前段所到达的那个理想。这样的线性化称为**中心的**。
    - 证明与定理 4 相同：交换前段之内的独立字母，保持 τ，也保持定律。
- 对"按类"的独立关系：
  - τ 就是流的组；
  - 中心的线性化恰好是独立同分布的日程，这是定理 4。
- **一般情形的问题**：对一个无穷迹 τ，它的中心线性化的极端点是什么？
  - 有限的块（例如被 c 隔开的 a、b 块）：块内均匀。
  - 一般的分类尚未完成。已知的工具（分级图上的中心测度）只作指导。

## 6. 汇总：部分可交换的一般表示

| 谁决定下一次读哪条流 | 类之内的次序 | 隐藏的结构 | 何时存在 | 实例 |
|---|---|---|---|---|
| 过程自己（日程是输出的一部分） | 任意 | 各条流，加上日程的定律 | 总存在（定理 4） | de Finetti；任意过程 |
| 当前的位置 | 可交换 | 每个状态的转移定律 | 常返时总存在 | Diaconis–Freedman |
| 提问者 | 任意 | 每类一个隐藏的记录 | ⟺ GLU（定理 6）；至多一类有选择时总存在 | PR 盒：不存在 |

**一句话**：
- 部分可交换的过程 = 迹（已经揭示的结构）+ 迹之内的新鲜次序。
- 隐藏的全局结构存在 ⟺ 各类的流能粘成一个全局定律。
- 它唯一的失败方式是语境性，而这需要提问者在至少两个类中都有选择。

这把 `62`–`63` 的"次序"线索与 `43` 的 GLU 线索接成了一条：**可交换给出分离；分离之后能否得到隐藏的结构，是 GLU 问题。**

## 7. 已知的与这里的

**已知的，只作指导**：
- de Finetti 定理；Diaconis–Freedman 的 Markov 链混合定理。
- 迹的投影引理（Cori–Perrin）：在一般的独立关系下，两个字同迹 ⟺ 它们在每一对不独立的字母上的投影相同。定理 1 是它在"按类"情形下的形式，这里给出了直接的证明。
- Fine 定理与 Abramsky–Brandenburger：没有语境性 ⟺ 有全局定律。
- 序列的 Bell 情形（Gallego 等，2014）：每一方依次做多次测量时的非定域性。
- 分级图上的中心测度（Vershik–Kerov）。

**这里的**：
1. 定理 4（任意的流，加上可交换的日程）。证明是 de Finetti 的条件形式加上定理 1、2；尚未查到这一形式的文献（待核验）。
2. 定理 5–7：
   - 把"迹可交换"认作"类之间不传信"；
   - 把"隐藏的结构"认作 GLU；
   - 给出失败的最小情形。
3. 统一的陈述：
   - de Finetti 型的表示 = GLU + 遍历分解；
   - 按"谁决定读哪条流"分成三种情形。

**如实的判断**：
- 各个部分都简单。
- 新的是把 de Finetti 与 Bell 放进同一个定理：前者是"没有选择"时的 GLU，后者是"有两处选择"时 GLU 的失败。
- 对 `64 §5` 第 1 条的回答：是，迹就是表示的指标；例外恰好是语境性。
