# 83 · 隐藏比率的相变：尺度不变的同步

> 第四十九轮，第一个问题（`82 §4` 第 1 条；`73`、`78`）。
>
> 数值：`experiments/birkhoff_diameter.py`，以及本篇 §3 的增长率比较。
>
> **范围**：本篇属于体系的过程层。这里的问题是：一个部分可交换的过程何时带着与次序无关的隐藏参数（de Finetti 型的频率）？

---

## 0. 路线检查

- **原则在推动的**：隐藏的比率由迹的渐近几何决定（`73`）；刚性 ⟺ 检查点核的射影直径 → 0（`78`）。
- **会拉着走的**：
  - 锥与楔中随机游走的 Martin 边界（其中的方向给出调和函数）；
  - 抛物形区域中的热方程。
  只作指导。
- **四种情形**：只处理"之前问了什么"。
- **是否回答 `00 §7`**：回答"与次序无关的隐藏参数"出现的精确条件。

## 1. 设定

- 同 `73 §2`、`78 §1`：两条链，块长 f(k)，同步点 p_k、q_k。
- 记 P_k = Σ_{l≤k} (f(l) + 1)，即到第 k 个同步点为止走过的"时间"。
- 关键的比值是

  > **ρ_k = f(k) / P_k**：同步间隔占已经过的时间的比例。

## 2. 定理：比例有正的下界时，隐藏比率存在

**定理 1**：若 liminf_k ρ_k > 0，则存活的比率组成一个非空的开区间。所以这个分量不是刚性的：它带着一个连续的隐藏比率。

*证明*：
1. **约束化为斜率的条件**。取 X 链与 Y 链的比率之比为 λ = (1−p)/p 的日程。同步约束在检查点处要求：
   - i 越过 P_k 时，j ≥ P_{k−1}，即 λ ≥ P_{k−1}/P_k；
   - j 越过 P_k 时，i ≥ P_k，即 λ ≤ 1。
2. **可行的斜率组成开区间**。liminf ρ_k > 0 等价于 limsup P_{k−1}/P_k < 1，所以开区间 (limsup P_{k−1}/P_k, 1) 非空。
3. **余量是线性的**。对其中的 λ，检查点处的余量是线性的，而涨落是 √n 量级；所以永不违反的概率为正（Borel–Cantelli）。
4. **结论**。由 `73` 定理 1，每个这样的 λ 给出一个不同的极端中心线性化。∎

**反过来**：若 ρ_k → 0，则可行的斜率只剩 λ = 1，而且下界处的余量为 0：约束要求 D = i − j ≥ 0。
- 对称的游走会无穷次取负值，所以永不违反的概率为 0，S(τ) = ∅。
- 这时没有"条件化的日程"型的隐藏比率。

## 3. 数值：相变的两侧

对不同的增长率，计算检查点核的射影直径 Δ(M_{K→L})。它趋于 0 就是刚性（`78` 定理 2）。

| f(k) | ρ_L（末端） | Δ 随 L 增大 | 判定 |
|---|---|---|---|
| k | → 0 | 0.550 → 0.013 → 0.000（K = 5） | 刚性 |
| k² | 0.15–0.17 | 5.24 → 2.06 → 0.75 → 0.41（K = 4） | 递减，与刚性相符 |
| k³ | 约 0.28 | 14.4 → 10.1 → 5.6 → 3.7（K = 3） | 递减；在这个规模上 ρ 仍大，不能判定 |
| 1.5^k | → ⅓ | 0.86 → 0.18 → 0.076 → 0.048 → 0.038（K = 4）；3.23 → 1.24 → 0.77 → 0.61 → 0.54（K = 6） | 收敛到正数：不刚性（定理 1） |
| 2^k | → ½ | 0.39 → 0.28 → 0.26（K = 2）；4.7 → 4.2 → 4.0（K = 4） | 收敛到正数：不刚性（`73`、`78`） |

## 4. 猜想：相变恰在尺度不变处

**猜想**：分量是刚性的，当且仅当 ρ_k → 0。
- 已证：liminf ρ_k > 0 ⟹ 不刚性（定理 1）。
- 数值支持：f(k) = k、k² 时刚性。

**连续极限的依据**（ρ_k → 0 的一侧）：
- 差 D = i − j 在检查点处被限制在 [0, f(k)] 中，其下界固定在 0。
- 在扩散尺度下，这是布朗运动被限制在一个宽度为次线性的区域中：
  - 宽度与 √t 同阶时，化为对数时间中有界区间上的 OU 过程，正的时空调和函数只有基态一个；
  - 宽度介于 √t 与 t 之间时，下界 0 起作用，上界只排除线性的漂移，剩下的也只有一个（相当于条件为正的布朗运动）。
- 两种情形都只有一个正的调和函数。把它变成离散的证明，需要离散的边界 Harnack 原理，尚未完成。

## 5. 读法（对概率的基础）

- de Finetti 的隐藏频率之所以存在，是因为各部分在一切尺度上都能自由漂开。
- 这里的结论是它的精确的"部分"版本：
  - 当各部分之间的同步**没有特征尺度**——间隔与已经过的时间成比例（对数周期）——时，隐藏的频率（比率）出现，并且可以取一个区间中的任何值；
  - 当同步间隔相对于经过的时间可以忽略时，隐藏的频率消失，次序被迹决定。
- 所以"与次序无关的隐藏参数"是一种**尺度不变性的后果**。这为 `65`–`73` 的"隐藏的结构"给出了一个判别的量：ρ = 间隔 / 时间。

## 6. 已知的与这里的

**已知的，只作指导**：
- 楔形区域中随机游走的 Martin 边界由其中的方向组成；
- 抛物形柱中的热方程只有一个正的解（在 Dirichlet 条件下）；
- 条件为正的布朗运动。

**这里的**：
1. 定理 1：ρ 有正的下界 ⟹ 分量之内有连续的隐藏比率。
2. 反面：ρ → 0 时存活的比率为空。
3. 相变的猜想（刚性 ⟺ ρ → 0），以及五种增长率的数值。
4. 读法：隐藏的频率是尺度不变的同步的后果。
