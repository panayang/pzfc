# 68 · 语境的实现与世界的汇合

> 第四十五轮，第四个问题（`64 §5` 第 4 条）。
>
> 形式化：沿用 `lean/Exchange.lean` §5（`shared_records_chsh`）。

---

## 0. 路线检查

- **原则在推动的**：
  - 这一轮之前，有两处"局部的东西粘不成整体"：
    - 定律层：语境上的定律没有全局定律（`61 §4`、`63 §5`、`65 §3`）；
    - 底座：两个世界没有共同的扩张（`55` 不假定汇合）。
  - 问题是：它们之间有没有推出关系？
- **会拉着走的**：
  - Mostowski 的不能汇合的例子；
  - 有限样本的 Bell 定理（Gill）；
  - Hamkins 关于汇合与现实主义的论证（`57`、`58`）。
- **四种情形**：本篇处理"同时问了什么"（语境）。
- **是否回答 `00 §7`**：是。本篇区分两种"全局模型不存在"：
  - 值的层次上的；
  - 世界的层次上的。

  并说明它们互相独立。

## 1. 两个层次上的汇合

先把三件事分开：

| 层次 | 什么需要粘合 | 在 B 中 | 出处 |
|---|---|---|---|
| 可能性（模态） | 从任何两个扩张出发，能否到达满足同样"稳定"陈述的扩张 | 成立：S4.2 | `56`、`57` |
| 世界（对象） | 两个具体的扩张 w₁、w₂ 是否有一个共同的扩张 | 不假定；在可数模型的解释中可以失败 | `55` |
| 值（记录） | 各语境的样本，能否由每个变量的一份共享记录给出 | 由定律决定；语境性时失败 | `61 §4`、`65 §3` |

- 第一行与第二行的区别已在 `57` 说明：
  - 强迫的 .2 公理只要求"同一类强迫"能在任何扩张之上再做一次；
  - 它不要求那两个具体的扩张能放进同一个世界。
- 本篇讨论第二行与第三行。

## 2. 语境性是有限的

**设定**：
- 有限个变量组成的集合 V，每个变量取值于有限集。
- 一族语境 𝒞 ⊆ 𝒫(V)，每个语境 C 上有一个定律 P_C。
- 一个**共享记录的表**是 (A^V)^n 中的一个元素：n 次试验，每次试验给每个变量一个值。
- 它的经验定律 Q_T 是 A^V 上的一个定律。

**定理 1**（有限的障碍）：若这族定律没有全局定律，则存在 η > 0，使得对**任何长度**的共享记录表 T，总有某个语境 C 满足

> d_TV(Q_T|_C, P_C) ≥ η。

*证明*：
- 令 η 为下面这个函数的最小值：Q ↦ max_C d_TV(Q|_C, P_C)。
  - Q 取遍 A^V 上的一切定律，这个集合是紧的；
  - 函数是连续的，并且处处为正（因为没有全局定律），所以最小值 η > 0。
- Q_T 是其中的一个定律。∎

- **CHSH 的情形**（`shared_records_chsh`）：
  - 任何共享记录的表，每条记录在四个语境中至多满足三个；
  - 所以四个语境的平均满足率 ≤ 3/4；
  - PR 盒在每个语境中要求满足率 1；与它相差 d 的经验定律，满足率至少是 1 − d；
  - 所以总有一个语境的偏差至少是 1/4，即 η ≥ 1/4。

**定理 2**（与世界无关）：设 w 是一个世界，(P_C) 编码在 w 中。以下各条等价，并且对一切世界同时成立或同时不成立：
1. 有全局定律。
2. 对每个 ε > 0，存在一个有限的共享记录表，它在一切语境上都与 P_C 相差小于 ε。
3. 在 w 中存在一列共享记录（每个变量一个序列），它在每个语境上的频率都收敛到 P_C。
4. 存在一些实数 s_v（v ∈ V，每个变量一个序列，可以属于不同的世界）。对每个语境 C，(s_v)_{v∈C} 属于某个世界，并且频率收敛到 P_C。

*证明*：
- (1 ⟹ 3)：取全局定律 Q 的一个频率收敛的序列。对有理的 Q 可取周期序列；一般地，可以在含 Q 的世界中计算出这样的序列。
- (3 ⟹ 4)：显然。
- (4 ⟹ 2)：
  - 对每个 ε，由每个语境的频率收敛，取一个足够大的 n；这样的 n 只有有限多个条件要满足，取其中最大的。
  - 各个 s_v 的前 n 项是遗传有限的集合，属于**每一个**世界。
  - 它们组成的表 T 是一个有限对象，在一切语境上都与 P_C 相差小于 ε。
  - 这一步不需要任何一个同时含有所有 s_v 的世界。
- (2 ⟹ 1)：紧致性。
- 第 2 条是算术的陈述，所以它的真假在一切世界中相同。∎

**读法**：
- 语境性由有限的对象判定，它属于可数核（事实上属于算术），在每个世界中都一样。
- 第 4 条说：即使把各语境的样本放到不能汇合的世界里，也逃不出这个障碍——有限的前段总在每个世界里。

## 3. 两个方向都推不出

**定理 3**（语境性不导致不能汇合）：对任何一族语境上的定律（有没有语境性都可以），每个语境都可以用独立的样本实现，而这些样本所在的世界总能汇合。
- 取法：依次抽取，每个样本相对于含有此前一切样本的世界是新鲜的（`61 §3`）。
- 这样，一切样本都在同一条扩张链的上端。
- 语境性只禁止"每个变量一份共享记录"（定理 1），并不禁止把各语境的样本放进同一个世界。

**定理 4**（不能汇合不产生、也不消除语境性）：
- 由定理 2，语境性在一切世界中相同。
- 所以无论哪些世界能汇合，一族定律有没有全局定律都不变；把样本放进不能汇合的世界，也不能让共享记录实现一个有语境性的族（定理 2 第 4 条）。

**不能汇合的例子**（Mostowski；待核验出处）：
- 设世界 w 在某个更大的世界中可数。
- 那么可以构造两个在 w 上 Cohen 泛型的实数 c、d，使 c ⊕ d 编码一个序型为 w 的高度的良序。
- 于是 w[c] 与 w[d] 没有同样高度的共同扩张。
- 注意这个障碍的性质：
  - 它**只在整个实数上**出现：c、d 的每一对有限前段都在 w 中，完全无害；
  - 它**依赖于良基**：障碍来自"编码了高度"。
- 在 B 中，高度扩张能否恢复这样的汇合，取决于有哪些实数可以被吸收；本篇没有研究。

## 4. 结论：两种粘合的失败，一有限，一无穷

| | 值的层次（语境性） | 世界的层次（不能汇合） |
|---|---|---|
| 缺少的是什么 | 每个变量一份共享记录（一个全局定律） | 一个同时含有两个世界的世界 |
| 由什么判定 | 有限的对象；算术的陈述 | 整个实数；依赖于高度 |
| 有限前段 | 已经显示障碍（定理 1） | 完全无害 |
| 与良基的关系 | 无关 | 由良基引起（`60`） |
| 度量 | 非上下文部分，η | 尚无 |
| 在体系中的位置 | 概率层、过程层（`61`、`65`） | 底座（`55`） |

**对体系的意义**：
1. **Bell 型的障碍（原始 prompt 中"墙"的物理实例）是有限的**。
   - B 不假定世界汇合，但它处理语境性并不靠这一点；
   - 靠的是概率层与过程层：定律属于语境，记录属于语境，全局的共享记录不存在（`65` 定理 6–7）。
2. **B 中世界的不能汇合是另一回事**：它是无穷的、由高度引起的。这正是 `60` 的 GLU–良基猜想所指的那一类。
3. **概率层从不遇到不能汇合**：它构造世界的方式本身就是一条链（定理 3）。
   - 这条链就是"独立的样本"，也就是经典概率里的线性时间；
   - 在这里，它是一个选择（让样本彼此新鲜），不是一个预设。
4. 所以 `00 §7` 所说的"全局模型不存在"有两个独立的来源，分别在两层：
   - 有限的（语境）；
   - 无穷的（世界）。

   原始问题中的物理之墙属于前者。

## 5. 仍然开放的

1. 世界层次上的"非上下文部分"：两个不能汇合的世界，能否度量它们"差多少能汇合"？
   - 例如，能汇合的最大的子扩张。
2. 在 D（允许非良基的增长，`60`）中，Mostowski 型的障碍是否消失？若消失，GLU–良基猜想就得到了一个具体的支持。

## 6. 已知的与这里的

**已知的，只作指导**：
- Fine 定理（有全局定律 ⟺ 满足全部 Bell 型不等式）；
- 有限样本的 Bell 定理（Gill）；
- Mostowski 的不能汇合；
- 强迫的 .2（Hamkins–Löwe）。

**这里的**：
1. 三个层次（可能性、世界、值）的区分，以及值与世界两层互相独立的证明（定理 2–4）。
2. "语境性是算术的，因而在一切世界中相同；世界的不能汇合只在无穷处出现"这一对照。
3. 对体系的结论：
   - 物理之墙在值的层次；
   - B 的不能汇合在世界的层次；
   - 概率层按构造只生活在能汇合的部分。

**如实的判断**：
- 这一问的答案是否定的：两者之间没有推出关系。
- 但这个否定是有内容的：它把"墙"定位到有限的层次，说明处理它的是概率层与过程层，而不是底座对汇合的放弃。
