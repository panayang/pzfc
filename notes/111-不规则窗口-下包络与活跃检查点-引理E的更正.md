# 111 · 不规则窗口：下包络与活跃检查点；引理 E 的更正

> 第五十九轮（`110 §3` 的引理 E）。
>
> **范围**：概率论（过程层）。

---

## 0. 路线检查

- **原则在推动的**：`110` 把两个概率缺口化为引理 E。这里先更正引理 E 的陈述，再证明它在一个包含随机跳动窗口的类中成立。
- **会拉着走的**：无新工具。只重用 `97` 的引理，外加一个"只在部分检查点上计入约束"的观察。
- **结论先说**：
  1. **更正**：`110` 的引理 E 对**任意**障碍是假的。需要一个正则性条件，见 §1。
  2. **下包络定理**（定理 1）：窗口序列只要满足下面三条，就刚性（缓变情形）：
     - 处处不低于一个正则的凹包络（误差 O(√W)）；
     - 在一个"活跃"的检查点集合上贴近它，活跃点之间的间隔有界；
     - 上方有界（窗口 ≤ ΓW）。
     窗口在其余检查点上可以任意地向上跳动。
  3. **随机跳动**（推论 2）：窗口在 ω 与 3ω 之间独立随机地跳动时，几乎必然刚性。这正是 `110 §2` 中数值检验的情形；证明是概要。
  4. **仍然开放的**：
     - 下包络本身不规则的窗口；
     - 多链尺度相当情形中的平移窗口：它的平移路径是扩散的，需要引理 E 的一个带"扩散正则性"的版本。

## 1. 引理 E 的更正

- **反例**（对任意障碍）：取宽度为 W 的窗口，每个检查点整体平移 W − √W。存活的路径必须每一步都落在新旧窗口仅有的 √W 宽的重叠区中，所以条件分布集中在末端窗口的边缘附近，不可能以正的比例在内部带 S 中。
- **更正后的陈述**：引理 E 应当附加一个正则性条件。本篇采用的是"下包络 + 活跃集"（§2）。多链的平移窗口需要的则是"平移路径每个间隔的移动 ≤ C√g，除一个小概率事件外"（§4）。
- `110` 中"两个概率缺口共用引理 E"这一判断保留，但两者需要的正则性不同。

## 2. 下包络定理（缓变情形）

**假设（LE）**：存在常数 C₀、G、Γ，与一个不减的凹函数 ω（满足 `97` 的假设 SV：ω′ω ≤ C₀），使在无穷多个块（X-时间 ≍ W²，W = ω(P_K)）上：
1. **下包络**：一切检查点 ℓ 处，W_ℓ ≥ ω(P_ℓ) − C₀√W；
2. **有界**：W_ℓ ≤ ΓW；
3. **活跃集**：令 𝒜 = { ℓ : W_ℓ ≤ ω(P_ℓ) + C₀√W }。𝒜 中相邻检查点之间的 X-时间 ≤ GW。

**定理 1**：在假设 LE 之下，堆刚性。

*证明*：逐条检查 `97` 的证明中用到上界正则性的地方：
1. **上界（存活的估计）**：`97` 引理 3 与引理 8(b) 的上界，只需要一族"至少这么严格"的约束。
   - 只保留 𝒜 中检查点的上约束（丢掉其余的约束只会增大存活概率）。
   - 在这些检查点上，障碍在 ω 的 C₀√W 之内，间隔 ≤ GW。于是引理 3 与倾斜的引理 7 照样适用。
   - 引理 7 中的倾斜参数只在 𝒜 中的检查点处改变。似然比的中间项需要 D 在改变点处有界：D ≤ W_ℓ ≤ ΓW。
2. **下界（构造）**：`97` 引理 5 的管与引理 8 的三步，只需要管在一切检查点的窗口之内。由第 1 条（下包络），一切窗口 ≥ ω − C₀√W，所以把管放在 ω − 2C₀√W 之下即可。这与正则的情形相同。
3. **中段**：`97` 引理 10 的下界用管（同第 2 步），上界用自由的局部极限定理，都不涉及上界的正则性。
4. **离开**（倒转）：与第 1–2 步对称。
- 上下界的量级都由 ω 决定，所以相同，三段夹逼给出有界的直径。∎

**读法**：
- 刚性只在乎**约束最紧的那些检查点**。
- 窗口在别处向上跳动，只是让某些检查点的约束变松，这不产生新的隐藏参数。
- 这与数值（`110 §2`）一致：随机跳动的窗口甚至收缩得更快，因为下降的窗口起了部分瓶颈的作用。

**宽窗口情形**：`98`、`108` 中用到上界正则性的只有顶角的边界层（`98` 引理 16）。同样的替换——上界只用活跃集，下界用下包络——适用于那里的层内分析。
- 这里只陈述，不重写细节。

## 3. 随机跳动

**推论 2**（概要）：设 W_k = ⌊ω_k (1 + 2B_k)⌋ + 1，其中 ω_k 是缓变的正则包络（例如 k^α，α ≤ 1），B_k 独立同分布，P(B_k = 0) = p > 0。则几乎必然刚性。

*证明概要*：
- 活跃集是 {k : B_k = 0}。它的间隔是几何分布，**无界**：在长度 Θk 的块中，最长的一段约为 log k。所以假设 LE 的第 3 条不能对一切块成立。
- **修改引理 3（记作引理 3′）**：
  - 下探—回升的论证中，回升所需的间隔是下探时刻 σ 所在的活跃间隔 g(σ)，回升的代价 ≲ E[g(σ)]/(A√W)。
  - σ 的分布密度 ≲ C(x + y)/τ^{3/2}。对几何分布的间隔，Σ_i g_i² τ_i^{−3/2} 在 τ ≥ L₀W 的部分，几乎必然 ≲ (L₀W)^{−1/2} · E[g²]/E[g]。
  - 所以只要块开头的 L₀ 个间隔都短，引理 3 的界就保持常数。
- **选块**：块的起点选在"此后 L₀ 个检查点都活跃"的位置。这个事件的概率是 p^{L₀} > 0，它们相互独立，所以几乎必然无穷多次出现。
- 其余同定理 1。∎

**如实的分级**：定理 1 是完整的证明（在 `97` 的引理之上）；推论 2 的引理 3′ 只写了概要。

## 4. 多链尺度相当的情形：需要的是另一种正则性

- 由 `109` 引理 3，条件于 (2,3) 的过程，U 的窗口是 [1 + D²/2, W¹ + D²/2]：宽度固定，随 c(t) = D²(t)/2 平移。
- c 的正则性：在 e₂ 的约束之下，D² 每个间隔的移动 ≍ √g。除概率 ≤ exp(−cA²) 的事件外，一个间隔内的移动 ≤ A√g。
- **需要的引理 E′**：宽度固定为 W、平移路径 c 每个间隔移动 ≤ A√g 的窗口中，U 的进入估计一致于 c 成立。
  - 与 §1 的反例对照：那里的平移是每步 W − √W，远超 √g。
  - 转到平移坐标 U − c，这是一个带"粗糙漂移"（每步 O(√g)，与游走自身同阶）的游走，在固定的窗口 [1, W] 中。
  - 困难：条件于一条最坏的粗糙路径时，漂移可以持续地把游走推向边界，所以一致的界不成立。
  - 真正需要的是对 c 的分布平均：好路径占绝大部分，坏路径的权重可以控制。这等价于直接做二维的联合估计。
- **判断**：多链的尺度相当情形不能完全化为一维的引理 E。它仍然需要一个二维的估计，只是比一般的楔形估计多了一个结构——两个坐标的过程独立（引理 3）。

## 7. 另外两个缺口的推进

### 7.1 Q\*\* 的 Borel 化约

v[m][r] 中的每个实数都是 (m, r) 的一个**地面编码**的 Borel 函数。所以若 Q\*\* 不成立，覆盖可以写成 N = N_{Φ(m, r)}，其中 Φ ∈ v（可以设 Φ 总是编码零测集）。对 `110` 定理 3 的一族实数 r∘g（g ∈ H ∩ v），令
> ψ(m′, g) := μ{ r′ ∈ P(m′) : r′∘g ∈ N_{Φ(m′, r′)} }，Z := { (m′, g) : ψ(m′, g) > 0 }。

它们都在 v 中。
- **对每个 m′**（不必泛型），截面 Z_{m′} 是 λ-零测的：这是 Kakutani–Fubini 论证，它不用到泛型性。
- **Q\*\* 不成立 ⟹ 对 Mathias 实数 m，H ∩ v ⊆ Z_m**。

所以问题化为：**是否有一个地面编码、截面处处 λ-零测的 Borel 集 Z，使 Mathias 实数处的截面包含一切地面参数，并且 Z 具有上面 ψ 的形式？**

- **不带形式限制时，这样的 Z 存在**：例如"g 的奇偶性沿 m′ 最终为常数"。它截面零测，并由 Mathias 的 Ramsey 性质包含一切地面的 g。
- **带形式限制时**：ψ(m′, g) > 0 需要 r′∘g 被 N 以正概率命中，也就是需要在无穷多个区间上精确地预言 r′ 在位置 g(n) 上的值。
  - 这要求 N 的构造"知道"g 在那些位置上的值，即在沿 m′ 的位置上猜中地面函数 g（各坐标以地面区块 B_n 为界）。
  - Laver 性质禁止这样的猜测，但只在区间位置以地面函数为界时（`109` 定理 2）。位置由 m 给出、快速增长时，现有的捕获论证不适用。
- **判断**：Q\*\* 的全部困难集中在"Laver 捕获能否推广到由 Mathias 实数本身给出的快速位置"。一个可能的工具是 Mathias 强迫的纯判定性质：对任何条件，存在只收缩无穷集部分的扩张来决定一个陈述。它可能允许在沿 m 的位置上逐块地做 Laver 式的捕获。这一步没有完成。

### 7.2 多链尺度相当：Holley 方法的障碍

- 在坐标 (D¹, −D²) 中，窗口约束是坐标方向的矩形，是格；但路径的联合分布不是 MTP₂。
- 以高斯近似说明：增量协方差 Σ 的相关为正时，路径精度矩阵的非对角块 −Σ^{−1} 含有正的元素，所以不是 M-矩阵。
- 在 (U, −D²/2) 中，路径分布是 MTP₂（两个独立的 MTP₂ 过程之积），但约束 U − D²/2 ∈ [1, W¹] 是对角的带，不是格。
- 所以 `98` 中处理行的 Holley 方法在多链中不可用。尺度相当的情形需要一个不依赖全正性的二维进入估计。
- 连续的类比（有界凸区域的内在超压缩性）支持它成立。
