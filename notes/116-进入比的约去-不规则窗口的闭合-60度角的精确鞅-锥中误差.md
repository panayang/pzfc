## 1. 不规则窗口：进入比的约去

### 1.1 设定

- 检查点链同 `97`，包络 ω 满足 SV，并且 ω_j ≤ W_j ≤ Γω_j。
- 高度 h = D − ω_j。
- 杀死机制 κ_j(h)：不减；h ≤ 0 时为 0；底部 D < 1 处必然杀死。
  - 确定性窗口：κ_j = 1{h > W_j − ω_j}；
  - 随机窗口的退火核：κ_j = F_j。
- **接触点**：W_j ≤ ω_j + ℓ 的检查点（软墙时，指该处杀死概率在 ℓ 之下为 0、之上 ≥ 常数的检查点）。

**（U）**（尺度 ℓ）：在块中，每 ⌈ℓ²/W⌉ 个相邻的检查点中至少有一个接触点。对软墙，改为 `114` 的（KU）。

### 1.2 三个引理

**引理 1**（上界，只用（U））：从时刻 s、深度 δ ≥ 0（或高度 ≤ 2ℓ，此时取 δ = 0）出发，
> P(存活到块末) ≤ C₁ (δ + ℓ)/W · Λ(s)，

其中 Λ(s) 是从 s 到块末的归一化（`97` 引理 8）。

*证明*：
1. **段的杀死**：取长为 ℓ²/(4W) 个检查点的段。检查点链每步的方差是 2W，所以段内的方差是 ℓ²/2。
   - 由反射原理，从高度 ≥ 2ℓ 出发，整段保持在 ℓ 之上的概率 ≥ 1 − 2P(Z > √2) ≥ 0.84 =: p₁。
   - 把段长放大 4 倍来使用（U），每个长为 ℓ²/W 的段至少含一个接触点；在接触点处，高度 ≥ ℓ 的路径必死。
   - 所以从高度 ≥ 2ℓ 出发的路径，在一段内被杀死的概率 ≥ c₁ := p₁·(1/4)（取四个子段之一），对软墙取 c₁ := p₁c₀。
2. **粗链**：在段起点处观察，得到步长 ≍ ℓ 的粗链；它每次在 2ℓ 之上时，以 ≥ c₁ 的概率被杀死。
   - 由反正弦律，粗链在 2ℓ 之上的访问次数 N_n 满足 P(N_n ≤ k) ≤ (1 + o(1))·√((k+1)/n)。所以
     > P(n 段后仍存活) ≤ Σ_k (1 − c₁)^k P(N_n = k) + P(n 步内未到 2ℓ)
     > ≤ (√π/(2√c₁))·n^{−1/2} + C δ/(ℓ√n)。
3. **换回单位并加上底部**：
   - n ≍ T·W/ℓ² 给出硬墙位于 2ℓ 时的形式 C(δ + ℓ)/√(TW)，常数 C₁ ≤ C(√π/(2√c₁) + 1)；
   - 加上底部与块长，同 `97` 引理 8(b)，只把边界层 √g 换成 ℓ。∎

**引理 2**（下界，不需要（U））：从深度 δ ≥ ℓ 出发，
> P(存活，末端 ∈ S) ≥ c₂ (δ + ℓ)/W · Λ(s)。

*证明*：管放在包络之下，那里 κ = 0，同 `97` 引理 5、8(a)。∎

**引理 D**（末次通过）：从高度 ≤ ℓ 出发，t₁ = Aℓ²/W 个检查点内，
> E[ 深度⁺_{t₁} · 1{存活于 [0, t₁]} ] ≤ (2 + C√A) ℓ · P(存活于 [0, t₁])。

*证明*：
- 深度 ≤ 2ℓ 的部分贡献 ≤ 2ℓ·P(存活)。
- 其余路径，按最后一次深度 ≤ ℓ 的时刻 u 分解。u 之后路径一直在包络之下，不被杀死，所以
  > E[深度_{t₁}; 存活，深度_{t₁} > 2ℓ] = Σ_u E[1{存活于 [0,u]，深度_u ≤ ℓ}·E_{D_u}[深度_{t₁}; 在 (u, t₁] 上深度 > ℓ]]，

  而同样的和把内层换成 P_{D_u}(在 (u, t₁] 上深度 > ℓ) 就是 P(存活，深度_{t₁} > ℓ) ≤ P(存活)。
- 条件于停在水平之下，末端深度的均值 ≤ ℓ + 越过量 + C√((t₁ − u)W) ≤ (1 + C√A)ℓ（标准的一侧条件的均值估计）。∎

### 1.3 引理 E*：约去

**引理 E\***：设起点 z 的高度 ≤ ℓ（深度 ≤ ℓ），并且 ℓ ≤ c′W^{3/4}。则
> P_z(存活，末端 ∈ S) ≥ ε · P_z(存活)，ε = c(A)·c₂ / (2 C₁ (3 + C√A))，

其中 c(A) := P(Z < −2/√(2A))。

*证明*：记 Σ₁ := 存活于 [0, t₁] 的权重（不含底部），G := {深度_{t₁} ≥ ℓ}，F := {在 [0, t₁] 中碰到底部}。
1. **分子**：
   - 检查点链的路径分布是 MTP₂ 的（全正核之积），Σ₁ 与 G 都是路径的减函数。由 Harris–FKG，E[Σ₁·1_G] ≥ E[Σ₁]·P(G)。
   - P(G) ≥ c(A)，因为 t₁ 内的方差是 2Aℓ²，而要下降 ≤ 2ℓ。
   - **底部**：P(F) ≤ exp(−W²/(C A ℓ²))。另一方面，"第一步下降 2ℓ，此后在包络之下停留到 t₁"给出 E[Σ₁] ≥ c·exp(−ℓ²/W)·√W/(√A ℓ)。
   - 当 ℓ ≤ c′W^{3/4} 时，前者 ≤ ½c(A)E[Σ₁]。
   - 于是由引理 2，分子 ≥ ½ c(A)·E[Σ₁]·c₂ ℓ/W·Λ(t₁)。
2. **分母**：由引理 1 与引理 D，
   > P_z(存活) ≤ E[Σ₁ · C₁(深度⁺_{t₁} + ℓ)/W]·Λ(t₁) ≤ C₁(3 + C√A)ℓ/W · E[Σ₁]·Λ(t₁)。
3. **相除**：E[Σ₁] 与 Λ(t₁) 约去。∎

**读法**：
- 从边界层内出发的路径，可能在最初的一小段时间里损失很多（例如下一个检查点就是硬接触）。
- 但这个损失对"最终进入内部"与"最终存活"是同一个因子。进入比只看损失之后的分布，而 Harris–FKG 保证损失之后的分布偏向内部，而不是偏向顶部。
- **软墙时的推广**：由 Jensen，E[Σ₁] ≥ e^{−A′} 是常数，所以底部的条件只要求 ℓ ≤ ηW。

### 1.4 定理

**定理 1**（不规则窗口，一般形式）：设在无穷多个块（X-时间 ΘW²）上：
- 块的两端都是接触点；
- （U）在某个尺度 ℓ 上成立，√W ≤ ℓ ≤ c′W^{3/4}（软墙时 ℓ ≤ ηW）。

则刚性。

*证明*：
- **进入**：块首是接触点，所以一切起点的高度 ≤ ℓ。深度 ≥ ℓ 的起点由引理 1、2 直接得到比值 ≥ c₂/C₁；其余由引理 E\*。
- **离开**：块末是接触点，对倒转的链同样处理（`97` 的倒转）。
- **中段**：同 `97` 引理 10。
- 由三段夹逼得 Δ ≤ C′，再由 `109` 定理 6 得到刚性。∎

**推论**：
1. **凸包定理**（`112` 定理 2）：ℓ = C√W。
2. **振荡窗口** k(1 + ½|sin k^{0.7}|)：
   - 零点间隔 Z ≈ 4.5W^{0.3}，每个零点附近最近的检查点的超出量 ≤ 0.18W^{0.7}；
   - 所以（U）在 ℓ = cW^{0.7} 上成立（ℓ²/W = c²W^{0.4} ≥ Z），而 W^{0.7} ≤ c′W^{3/4}；
   - 块的两端取在零点附近。刚性。
   - **`115` 命题 1（三距离定理）不需要。**
3. **随机窗口 ω_j U_j**，U 在 1 附近的密度 ≍ (U − 1)^β，β < 1：
   - 对单个窗口序列直接成立：取 ℓ = A W^{(β+2)/(β+3)}(log W)^{1/(β+3)}，则每段没有接触点的概率 ≤ e^{−cA^{β+3} log W}，对块中 ≲ W 个段取并，几乎必然成立；
   - 块首取为 K 之后的第一个接触点，块末取为 2K 之前的最后一个接触点。
   - 对任何 β（包括 β ≥ 1），用 `113` 定理 1 的退火路线，其中的软墙引理 A 现在由定理 1 的软墙形式给出（ℓ ≤ ηW）。
4. `111` 推论 2（Bernoulli 跳动）：F 有原子，ℓ ≍ √W。

**更正与撤回**：
- `114` 引理 S 与 `115` 引理 S′ 中的（KL）与缓变条件（H）都不需要。它们的结论仍然正确，但由定理 1 蕴含。
- `114` 引理 S 的第 3 步（"停在上方"与"下来"的指数比较）有一个没有写出的缺口：块剩余时间的归一化 Λ 不同。现在由"块首取在接触点"整个绕开。

## 2. 多链：60° 角的精确鞅与 120° 角的误差

### 2.1 60° 角是精确可解的

**命题 2**：在三链路状同步中，(D¹, D²) 的单步增量为 (1,0)、(−1,1)、(0,−1)。
- 白化之后，它们是三个互成 120° 的等长向量 s·e^{i(φ₀ + 2πk/3)}。
- 窗口矩形的 60° 角（(低,低) 与 (高,高)）的一条边沿着某个增量方向。
- 令 h = r³ sin 3θ（θ 从这条边量起）。则对任何间隔 c 的采样链 Y，h(Y) 是**精确的鞅**：
  > E h(y + ξ) = h(y)，对一切 y 成立。

*证明*：
1. **h 是多项式**：在白化的复坐标中，h = Im(e^{−3iφ}w³)，φ 是那条边的方向。这是一个三次多项式，所以 D⁴h = 0，Taylor 展开到三阶是精确的。
2. **二阶项**：ξ 是 c 个独立单步之和，白化后协方差是 cI，所以二阶项 = (c/2)Δh = 0。
3. **三阶项**：零均值独立和的三阶矩张量是各项之和，所以三阶项 = (c/6)·Im(e^{−3iφ}·E[η³])，η 是白化的单步（复数）。
   - E[η³] = (s³/3)Σ_k e^{3i(φ₀ + 2πk/3)} = s³e^{3iφ₀}。
   - φ 与 φ₀ 相差 π/3 的整数倍，所以 e^{3i(φ₀ − φ)} = ±1 是实数，Im = 0。
4. h 是整个平面上的多项式，所以不需要"远离边界"的限制。∎

**推论**：在 60° 角，逃逸概率由可选停止**精确**给出：
> P_x(σ_R < τ) = ( h(x) − E_x[h(Y_τ); τ < σ_R] ) / E_x[h(Y_{σ_R}) | σ_R < τ]。

越过边界时 h(Y_τ) ≤ 0，大小 ≲ 越过量·r²（越过量是 O(√c)）。
- 所以 P_x(σ_R < τ) ≥ h(x)/(C R³)，并且 ≤ (h(x) + C√c|x|²)/(cR³) ≍ V(x)/R³。
- **引理 W′ 在 60° 角无需任何误差估计。**

### 2.2 120° 角的误差

**引理 G（精确形式）**：在 120° 角，h = r^{3/2} sin(3θ/2)，对 |x| ≥ A√c，
> | E_x[h(Y_T)] − h(x) | ≤ C_G (1/|x| + c/|x|²)·V(x)。

- **三阶项**：c·|m₃|·|D³h| ≲ c|y|^{p−3}。在 |y| ≍ r 的环带中停留 ≍ r²/c 步，累计 ≍ r^{p−1}，相对于 r^p 是 1/r，**与 c 无关**。
- **四阶项**：c²|y|^{p−4}，累计相对误差 c/r²。
- 环带求和与尺度归纳同 `115` 引理 G，常数 C_G = C_T C_P (p³|m₃|/3 + p⁴/6)。其中：
  - C_T 是环带中的停留时间常数；
  - C_P 是逃逸上界的常数；
  - m₃ 是白化单步的三阶矩。
- `115` 写的 √c/|x| 在 c ≥ 1 时比 1/|x| 弱，仍然正确；这里的形式更精确。

### 2.3 数值（`experiments/cone_harmonic.py`）

**设定**：在锥 ∩ {|w| < 45} 上，用稀疏线性方程组精确求解 u(x) = E_x[h(Y_T)] 与逃逸概率。

| 角 | c | 相对误差 max·\|x\|（各尺度） | 逃逸·R^p/V 的范围 |
|---|---|---|---|
| 60° | 1 | 0（精确） | [0.68, 2.99] |
| 60° | 4 | 0（精确） | [0.95, 2.54] |
| 120° | 1 | 0.14、0.15、0.15、0.14 | [0.90, 2.11] |
| 120° | 4 | 0.12、0.13、0.13、0.12 | [0.83, 1.89] |

**读法**：
- 60° 角的误差恰为 0（命题 2）。
- 120° 角的误差 × |x| 在各尺度上是常数，并且与 c 基本无关（引理 G 的 1/|x|）。
  - 表中 c = 4 的一行是 0.06–0.07 乘以 √c = 2 换回的绝对单位。
- 逃逸概率与 V(x)/R^p 同阶。
