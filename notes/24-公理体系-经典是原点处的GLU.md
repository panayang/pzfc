# 24 · 公理体系：经典是原点处的 GLU

> **第十七轮注**：公理体系的当前写法见 `33`。本篇的核心（问、GLU₀、大小）不变；四个参数后来收成三个（W，S，𝒞），各种情况改写为一条公理模式 GLU(π)（`27`、`28`）。

> **经典基础是一句话**：记录恰好是小的、良基的局部数据的唯一粘合；小的族也有非唯一的粘合。
> **拓展是改变这句话里的形容词**：良基的（形状）、唯一与非唯一的范围（对称）、回答的值（权重）、局部数据是否全局（上下文）。经典的取值就是原点。

> 接 `17`（PZF 核心）与 `22`、`23`（GLU）。本篇把前十轮收拢为公理体系本身：核心里只有一条关于粘合的公理，家族是一个构造。
> 形式化见 `lean/Shapes.lean` §7：新增 7 条，都不依赖任何公理。其余引用的定理在文中标出。文献最后核查。

## 0. 历史：公理体系是怎样收窄到这里的

| 轮 | 对公理体系留下的 | 现在的位置 |
|---|---|---|
| 一（`01`） | 对象就是它的回答族；外延 → 互模拟；良基 → 终性；把 GLU 写出来，而不假设它 | 方向保留。材料（探针复形、经验模型）取自物理形式，已弃 |
| 二（`05`–`09`） | 基础层 / 建模层 / 不变层；对角线在任何基础里都会重现 | Kolmogorov 的全局 Ω 属于建模层；对角线不在拓展范围内 |
| 三（`10`–`13`） | 四条原理；缝定理；CH 一分为二 | 缝定理成为 ! 与 ∃ 的耦合（§4） |
| 四、五（`14`–`16`） | 值代数、缺陷、吸收梯子 | 值参数 W 的内部结构 |
| 六（`17`） | PZF：问题与记录，对 ZF(C) 保守 | **核心保留**；本篇把它的公理重排为 GLU 的条款 |
| 七（`18`–`20`） | 情况是核心内可定义的宇宙，经典是原点 | 机制保留；八条轴过宽，现在只留 GLU 的参数 |
| 八（`21`） | 墙在从事件到点的桥上 | 这些桥是 GLU 的面 |
| 九（`22`） | 墙就是 GLU：∃、!、形状、值 | 本篇的骨架 |
| 十（`23`） | 参数之间并不独立 | 本篇"参数只有这几个"的依据 |

两处教训直接决定了本篇的形状：
- 第六轮把"情况"写成核心之外的公理，于是情况之间、情况与原点之间都没有映射；
- 第七轮改为核心内部的宇宙，却把能想到的构造都排成了轴。

本篇保留第七轮的机制，但把参数限定为 GLU 本身的参数。

## 1. 开工前的自检

- **目标**是公理体系，GLU 是它的骨架，不是再写一张"面"的表。
- **不做大统一**：参数只取 GLU 的。逻辑、非谓词性、宇宙层级、可实现性、大基数都不进来。
- **不拼图**：核心是一条公理的四个条款；家族是一个构造的四个参数；参数之间的耦合是定理。
- **以经典为原点，保守**：每个情况都含有经典的像。
- **0/1**：局部 / 整体是 GLU 本身的两边，不是开关；四个参数都是序或格。

## 2. 语言：问题是局部数据，记录是它们的粘合

沿用 PZF 的语言（`17 §2`）：
- 个体；
- 关系 $x\,\varepsilon\,q$：$x$ 对问题 $q$ 回答"是"；
- 谓词 $\mathrm Q(q)$：$q$ 是一个问题。

由此分出两层：
- **局部层**：问题及其回答。回答取什么值（锐的或分级的）、哪些问题能一起问（上下文），都是这一层上可定义的结构（§5）。
- **整体层**：记录，即能作为回答出现的个体。

几种个体的身份：
- **集合**：既是问题又是记录；
- **原子**：是记录，但不是问题；
- **真类**：是问题，但不是记录。

一个问题成为对象，当且仅当它本身可以被问及——**完成，就是变得可被回答**。

## 3. 公理：问、GLU₀、大小

**问（局部数据总能形成）**
- 对每个只量化记录的条件，有一个问题，它的回答恰好是满足条件的记录。
- 回答相同的问题相等。

**GLU₀（原点处的粘合）**
> 记录恰好是小的、良基的局部数据的唯一粘合；小的族也有非唯一的粘合。

它有四个条款：
1. **唯一（!）**：回答相同的问题是同一个。对集合而言，这就是外延公理。
2. **确定的存在（∃）**：小的问题都是记录。
3. **形状**：每个记录都是某个良基系统的解。
4. **非唯一的存在**：由非空记录组成的小族，有一个记录，从每个成员里取出一个回答。

**大小（Russell 给的界）**
- "小"是指某个记录在函数型问题下的像；
- 并与幂的问题是小的；
- 有一个无穷的记录。

这里不用冯·诺伊曼的大小限制（不与全宇宙等势即为小），因为它推出全局选择，会把条款 4 偷偷带进条款 2（待核验）。

除此之外不再需要别的公理。"锐"也不是另加的：ε 的回答本身就只有是与否。

### 经典公理都是 GLU₀ 的条款

| 经典公理 | GLU₀ 的条款 | 依据 |
|---|---|---|
| 外延 | 1 唯一 | 在良基结构上，下面四者等价：外延；强外延；良基系统的解唯一；一切系统的解唯一（`wf_ext_iff_strong`、`ext_of_unique_wf`、`unique_of_wf`、`strong_of_unique`） |
| 配对、分离、替换 | 2 确定的存在 | "小"的定义 |
| 基础 | 3 形状 | 隶属是良基的，当且仅当每个元素都是某个良基系统的解（`wf_iff_solved`） |
| Mostowski 坍缩（定理） | 2 与 3 合起来 | 由外延与替换推出：每个良基系统恰有一个解，由递归得到，不用选择（`recursion_solves`；良基树模型中的 `solve_*`） |
| 选择 | 4 非唯一的存在 | `22 §1` |
| 并、幂、无穷 | 大小 | — |
| 排中律 | 被 1 与 4 迫使 | Diaconescu（`em_of_choice`） |

**定理（经典实例）。** 问、GLU₀、大小三组公理（允许原子），就是 PZFC₀（`17 §3`）的公理的重排，因而对 ZFC 保守（`17 §4`）。

GLU₀ 的四个条款并不对称：
- 条款 1–3 合在一起不需要任何选择（`recursion_solves`）；
- 真正额外的承诺只有条款 4（`23 §4`）。

所以 `22 §4` 所说经典"过宽"的那一部分，恰好是一个条款。

## 4. 拓展：同一句话，换它的形容词

GLU₀ 里的每个形容词都是一个参数，经典的取值就是原点：

| GLU₀ 里的词 | 参数 | 经典取值 | 离开原点，到达的情形 |
|---|---|---|---|
| 良基的 | 形状 S | 良基的图 | 按关系、可以循环的同一 |
| 唯一的；非唯一粘合的范围 | 对称 𝔖：原子、置换群、子群滤子 | 平凡 | 数得出、分不开的个体；选择只在对称允许处成立 |
| （回答是）锐的 | 值 W | 2 | 回答是权重 |
| （局部数据是）全局的 | 上下文 𝒞 | 单点 | 只有局部的联合 |

参数只有这四个，而且彼此咬合（`23 §4`）：
- **唯一性的形式由 S 决定**：良基处是外延，一切图上是强外延（§3 表）。S 与同一原理之间也不只是二分：Aczel 讨论过一族反基础公理（AFA、Finsler 的 FAFA、Scott 的 SAFA、Boffa 的 BAFA），各对应一种同一原理（待核验）。
- **𝔖 同时决定 ! 与 ∃ 在哪里失效**：! 在原子之间失效；∃ 在等变选取不存在处失效（`Invariants.no_equivariant_choice`）。缝定理说，二者是同一个对称的两面。
- **锐性被 ∃ 与 ! 迫使**。所以 W、𝒞 离开原点时，真值的分级只能出现在情况的内部（见下）。

**一个构造。** 对参数 π =（S，𝔖，W，𝒞），令 U(π) 为 **π-系统的解所组成的宇宙**：
- 它的点是带基点的系统：形状属于 S，隶属取值于 W，可以随 𝒞 中的上下文变化，并且被 𝔖 的滤子里某个子群固定；
- 其中的相等是 π-互模拟。

在原点，U(π₀) 就是核心的记录宇宙。已知的单参数情形都是这个构造的特例：

| 参数 | U(π) | 经典原点的像 |
|---|---|---|
| S = 一切图 | Aczel 的反基础宇宙 | 良基部分 |
| 𝔖 非平凡 | Fraenkel–Mostowski 置换模型 | 纯部分（核） |
| W = 完备布尔代数 B | 布尔值宇宙 $V^B$（B-名就是 B 值隶属的良基系统） | 检验名 |
| 𝒞 = 一个位形（locale） | Heyting 值宇宙 | 常对象 |

这些宇宙都在核心内可定义（置换模型要用到核心里的原子），而且每一个都含有经典原点的像。

它们分成两类：
- 前两类保持锐的真值，可以写成经典的一阶理论 T(S, 𝔖)；
- 后两类的真值取值于 W，或位形的 Heyting 代数，只能作为核心内部的宇宙。

这个区别不是另外选的。核心的经典逻辑，就是真值层面的全局粘合；按 Diaconescu，只要 ∃ 与 ! 都在，它就去不掉。

## 5. 局部层：概率的语言

对每个记录 r，它的子问题构成一个事件代数；这个代数上的**态**就是局部数据。
- **锐态**：主超滤恰好对应 r 的元素，也就是说，**记录的元素正是被实现了的锐态**。非主超滤是锐的局部数据，却不粘合成任何元素。
- **分级的态**：测度。
- 一般的事件代数不必是某个记录的全部子问题。例如测度代数没有点；Russell 的袜子也是这种情形（`21 §5`）。

这就是开头"用概率的语言表述集合论"的精确形态：
- 集合是被实现了的锐态；
- 子集是事件，只在被实现处才是点集——"子集只在某种意义上成立"；
- 底层是局部层，顶层是整体层。

**回收标准测度论。** 权重的粘合在原点成立：
- 在可数选择之下，有限生成的权重在正则事件上可加（`16 §3`，`Weights.nullMeasurable_iff_additive`）；
- Kolmogorov 扩张在有向形状上成立（`22 §1`）。

所以标准测度论，就是权重的 GLU 在原点、在选择坐标 ≥ CC 处的形态（`17 §5`）。

**Kolmogorov 被局部化**（`22 §3`）：每个上下文一个概率空间；全局的 Ω 存在，当且仅当这族局部空间的粘合没有障碍。

## 6. 保守性

- 核心对 ZF(C) 保守（`17 §4`）。本篇只重排了公理，没有改动核心。
- 每个 U(π) 都在核心内可定义，所以谈论它们不会增加关于集合的定理；而每个 U(π) 都含有经典原点的像。
- 保持锐真值的 T(S, 𝔖)，是相对于经典区域的保守扩张：
  - 它的纯良基部分满足 ZFC；
  - ZFC 的每个模型，都是某个 T(S, 𝔖) 模型的纯良基部分。

  S 这一维已核查（`17 §6` F 行）；与置换模型组合的情形待核验。

## 7. 对照开头那段话

| 倾向 | GLU₀ 中的词 | 在哪里拓展 |
|---|---|---|
| 线性时间 | 良基的：粘合就是递归 | S：解方程（`23 §3`） |
| 还原论 | 唯一的 + 良基的：外延加基础 | S 给出强外延；𝔖 给出原子 |
| 绝对因果 | 非唯一粘合存在 | 𝔖：按对称分级 |
| 目标拟合（单一标量） | 非唯一粘合用于比较（Hartogs） | 𝔖 |
| 绝对状态（全局的 Ω） | 局部数据是全局的 | 𝒞、W：局部层 |

症状"突破之后无法描述"在这里可以这样读：
- 在经典语言里，不粘合的局部数据没有对象身份，只能被说成"找不到全局模型"；
- 在这里，它们是局部层里的一等对象（问题、态），它们不粘合的程度是可以陈述的障碍。

## 8. ZFC 判定不了的，落在哪里

- **CH** 问的是连续统有多少个点，属于整体层。在局部层，连续统的测度代数是规范的（Carathéodory，`21 §6`），CH 在那里看不见。
- **CH_C 与 CH_ℵ**（`17 §7`）：
  - CH_ℵ 用到良序，也就是非唯一的粘合（条款 4）；
  - CH_C 与权重的粘合（正则性）相连；
  - 两者在不同的 U(π) 中被分开判定。

> **第二十轮注**：上面最后一句不准确。它只是说：在不同的内部宇宙里，相应的命题取不同的值——这与强制法给出不同的模型是一回事，不是在 ZFC 中判定 CH。本体系对 ZFC 保守，所以不判定任何新的集合论命题（`37 §3`）。
