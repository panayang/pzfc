# 28 · π 是否完整，以及 GLU(π) 的整体形式化

> **第十七轮注**：§6 的计划已完成（`29`–`32`）；公理体系的当前写法见 `33`。

> **第十六轮注**：§3 把"带标签的观测"排除在外，是错的。纯集合承载不了对称（`Kinds.kind_all_fixed`），数得出、分不开的个体需要标签（原子）。"回答是什么"包括值与标签；这不增加参数，是把 W 补全。见 `29 §4`。

> 回答两个问题：
> - 参数 π =（S，𝒞）是定的吗？还是说 GLU₀ 与墙还有别的部分？
> - GLU(π) 整体应当怎样形式化？
>
> 短答：
> - **π =（S，𝒞）不完整。** `25` 把"值"折叠得太早。恢复之后 π =（W，S，𝒞）：它恰好是一个局部数据的三个方面，也恰好是第一轮三个旋钮在一个模式里的位置。
> - **墙还有第一层**，即全局上下文。它不是参数，而是种类之间的映射：整体截面。
> - **形式化**：用一条泛性质——种类 π 的宇宙，是小的 π-系统之中的终对象；参数之间的映射，给出坐标轴与原点。
>
> 形式化的第一步：`lean/Scheme.lean`，4 条，只用到外延的认同（`propext`、`Quot.sound`）。

## 0. 自检

- **不拼图**：参数必须来自 GLU 自身的结构。其余的成分，要么是推论，要么是每个基础都要付的不变的墙；凡是列进来的，都要说出它属于哪一种。
- **不迷失在形式化**：本轮只写统一的接口，并检验设计的两个断言；其余给出分阶段的计划。

## 1. 逐词检查 GLU₀

GLU₀：**记录恰好是小的、良基的局部数据的唯一粘合；小的族也有非唯一的粘合。**

| GLU₀ 中的成分 | 它是什么 | 在形式化中的位置 |
|---|---|---|
| 局部数据的值：回答只有"是 / 否" | 墙：回答可以是权重 | 参数 **W** |
| 局部数据指向什么：良基的 | 墙：按关系、可以循环的同一 | 参数 **S** |
| 局部数据在哪里给出：单一的全局上下文 | 墙：没有全局上下文；数得出、分不开 | 参数 **𝒞** |
| 一个上下文结构上的对象，是否有全局的版本 | 墙的第一层（`22 §1`） | 种类之间的映射：**整体截面** |
| 唯一：同一原理 | 推论：由 W、S 决定（π-互模拟）；失效之处（原子）属于 𝒞 | — |
| 非唯一的粘合：选择 | 推论：由 𝒞 决定（`25 §5`） | — |
| 真值是锐的：排中律 | 推论：由 𝒞 决定（`Contexts`） | — |
| 小的 | 不变的墙：对角线给出的界，每个基础都要付（`07`、`21 §7`） | — |
| 描述这些数据的语言是经典的 | 这是保守性与"以经典为原点"的含义，不是墙 | 描述层 |

## 2. 发现一：少了值 W

`25 §4` 只把权重读成"真值上的态"，也就是一个陈述成立的概率。但权重还有另一种读法：**它是局部数据本身的值**，即"y 以多大的权重属于 x"。

以这种局部数据为材料的对象（带权的集合、概率的过程）：
- 有自己的同一原理：带权互模拟。两个过程等同，当且仅当它们对每一类后继给出相同的权重。
- 也有自己的粘合：局部的边缘分布粘成整体分布，即 Kolmogorov 扩张。

它不能归结为"锐的隶属加上一个态"。

这正是开头的直觉所要的东西："用概率的语言表述集合论，'子集'只在某种意义上成立"——隶属本身带权重。`25` 把它折叠掉，是过度约简。

恢复之后，**π =（W，S，𝒞）**。

## 3. 为什么是这三个，而不是拼图

GLU 说：对象与局部数据一一对应。所以 GLU 全部的自由度，就是局部数据的自由度。而一个局部数据有且只有三个方面：
- **回答是什么**：值 W；
- **回答指向什么**：形状 S；
- **回答在哪里给出**：上下文 𝒞。

其余的成分，都由这三个决定（§1 表）。

这也正是第一轮的三个旋钮（`01`）：
- WF → S；
- Sharp → 第二轮已经指出，它混了两个正交的方向（`06 §1`）：分级 → W；构造性、随上下文变化 → 𝒞；
- GLU 的第一层（全局上下文）→ 𝒞 与整体截面。

三个旋钮本身没有错；错在把它们当成三条独立的公理，而不是同一个模式里局部数据的三个方面。

参数之间的耦合是定理，不是新的参数：
- **幂等的值就是真值，归入 𝒞。** 取值于"在上下文的细化下保持的命题"的回答，恰好等于在每个上下文里各自的回答（`Scheme.solvesV_truth_iff`）；单一上下文就是锐的回答（`Scheme.solvesV_point_iff`）。
- **𝒞 中的对称，迫使内在的权重。** 在数得出、分不开之处，权重由对称定出（`Principles.gap`、`Socks`；有理数来自轨道，`16 §1`）。
- 所以 W 中真正自由的，是**可加的、外在的**权重。

不纳入的，及其理由：
- **其他观测签名**（带标签的隶属等）：没有哪一种不适用的情形需要它。
- **结构规则**（复制、丢弃）：第三轮审计过，没有原理支持（`10`）。
- **可实现性**（回答要有计算的见证）：它是 𝒞 的另一种形态（不是场景），暂不纳入，记为开放。
- **大基数**：不属于 GLU。

## 4. 发现二：墙的第一层是种类之间的映射

`22` 把墙分成两层：
- 存在一个全局上下文；
- 在其中，局部与整体完全对应。

`27` 的模式 GLU(π) 只写了第二层，也就是每个种类内部的对应。

第一层问的是：**一个上下文结构上的对象，何时有全局的版本。** 它是一个映射——整体截面：

Γ：种类（W，S，𝒞）→ 种类（W，S，单点）。

- Γ 不满射，就是"局部一致而没有联合"的那类不适用（`22 §4`）。
- Kolmogorov 扩张，就是带权种类在有向上下文上的这一层粘合：局部的边缘分布粘成整体分布。

所以形式化不能只写每一个种类，还必须写**种类之间的映射**。

## 5. GLU(π) 的整体形式化

**一条泛性质。** 种类 π 的宇宙，是小的 S-形 π-系统之中的**终对象**：
- 每个这样的系统，恰有一个解（到宇宙的保结构映射）；
- 宇宙的每个对象，都是某个这样的系统的解。

这是 `Shapes.GLUShape` 的一般形式，也回到了第一轮 `01` 的 A1–A2（同一 = 互模拟；良基 → 终性）。只是现在，它是由 GLU 推出的，参数也清楚了。

**π-系统的写法。**
- **W**：一个值结构，即回答的值域，加上"族中之一"的聚合方式：锐的回答是"存在"，真值是"并"，权重是"和"（`Scheme.Val`）。
- **S**：关于系统的一个谓词：良基的，或一切。
- **𝒞**：一个小范畴作为上下文结构。
  - 单点：经典；
  - 预序：可以细化的上下文，真值随之变化（`Contexts`）；
  - 群（一个对象，加它的自同构）：对称，即支撑（`Supports`）；
  - 一般的小范畴加覆盖：两者兼有，即场景。

  这统一了 `27 §7.1` 的两种形态：**细化是态射，对称是自同构。**
- **π-系统**：𝒞 上的一个预层 A，连同每个结点在每个上下文里给出的局部数据——它的子结点，以及各自的值；形状属于 S。
- **解**：一个保结构的映射 f，使对象的局部数据恰好是子结点的像，按 W 聚合（`Scheme.SolvesV`）。

**推论，而不是公理。**
- 同一是 π-互模拟（终对象的余归纳原理）；在良基处，退化为外延的归纳（`Shapes` §7）。
- 排中律与选择，由 𝒞 决定。

**种类之间的映射：坐标轴与原点。** 参数之间的映射，诱导种类之间的映射：
- **S**：良基 ⊆ 一切 ⟹ 嵌入（已证：`UA.embed_eq_iff`、`UA.embed_mem_iff`）。
- **W**：
  - Bool → W（锐的回答是一种特殊的权重）⟹ 经典的种类嵌入带权的种类；
  - W → Bool（支撑，n ↦ [n > 0]）⟹ "存在是计数的影子"（`15 §5`）成为种类之间的映射；`Grades.any_iff_count_pos` 是它的最小形态。
- **𝒞**：𝒞 → 单点，诱导两个方向的映射：
  - 常对象：经典的种类嵌入每一个上下文种类；
  - 整体截面 Γ：墙的第一层。

π₀ =（Bool，良基，单点）是参数的原点：每个参数方向都有从它出发的规范映射，有的还有回到它的映射（Γ、支撑）。

"以经典为原点、沿坐标轴到达各种情况"，在这里有了精确的含义：**整个家族应当是 π 的函子（阶段 4 要证明），经典是它在原点的值。**

**实现，也就是保守性。** 每个种类都能由记录构造出来：把小的带基点 π-系统按 π-互模拟取商（Aczel–Mendler 的构造）。所以对 ZFC 保守。已做的：（Bool，一切，单点），见 `Shapes` §8。

## 6. 分阶段的形式化计划

| 阶段 | 内容 | 状态 |
|---|---|---|
| 1 | 统一接口：值结构、解、GLU(π) 作为终性。检验两件事：锐的回答时就是 `GLUShape`（`gluV_sharp`）；取值于真值的回答恰好是逐上下文的回答，单一上下文就是锐的（`solvesV_truth_iff`、`solvesV_point_iff`） | 完成（`Scheme.lean`） |
| 2 | 𝒞 作为小范畴：预层上的系统与解；构造（Bool，一切，𝒞），推广 `UA`；对称一支接上 `Supports`；常对象与整体截面 Γ | 完成（`29`、`30`） |
| 3 | 可加的 W，放在 mathlib 部分（有限支撑的权重）；带权互模拟；支撑映射 W → Bool | 完成（`31`、`34`）；带权互模拟的关系形式未做 |
| 4 | 种类之间的映射与耦合定理：选择 ⟺ 局部选择能沿 𝒞 粘起来；Kolmogorov 扩张作为带权种类在有向上下文上的整体截面 | 四种情形与各方向的映射完成（`32`、`33 §4`）；一般判据与函子性未做 |

风险与注意：
- 宇宙层级：种类的对象在高一层，例如 `UA : Type 1`。
- "小"用类型的层级来表示。
- 预层上的"子结点的集合"要仔细写：它在每个上下文里给出，并且沿细化相容。
- 可加权重的像，需要有限支撑，或者完备性。

## 7. 回答

- **π =（S，𝒞）不是定的：少了 W。** 恢复后 π =（W，S，𝒞），恰好是一个局部数据的三个方面，也是第一轮三个旋钮在一个模式里的位置。其余成分都是推论，或者是不变的墙。
- **墙还有第一层。** 它不是参数，而是种类之间的整体截面 Γ。
- **形式化**：一条泛性质（终对象）；参数化的局部数据；参数之间的映射给出坐标轴与原点。
- `27` 里"两种形态待统一"的问题已有答案：上下文是小范畴，细化是态射，对称是自同构。
