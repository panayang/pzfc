# 98 · 宽窗口的刚性，以及相变的闭合

> 第五十三轮，第二块（`94 §4` 的第二个问题；`83`、`88`、`97`）。
>
> **范围**：概率论（过程层），主线。

---

## 0. 路线检查

- **原则在推动的**：`97` 证明了缓变窗口的刚性。剩下的是宽窗口：窗口远大于扩散的尺度，但 ρ → 0。证明之后，`83` 的相变猜想（刚性 ⟺ ρ → 0）对正则的窗口完全成立。
- **会拉着走的**：全正性与 Holley 不等式（FKG 一类）、Cramér 倾斜、条件为正的游走。只作工具。
- **是否回答 `00 §7`**：回答"次序何时完全由迹决定"——恰好在同步没有特征尺度的时候不是。

**与 `97` 的不同**：
- 宽窗口中，一个块的行（第 K 层，尺度 W_K）与列（第 L 层，尺度 W_L ≫ √P_L）不在同一个尺度上。
- 列 u 很大时，到达 u 的路径是一个带漂移 u/P_L 的大偏差；它给行的依赖加上一个因子 e^{−λd}。
- 所以块必须长到 ρ_L W_K ≲ 1，才能使这个因子有界。块跨越许多尺度，不能照搬 `97` 的三段夹逼。
- 这里改用 `94` 的**角点公式**：只需要四个角点。全正性与 Holley 不等式替代了大部分边界的分析；剩下一处真正的边界层，在右上角点。

## 1. 设定与假设

记号同 `97 §1`：
- X-时间中的游走 D，增量 ζ = 1 − 几何(½)；
- 检查点 P_ℓ，约束 D(P_ℓ) ∈ [1, W_ℓ]；
- M_{K→L} 是检查点之间的核之积。

**假设（WW，宽窗口）**：存在函数 ω : [0, ∞) → [1, ∞)，以及常数 C₀ 与 θ < 1，满足：
1. ω 不减、凹、倍增有界（ω(2P) ≤ C₀ ω(P)）；
2. |W_ℓ − ω(P_ℓ)| ≤ C₀ √W_ℓ；
3. **宽**：ω(P)/√P → ∞；
4. **ρ → 0**：ω(P)/P → 0；
5. **严格凹**：ω′(P) P / ω(P) ≤ θ。

**例子**：f(k) = ⌊c k^α⌋，α > 1。这时 ω(P) ≍ P^β，β = α/(α+1) ∈ (½, 1)，θ = β。

## 2. 工具

### 2.1 全正性（`94`）

**引理 11**：
1. 每个 M_{K→L} 是 TP₂ 的。其行的条件分布 π_d := M(d, ·)/M(d, ·)（行和归一）在 d 上按似然比递增。特别地，它们按随机序递增。
2. （角点公式，`94` 定理 1）Δ(M) = log CR，其中
   > CR = M(d⁺, u⁺) M(d⁻, u⁻) / ( M(d⁺, u⁻) M(d⁻, u⁺) )，
   
   d^±、u^± 是行与列的最高与最低指标。
3. 对 s < s′，列函数之比 M(s′, u)/M(s, u) 在 u 上递增。

*证明*：
- 负二项的概率质量函数是对数凹的，所以 P(ξ = d′ − d) 是 TP₂ 的 Toeplitz 核。限制到窗口与相乘都保持 TP₂（Cauchy–Binet）。第 1、3 条就是 TP₂ 的定义。
- 第 2 条：有序的行对与列对，其交叉比 ≥ 1，并且沿行（列）的间隔可乘。所以最大者在两端取到。∎

### 2.2 Holley 不等式：上界约束只会把路径往下压

**引理 12**：设 B = {一切检查点 D ≥ 1}，T = {一切检查点 D ≤ W_ℓ}。对任何起点，在检查点值上，
> P( · | B ∩ T ) ≤_st P( · | B )（逐坐标的随机序）。

特别地，对 D 的任何递增函数 φ（例如 φ = e^{λ D_end} 1_{D_end > a}），E[φ | B ∩ T] ≤ E[φ | B]。

*证明*：
- 检查点链是转移核为 TP₂ 的 Markov 链，所以它的有限维联合分布 p 是 MTP₂ 的（Karlin–Rinott 1980）：
  > p(x ∧ y) p(x ∨ y) ≥ p(x) p(y)。
- 令 μ₁ ∝ p·1_{B∩T}，μ₂ ∝ p·1_B。B∩T 与 B 都是坐标区间之积。所以当 x ∈ B∩T、y ∈ B 时，x ∧ y ∈ B∩T，并且 x ∨ y ∈ B。于是
  > μ₁(x ∧ y) μ₂(x ∨ y) ≥ μ₁(x) μ₂(y)。
- 由 Holley 不等式（先对有界的截断成立，再取极限），μ₁ ≤_st μ₂。∎

### 2.3 局部的破产估计（`97` 引理 2–5 的推论）

**引理 13**（两侧的 ballot 估计）：设一段检查点区间的 X-时间为 t ∈ [W², ΘW²]，其中的窗口都 ≥ ΓW，间隔都 ≤ C W²。则：
1. **上界**：对一切 x、z ≥ 1，
   > P_x( 存活，D(t) = z ) ≤ C (x + √W)(z + √W) / t^{3/2}。
2. **下界**：对 x ∈ [1, ΓW]、z ∈ [W/8, ΓW]，
   > P_x( 存活，D(t) = z ) ≥ c (x + √W) / W²；
   
   对 z = 1 与 x ∈ [W/8, ΓW]，同样的下界成立，右边换成 c √W / W²。
3. **存活**：P_x(存活) ≤ C_B (x + √W)/√t（`97` 引理 3），并且对 x ≤ ΓW，P_x(存活) ≥ c (x + √W)/W。

常数只依赖于 Θ、Γ 与类 𝒢。

*证明*：
- **上界**：在 t/2 与 3t/4 处分段。
  - 前半段用 `97` 引理 3，得 P_x(前半段存活) ≤ C(x + √W)/√t；
  - 中间一段用局部极限定理，点概率 ≤ C_L √4/√t；
  - 最后一段倒过来读：Σ_b P_b(最后一段存活，终点 z) = P̂_z(反向存活) ≤ C(z + √W)/√t。
  - 三者相乘。
- **下界**：与 `97` 引理 8(a) 的三步相同：抬离边界、升到 W/4、沿直线的管，只是终点钉在 z（`97` 引理 5 给出 c₅/W）。
  - 终点为 1 时，把整段倒过来读：反向的游走从 1 出发抬离边界、升到 W/4，再沿直线到 x。
  - 窗口 ≥ ΓW，所以管在允许的范围内。
- **存活的下界**：同一构造，不钉终点。∎

**关于块开头的窗口**：在第 K 层，窗口只有 W = W_K。
- 在 WW 之下，P_K ≪ W²（因为 ω(P_K) = W ≫ √P_K）。
- 所以经过 X-时间 t_* = W²/100 之后，窗口 ≥ ω(t_*) − C₀√W ≫ W。
- 引理 13 用于第 K 层起的块时，把"窗口 ≥ ΓW"理解为：
  - 在 [0, t_*] 中窗口 ≥ W；
  - 之后窗口 ≥ ΓW。
- 下界的构造路径在 [0, t_*] 中留在一个宽 hW 的管里（h 小），这仍是 `97` 引理 5 的变体（R = hW/2，段数随 h 增加）。所以引理 13 照样成立，常数还依赖于 h。

## 3. 块的取法

给定 K，记 W = W_K，s₀ = W/2，S = [W/4, ΓW]。Θ、Γ 在下面选定。
- **第一段**：m₁ 是使 P_{m₁} − P_K ≥ ΘW² 的最小的层；A = M_{K→m₁}。
- **中段**：m₂ 是使 P_{m₂} − P_{m₁} ≥ W² 的最小的层；Q = M_{m₁→m₂}。
- **长段**：N = M_{m₁→L} = Q · M_{m₂→L}。L 的选法如下。令
  > m_L := (W_L − s₀) / (P_L − P_{m₁})，
  
  取 L 使 m_L ∈ [1/(8W), 1/(4W)]。
  - 这样的 L 存在：m_{m₁+1} ≈ 1；由 ρ → 0，m_L → 0；并且当 L 足够大时 m_{L+1}/m_L ≥ ½。
  - 于是 t := P_L − P_{m₁} ≍ W · W_L ≫ W²。
- **倾斜**：令 λ 满足 Λ′(λ) = m := m_L。于是 0 < λ ≤ m ≤ 1/(4W)，所以 **λW ≤ ¼**。

**常数倾斜是精确的**：在测度 Q_λ 下（每步按 λ 倾斜），对一切 s、u，
> N(s, u) = e^{−λ(u − s) + tΛ(λ)} · N^λ(s, u)，

其中 N^λ 是 Q_λ 下的同一个核。这是一个对角的规范变换，没有误差项（`97` 引理 7 中的中间和在 λ 为常数时为零）。

## 4. 行：四个角点中的两行

**引理 14**：存在 Θ、Γ，使对一切足够大的 K 与 d ∈ {1, W}，
1. π_d(S) ≥ ½；
2. E_{π_d}[ e^{λ(D − s₀)} ; D > ΓW ] ≤ ¼。

*证明*：
1. **底行不贴底**。由引理 13，
   > π_1([1, W/4)) ≤ Σ_{z<W/4} C(1 + √W)(z + √W)/(ΘW²)^{3/2} ÷ ( c√W / (√Θ W) ) ≤ C′/Θ。
   
   分母是存活的下界：先升到 W/4，再以 ≥ c/√Θ 的概率存活到块末。
2. **顶行不贴底**。由全正性（引理 11 第 1 条），π_W ≥_st π_{W/2}，所以 π_W([1, W/4)) ≤ π_{W/2}([1, W/4))。
   - 对 d = W/2，同样的计算给出 ≤ C(W)(W²)/(Θ^{3/2}W³) ÷ (c/√Θ) = C′/Θ。
   - 分母：从 W/2 出发，先在 [W/4, 3W/4] 的管中待到 t_*，再以 ≥ c/√Θ 的概率存活。
3. **顶行不贴顶**：由 Holley（引理 12），对递增的 φ = e^{λ(D − s₀)} 1_{D>ΓW}，
   > E_{π_W}[φ] ≤ E_W[φ(D_t) ; B] / P_W(B) ≤ E_W[φ(D_t)] / P_W(B)。
   
   这里 t = ΘW² + O(W)。
   - P_W(B) ≥ c/√Θ（引理 13 第 3 条，只有下界约束）；
   - 由 Cauchy–Schwarz，E_W[φ] ≤ (E_W e^{2λ D_t})^{½} P_W(D_t > ΓW)^{½}；
   - 第一个因子 ≤ exp(λW + tΛ(2λ)/2) ≤ e^{1 + CΘ}，因为 λ ≤ 1/(4W)、Λ(2λ) ≤ 8λ²；
   - 第二个因子 ≤ (2ΘW²/((Γ − 1)W)²)^{½}（Chebyshev）。
   - 先取 Θ 使第 1、2 条中的 C′/Θ ≤ ⅛，再取 Γ 使本条 ≤ ⅛。
4. **底行不贴顶**：π_1 ≤_st π_W（全正性），而 φ 递增，所以 E_{π_1}[φ] ≤ E_{π_W}[φ] ≤ ⅛。
5. **合起来**：取 φ 中 λ = 0，得 π_d((ΓW, ∞)) ≤ ⅛；所以 π_d(S) ≥ 1 − ⅛ − ⅛ − ⅛ > ½。∎

**读法**：行一侧的边界全被全正性与 Holley 处理了，不需要分析顶端的边界层：
- 上界约束只会把条件化的路径往下压（Holley）；
- 较高的起点在随机序上较高（全正性）。

## 5. 列：两个角点列

记 n_u(s) = N(s, u)，s 是第 m₁ 层的状态。需要 u = 1（底角）与 u = W_L（顶角）两列。

### 5.1 中段给出的控制

**引理 15**：对 1 ≤ s < s′ ≤ ΓW，且 s′ ≥ W/8，对一切 u：
> n_u(s) ≤ C₁₅ · n_u(s′)。

*证明*：
- N = Q · N₂，其中 N₂ = M_{m₂→L}。
- 由 Q 的全正性，Q(s, v)/Q(s′, v) 在 v 上递减（s < s′），所以它的最大值在 v = 1 取到。
- 由引理 13（中段的 X-时间在 [W², W² + O(W)] 中，窗口 ≥ ω(ΘW²) ≫ ΓW）：
  > Q(s, 1) ≤ C(s + √W)√W / W³ ≤ C(Γ + 1)√W / W²，而 Q(s′, 1) ≥ c √W / W²。
- 于是 Q(s, ·) ≤ C₁₅ Q(s′, ·) 逐项成立，乘以 N₂ 即得。∎

**推论**：
- 由引理 15，对 s ≤ s₀，n_u(s) ≤ C n_u(s₀)；对 s₀ ≤ s ≤ ΓW，n_u(s₀) ≤ C n_u(s)。两者对一切 u 成立。
- 由引理 11 第 3 条，n_u(s)/n_u(s₀) 在 u 上单调：
  - s > s₀ 时，它 ≤ 顶角列的比 G(s) := n_{W_L}(s)/n_{W_L}(s₀)；
  - s < s₀ 时，它 ≥ G(s)。

所以只剩顶角列的 G。

### 5.2 顶角附近的边界层

从顶角 W_L 倒着读。在 Q_λ 下，反向的游走 D̂ 的漂移是 −m：在倒转的时间中离开角点向下。反向的上界是 ω(P_L − τ)，它以速度 ω′ 下降。

**相对漂移**：记 ε = (1 − θ)/4。对 τ ≤ εt，
> v(τ) := m − ω′(P_L − τ) ≥ m − θ ω((1−ε)P_L) / ((1−ε)P_L) ≥ c_v m，c_v = (1 − θ)/4 > 0。

- 这里用了严格凹（假设 5）、ω 不减，以及 m ≥ (1 − o(1)) W_L/P_L。
- 并且 v(τ) 在 τ 上递减（ω 凹）。

**引理 16**（角点）：记 ȳ = W_L − mεt，Y = [ȳ − A√t, ȳ + A√t]，e_c = P̂^λ_{W_L}( [0, εt] 中存活 )。则对足够大的 A，
> P̂^λ_{W_L}( [0, εt] 中存活，D̂(εt) ∈ Y ) ≥ c₁₆ · e_c。

*证明*：令 U(τ) = ω(P_L − τ) − D̂(τ) 为到上界的距离。约束 D̂ ≤ W_ℓ 即 U(T_ℓ) ≥ −C₀√W_L。

1. **边界层的时间**：τ₁ = A₁/(c_v m)²。
   - 由 WW，m²t ≍ W_L²/P_L → ∞，所以 τ₁ ≪ εt。
   - **若 τ₁ 小于一个检查点间隔 g**（快速后退：(c_v m)² g > A₁，于是 v√g > √A₁；例如 α > 2 时）：
     - 在第一个检查点，U(T₁) 的均值 ≥ vg − C₀√g ≥ (√A₁ − C₀)√g，标准差 √(2g)。
     - 所以以 ≥ ½ 的概率存活，并且 U(T₁) ∈ [vg/2, 2vg]，于是 e_c 与"存活并落在好的窗口中"的概率同阶。
     - 然后直接进入第 3 步，其中 √τ₁ 换成 vg/2。
     - 下面写慢后退的情形。
2. **层内**：在每个间隔上取常数倾斜 λ′_ℓ，使 U 的漂移为零（即抵消 v）。λ′_ℓ ≈ v_ℓ/2 ≤ m，并且单调递减。
   - 似然比写成 U 的形式（`97` 引理 7 的分部求和）：
     > exp( −λ′_n U_n + λ′_1 U_0 + Σ_ℓ (λ′_{ℓ+1} − λ′_ℓ) U(T_ℓ) + 常数 )。
   - 常数 ≤ τ₁ · v_max² ≤ A₁/c_v²（λ′ ≈ v/2，Λ(λ′) ≲ v²；更正：原写作 τ₁ m²，见 `108` 定理 1 第 3 步）。
   - 这是慢后退的情形：τ₁ 至少是一个间隔，即 (c_v m)² W_L ≤ A₁，所以 v√W_L ≤ m√W_L ≤ √A₁/c_v。
   - λ′ 递减，并且存活时 U(T_ℓ) ≥ −C₀√W_L。所以中间的和与末项的正部 ≤ 2λ′₁ C₀√W_L ≤ 2C₀√A₁/c_v。
   - 于是**在存活的事件上 dP/dQ′ ≤ C**；在"一切检查点上 U ≤ a₂ := 3√τ₁"的事件上 dP/dQ′ ≥ c（因为 λ′U ≤ 3m√τ₁ = 3√A₁）。
   - **上界**：由 `97` 引理 3，
     > e_c ≤ P̂( [0, τ₁] 中存活 ) ≤ C · C_B (U₀ + (C₀ + 1)√W_L) / √τ₁ ≤ C′ √W_L / √τ₁。
   - **下界**：按 `97` 引理 8(b) 的三步（抬离、升到 2√τ₁、在宽 √τ₁ 的管中待到 τ₁）：
     > P̂( [0, τ₁] 中存活，U(τ₁) ∈ [√τ₁, 3√τ₁]，途中 U ≤ a₂ ) ≥ c √W_L / √τ₁。
3. **层外**：从 U(τ₁) ≥ √τ₁ = √A₁/m 出发，U 的漂移 ≥ c_v m。
   - 由指数鞅 e^{−κU}（κ ≍ c_v m，越界量的指数矩有界），此后回到上界的概率 ≤ C e^{−κ√A₁/m} = C e^{−c√A₁} ≤ ½（A₁ 足够大）。
   - 下界约束在 W_L/2 以下，而 D̂ 的涨落 ≍ √t ≪ W_L：可以忽略。
   - D̂(εt) 的均值与 ȳ 之差 ≤ mτ₁ + 3√τ₁ ≤ (A₁ + 3√A₁)/m ≪ √t（因为 1/m ≍ P_L/W_L ≪ √P_L）。由 Chebyshev，D̂(εt) ∈ Y 的条件概率 ≥ ¾。
4. **合起来**：P̂(存活，D̂(εt) ∈ Y) ≥ c √W_L/√τ₁ · ¼ ≥ c₁₆ e_c。∎

### 5.3 顶角列

**引理 17**：
1. 对一切 s，G(s) ≤ C₁₇ e^{λ(s − s₀)}；
2. 对 s ∈ [W/4, s₀]，G(s) ≥ c₁₇。

*证明*：由 §3 的精确倾斜，G(s) = e^{λ(s − s₀)} · N^λ(s, W_L) / N^λ(s₀, W_L)。只需证明：对一切 s，N^λ(s, W_L) ≤ C e_c/√t；对 s ∈ [W/4, s₀]，N^λ(s, W_L) ≥ c e_c/√t。

- **上界**：在 (1 − ε)t 处分开。
  - 前面只保留点概率：局部极限定理（倾斜的游走）给出 ≤ C_L/√((1 − ε)t)；
  - 后面对中间点求和，由倒转得 e_c。
- **下界**：在 t/2 与 (1 − ε)t 处分开。令 X = [s + mt/2 − A√t, s + mt/2 + A√t]。
  1. **P^λ_s( [0, t/2] 中存活，D(t/2) ∈ X ) ≥ c。**
     - 下界约束：漂移 m ≥ 1/(8W)，起点 s ≥ W/4。由指数鞅，永不降到 0 以下的概率 ≥ 1 − C e^{−κ s} ≥ c > 0。
     - 上界约束：平均路径 s + mτ 与上界 ω(P_{m₁} + τ) 的距离，在 τ ≤ t/2 上 ≥ max( ω(P_{m₁}) − ΓW，c m τ )。
       - 这由 ω 的凹性给出：弦的一端在 ω(P_L) ≈ W_L 处。
       - 这个距离 ≥ A√τ（ω(P_{m₁}) ≫ W ≍ 1/m，由 WW）。
       - 对二进的时间区间用 Kolmogorov 不等式求和，碰到上界的概率 ≤ ⅛。
     - D(t/2) ∈ X：由 Chebyshev，概率 ≥ 1 − 1/A²。
  2. **对 x ∈ X、y ∈ Y，P^λ_x( [t/2, (1−ε)t] 中存活，D = y ) ≥ c/√t。**
     - |y − x − m(½ − ε)t| ≤ 2A√t + O(W)，所以由 `97` 引理 4（κ = 2A + 1，R = A′√t）。
     - 离直线不超过 A′√t 的路径离两个约束都远：
       - 上界与直线的距离 ≥ (1 − θ)m εt/2 ≫ √t（WW）；
       - 下界 ≤ 1，而直线 ≥ W_L/2 ≫ √t。
  3. **最后一段**：由引理 16，≥ c₁₆ e_c。
  - 三者相乘：N^λ(s, W_L) ≥ c · (c/√t) · c₁₆ e_c。
- 最后，e^{λ(s − s₀)} 在 s ∈ [W/4, s₀] 上 ≥ e^{−λW/4} ≥ e^{−1/16}。∎

## 6. 定理

**定理 2**（宽窗口的刚性）：设窗口满足假设 WW。则对一切足够大的 K，
> Δ(M_{K→L(K)}) ≤ C*，

C* 只依赖于 C₀ 与 θ。所以相应的堆是刚性的。

*证明*：记 a(d) 为 A 的行和，于是 M(d, u) = a(d) ⟨π_d, n_u⟩。对 d ∈ {1, W}、u ∈ {1, W_L}：
- **上界**。把 s 分成三段：
  - s ≤ s₀：由引理 15 的推论，n_u(s) ≤ C n_u(s₀)；
  - s₀ < s ≤ ΓW：n_u(s) ≤ G(s) n_u(s₀) ≤ C e^{Γ/4} n_u(s₀)（引理 17）；
  - s > ΓW：n_u(s) ≤ C e^{λ(s − s₀)} n_u(s₀)，由引理 14 第 2 条，这部分的 π_d-均值 ≤ C n_u(s₀)/4。
  
  所以 ⟨π_d, n_u⟩ ≤ C′ n_u(s₀)。
- **下界**。在 S 上：
  - s ∈ [W/4, s₀] 时，n_u(s) ≥ G(s) n_u(s₀) ≥ c n_u(s₀)；
  - s ∈ [s₀, ΓW] 时，由引理 15，n_u(s) ≥ n_u(s₀)/C。
  
  所以 ⟨π_d, n_u⟩ ≥ π_d(S) · c n_u(s₀) ≥ (c/2) n_u(s₀)。
- 于是 M(d, u) ∈ [c′, C′] · a(d) n_u(s₀)。四个角点的交叉比 ≤ (C′/c′)²，由角点公式（引理 11 第 2 条）Δ ≤ 2 log(C′/c′)。
- 取互不重叠的块 [K_n, L(K_n)]，由 `78` 推论，刚性。∎

## 7. 相变的闭合

**定理 3**（正则窗口的相变）：设窗口由一个凹的、倍增有界的包络 ω 给出（|W_ℓ − ω(P_ℓ)| ≤ C₀√W_ℓ），并落在以下三类之一：
1. **缓变**：ω′ω ≤ C₀（即 W² = O(P)）；
2. **宽**：ω(P)/√P → ∞，ω(P)/P → 0，并且 ω′P/ω ≤ θ < 1；
3. **尺度不变**：liminf ρ > 0。

则：**堆是刚性的，当且仅当 ρ_k → 0。**

*证明*：
- 类 1 是 `97` 定理 1，类 2 是定理 2：此时 ρ → 0，刚性。
- 类 3 是 `83` 定理 1：不刚性，有连续的隐藏比率。∎

**推论**：
- f(k) = ⌊c k^α⌋：对一切 α > 0，刚性；
- f(k) = ⌊c a^k⌋（a > 1）：不刚性。

`73`、`78`、`83`、`93`、`94` 的数值例子全部被覆盖。

**第五十六轮更新**：下面两条中，第 2 条（临界情形）已由 `108` 定理 1 闭合；第 1 条中凡有凹包络的情形由 `108` 定理 2 闭合。

**没有覆盖的**：
1. **在两类之间振荡的窗口**：W²/P 既不有界也不趋于无穷，例如在一些尺度上缓变、在另一些尺度上宽。
   - 两个证明的块都是局部于一段尺度的，所以只要有无穷多个块分别落在某一类中，就仍然刚性。
   - 剩下的只是完全不规则的窗口。
2. **ρ → 0 但严格凹失败**：例如 ω(P) ≍ P / log P。此时 ω′P/ω → 1，顶角的相对漂移 v 比 m 小一个 1/log 的因子；引理 16 的层时间变成 A₁/v²。
   - 若 v²t → ∞，证明照旧（把 m 换成 v）；
   - 否则开放。这是相变边界上的临界情形。
