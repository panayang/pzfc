## 0. 路线检查

- **原则在推动的**：
  - `93` 把 ρ → 0 时的唯一性化为一维的、被杀死的零均值随机游走。
  - 这里用它的**全正性**，把问题再化简一步：从"一切正调和函数"化到"四个角点的路径数"。
- **会拉着走的**：
  - 全正性（TP₂）与单调似然比；
  - Martin 核；
  - Birkhoff 收缩。
  只作工具。
- **是否回答 `00 §7`**：回答"次序是否完全由迹决定"的判定方法。

## 1. 全正性

**引理 1**：检查点的核 q_k(d, d′) = P(ξ_k = d′ − d) 在 (d, d′) 上是 TP₂ 的，其中 ξ_k = W_{k+1} − 负二项(W_{k+1}, ½)，限制在窗口内。它们的一切乘积也都是 TP₂ 的。

*证明*：
- 负二项分布的概率质量函数是对数凹的。所以以它为序列的 Toeplitz 核是 TP₂ 的。
- 限制到区间不破坏 TP₂；乘积保持 TP₂（Cauchy–Binet）。∎

**推论**：
- 由 D 的较大初值出发、在存活条件下的分布，在似然比的意义下占优于由较小初值出发的分布。
- 这对一切中间层与终点都成立。

## 2. 角点判据

记 M = M_{K→L} 为从层 K 到层 L 的核之积。

**定理 1**（直径就是角点）：
1. 对 TP₂ 的正矩阵，Birkhoff 射影直径 Δ(M) 等于四个角点的交叉比的对数：

   > Δ(M) = log [ M(顶, 顶) · M(底, 底) / ( M(顶, 底) · M(底, 顶) ) ]。

   其中"顶""底"是窗口的最高与最低状态。
2. 它也等于：从顶端与从底端出发、在存活条件下到达层 L 的两个分布之间的 Hilbert（比值）距离。

*证明*：
- 由 TP₂，任意两行之比沿列单调，所以最大与最小的比在两端的列上取到。
- 交叉比沿行的间隔可乘，并且每一段都 ≥ 1，所以最大的交叉比取在最两端的行上。∎

**定理 2**（角点判据）：以下各条等价：
1. 刚性（中心线性化唯一）；
2. 对每个 K，Δ(M_{K→L}) → 0（`78` 定理 2）；
3. 对每个 K，从窗口最低与最高状态出发的两个存活条件分布，比值距离趋于 0；
4. 对每个 K，以最高与最低状态为终点的两列 Martin 核，有同一个极限。

*证明*：
- 1 ⟺ 2 是 `78` 定理 2；2 ⟺ 3 是定理 1。
- 2 ⟹ 4 显然。
- 4 ⟹ 1：由 TP₂，任何终点 u 的 Martin 核都被夹在最低与最高终点的 Martin 核之间（在似然比的意义下）。两端的极限相同时，一切 Martin 核有同一个极限。而每个正调和函数都是 Martin 核的混合，所以唯一。∎

**读法**：
- 次序是否完全由迹决定，归结为一个具体的问题：从最"落后"的状态与从最"领先"的状态出发，经过很长的时间，在存活的条件下，两者到达的分布在比值上是否不可区分。
- 也就是四个角点的路径数之比是否趋于 1。

## 3. 数值（`experiments/ratio_mixing.py`）

从层 K 的最低与最高状态出发，精确地推进存活加权的分布，打印两者在层 L 的比值距离，即 Δ(M_{K→L})。

| 同步 | K | 随 L 增大 |
|---|---|---|
| f(k) = k（缓变窗口） | 10 | L = 20：0.002；30 以后：0.000 |
| f(k) = k | 40 | L = 50：0.253；60：0.008；80 以后：0.000 |
| f(k) = k²（宽窗口） | 4 | 2.06 → 0.75 → 0.27 → 0.15 → 0.08（L = 8 → 40） |
| f(k) = k² | 8 | 9.75 → 4.59 → 2.14 → 1.34 → 0.94（L = 12 → 40） |
| f(k) = 2^k（尺度不变，对照） | 3 | 3.09 → 1.63 → 1.34 → 1.26 → 1.25：收敛到正数 |
| f(k) = 2^k | 5 | 16.6 → 11.4 → 10.4 → 10.2：收敛到正数 |

- 缓变窗口：一次加倍之内比值距离就近于 0。
- 宽窗口：稳定地趋于 0，但较慢。
- 尺度不变：趋于正数，与已证的不刚性一致（`83`）。

## 4. 两个区的状态

| 区 | 已证 | 剩下的 | 连续的对应 |
|---|---|---|---|
| 缓变窗口（f(k) = k^α，α ≤ 1） | 平台情形（`93` 定理 2）；判据化为四个角点（定理 2） | 四个角点概率之比 → 1 的解析估计。需要局部极限定理，以及缓变区间上的赌徒破产估计 | 抛物形柱中正解唯一（基态），已知 |
| 宽窗口（f(k) = k^α，α > 1，ρ → 0） | 判据化为四个角点（定理 2） | 同上，但此时只有下界起作用：需要"条件为正"的游走的比值极限 | 条件为正的布朗运动唯一；带漂移的解被次线性的上界排除 |

**判断**：
- 两个问题都已化到一个具体的、有标准工具的估计：四个角点概率之比。
- 数值上，缓变窗口已经确定；宽窗口的趋势也清楚。
- 剩下的是篇幅较长的随机游走分析（局部极限、赌徒破产、边界 Harnack）。它不改变任何体系层面的结论：隐藏比率的相变已经闭合（`88`）。
- 所以把它记为**"数值上确定，解析证明待写"**，主线到此告一段落。
