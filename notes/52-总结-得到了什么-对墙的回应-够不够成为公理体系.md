# 52 · 总结：得到了什么；对墙与思维惯性的回应；够不够成为公理体系

> 你的问题：到底得到了什么？对开头的墙与思维惯性，是怎样回应的？够不够成为公理体系？
>
> 本篇如实地分三类写：**新的**（原则、诊断、分类、定义）、**已知的重读**（形式内核与许多定理本身）、**还缺的**。

---

## 1. 三句话的回答

1. **得到了什么**：
   - 一个诊断：经典基础假定一切回答都是记录，经典靠"个别化"把这一点维持住。
   - 一套把这个诊断变精确的定义与小定理。
   - 一个以记录为唯一原语的底座：T₀、T₁，以及回到 ZFC 的理想化完成。
2. **对墙的回应**：四个倾向与三种形式化，各有一个精确的对应陈述，指出它在哪里合法、在哪里越界。对 ML 与物理只给出了陈述问题的语言和几条定理形状的结论，没有给出方法或理论。
3. **够不够成为公理体系**：**形式上够，内容上还不够新。** T₀、T₁ 是确切的公理系统，但它们的形式内核是已知的（遗传可数集合的理论；"ω₁ 对实数不可达"）。新的是组织它们的原则、定义层和读法。要成为内容上新的公理体系，还缺三样东西，见 §5。

## 2. 得到了什么

### 2.1 诊断（新的）

- **根**：经典基础假定一切回答都是**记录**——在再问、谁问、之前问了什么、同时问了什么四种情形下都不变（`42`、`46`）。
  - 四个倾向、第一轮的三个旋钮、Kolmogorov、ZFC、图灵，都是这一条的面。
  - GLU 是它在"同时问了什么"这一面的形态，这是一条定理（`43 §1`）。
- **机制**：经典靠**个别化**维持它——把情形写进问题（时间下标、观察者下标、语境下标），或者等价地把情形存进隐藏状态（`47 §2`、`49 §2`）。
  - **线性时间就是把反复提问个别化的下标。**
  - 墙不在于个别化可以做（它总可以做），而在于它被当作唯一的描述方式。
- **失败只能相对地测量**：隐藏状态模型总存在，所以"全局模型为假的程度"= 经典描述必须虚构的量（`47 §3`）。这是 `00 §7` 的一个可计算的形态。
- **结构与位置**：事实恰好看见结构（各种情形下视角的全体），看不见位置（此刻是哪一种情形）；预测 = 结构 + 位置（`48`、`49 §4`）。
- **网络**：提问者在系统之内时，公共使扰动成为干扰（`51`）。

### 2.2 形式结果（精确，但大多初等）

不依赖 mathlib 的约 90 条（`Records`、`Circumstances`、`Individuation`、`Network`），都不用选择；依赖 mathlib 的 30 条（`Askable`、`Sources`）。要点：

| 主题 | 定理 |
|---|---|
| 记录是什么 | 记录 = 复读与复制分不开；GLU ⟺ 跨语境的记录；来源的记录 = 原子 = 重读以正概率一致；可以问 ⟺ 可测；没有原子的来源没有记录 |
| 情形 | 有记录模型 ⟺ 公共且不被扰动；隐藏状态模型总存在；最少隐藏状态 = 余下行为的个数；四种失败两两独立 |
| 结构 | 事实全同 ⟺ 视角的全体相同；位置何时是事实（一般判据）；不被扰动时结构即位置 |
| 任务 | 预测 = 定死回答的任务；关系的任务不是预测；读取即更新的记忆由关系的事实定义 |
| 个别化 | 个别化之后任何行为都有记录模型，只在不公共或被扰动时才需要 |
| 网络 | 公共 + 不干扰 ⟹ 不被扰动；记录经过一读就变的共享转述，不再是记录 |

**如实说明**：这些定理的数学都是初等的；有几条是已知结果（最小状态数、可测 ⟺ 可逼近、Fine 型的粘合）在新定义下的形态。它们的价值在于**把诊断里的词都钉成了确切的定义与判据**，不在于数学难度。

### 2.3 公理体系（`50`）

- **T₀**：唯一的原语是记录（遗传可数的集合：ZFC 去掉幂集，再加"每个集合都可数"）。来源、行为、事实、结构、位置都是定义。
- **T₁ = T₀ + (C)**："分阶段会用完"。它判定 Σ¹₂ 集合的正则性、V ≠ L 等 ZFC 判定不了的问题，并与 ZFC + 大基数相容。
- **理想化的完成 I**：个别化一切情形，一切总体都算记录，再加选择公理，就回到 ZFC。

## 3. 对开头的问题的回应

### 3.1 四个倾向

| 倾向 | 现在能精确说的 | 出处 |
|---|---|---|
| **线性时间** | 它是把反复提问个别化的下标。它在扰动不可撤销时合法：这时位置由事实决定。在会回到原处的结构里，"此刻是哪一点"不是事实。从任何记录出发，它到不了连续统（(C)） | `49 §2`、`48 §2`、`44` |
| **绝对因果** | 预测 = 结构 + 位置。关系的任务不是预测。"是读取引起了改变"只在规律被改变时才是事实 | `48`、`47 §5`、`49 §1` |
| **还原论** | 整体不由部分决定（耦合）。关系可以是记录而两端不是。事实看见的是结构 | `42 §10`、`45 §3`、`48` |
| **目标拟合** | 可信的评价 = 公共的、可复读的记录，标量只是其中一种。评价就是看哪些事实被维持，按包含关系比较 | `46 §6`、`47 §5` |

这些都是**从同一个原则推出的陈述**，不是四条各自的补丁。

### 3.2 三种形式化

- **Kolmogorov**：
  - 样本空间 = 按时间个别化，再加"每个来源都是记录的混合"；
  - 来源不以点为前提；
  - 可测性不是公理，而是"可以问"的意思；
  - "有规律而无记录"在连续的随机性里处处都在（`43`–`45`、`49`）。
  
  **回应得最完整。**
- **ZFC**：
  - 独立的命题，是随位置而变的回答：换一个宇宙（谁问），或做一次强迫（之前问了什么）；
  - T₁ 判定了第一层（Σ¹₂）；
  - CH 在 T₀ 中被消解（不能表述），**没有被判定**（`44`、`46 §7`）。
- **图灵**：只有一句读法——以步数个别化的、做记录的过程（`49 §5`）。**没有展开，这是一个空缺。**

### 3.3 两堵应用的墙（只在陈述问题的层面）

- **ML**：
  - 那个"小怪圈"被诊断为：把"公共的、可复读的记录"等同于"一个标量"。
  - 对由"被问时怎样改变"来定义的系统，它的记录是跨历史的关系事实，快照不是（`46 §6`、`48 §3`）。
  - "测试集污染"是"公共 + 读取即更新"的必然后果（`51 §3`）。
  - **没有给出**：具体的评价方法、数据集或指标。那是应用层的工作，本项目不做。
- **物理**：
  - "预测演化还是结构" = "结构 + 位置，还是结构"；关系可以是记录；
  - 触发器循环有一个定理的形状：共享的记录由会改变被读者的提问产生，提问之间就必然互相干扰。
  - **没有给出**任何物理理论。

### 3.4 思维惯性

- **认知上的惯性**（四个倾向）：见 §3.1。对它们的回应不是"反对"，而是**划出它们合法的范围**：
  - 线性时间在扰动不可撤销处合法；
  - 预测在位置可得处合法；
  - 标量在要比较的东西排成一条线时合法：被维持的事实按包含关系恰好是全序，这时一个数就忠实地表示了比较（`13 §1` 的 Hölder 条件是它的经典形态）。
- **本项目自己的惯性**：共有五次，自检清单第 12–18 条都记着。
  - 第五到七轮滑向大统一；
  - 第十六到十九轮用了范畴论的词；
  - 第二十九到四十轮在翻译已知结果；
  - 第二十六到二十七轮退回"记录优先"，又差点往上爬内模型的阶梯；
  - 第二十五到二十八轮丢掉了第 1 轮已经看到的"读取即更新"。
  
  每一次都是被你或路线检查拉回来的。这说明墙也在做研究的人身上：**已经会用的描述方式，总会把新东西重新个别化成旧的形式。**

## 4. 够不够成为公理体系

### 4.1 形式上：够

- T₀ 是一个确切的一阶理论：ZFC 去掉幂集，再加"每个集合都可数"。T₁ 再加一条确切的公理 (C)。
- 其余都是定义（`50 §3`），每个定义都有出处与形式化。
- 回到经典的方式是确切的：任何 ZFC 宇宙的遗传可数部分都满足 T₀；ZFC 加一个可测基数满足 T₁（按已知的集合论，待核验）。

### 4.2 内容上：形式内核是已知的

- T₀ 与二阶算术相当，(C) 就是"ω₁ 对每个实数不可达"。两者都是已知的。
- 新的是：
  - **选择这两条的理由**：一份记录由可数多次有限的回答写成；线性时间到不了连续统；
  - **定义层**：来源、行为、四种情形、事实、结构、位置、个别化；
  - **读法**：经典 = 个别化一切情形之后的理想化完成；独立性 = 随位置而变。

### 4.3 对照 `01` 的目标

| 目标 | 现状 |
|---|---|
| 以测量为核心的语言 | 部分达到：测量的概念都是定义，原语仍是记录（集合）。这是有意的：断言本身是记录（`46 §7`）。但你最初设想的"以概率为底层"，在形式上**没有实现为原语** |
| 能回到 ZFC 与标准测度论 | 达到：ZFC 是理想化的完成，测度论在标准空间上照常 |
| 更广的族 | 部分达到：墙外的对象（没有记录的来源、被扰动的、相对的行为）都能描述、能度量。但它们在 ZFC 里本来也能定义；新的是**分类与度量**，不是对象本身 |
| 判定 ZFC 判定不了的问题 | 部分达到：T₁ 判定第一层（Σ¹₂），理由可以读懂；CH 只被消解，没有被判定 |
| 公理更可解释 | 达到：R、(C)、I 都有一句话的读法 |

## 5. 还缺的三样东西

要从"一个有新原则的公理体系"变成"内容上新的公理体系"，至少缺这三样：

1. **测量层自己的公理。**
   - 现在，测量层只有定义，没有公理：哪些来源、哪些行为存在，完全由 T₀ 的集合论决定。
   - 一条属于测量层、又不是定义的原则——例如关于"哪些来源存在"，或关于事实与结构之间的关系——而且它还能约束经典的部分，现在一条也没有。(C) 是唯一的候选，但它说的是记录。
2. **一个方法。**
   - 第二十一轮就指出过"方法还弱"（`38 §5`），到现在仍然如此：
   - 还没有一块数学，在这种语言里做出了经典语言做不出、或做得更差的东西。
   - 最有希望的地方是概率论：没有样本空间的概率、以偏序为时间的过程、关系作为记录。
3. **判定的来源。**
   - T₁ 的判定停在第一层，更高的层次要沿已知的大基数阶梯走，而那会变成翻译（`45 §0.2`）。
   - 需要二选一：
     - 要么从测量层的原则推出更高层的判定；
     - 要么给出一个有原则的理由，说明底座为什么应当停在第一层。

另外两个空缺，比上面三样次要：
- **不可数的数学**（不可分的空间、一般拓扑、集合论本身）只住在理想化的完成里，T₀ 中没有它们的位置。需要一个明确的立场。
- **图灵**：没有展开。

## 6. 判断

- 这四十多轮真正的成果，是**一个诊断和一个原则**。它们足够精确，可以写成定义与定理，而且它们选出了一个确切的公理系统。
- 这个系统在形式上是一个公理体系，**在内容上还是已知数学的重新组织**。你担心的"拼图"已经避免了：原则在前，选择由原则决定。但"新数学"还没有出现。
- 所以，下一阶段的重心不该再是扩充诊断，而是 §5 的前两样：
  - **找到测量层自己的一条公理**；
  - **在一块具体的数学里用出一个方法**。

## 7. 下一步

1. 按 §5 第 2 条，选定一块数学作为试验场。建议是没有样本空间的概率论：
   - 条件化，即"信息"与"扰动"的区分（`49 §1`）；
   - 以偏序为时间的过程；
   - 看能不能得到经典写法里不自然、甚至得不到的结果。
2. 同时找 §5 第 1 条：测量层是否有一条非定义的原则，例如"一切来源都可以被联合"，或者它的某种受限的形式，并看它对经典部分有没有约束。
3. 文献核查：先核与底座直接相关的几条。
4. 干扰的度量（`51 §6` 第 2 条）顺延。
