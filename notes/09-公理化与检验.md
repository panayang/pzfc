# 09 · 公理化方案与检验协议

> **第三轮注**：命题 T 撤回，由 `11 §5` 的 T′ 取代；T5 由 `11 §6` 的 T5′、T6 取代；M5（尺度）删除。§1 的反病态基础族表保留。

> 第一轮给了九条公理（A1–A9），它们是在经典元逻辑里写的、单轴驱动的、没有检验协议的。
> 第二轮不急着写新公理。先看**已经存在的"更广的族"**，再看以测量为原语的思路预测它应该落在哪里，最后给出任何提案都必须通过的检验。

## 1. 反病态基础族：它已经存在，只是散落着

`05 §4`：L0 的改变把纪律变成必然，从而产出 ZFC **证伪**的免费定理；代价是被排除的病态对象不再存在。

| 基础 | 去掉什么 | 免费定理（在 ZFC 中为假或不可证） | 付出什么 |
|---|---|---|---|
| Brouwer 直觉主义分析 | LEM，加连续性原理 | 每个 $\mathbb R\to\mathbb R$ 函数连续 | LPO；介值定理只剩近似形式 |
| 有效拓扑斯 / 俄国构造主义 | LEM | 每个 $\mathbb N\to\mathbb N$ 函数可计算（CT₀） | Kőnig 引理失效（Kleene 树） |
| Solovay 模型（ZF+DC） | AC | 每个实数集 Lebesgue 可测 | 需要不可达基数（Shelah：必要）；无 Hamel 基 |
| ZF + AD | AC | 所有实数集可测、有 Baire 性质、完美集性质 | 大基数强度；AC |
| 综合微分几何（光滑拓扑斯） | LEM | 每个 $R\to R$ 函数光滑；存在 $d^2=0$ 的无穷小 | LEM；不能判定 $d=0$ |
| Nominal 集合 / FM 置换模型 | 原子上的 AC | 一切构造自动等变 | 原子上无选择；确定性计算变弱（`08`） |
| NF | 大小限制 → 分层 | 存在全集 | ¬AC（Specker） |
| Łukasiewicz 朴素集合论 | 0/1 真值，收缩 | 朴素概括 | 算术 ω-不协调〔待核验〕 |
| LAST | 收缩（light） | 朴素概括 | 计算只剩 PTIME |
| HoTT / 单值基础 | 命题性同一 | 同构即相等（沿同构免费搬运一切） | UIP；对一般类型的 LEM |

**这就是你要的"更广的族"——它们每一个都"判定"了某些 ZFC 判定不了、或 ZFC 判定为假的东西。**
例如"所有实数集可测"在 ZF 中不可证；NF 否定了 AC。你对"狭义测度"的不满，在 Solovay / AD 宇宙里有精确回答：那里测度适用于**一切**集合。

缺的不是新成员，是两样东西：
1. 一个让它们**可比较**的坐标系（`06`）；
2. 一个**有原则的理由**去选择其中某一点。以测量为原语的思路可以提供这个理由（§2）。

另外注意最右一列：**没有一行是空的。** 这是 `07` 的"墙守恒"在基础层面的样子。

## 2. 以测量为原语，预测落点

从 `05 §3` 的六个侧面逐条推：

| 侧面 | 推出 | 性质 |
|---|---|---|
| 有限观测 | Λ 为 Heyting + 连续性原理；经 Diaconescu 推出 ¬AC | 推导，非规定 |
| 扰动 | Σ 受控：线性 / 仿射，用 `!` 标出可复制对象 | 推导，非规定 |
| 不可区分 | Χ 对称：nominal 型 | 需要额外假设（存在不可区分者） |
| 上下文 | Γ 层式 | 由 Σ 受控蕴含其可能性（`06 §2`） |
| 自包含 | Δ：对角线的形状由上面几条决定 | 约束 |

> **命题 T（可证伪的主张）。** 以测量为原语的基础位于区域
> $$(\text{Heyting} + \text{连续性}) \;\cap\; (\text{非笛卡尔，带 } !) \;\cap\; (\text{对称})$$
> 据我所知，**没有现成基础同时占据这三者**：可实现性与层模型是笛卡尔的；LAST 既不连续也不对称；nominal 集合是笛卡尔的。〔文献待查：线性组合代数（Abramsky–Haghverdi–Scott）上的可实现性、"nominal realizability" 之类的工作可能部分覆盖。〕

T 若成立，这个区域就是项目的真正研究对象；若某个现成基础已占据它，项目就变成研究那个基础——两种结果都是进展。

## 3. 检验协议：任何提案都必须回答的五个问题

**T1 相对协调性。** 给出模型。自然候选：在"线性 + nominal"的组合代数上做可实现性构造。

**T2 回收。** 找出一个模态或子宇宙——**锐的 ∧ 可复制的（`!`）∧ 对称下固定的 ∧ 可粘合的**那部分对象——
证明它解释一个经典片段（至少二阶算术的某个子系统；理想情形是 ZF 型）。
回收应当是**关于子宇宙的定理**，而不是第一轮说的"极限"或"回归"。

**T3 区分力。** 列出与 ZFC 判定不同的命题。在区域 T 中至少应有：¬AC（推导）、函数连续（推导）、等变免费、（若收缩受控）朴素概括。

**T4 付账（L\*）。** 指出对角线与对称的墙在哪里重现。**一个声称不付代价的提案几乎可以肯定是错的。**
候选付账处：非标准算术？计算缩水？语言无法谈论自身的某个范畴（复仇）？

**T5 科学适配。** 把结构规则与领域的结构事实对照：

| 领域的结构事实 | 对应要求 |
|---|---|
| 量子：不可克隆、上下文性、全同粒子、有限观测 | 非笛卡尔 ✓、层式 ✓、对称 ✓、连续 ✓ |
| 物理计算：资源无界时计算一切图灵可计算函数 | 无界 `!` 下恢复图灵（`08` Q4） |
| 经典统计实践 | 在锐 ∧ 可复制 ∧ 可粘合子宇宙上恢复 Kolmogorov |
| 热力学：擦除有代价（Landauer） | 弱化（丢弃）不应免费——**比线性逻辑更强的要求，尚未想清** |

数学不管自然；但自然科学用数学说话，所以 T5 不是公理的**证明**，而是公理作为**语言**是否合用的检验。

## 4. 第一批可以真正做的数学

- **M1**（已做）不变式的形式化：`lean/Invariants.lean`——Lawvere（绝对与相对）、Russell 只依赖否定无不动点、
  Kripke 的单调逃逸、复仇、等变性障碍、全序破坏对称。11 条定理，均不依赖任何公理。
- **M2**（中）文献核查：区域 T 是否已被占据。先查线性组合代数上的可实现性与 nominal 可实现性。
- **M3**（中）`08` Q1：无唯一重组的 Gandy 机器。
- **M4**（研究）`08` Q3：对称、无序基础中的内部计算及其表示定理。
- **M5**（研究）尺度轴 Ρ：先判断它是否属于 L0。候选数学对象：粗几何（Roe）、拟等距不变量、重整化的 Hopf 代数结构（Connes–Kreimer）。

## 5. 不主张的东西

- 不主张解决 CH。在区域 T 的大多数候选里，"连续统"会分裂成多个不等价的版本，CH 要么独立，要么不再是一个问题。
- 不主张自然"选择"了某个基础。只主张：科学中的结构事实（不可克隆、上下文性、不可区分、Landauer）使某些基础成为**更合用的语言**，
  而不同的语言让不同的问题**可以被问出来**。
