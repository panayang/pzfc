# 37 · 停下来审视：公理体系在哪里，怎样在上面做数学，保守能不能判定问题

> **第三十三轮注**：公理体系的当前写法已改为 `50`（底座以记录为唯一原语，经典是个别化一切情形后的理想化完成）。本篇的 GLU(π) 保留为可加在任何底座上的保守的语言层。

> 回答三个问题：
> - 公理体系到底在哪里？
> - 怎样在上面构建已有的数学，以及还没有的分支？
> - 它能不能判定原来无法判定、或者还不知道能否判定的问题？
>
> 并自检：最近几轮用了不少范畴论的词，哪些说法不够严谨。
> 本篇起，公理体系以 §1 的写法为准。它只用集合论的语言，不需要范畴论。

---

## 0. 先说结论

1. **公理体系**：
   - 记录层就是 ZF 或 ZFC（允许原子），原样不动；
   - 再加一条公理模式 GLU(π)：对每个参数 π，有一类新的对象（种类 π），它们恰好是小的 π-系统的唯一解。

   §1 给出完整的写法。Lean 里形式化的是这些公理成立的**构造**（模型），不是公理本身；公理是一个写在纸上的一阶理论。
2. **做数学**：
   - 已有的数学全部在记录层里做，和在 ZFC 里完全一样。
   - 种类提供新的对象：循环的、带权的、随上下文变化的、带对称的。可以在上面发展新的理论，并用嵌入与影子与经典数学连接。
3. **判定**：
   - **保守的拓展不能判定任何新的集合论命题。** 这是"保守"的定义直接推出的，不是做得不够。CH 这类在 ZFC 中独立的命题，在这里依然独立。
   - 能做的有三件：判定关于新对象的问题；给已有的问题提供新方法；说明独立性出在哪里。
   - 若要判定独立的命题，必须加入不保守的公理。这需要你来选择（§3.3）。

## 1. 公理体系：不借范畴论的写法

### 1.1 语言

两类个体：
- **记录**：普通的集合，以及原子。关系是 ∈。
- **对象**：种类中的成员。

| 符号 | 读法 |
|---|---|
| κ(a) | a 的种类：一个参数，它本身是记录 |
| γ(a) | a 所在的上下文：一个记录 |
| E(b, a) | 在 a 所在的上下文里，b 作为 a 的成员的值：一个记录，属于该种类的值的集合 |
| ν(a) | a 的名字：一个记录，或"无" |
| f·a | 沿箭头 f，把 a 搬到另一个上下文 |
| D(π, G, c, x) | 系统 G 在上下文 c 的结点 x 的解：一个对象 |

### 1.2 参数 π

一个参数是一个记录，给出三件事。

- **值**：
  - 一个值的集合 W，以及"族中之一"的聚合方式 ⊕。⊕ 是一个可定义的运算，所以 GLU(π) 是一个公理模式。
  - ⊕ 满足三条律：与编号方式无关；单个元素的聚合是它本身；可以分块聚合。
  - 例：{是，否} 与"存在"；[0, ∞] 与求和。
- **形状**：良基的，或一切。
- **上下文**：
  - 一个上下文的集合，以及上下文之间的箭头——细化，或对称；
  - 箭头可以接连做，每个上下文有一个不动的箭头；
  - 每个上下文里有一个可用的名字的集合，名字随箭头搬运。

一个 **π-系统**是一个记录，包括：
- 每个上下文里一个结点的集合，以及沿箭头搬运结点的映射；
- 结点之间取值于 W 的关系，沿箭头保持；
- 有的结点带名字；
- 形状属于所要求的一类。

### 1.3 公理

- **(A0) 记录**：记录满足 ZF（或 ZFC），允许原子。
- **(A1) 类型**：
  - κ(a) 是参数，γ(a) 是它的一个上下文；
  - E(b, a) 只在 b 与 a 同种类、同上下文时有定义，取值于 W；
  - 名字属于可用的名字；
  - 沿箭头搬运与"接连做"一致，不动的箭头不动；名字随之搬运。
- **(A2) 存在**：对每个参数 π 和每个 π-系统 G，D(π, G, ·, ·) 是 G 的一个解：
  - 沿箭头相容；
  - 保持名字；
  - E(b, D(π, G, c, x)) 等于下面这些值的聚合：对 x 的每个满足 D(π, G, c, z) = b 的成员 z，取它的值 R(z, x)。
- **(A3) 完备**：种类 π 的每个对象，都是某个 D(π, G, c, x)。
- **(A4) 同一**：D(π, G, c, x) = D(π, H, c, y)，当且仅当有一个 π-互模拟（它是一个记录）联系这两个结点。π-互模拟的定义随 π 而定：
  - 锐的回答：通常的互模拟；
  - 一般的值：Larsen–Skou 互模拟——一个等价关系，相关的结点给每个等价类的聚合值相同（`Values.same_iff_ls`）；
  - 有上下文时，还要求沿箭头保持。
- **(A5) 分离与替换**：对提到对象的公式也成立。

(A2)–(A4) 合起来就是 GLU(π)。

**原点。** 经典是参数 π₀ =（{是，否}，良基，单个上下文）的情形。
- 这个种类就是记录本身（`Shapes` §7、§9）。
- GLU(π₀) 就是外延、基础，以及确定的存在（配对、分离、替换）。
- 选择（GLU₀ 的条款 4）只作为 ZFC 的一部分，属于记录层。

### 1.4 定理：保守

> **对任何只谈记录的命题 φ：本体系证明 φ，当且仅当 ZF（相应地 ZFC）证明 φ。**

**理由。** ZF 的每个模型都能扩成本体系的模型，而且记录不变：
- 把种类 π 的对象，取为带基点的小 π-系统按 π-互模拟分成的类；每个类用 Scott 的技巧取一个集合作代表，这在 ZF 中可行，因为记录满足基础公理。
- D 取为"系统连同结点"所在的类。
- (A2)–(A4) 正是这个构造满足的性质。

**Lean 中已经验证的，是这个构造对以下几族参数成立**（形状取良基时，是其中的子种类）：

| 参数 | 文件 |
|---|---|
| 任意完备的值，一切形状，单个上下文 | `Values`（`glu`、`same_iff_ls`） |
| 锐的回答与名字，一切形状，任意上下文结构 | `Kinds`（`glu_over_contexts`） |
| 带序的值，一切形状，预序上下文（整体对象的表示） | `Over`（`glu_over`） |
| 任意完备的值，一切形状，一个对称群，带名字 | `Symmetric`（`gglu`，`38 §3`） |

**尚未构造的**：值、名字与有不可逆箭头的上下文结构三者一起的一般情形（对称群的情形已构造，`38 §3`）。在构造出来之前，公理模式只对上表中的参数断言。

**这意味着什么。** 种类都能在 ZF 中定义出来，所以本体系是 ZF 的一个**定义性扩张**：加了新的一类个体，但它们都由旧的东西定义。
- 关于记录，它不多证明任何东西；
- 关于对象，它证明的一切，翻译回来都是 ZF 的定理。

它的作用在语言：让"墙外的东西"成为有统一公理的对象，而不是编码。

## 2. 在上面做数学

### 2.1 已有的数学

在记录层里原样进行：自然数、实数、空间、测度、作为集合的范畴……ZF(C) 的一切定义与定理都不变。保守性保证，引入种类不会与任何已有的结论冲突。

### 2.2 新的对象

每个种类是一个新的对象世界。在其中，可以像在集合论里一样定义、构造、证明：
- **一切形状**：满足方程的对象。例：流 x = (1, x)，自指的结构，无穷的行为（自动机、过程）。
- **权重**：成员带权重的对象。例：
  - 一枚均匀的硬币，是一个对象，两个成员各带权重 1/2；
  - Kolmogorov 扩张，是一条粘合定理（`31`）。
- **上下文**：随上下文变化的真值与存在。例：在每个上下文里都有成员、却没有整体成员的对象（`29`、`36`）。
- **对称与名字**：数得出、分不开的个体（Russell 的袜子，`30`）。

### 2.3 桥

- 每个种类里都有经典的像，这是嵌入。
- 有的方向还有影子：只看一个上下文；只看权重是否为零。

于是，可以把新对象上的问题投回经典，也可以把经典对象放进新种类里研究（`33 §4`）。

### 2.4 还没有的分支（方向，不是成果）

- **带权的循环对象**：例如概率过程，作为对象（权重加一切形状）。
- **带权的上下文对象**：权重随信息增加（`36`）。
- **对称加权重**：可交换的随机个体，例如袜子的均匀权重，作为对象。

这些都能在本体系里定义并研究。不过，因为是定义性扩张，它们原则上也能在 ZFC 中用编码来做；本体系给的是自然的语言与统一的公理。

## 3. 保守与"判定"

### 3.1 事实

保守，就是对集合论的命题，可证的完全一样。所以：
- CH、Suslin 假设等在 ZFC 中独立的命题，在这里依然独立；
- 你的目标"对 ZF(C) 保守"与"判定原本无法判定的问题"，对集合论本身的命题不能同时成立。

这是定义的直接推论，与构造得好坏无关。

### 3.2 保守的拓展仍然能做的

- **(a) 判定新对象上的问题。**
  - 关于种类中的对象，有些问题在本体系中有确定的答案。例如预序上的选择判据（`35 §2`）。
  - 这些问题在经典语言里只能通过编码来问。
- **(b) 给已有的问题新的方法。**
  - 保守的拓展，仍可能让一些 ZFC 能证明、但还没人证出的命题变得容易证。
  - 先例：非标准分析——Nelson 的 IST 对 ZFC 保守，却提供了新的证明方法（待核验）；布尔值模型与强制法，也是作为方法起作用的。
  - 对"还不知道能否判定"的问题：如果它其实在 ZFC 中可证或可驳，新方法可能有帮助，但不能保证。
- **(c) 说明独立性出在哪里。**
  - 例：CH 问的是一个锐的、整体的回答，即原点处的粘合；在带权的局部层，连续统的测度代数是规范的，CH 在那里看不见（`24 §8`）。
  - 这是重新表述，不是判定。

### 3.3 若要判定独立的命题

必须加入不保守的、关于记录的公理。框架能说明这些公理作用在哪里——都在原点处的粘合与大小上——但不能替你选出"正确"的一条。

三个选项：
- **A. 保持保守**：判定只指 §3.2 的 (a)(b)(c)。
- **B. 核心保守，另设一层**：在核心之外，另设一层明确标为"不保守"的原点公理（例如在条款 4 的位置，换成更强的原理），研究它们判定什么。
- **C. 放弃保守**：不推荐，因为那样经典就不再是原点。

推荐 A 作为核心；如果需要，再把 B 作为一项独立的研究。

## 4. 自检

### 4.1 词汇对照：范畴论的词，与直白的意思

| 笔记里的说法 | 直白的意思 | 公理体系是否需要 |
|---|---|---|
| 小范畴（上下文结构） | 一个上下文的集合，加上上下文之间的箭头（细化或对称）；箭头可以接连做，每个上下文有不动的箭头 | 需要，用直白说法。常用的只有两种：预序（细化）与群（对称） |
| 终对象 | 每个小系统恰有一个解；每个对象都是某个解的值 | 需要，就是 GLU(π)，按 §1.3 写 |
| 预层 | 按上下文编号的一族集合，沿箭头有映射 | 需要：上下文上的系统就是它 |
| 整体截面 | 在每个上下文里取一个对象，沿每个箭头搬过去仍是它 | 需要："整体的对象" |
| 余代数、推出 | 证明里的步骤：系统，系统之间的解，把两个系统沿公共部分粘起来 | 不需要，只在构造与证明中 |
| 函子（种类之间的映射构成 π 上的函子） | 参数之间的映射给出种类之间的映射，并且与接连做相容 | 目前只沿值的方向证明了；其余是描述，不是定理 |
| Kripke 模型、Heyting 值模型、拓扑斯 | 文献中的对应物 | 不需要，只用于核对文献 |

### 4.2 需要修正或限定的说法

1. **`33 §2`"对每个参数 π"**：实际只构造了其中几族参数，已在 §1.4 限定。
2. **`33 §2` 的一阶写法漏了两点**：
   - 聚合 ⊕ 是可定义的运算，所以 GLU(π) 是一个模式；
   - 分离与替换要对提到对象的公式也成立（§1.3 的 (A5)）。
3. **"π-互模拟"**：在不同的 π 下定义不同（§1.3 的 (A4)），之前没有逐一写明。
4. **`28 §5`"种类之间的映射构成 π 上的函子"**：只沿值的方向证明了（`Values.UV.map_id`、`UV.map_comp`）。
5. **`24 §8`"两者在不同的 U(π) 中被分开判定"**：不准确。
   - 它的意思只是：在不同的内部宇宙里，相应的命题取不同的值。这与强制法给出不同的模型是一回事。
   - 这不是在 ZFC 中判定 CH。`17 §7`"CH 的分解"应作同样的理解。
6. **与 Kripke 模型、Heyting 值模型、拓扑斯的等同**：都只是与文献的对应，待核验，公理体系不依赖它们。
7. **"拓展让原来无法描述的东西变得可以描述"**：成立，但意思是"成为对象，并且有统一的公理"，不是"能证明新的集合论定理"。

### 4.3 偏离

- 第十六到十九轮，主要在构造种类，也就是验证 GLU(π) 与保守性。这是必要的支撑，但公理体系本身没有随之用直白的语言重写，范畴论的词多了起来。
- 本篇把公理体系放回中心；自检清单加两条（13、14）。

## 5. 下一步（建议）

1. 以 §1 为公理体系的正式写法：
   - 把值、名字、任意上下文三者一起的一般情形构造出来，或者把公理模式正式限制在已构造的参数上；
   - 可以在 Lean 中把公理写成一个结构，证明各个构造是它的模型，让"公理体系"本身也有形式的版本。
2. 在一个新种类里做一段具体的数学，检验"在上面做数学"是否顺手。建议选带权的种类（概率作为隶属），因为它最接近开头"用概率的语言表述集合论"。
3. 关于判定：按你在 §3.3 中的选择进行。
