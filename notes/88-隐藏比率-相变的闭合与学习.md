# 88 · 隐藏比率：相变的闭合与学习

> 第五十轮，前两个问题（`87 §4` 第 1、2 条）。
>
> **范围**：过程层，即反复观察的概率论。

---

## 0. 路线检查

- **原则在推动的**：
  - `83` 找到了隐藏比率的相变量 ρ = f(k)/P_k。
  - 这里要：
    - 把"比率"这一侧完全闭合；
    - 把"是否还有别的隐藏参数"分出去，作为更细的问题；
    - 回答隐藏比率能否被学到、学得多快。
- **会拉着走的**：de Finetti 的学习理论（计数充分、大数律、√n）；Rényi 的混合型中心极限定理。只作工具。
- **四种情形**：只处理"之前问了什么"。
- **是否回答 `00 §7`**：回答隐藏的全局参数何时存在、能否被一次观察揭示。

## 1. 相变在"比率"上闭合

**定义**：R(τ) 是由中心的穷尽线性化以概率一实现的渐近比率——X 步所占比例的极限——的集合。

**定理 1**：
- 若 liminf_k ρ_k > 0，则 R(τ) 包含一个非退化的区间；
- 若 liminf_k ρ_k = 0，则 R(τ) ⊆ {½}。

*证明*：
- 第一条是 `83` 定理 1。
- 第二条：沿使 ρ_k → 0 的那些检查点，每个线性化都满足 |i − j| ≤ f(k) + 1 = o(P_k)。所以只要 X 的比例收敛，极限就是 ½。这对每一条路径成立，与测度无关。∎

**所以**：隐藏比率（de Finetti 型的参数）存在，当且仅当同步间隔占已过时间的比例有正的下界。相变在比率上完全确定。

**分出去的更细问题**：
- 当 ρ → 0 时，中心线性化是否唯一？这是"有没有别的隐藏参数"，而不是"有没有隐藏比率"。
- 数值上唯一（`78`、`83`），证明需要离散的边界 Harnack 估计。
- 它不影响比率的理论，标为开放。

## 2. 隐藏比率能被学到

**设定**：
- 迹 τ 已知（同 `73 §2`），过程按某个中心的线性化逐步展开。
- 极端的线性化记作 μ_p：它就是 X 步概率为 p 的独立同分布日程，条件在"永不被阻塞"上（`73` 定理 1）。

**定理 2**（充分性）：在任何中心的测度下，一个观察到的前段的概率只依赖于它到达的理想，这里就是计数 (i_n, j_n)。所以计数是隐藏比率的充分统计量。
- 这是 de Finetti 的"计数充分"在部分可交换情形中的形式；
- 它由中心性直接得出，对一般的迹同样成立：迹就是充分统计量。

**定理 3**（相合性）：
- 在 μ_p 下，i_n / n → p 几乎必然。
- 对诸 μ_p 的混合，后验几乎必然集中在真实的 p 上（Doob 定理）。

**定理 4**（速率）：在 μ_p 下，√n (i_n/n − p) 依分布收敛到 N(0, p(1 − p))，与没有同步约束的独立同分布日程完全相同。

*证明*：
- μ_p = P_p(· | A)，其中 A 是"永不被阻塞"，P_p(A) > 0。
- 由 Rényi 的定理，独立同分布和的中心极限定理是"混合的"：它在任何对 P_p 绝对连续的测度下仍然成立。∎

**读法**：
- **同步决定哪些比率存在，不决定比率被学得多精确**。
  - 在隐藏比率存在的地方，de Finetti 的学习理论——计数充分、大数律、√n 的速率——原样成立；
  - 同步约束在渐近意义下不花任何精度。
- 在刚性的情形中，给定迹之后次序是均匀的，不携带关于任何隐藏参数的信息：没有东西可学。

## 3. 已知的与这里的

**已知的，只作指导**：
- de Finetti 的学习理论；
- Doob 的后验相合性；
- Rényi 的混合型中心极限定理。

**这里的**：
1. 定理 1：相变在比率上闭合——隐藏比率存在 ⟺ liminf ρ > 0。
2. 定理 2–4：隐藏比率的学习理论——迹充分、相合、√n 且方差与无约束时相同。
3. 把"ρ → 0 时的唯一性"分出去，成为一个比比率更细的问题。
