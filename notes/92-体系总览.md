## 1. 这个体系是什么

- **ZFC 描述一个集合宇宙。本体系（B）描述一族集合宇宙——世界——以及它们之间的扩张。**
  - 每个世界内部都是 ZFC；
  - 不假定所有世界能合成一个世界，这就是去掉 GLU₀；
  - 经典数学 = 取定一个世界。
- **全局的数学**：在一切扩张下不变的陈述，包括有限层、可数核、由实数可定义的一切。
- **局部的数学**：随世界而变的陈述，包括完成的总体、选择对象、CH、集合的共存。
- **三个范围**：
  - 概率论：主线，`64`；
  - 集合论：底座，`55`；
  - 多宇宙的模态逻辑：外层，`90`。

## 2. 公理（`55 §2`）

| 公理 | 内容 |
|---|---|
| M1 | 每个世界是传递的 ZFC 模型；每个集合在某个世界中 |
| M2 | 扩张由宽度（泛型扩张）与高度（秩初段）两种步骤生成 |
| M3 | 每个世界对每个偏序都有泛型扩张，也有真正的高度扩张 |
| M4 | 沿扩张，可数核 H(ω₁) 的一切断言不变。等价于每个世界满足 PGA₂；与无穷多个强基数等一致（`103`） |
| M4⁺ | 沿扩张，L(ℝ) 的理论（带实数参数）不变。推出 AD^{L(ℝ)}（`103`） |

**两层**（`106`）：
- **B = M1–M4**：最小底座。最初的目标（去掉 GLU₀、测量它的失败）、概率层与过程层的全部，都只需要 B。
- **B⁺ = B + M4⁺**：标准理论。全局的数学 = 决定性之下的 L(ℝ)；独立性只来自局部性与一致性强度的阶梯。
- **强度**（`122 §1`）：B⁻ = M1–M3 只比 ZFC 多"有足够多的传递模型"；B 与无穷多个强基数等一致；B⁺ 至少需要 ω 个 Woodin 基数。大基数强度全部来自 M4；初始目标几乎都只需要 B⁻。

**不假定**：汇合，全局配对。

## 3. 三层的核心结论

**底座**（`55 §3`）：
- 大小是局部的，可数是全局的；完成的无穷总体（幂集、ℝ）是局部的；
- 选择给出的对象是局部的；定律与描述的测度是全局的；CH 是局部的。
- **全局结构**（`55 §3.7`）：
  - 两条界线：良基管可能性（S4.2），ω 标准管有限层；
  - 可数核上的模态平凡；
  - 有全局的 ∈，没有全局的配对；
  - 全局性严格地分三级，经典的单一宇宙不在其中；
  - **不规则只在局部的选择层**。

**概率**（`64 §1`）：
- 事件是描述；概率谈论新鲜的样本；独立是扩张。
- 语境上的定律：有全局定律 ⟺ 能一致实现；障碍是有限的、算术的。
- 局部点集的测度命运：
  - 随机与 Cohen 对偶；
  - 由零测族的覆盖刻画；
  - 对可定义的记录二值；
  - 一般地落在内外测度的窗口里。
- 概率层对抽样封闭。

**过程**（`64 §2`）：
- 记录 ⟺ 公共且不被扰动；最少隐藏状态 = 余下行为数；此后与次序无关 ⟺ 两两可交换。
- **部分可交换的一般表示**：迹 + 比率边界上的一点 + 新鲜的洗牌。
  - de Finetti 与 Bell 是同一个定理（隐藏的结构 ⟺ GLU）的两端；
  - **隐藏比率存在 ⟺ 同步没有特征尺度**；在比率存在处，de Finetti 的学习理论原样成立。
  - **相变闭合**（`97`、`98`、`108`）：对一切有凹包络的同步，刚性 ⟺ ρ → 0。隐藏的参数恰好是比率，不多也不少。多链时，隐藏比率组成一个开多面体。
- 次序谱：经典看不见的不变量。

## 4. 对最初问题的回应

| 最初的问题 | 在本体系中的位置 | 出处 |
|---|---|---|
| 线性时间 | 时间是提问的次序：可交换时是多重集，部分可交换时是迹，否则是树；线性时间是个别化的下标 | `49`、`62`、`65` |
| 绝对因果（隐藏的原因总存在） | 隐藏的全局结构存在 ⟺ GLU；Bell 是它在两类都有选择时的失败 | `65` |
| 还原论（完成的全局总体） | 完成的总体是局部的；只有可数的东西是全局的 | `55 §3.1–§3.2`、`§5` |
| 目标拟合（单一标量的评价） | 可重做的评价只看见终局；次序谱是偏序的不变量 | `53`、`66` |
| Kolmogorov 的墙（全局样本空间） | 定律全局、样本空间局部；事件是描述；测度命运 | `61`、`64 §1` |
| ZFC 的墙（GLU₀） | 世界不汇合；全局性三级；事实能粘、存在不能粘 | `55`、`74`、`81`、`86` |
| Turing 的墙（单一全局状态上的下一步预测） | 行为与余下行为；藏回次序依赖的代价；评价的限度 | `47`–`53`、`66` |
| Bell（隐含假设被否定） | 值的层次上 GLU 的失败；有限的、算术的，与世界的汇合无关 | `65`、`68` |

**总评与三个方向**（`121`）：六条初始要求的逐条评估；统一的形状"全局 = 在一切个别化下不变"；物理（触发器的盲区）、ML（标量 = 线性扩张，序维数 = 所需指标的个数）、计算（答案沿记录化的稳定，把 Turing、极限可计算、泛型绝对性放进同一个定义）。

**计算即沿记录化的稳定**（`122`）：在满足 .2 的记录化系统中，改变数有限 ⟺ 有限多个按钮的 Boolean 组合，并且极限值唯一（定理 A，`Stabilize.lean`）。线性时间不本质，汇合本质。集合论中层 0、每个有限层、层 ∞ 都实现；ZFC 独立的陈述分三类。

**第六十九轮**（`123`）：定理 B（一般预序的稳定）；ZFC 独立陈述的四分类（可判定、神谕位、极限可判定、开关）；尖峰即重置；三链的一切同步图刚性；m 链全低角是 Weyl 室。

**完成度**（`124 §4` 的账本）：
- 底座、概率层、过程层的核心结论都是"完整"或"完整（引用）"；
- m ≥ 4 链尺度相当是"结构"（一个引理 W_d 待写，数值刚性）；
- 开放：分形的窗口剖面、Q\*\*、D 的一般模态逻辑、一般世界汇合高度的下界是否被达到。
