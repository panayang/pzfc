## 0. 路线检查

- **原则在推动的**：
  - `121 §2`：全局 = 在一切个别化下不变；
  - `121 §5.2`：计算 = 答案沿记录化的稳定。
  - 这一轮把后者写成定理。
- **会拉着走的**：Ershov 层级（可计算性理论）、Hamkins–Löwe 的按钮与开关（集合论的模态逻辑）。
  - 两者都只作参照；新的是把它们放在同一个定理之下，并找出真正需要的条件：不是线性时间，而是汇合（.2）。
- **结论先说**：
  1. **强度**（§1）：B 在一致性强度上严格强于 ZFC（与"无穷多个强基数"等一致），B⁺ 更强（至少"ω 个 Woodin 基数"）。
     - 但体系对初始目标起作用的部分，几乎都只用 M1–M3。M1–M3 的强度只比 ZFC 多"有足够多的传递模型"一层。
     - 大基数的强度全部来自 M4——"可数核是全局的"。
  2. **稳定定理**（§2，定理 A）：在一个满足 .2 的记录化系统中：
     - 一个问题的答案沿扩张最多改变 n 次，当且仅当它是 n 个持久的回答（按钮）的 Boolean 组合（相差一个按连通部分取常值的量）；
     - 并且它的极限值唯一。
     - 这是 Ershov 层级的推广，**不需要线性时间，需要的是汇合**。没有汇合时，极限依赖于路径（`63` 的不可交换学习就是这种情形）。
  3. **集合论中的稳定层级**（§3）：沿世界的扩张，陈述按"最多改变几次"分层：
     - 0 次：可数核，由 M4 保证；
     - 有限次：按钮的 Boolean 组合，每一层都实现；
     - 无穷次：开关，例如 CH。
     - 于是 ZFC 独立的陈述分成三类：
       - 全局而独立（PD，由 B⁺ 决定）；
       - 有限层（有唯一的极限值——体系给出一个规范的回答）；
       - 开关（没有回答，是局部的）。

## 1. 体系的强度

### 1.1 三层

| 体系 | 公理 | 一致性强度 | 世界内部多出的定理 | 出处 |
|---|---|---|---|---|
| B⁻ | M1–M3 | ZFC 之上加"有足够多的传递模型"（大约是"真类多个世俗基数"的级别，低于不可达基数） | 无（每个世界只是 ZFC 模型） | 本节 |
| B | M1–M4 | 恰好是"无穷多个强基数"（Woodin 上界、Hauser 下界） | PGA₂；每个集合有 sharp；Σ¹₂ 普遍 Baire；投影集可测 | `103` 定理 1–3 |
| B⁺ | M1–M4⁺ | 至少"ω 个 Woodin 基数"的可迭代内模型；由真类多个 Woodin 基数得到模型 | AD^{L(ℝ)}、PD、L(ℝ) 中一切实数集的正则性 | `103` 定理 4 |

**所以答案是**：
- **是的，B 比 ZFC 强**，而且是大基数级别的强：它与"无穷多个强基数"等一致，远强于 ZFC；
- B⁺ 更强。
- 早期的写法 GLU(π)（第十一至二十四轮）对 ZFC 保守；从第三十七轮（`55`）起的底座 B 不是保守的。

### 1.2 强度从哪里来

- M1–M3（每个世界是 ZFC；扩张总存在；不假定汇合）只需要一族可数传递模型对强迫与秩初段封闭。它的强度来自"有足够多的传递模型"，与大基数的中间层级无关。
- **M4（可数核在扩张下不变）是全部大基数强度的来源**：
  - 它等价于每个世界满足两步投影泛型绝对性 PGA₂；
  - 由 Hauser 的定理，这需要（在核心模型 K 中）无穷多个强基数。
- **原因的读法**：
  - "由实数描述的一切都是全局的"（M4）是一个关于**一切**实数描述的承诺；
  - 让一切投影陈述都不被强迫改变，需要强迫改变不了的"坚硬"结构，也就是大基数。
  - 只要求较低的复杂度全局化是免费的：算术陈述（ω 标准）与 Σ¹₂ 陈述（Shoenfield 绝对性）在 B⁻ 中已经全局。

### 1.3 哪些结论只需要 B⁻

| 结论 | 需要 | 出处 |
|---|---|---|
| 大小是局部的，可数是全局的；完成的总体是局部的；选择对象是局部的；CH 是局部的 | B⁻（只用强迫） | `55 §3.1–§3.6` |
| 定律、Borel 测度是全局的；随机点局部 | B⁻（Borel 码是绝对的） | `55`、`61` |
| 模态逻辑 S4.2；良基与 ω 标准两条界线；汇合高度 | B⁻ | `56`、`71`、`119` |
| 概率层、过程层的全部定理（隐藏比率、刚性、次序谱……） | 单个世界内的 ZFC | `64`、`120` |
| **投影集可测、可定义记录的测度命运二值** | **B（M4）** | `95`、`79` |
| 可数核的理论全局不变；PD 在 B⁺ 中成立 | B、B⁺ | `103`、`106` |

**判断**：
- 初始目标（去掉 GLU₀、测量它的失败、概率与过程两层）几乎都在 B⁻ 中。
- M4 带来的大基数强度，只用于"由实数可定义的东西都表现得整齐"这一原则（投影的正则性与测度命运的二值）。
- 如果希望底座尽量弱，可以采用 B⁻ 作为最小的一层，把 M4 当作可选的加强。这与 `106` 的两层方案相容：三层 B⁻ ⊂ B ⊂ B⁺。

## 2. 计算即沿记录化的稳定

### 2.1 设定

- **记录化系统**：一个预序 (W, ≤)。w ≤ v 读作"v 由 w 补充记录而来"。
  - 例：计算的有限阶段（线性）；世界的扩张（`55`）；学习过程的提问历史（`62`）。
- **问题**：P : W → {真, 假}。
- **改变 k 次**：Alt(P, k, w) 表示从 w 出发有一条扩张的链，P 沿它改变 k 次（`Stabilize.Alt`）。
  - 由传递性，只需记录改变发生的点。
- **改变数**：c(P, w) := sup{ k : Alt(P, k, w) } ∈ ℕ ∪ {∞}。
- **持久的回答（按钮）**：U 在扩张下封闭（一旦为真，在一切扩张中为真）。
  - 在计算中是可枚举的（Σ⁰₁）性质；
  - 在集合论中是 Hamkins–Löwe 的按钮（按下后的状态）。
- **.2（对 P）**：◇□(P = b) → □◇(P = b)，对 b = 真、假。

### 2.2 定理 A（稳定定理）

**定理 A**：
1. **（按钮组合的改变是有界的）** 若 P 由 n 个持久的回答 U₁, …, U_n 决定，则处处 c(P, w) ≤ n。
   - 更精确地，可能的改变数不超过尚未按下的按钮数（`alt_le_unpushed`、`no_alt_of_combination`）。
2. **（极限唯一）** 若 .2 对 P 成立，则 P 与 ¬P 不能都被扩张成永久的（`unique_limit`）。
3. **（有限改变 ⟹ 奇偶表示）** 设 .2 对 P 成立，c(P, w₀) ≤ N < ∞。则：
   - 有一个极限值 e；
   - 在 w₀ 之上每个恰好还能改变 k 次的阶段 w，P(w) = e 翻转 k 次（`parity_representation`）；
   - 集合 S_j := { w : 从 w 起改变不到 j 次 } 都是持久的（`persistent_bounded`）。
   - 所以在 w₀ 之上，P = e ⊕ #{ j < N : w ∉ S_{j+1} } (mod 2)，是 N 个持久集合的 Boolean 组合（再加上常数 e）。

*证明*（全部在 `Stabilize.lean` 中形式化）：
- **第 1 条**：P 在一步中改变时，某个 U_i 在这一步中改变。由持久性，它只能从假变成真。所以尚未按下的按钮数严格减少。
- **第 2 条**：
  - 若 v ≥ w 处 □¬P；
  - 由 .2，w 处 □◇P，于是 v 之上有 u 使 P(u)；
  - 矛盾。
- **第 3 条**：
  - 有界时，沿一条改变最多的链走到底，得到一个稳定的阶段（之后不再改变）。
  - 由 .2，w₀ 之上一切稳定阶段的值相同，这就是 e。
  - 然后对 k 归纳：恰好还能改变 k + 1 次的阶段 w，有一步改变到恰好还能改变 k 次的阶段 v，于是 P(w) = ¬P(v)。∎

**两个方向合起来**：在 .2 之下，"改变数有限"恰好是"持久回答的有限 Boolean 组合"，改变数就是所需的按钮数（差分层级的层）。

### 2.3 特例与反例

- **线性阶段**（计算）：
  - 线性的预序自动满足 .2，因为线性序是汇合的。
  - 取 P 为一个 Δ⁰₂ 集合的可计算逼近，定理 A 就是 Ershov 的定理：n-c.e. 集恰是 c.e. 集的 Boolean 组合（差分层级的第 n 层），并且极限存在（Shoenfield 的极限引理）。
- **分叉而汇合**（世界的扩张，S4.2）：定理 A 原样成立（§3）。
- **分叉而不汇合**（S4）：极限可以依赖于路径。
  - 例：Hamkins–Woodin 的顶部扩张潜在主义，其模态逻辑恰是 S4（`57`）。那里有句子沿一条扩张路径变成永久真，沿另一条变成永久假。
  - 例：沿不可交换的提问树，每条路是经典的鞅，学习的极限依赖于提问的策略（`63 §1`）。在本定理的语言中，这正是 .2 对"极限估计 = b"的失败。

**读法**：
- 可计算性理论中的"极限可计算"与"有限次改变"，传统上建立在线性的阶段上。定理 A 说线性不是本质的，**汇合（.2）才是**。
- 这直接对应初始 prompt 中的判断——"图灵论题……都是在线性时间认知下的公理定义"：
  - 稳定的概念在去掉线性时间之后仍然成立，只要记录化是汇合的；
  - 去掉汇合时，失去的恰是"答案"本身的唯一性：答案变成路径的函数。

### 2.4 定义：沿记录化的可计算

在一个满足 .2 的记录化系统中，一个问题 P 在阶段 w：
- **已判定**：c(P, w) = 0，也就是 w 处 □P 或 □¬P；
- **n 层可极限判定**：c(P, w) = n < ∞。它有唯一的极限值，并且是 n 个按钮的组合；
- **不可极限判定**：c(P, w) = ∞。

**丘奇—图灵的情形**：
- 系统是计算的有限阶段；
- 可计算 = 在一个**可由已有记录确定的**阶段已判定；
- Δ⁰₂ = 有限层可极限判定（带可计算的逼近）。

## 3. 集合论中的稳定层级

**系统**：B 的一个世界 w 与它的强迫扩张；陈述可以带 w 中的参数。
- 强迫潜在主义满足 S4.2（Hamkins–Löwe；`56`），所以 .2 对每个陈述成立，定理 A 适用。
- 这里用的是宽度扩张；高度扩张不改变可数核，对下面的例子不起作用。

**层 0（已判定）**：
- 由 M4，关于 H(ω₁) 的一切陈述（带实数参数）在一切扩张中不变：可数核在"第 0 阶段"就已判定。
- 在 B⁺ 中，L(ℝ) 的一切陈述都在层 0。
- 注意：层 0 不等于被 B 的公理决定。例如 PD 在 B 中是层 0 的（全局的），但 B 不决定它（`103` 定理 3）；B⁺ 决定它。

**层 1（按钮）**：
- 例：以 w 中的序数 ℵ₁^w 为参数，"ℵ₁^w 是可数的"。
- 它在 w 中为假，坍缩后永远为真。它的极限值是真。

**层 n**：
- 取以 w 中的参数给出的一列棘轮按钮 b_i := "ℵ_i^w 是可数的"（按下 b_j 就按下一切 b_i，i ≤ j）。
- 令 φ_n := "b₁, …, b_n 中被按下的个数是奇数"。
  - 在 w 中 φ_n 为假。
  - 依次坍缩 ℵ₁^w, …, ℵ_n^w，φ_n 改变 n 次。
  - 由定理 A 第 1 条，它最多改变 n 次。
- 所以每个有限层都实现。

**层 ∞（开关）**：
- CH 可以被强迫为真、再为假、再为真，无穷多次，c = ∞，没有极限值。
- 一切"连续统的大小是 ℵ_k"都是开关。

**边界在哪里**：
- 在 B 中，投影陈述（关于 H(ω₁)）都在层 0。
- 开关出现在 Σ²₁ 一层：CH 是 Σ²₁ 陈述。
- 已知（Woodin 的 Σ²₁ 绝对性，需要真类多个可测的 Woodin 基数，比 B⁺ 强）：若只在满足 CH 的扩张之间比较，Σ²₁ 陈述是层 0 的。这是"条件化之后的稳定"，不在 B⁺ 的范围内，只作参照。

**对初始要求 R4 的更精确的回答**（更新 `121 §1.1`）：ZFC 不能判定的陈述，在 B 中分成三类。

| 类 | 例 | 体系给出的 |
|---|---|---|
| 全局而独立（层 0） | PD | 在每个连通部分内有确定的值，但要由更强的公理（B⁺）决定：一致性强度的阶梯 |
| 有限层（1 ≤ c < ∞） | 带参数的按钮与棘轮的组合 | **唯一的极限值**：体系给出一个规范的回答——沿记录化最终的回答 |
| 开关（c = ∞） | CH | 没有回答：它是局部的，只在一个世界之内有值 |

**读法**：
- "ZFC 独立"不是一个性质，而是三种不同的情况。只有开关是真正"没有回答"的。
- 有限层的陈述在计算上相当于"尚未停机的可枚举问题"：现在没有判定，但它的答案作为极限是确定的。
- CH 相当于一个永不稳定的问题。
- 这是 `121 §5.2` "ZFC 独立性的计算的读法"的定理形式。

## 4. 仍然开放的

1. **不汇合时的结构**：在 S4 的系统中，有限改变的问题是否仍是按钮的 Boolean 组合？
   - 反例的可能：极限依赖路径时，奇偶表示中的"极限值"变成一个依赖阶段的持久量；它本身可能不是有限多个按钮的组合。
2. **高度扩张**：把高度步骤（M2b）也算进记录化，层级是否改变？
   - Hamkins–Woodin 的顶部扩张给出 S4，由第 1 问，这里可能出现路径依赖的极限。
3. **可判定性的"已知阶段"**：丘奇—图灵的情形要求稳定的阶段可以由已有记录计算出来。
   - 集合论中与之对应的是什么？候选：层 0 且由 B 的公理可证。
   - 这时"可计算的集合论问题"恰是 B 能判定的问题。需要检验这一对应是否有内容。
4. **与学习的联系**：`62`、`63` 的学习过程作为记录化系统，其中哪些量是有限层的（可以在极限中学到）？
   - 猜想：在可交换的情形，.2 成立，一切有限改变的量都有唯一极限；在不可交换的情形，.2 失败，极限依赖提问策略。这把 `63` 的结论写成定理 A 的实例。
