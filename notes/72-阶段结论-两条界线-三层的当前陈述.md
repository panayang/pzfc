## 0. 路线检查

- **推动这两轮的**，只有一个原则：
  - 全局模型在哪里存在、在哪里不存在；
  - 不存在时，缺的是什么，由什么度量。
- **已知的体系**（de Finetti、Bell、强迫的保持理论、可容许集）只提供了证明的零件。
- **仍在回答 `00 §7`**：本篇把"全局模型存在"为假的程度，分成两个来源，给出各自的度量。

## 1. 一个新的原则：ω 的标准性

B 的世界是传递的（M1），所以自然数在一切世界中是同一个 ω。这一轮之前，它只是 M1 的附带结果；现在它有了独立的内容。

**原则（ω 标准）**：一切世界有同一个自然数集，从而有同样的遗传有限集。

**它推出的**：
1. **有限层是全局的**。
   - 有限的记录、有限的频率表、语境性的判定都是算术的，在一切世界中相同（`68` 定理 2）；
   - 部分可交换过程的有限表示，也属于这一层（`65`、`69`）。
2. **对象层面的高度障碍不可避免**。在一般情形下，两个同高的世界不能同高汇合；非良基的增长也不消除这一点（`71` 定理 1、2）。

**它不推出的**：可能性的汇合。那由另一条界线——良基——决定（`57`、`71 §4`）。

**两条界线**：

| 界线 | 管辖 | 保持时 | 放弃时 |
|---|---|---|---|
| 良基 | 可能性（模态） | 汇合（S4.2） | 可以分叉（S4） |
| ω 的标准性 | 对象与有限层 | 有限层全局；世界之间有高度障碍 | 高度障碍可消；有限层随世界而变 |

B 两条都保持。D 放弃第一条；放弃第二条的 D′ 被体系排除（`71 §5`）。

## 2. "全局模型不存在"的两个来源

| | 值的层次 | 世界的层次 |
|---|---|---|
| 缺的是 | 每个变量一份共享记录（全局定律） | 一个同时包含两个世界的同高世界 |
| 性质 | 有限的，算术的 | 无穷的，由高度引起 |
| 度量 | η（非上下文部分），[0, 1] 中的数 | 汇合高度，下界是联合 Church–Kleene 序数 |
| 在哪一层处理 | 概率层与过程层 | 底座 |
| 原始问题中的实例 | Bell 的墙 | 选择、CH、不可测集等局部对象 |

**两者独立**（`68`）。它们又由同一条界线联系起来：ω 的标准性使前者全局可判定，同时使后者不可避免。

## 3. 三层的当前陈述

**第零层：底座 B**（`55`）
- 世界、宽度与高度扩张、可数核的绝对性（M1–M4）；不假定汇合。
- 新增：
  - ω 标准原则（§1）；
  - 不假定汇合的原则性理由：在 ω 标准之下，同高汇合一般不成立（`71`）。

**第一层：概率**（`64 §1`）
- 测度属于描述；概率谈论新鲜的样本；独立是扩张；语境上的定律（非上下文部分；有限的障碍）。
- 新增：
  - **抽样由测度承载**，所以保持一切旧点集的外测度——概率层在自己的运算下封闭（`67` 定理 7、`70` 定理 2）；
  - **测度的命运**：
    - 由测度承载的记录精确保持；
    - 其余的记录可以用零测族捕获旧点，不需要 Cohen 实数（`70` 定理 1）；
    - 捕获可以按"点来自哪个世界"有选择，这使命运取中间值（`70` 定理 3–4）。

**第二层：过程**（`64 §2`）
- 余下行为、事实、结构与位置；次序与迹；次序谱。
- 新增：
  - **部分可交换的一般表示**：迹可交换的过程 = 隐藏的迹 + 无穷处每个依赖分量的一个比率 + 新鲜的部分（分量之间的独立同分布日程，分量之内的中心线性化）。在完全切口或有界不可比时，分量之内是刚性的（`65`、`69`）。
  - **隐藏的结构 = GLU**：提问者有选择时，分离总成立，隐藏的全局结构存在当且仅当 GLU。它的唯一失败是语境性，需要两个类都有选择（`65`）。
  - **次序谱的定量理论**：指标集、可达的上界、次序熵的可加性、概率版本的界（`66`）。

## 4. 对原始问题的回应（这一阶段）

- **Kolmogorov 的墙**：一个预先给定、装着一切样本的全局空间。
  - B 用描述代替点集。
  - 这一阶段证明了：抽样本身不破坏任何旧的测度；能破坏测度的只有离开概率层的记录。
- **Bell 的墙**（原始 prompt 所说的"隐含假设被否定"）：
  - 它位于有限层，是 GLU 在"观察者有选择"时的失败；
  - de Finetti 是同一个定理在"没有选择"时的成立（`65`）。
  - 所以这堵墙不是由放弃世界的汇合来处理的，而是由"记录属于语境"来处理的（`68`）。
- **ZFC 的墙**（选择对象、CH、不可测集）：它们是无穷层的局部对象。高度障碍说明，这一层的"不能汇合"是有限层全局化的代价（`71`）。
- **线性时间**：
  - 可交换时，时间是多重集的偏序；
  - 部分可交换时，时间是迹，隐藏的只有各分量的比率；
  - 不可交换时，时间是树。
  线性时间是其中"每一步只有一个分量前进"的特例（`62`、`65`、`69`）。

## 5. 新的与不新的

**新的**（据目前所知，均待文献核验）：
1. de Finetti 与 Bell 作为同一个定理的两端（`65` 定理 5–7）。
2. 一般独立关系下，隐藏的比率恰好住在无穷处的依赖分量上；迹几乎必然没有最大元（`69` 定理 2–3）。
3. "由测度承载"的保持判据，以及杀死的轮廓（`70`）。
4. 两条界线：良基管可能性，ω 的标准性管对象与有限层；高度障碍是全局有限层的代价（`71`）。

**不新的**：所用的零件——de Finetti、Diaconis–Freedman、迹的投影引理、Fine 定理、Fubini、Kuratowski–Ulam、Mathias 与 Laver 强迫的性质、可容许集、Hamkins–Woodin。

## 6. 下一阶段的问题（排序）

1. **分量之内的刚性**：有限不可比是否总蕴含刚性？检验例子是 ∏_k (x^k y^k p q)（`69 §5`）。
2. **吸收问题**：在 B 的扩张关系下，两个宽度扩张是否总能在某个高度汇合（`71 §6`）？它决定 B 的世界层次是否"只差高度"。
3. **非分层集合的命运**；轮廓的可实现性（`70 §6`）。
4. **保持 ω 标准的 D 的模态逻辑**：宽度扩张加上非良基的高度增长（`71 §6`）。
