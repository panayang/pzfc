## 0. 路线检查

- **原则在推动的**：
  - `68` 把"全局模型不存在"分成两层：值的层次（语境性，有限的）与世界的层次（不能汇合，无穷的）。
  - 遗留两问：
    - 世界层次的"差多少能汇合"怎样度量？
    - 在允许非良基增长的 D 中（`60`），Mostowski 型的障碍是否消失？
- **会拉着走的**：
  - 可容许集与 Church–Kleene 序数；
  - ω-模型的绝对性；
  - Hamkins–Woodin 的普遍有限集。

  只用它们的标准事实。
- **四种情形**：本篇不涉及单次提问的情形，处理的是世界之间的关系。
- **是否回答 `00 §7`**：回答世界层次上"全局模型不存在"的程度与来源。

## 1. 设定

- B 的世界是传递的（M1），所以都是 **ω-模型**：它们的自然数就是真的自然数，遗传有限集在一切世界中相同。
- w 是一个世界；w₁ = w[c]、w₂ = w[d] 是它的两个宽度扩张（同样的高度 o(w)）。
- **同高汇合**：有一个同样高度的世界同时包含 w₁ 与 w₂。
- 在可数模型的解释中，Mostowski 型的例子说明：同高汇合可以失败，因为 c ⊕ d 编码了一个序型为 o(w) 的良序（`68 §3`）。

## 2. 高度的代价

**引理**（标准）：设 M 是包含实数 z 的传递 ZFC 模型，则 M 的高度 > ω₁^z。
- 这里 ω₁^z 是由 z 可计算的良序的序型的上确界。
- M 含有每个这样的良序，因而含有它的序型。

**定义**：
- **汇合高度** amh(w₁, w₂)：同时包含 w₁、w₂ 的传递 ZFC 模型的最小高度。在可数模型的解释中，它总是存在的。
- **联合 Church–Kleene 序数** jck(w₁, w₂) = sup { ω₁^{x ⊕ y} : x ∈ ℝ^{w₁}，y ∈ ℝ^{w₂} }。

**定理 1**：
1. amh(w₁, w₂) ≥ jck(w₁, w₂)。所以只要 jck(w₁, w₂) ≥ o(w)，就不能同高汇合。
2. Mostowski 型的一对满足 jck > o(w)：c ⊕ d 计算出一个序型为 o(w) 的良序。
3. 互为泛型的一对满足 amh = o(w)：w[c][d] 就是同高的共同扩张。
4. **有限的影子为零**：c、d 的有限前段都在 w 中，由它们可计算的良序也都在 w 中。

所以障碍在有限处完全看不见。

**读法**：
- 世界层次上"差多少能汇合"，由一个**序数**度量：汇合高度超出 o(w) 的部分，下界是联合 Church–Kleene 序数。
- 它不是 [0, 1] 中的一个数。对照语境性：那里的度量是非上下文部分 η，由有限的数据算出（`68 §2`）。
- 两种度量的类型不同，正对应"有限的"与"无穷的"。

## 3. 非良基的增长不消除这个障碍

**定理 2**：设 N 是任何 ω-模型（自然数是标准的，但可以非良基）。若 N ⊨ ZFC 且含有实数 x、y，则 N 的良基部分的高度 > ω₁^{x⊕y}。

*证明*：设 R 是由 x ⊕ y 可计算的一个良序。
1. **R 在 N 中**。N 的自然数是标准的，所以 N 中由同一个算法定义的集合就是 R 本身。
2. **N 知道 R 是良序**。"R 是良基的"是 Π¹₁ 陈述：
   - N 的实数都是真的实数；
   - 所以 N 中没有 R 的无穷下降序列。
3. **R 的序型在 N 的良基部分里**。
   - N 中有一个序数 ξ 与一个同构 f : (ω, R) ≅ (ξ, ∈^N)。
   - 在 V 中，f 仍是 (ω, R) 与 ξ 的 ∈^N-前驱之间的同构。
   - 所以 ξ 的前驱是良序的，ξ 在 N 的良基部分中，序型等于 R 的序型。∎

**推论**：
- Mostowski 型的一对，即使在非良基的 ω-模型中，也不能同高汇合：任何同时含有 c、d 的 ω-模型，良基部分都高于 o(w)。
- **所以 D——只要它保持 ω 标准——不消除这个障碍。**
- 障碍消失的唯一途径，是让自然数本身非标准。那时：
  - "c 属于 N"只能指 N 中某个标准部分为 c 的实数；
  - N 可以把 R 看成非良基的。

## 4. 两条界线（修正 `60` 的 GLU–良基猜想）

`60` 猜想：良基是一个全局的语境，可能性的真正分叉需要非良基的增长。现在可以把它分成两条界线：

| 界线 | 保持时 | 放弃时 | 依据 |
|---|---|---|---|
| **良基**（序数是真的序数） | 可能性汇合（S4.2） | 可能性可以分叉（S4）：非良基的顶部扩张，ω 仍标准 | `57`；Hamkins–Woodin |
| **ω 的标准性**（自然数是真的自然数） | 有限的东西在一切世界中相同：记录、频率、语境性（`68`）；对象层面的高度障碍不可避免（定理 2） | 高度障碍可以消失；但有限的东西随世界而变 | 本篇 |

**所以**：
1. 可能性的分叉只需要放弃良基；对象层面的不能汇合，只有放弃 ω 的标准性才能消除。
2. 两种"粘合的失败"对应两条不同的界线：
   - 可能性的分叉——良基；
   - 世界的不能汇合——ω 的标准性。

## 5. 对体系的意义

**B 不假定汇合，原来的理由是"不需要"**（`55`）。现在有了更强的理由：
- 只要自然数是标准的，同高的汇合在一般情形下就**不成立**（定理 1、2）；
- 而自然数的标准性，正是使有限层——记录、概率的频率、语境性的判定——在一切世界中相同的东西（`68` 定理 2）。

**所以，世界之间的高度障碍，是"有限的东西全局"的代价。**

体系在这里做了一个明确的选择：保持 ω 标准，接受世界层次的不能汇合。

**对 D 的判断**：
- D 保持 ω 标准、允许非良基的增长：它得到可能性的分叉，但不消除对象层面的障碍。
- 放弃 ω 标准性的 D′ 会失去全局的有限层，与概率层（有限的频率）以及语境性的有限处理相冲突。
- 所以体系的原则排除 D′。

## 6. 仍然开放的

1. amh 的精确刻画：它除了下界 jck，还依赖什么？——**已答**（`119`）：amh = L[A, c ⊕ d] 在 α 处或之上的第一个 ZFC-高度。
2. **吸收问题**：在 B 的扩张关系下（宽度与高度的步骤），两个宽度扩张是否总能在某个高度汇合？

   - 在没有大基数时，这不是显然的（`68 §3`）。
3. 保持 ω 标准、允许非良基增长、同时有宽度扩张的潜在主义系统，它的模态逻辑是什么？

## 7. 已知的与这里的

**已知的，只作指导**：
- Mostowski 型的不能汇合；
- 可容许集与 ω₁^z；
- Π¹₁ 陈述对 ω-模型向下绝对；
- Hamkins–Woodin 的普遍有限集（非良基的顶部扩张给出 S4）；
- Hamkins–Linnebo 的潜在主义表。

**这里的**：
1. 用汇合高度度量世界层次的不能汇合，以及它的下界（定理 1）。
2. 定理 2 作为对 D 的判断：非良基的 ω-模型不消除高度障碍。
3. 两条界线的区分：良基对应可能性，ω 的标准性对应对象；以及"高度障碍是全局有限层的代价"这一结论。

**如实的判断**：
- 定理 1、2 的证明都是标准的论证。
- 新的是它们在体系中的位置：它们把 `60` 的一条猜想分成了两条界线，并给了"不假定汇合"一个原则性的理由。
