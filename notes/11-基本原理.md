# 11 · 基本原理

> 四条原理，都只谈"问题"与"回答"，不引用任何理论也能读懂。
> 目标是：经典公理作为它们的特例或否定而**出现**，而不是被我们挑选。

---

## 1. 四条原理

**P1 可辨性相对于问题。**
两个东西能否被区分，取决于允许问哪些问题。一个对象，对我们而言，就是它回答可允许问题的方式。

**P2 计数可以超过辨别。**
知道"有两个"，不等于能说出"哪一个是哪一个"。

**P3 有限性。**
任何一次提问与回答，只涉及有限多的信息。

**P4 自反性。**
问题本身也可以被问。

P2 看起来像是 P1 的一部分，单独列出是因为几乎所有有意思的推论都发生在"数得出、分不开"的那条缝里（`12`）。

---

## 2. 经典公理作为特例

| 经典公理 | 在原理下的身份 |
|---|---|
| 外延公理 | P1，但**只允许问"某物是不是你的元素"** |
| 基础公理（WF） | 上述问题可以自底向上**逐层问完** |
| Aczel 反基础公理 | P1，允许问"你被问时怎样回应"，**不要求逐层问完**；同一性 = 互模拟 |
| 单值公理（HoTT） | P1，问题 = 所有保结构的问题；结构上不可区分 ⟹ 相等 |
| 选择公理 | **否定 P2**：每一个数得出的区分，都能被单独指认（选出） |
| 排中律 | 在断言层面**否定 P3**：每个问题都有确定回答，无论有没有有限的行为能确定它 |
| Frege 基本律 V（朴素概括） | "每个问题都有一份**完成了的**回答记录"——与 P4 加锐性回答冲突（Russell） |

几条观察：

- **还原论（两种都是）= P1 的一个特例**：只允许问"你由什么组成"，且能问到底。
  集合论的还原论与物理的还原论在这里是同一个同一性标准的两种实现。
- **AC 是对 P2 的否定。** 你说"AC 可以视为对测量存在的坚信"，在这里得到精确形态：
  AC 相信**一切存在的区分都能被指认**——凡是能数出来的，都能被单独拿出来。
- **排中律是对 P3 的否定**，但只在"断言"这一层。对象层面的 P3 是另一回事（§4）。
- Frege 的律 V 值得停一下："每个概念都有外延"，用本文语言说就是"**每个问题的回答都能完成成一份记录**"。
  ZFC 的修补方式是：只能在**已经完成的**定义域上完成记录（分离公理）。于是记录的完成有了先后次序——累积层谱，也就是构造的线性时间。

## 3. 直接推论（`lean/Principles.lean`）

**由 P3：**

- 全称陈述"所有回答都是否"可以被**一次**反例驳倒，却不能被任何有限次观察证实：
  不存在由有限前缀决定的"全零检验"（`no_finite_zero_test`，即 LPO 在有限行为下不成立）。
- 两份无穷记录**是否相等**不能由有限行为判定（`no_finite_equality_test`）；
  而**是否不同**一旦被看到，就对一切更长的观察保持成立（`apartness_is_open`）。
  所以：**区分（apartness）是原始的，相等是派生的。** 这与 P1 一致。
- 经典逻辑在其上作为"**不可驳倒**"层恢复：排中律的每个实例都不可驳倒（`lem_irrefutable`），
  这一层是稳定的（`triple_neg`）。**经典真 = 不可驳倒；测量真 = 可证实。**

**由 P1 + P2：**

- 若可允许的问题分不开任何两点（传递的不可察觉变换），而点又不止一个，则：
  **一切可定义的权重必须处处相等，且没有任何一点能被指认**（`gap`）。
  概率的内在值与选择的失效，是同一个假设的两面。展开在 `12`。
- 反之，缝合上（变换全是恒等）时，不变性对权重毫无约束——概率只能从外部给出（`gap_closed`）。

**由 P4：**

- Lawvere：若问题能枚举关于自身的一切问题，回答值上的每个变换都有不动点（`lean/Invariants.lean`）。
  墙的形状由回答值决定：二值回答 ⟹ Russell；允许"未定"且只用单调操作 ⟹ 不动点而非矛盾；想谈论"未定"本身 ⟹ 复仇。

## 4. P3 的两种读法——一个真正的分岔

- **断言层**：一个断言只有在有限行为能证实它时才算成立。⟹ 直觉主义逻辑、Brouwer 连续性。
- **对象层**：逻辑保持经典，但每个对象都能被有限问题**逼近**。⟹ 所有实数集可测、有 Baire 性质、有完美集性质（Solovay 型宇宙）。

两者都是 P3，推出的数学不同。你原话"以测量为核心的语言去**表述逻辑结构**"指向断言层；
"回归 ZFC"与"判定 ZFC 判定不了的问题"则分别在两条路上更容易实现（`13 §4`）。
这个分岔我没有答案，它是本项目需要做的一个真实选择。

## 5. 原理预测什么、不预测什么（取代第二轮的命题 T）

| 基础 | 由哪条原理选出 |
|---|---|
| Brouwer 直觉主义 / 有效拓扑斯 | P3（断言层） |
| Solovay 型宇宙 / AD | P3（对象层） |
| Nominal 集合 / FM 置换模型 | P1 + P2 |
| Aczel 反基础 | P1，去掉"逐层问完" |
| HoTT 单值性 | P1，问题取为保结构的问题 |
| LAST（收缩受控） | **无**——数学上成立，但没有原理要求它 |
| 综合微分几何 | **无** |
| NF | **无**（分层或可读作一种对称，但牵强） |

**命题 T′（取代 T）**：原理选出的区域是 {P3 的某种读法} ∩ {P1 + P2 的对称性约束}，可再加 P1 的非良基或单值形式。
每一片都有现成的实现，**是否存在同时实现它们的单一框架**是开放的。第二轮命题 T 中的"非笛卡尔"分量没有原理支持，撤回。

## 6. 检验协议的修订

第二轮 T1–T4 保留。T5（科学适配）替换为：

- **T5′ 原理可追溯性。** 每条公理要么能追溯到 P1–P4，要么被明确标为"自由选择"。
- **T6 科学只在原理层起作用。** 允许的用法形如："任何科学实践都接触不到一份完成了的无穷记录"——这支持 P3。
  不允许的用法形如：取某个物理理论的数学形式，作为基础的形式。
