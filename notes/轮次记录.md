## 1. 各轮摘要

- 第一轮（`00`–`04`）：一个轴解释一切，过早走向应用。
- 第二轮（`05`–`09`）：修正单轴，但把"测量"实现成了量子测量的现象学。
- 第三轮（`10`–`13`）：去物理化；四条原理；"计数与辨别之间"。
- 第四轮（`14`–`15`）：第三轮几乎处处是 0/1 开关。逐个换成纯数学里现成的分级结构；推导中暴露出一条主要裂缝并修补。
- 第五轮（`16`）：值代数从哪里来；缺陷坐标；E 与 W 的耦合；吸收梯子。引入 mathlib 做实数部分。
- 第六轮（`17`）：回到主目标——**PZF，一个以问题为原语、对 ZF(C) 保守的公理体系**。
- 第七轮（`18`–`20`）：给所有内部宇宙画地图、跨一切构造的存活——**偏离，是"大统一"**，降为记录。
- 第八轮（`21`）：回到开头那段话，把墙定位到**从事件到点的五座桥**（P 联合结果、U 函数化、W 线性排列、C 标量可比、R 还原同一），只在那里拓展。
- 第九轮（`22`）：五座桥读起来像清单。重想后，它们与第一轮的三个旋钮都是**同一个原理（GLU）**的面与参数：∃、!、形状、粘的是锐值还是权重。
- 第十轮（`23`）：形状这个参数。参数之间并不独立：唯一性的形式由形状决定，存在只在非唯一处才是承诺，二值被这一承诺连同外延迫使。
- 第十一轮（`24`）：回到公理体系本身。核心 = 问 + GLU₀ + 大小，是 PZFC₀ 的重排，对 ZFC 保守；家族 = 一个构造 U(π)，π 只取 GLU 的四个参数。
- 第十二轮（`25`）：把拓展逐个构造出来，写出它们满足的公理。形状的拓展在 Lean 中完整构造（反基础宇宙，经典原点在其中，不用选择）；四个参数收成两个——形状与上下文结构；家族的共同核心是 IZF。
- 第十三轮（`26`）：澄清。IZF 不是 ZFC 的保守扩张，而是比它弱；它是 GLU₀ 去掉条款 4、不预设排中律。保守性在外层（公理体系本身），IZF 在内层（各情况共有）。真值随上下文的逻辑在 Lean 中写出：排中律恰在上下文不能再细化处成立。
- 第十四轮（`27`）：IZF 不是拓展——它只是少断言，在形状上和 ZFC 一样窄。拓展是一条公理模式 GLU(π)：经典记录是原点实例，墙外的对象是其他实例的对象；不同形状不能共用一个隶属关系，所以拓展是加种类。
- 第十五轮（`28`）：π =（S，𝒞）不完整，少了值 W；恢复后 π =（W，S，𝒞），恰是第一轮三个旋钮在一个模式里的位置。墙的第一层是种类之间的整体截面。GLU(π) 写成终对象的泛性质；统一接口在 Lean 中完成第一阶段。
- 第十六轮（`29`）：上下文种类在 Lean 中构造出来：GLU 在任意上下文结构上成立；经典作为常对象嵌入；墙的第一层形式化为"存在是局部的"；纯集合承载不了对称，所以"回答是什么"须包括标签（原子）——修正 `28`。
- 第十七轮（`30`–`33`）：完成 `28 §6` 的计划。名字进入回答，Russell 的袜子在种类里（一双是整体的，没有一只是）；存在是权重的影子，Kolmogorov 被局部化；选择的判据的四种情形，公理剖面本身就是证据。然后回到公理体系，把它收成一处（`33`）。
- 第十八轮（`34`）：带权的种类，对任何完备的值结构用同一个构造给出，只用 `Quot.sound`；锐的实例的同一是互模拟；支撑是影子，会忘掉重数；经典原点沿 W 是收缩。
- 第十九轮（`35`、`36`）：统一 Lean 版本，模块可以互相引用；一个构造回到 mathlib-free 部分，它的锐的实例被证明就是形状的拓展；预序上的选择判据：局部的存在总能粘成整体的，当且仅当每个连通分支都有最小的上下文；同一的关系形式对每个值结构成立（Larsen–Skou）；把上下文放进值里（只增不减），三个参数在预序上合在一起（`36`）。
- 第二十轮（`37`）：停下来审视。公理体系用集合论的直白语言重写；保守拓展不判定新的集合论命题；范畴论词汇的对照与不严谨之处的修正。
- 第二十一轮（`38`）：什么算有意义（成为对象、方法、自己的问题有答案、回答开头）；局部何时成为整体，对任意上下文结构有了完整答案；值、名字、对称三者一起的构造；Russell 袜子的概率形式——选不出一只袜子，但"随机的一只"是整体的对象，权重被对称定为 1/2；如实检查：方法还弱。
- 第二十二轮（`39`）：计算的定义。Gandy 的机器原则就是原点处的 GLU；推广的方式是改粘合（π），而不是改机器。确定性局部算法只看得见对象；所有结点是同一个对象时选不出领袖；看得见什么由值决定（集合还是计数）；硬币打破确定性打不破的对称。丘奇—图灵论题是原点处的陈述，离开原点，计算分裂成对 π 可解的任务（假设）。
- 第二十三轮（`40`）：概率过程作为对象。不加观察，所有随机过程都是同一个对象；以停止作为观察时，停止概率是对象的性质，合并保持它；对象比停止的规律更细——它记得随机性何时被决定；n 个结点的循环对称迫使均匀分布 1/n。
- 第二十四轮（`41`）：深度反思。第二十九到四十轮大多是已知结果的翻译，属于这里的只有诊断、以经典为原点的组织与统一的构造。GLU(π) 实为"对象即其回答族、按不可区分认同"的定义，存在的一半是同义反复；它靠增加对象吸收失败，原点处的墙原样保留。完全没有粘合的体系做不了底座；真正的问题是底座假设哪些粘合。直接的选项：去掉全局选择、保留依赖选择、加上"每个实数问题都有概率"（ZF + DC + LM + PSP）——不保守，但经典作为内部世界 L、低复杂度命题一致、给出有内容的回答。
- 第二十五轮（`42`）：从头想，不用前几轮的框架。B 没动根：Kolmogorov 在其中原样不变，因为它仍假定一切回答都是记录。只用"问"与"回答"想：再问一次一定同样的是**记录**，可能不同的是**来源**（稳定的是规律）。经典基础共同的前提是"一切回答都是记录"；四个倾向、三个旋钮、三种形式化都是它的面，基础里的线性时间（分阶段）是它的代价。一条轴（记录的界线画在哪里）放下经典、B、构造主义与新的底座；底座草案 S1–S8：断言经典、对象可以是来源、无穷的总体是来源、记录是做出来的；Kolmogorov 是对能被一起记下的来源族的记录侧描述；ZFC = 底座 + "一切回答都是记录"。判定：弱底座只解释 CH；强底座（记录都是做出来的）猜想判定一批经典问题，不保守。
- 第二十六轮（`43`）：记录与 GLU 打通——一族回答来自同一个整体对象，当且仅当每个回答是跨语境的记录（定理）；Kolmogorov 的隐含前提是"每个来源都是记录的混合"；GLU(π) 改了记录什么，没改回答是不是记录。三种失败；没有原子的来源没有记录（连续随机性的常态）。"可以问"定义为用有限读取以任意小误差回答，定理：恰是可测。T₀：一切记录可数，来源、可以问的问题、来源的记录、联合来源，ZFC 是理想化完成，CH 被消解。T₁ = T₀ + "能构成的就能问" + "要么列得出、要么承载一个来源"：判定 ZFC 判定不了的问题，与 ZFC + 大基数相容，落在已知的规范界线上。
- 第二十七轮（`44`）：T₀ 只有一类原语（记录）；来源由读取、规律、细化相容给出，不以点为前提；规律是对象，随机的回答不是。已证：读取问题的概率与读的层次无关；来源的记录恰是原子；公平的硬币没有记录。(A)、(P) 在第一个非平凡层次上由一条原则 (C) 给出——从任何记录出发，分阶段的构造只做出可数多份记录（线性时间到不了连续统）：(P) 就是它，(A) 是它加上规律的可数可加性；"V = L"是它的反面（线性时间用完一切，没有随机性）。T₁ = T₀ + (C)，判定一批 ZFC 判定不了的问题，与 ZFC + 可测基数相容。
- 第二十八轮（`45`）：先反思路线——三处漂移（形式系统退回记录优先；往上爬 (Cₙ) 会变成内模型理论的翻译；失败的度量被搁下），决定不往上爬、转到来源一侧。(D) 统一读法：确定的总体是记录，其余来自来源（随机比构造多）。定理：来源有记录，当且仅当两遍独立重读一致的概率有正的下界（记录 = 能复读 = 原子）。"全局模型存在"有两种意思——全局规律存在、全局规律有记录——彼此独立，各有度量，经典的语言用"有点"把它们一起代替。关系可以是记录而两端不是：同步耦合无记录而"相同"必然，独立耦合部分相同而"相同"概率为 0；来源的事实就是它必然的问题。
- 第二十九轮（`46`）：回到墙逐堵检查缺的工具。诊断修正：经典的记录是在四种提问情形——再问、谁问、之前问了什么、同时问了什么——下都不变的回答；前几轮只放开了"再问"（与"同时问"的一半），而 ML 与物理的墙主要在"之前问了什么"（读取即更新，第 1 轮看到过、后来丢了）与"谁问"。经典总能把失败藏回去（历史或提问者变成隐藏状态），藏回去的方式就是预测，所以失败只能相对于模型类度量。可信 = 公共的、可复读的记录，标量只是一种；以改变来定义的系统，记录是跨历史的不变量（每读一次就翻转的记忆：回答不是记录，"相邻不同"是）。ZFC 的独立性是随"谁问"（宇宙）与"之前问了什么"（强迫法）而变的回答；断言层保持经典，因为证明本身就是记录。
- 第三十轮（`47`）：行为（此前谁问了什么、现在谁问、问什么 → 回答）；公共、不被扰动、不依赖语境、可复读四种性质，两两独立（每种都有只放开它的例子）。有记录模型 ⟺ 公共且不被扰动；每个行为都有隐藏状态模型（状态 = 历史）；不被扰动 ⟺ 有状态不动的模型。藏回扰动的最少隐藏状态数 = 余下行为的个数，失败的程度就是经典描述必须虚构的量（`00 §7` 的可计算形态）。任务是事实，预测是定死回答的任务；关系的任务（相邻两次不同）不是预测；评价按事实的包含关系比较，事实与怎样藏回去无关。T₀ 不需要新的原语：测量优先落在"哪些东西算事实"上。
- 第三十一轮（`48`）：两个行为的不变事实全同，当且仅当余下行为全同——事实看见结构（可能处于的一切情形），看不见位置（此刻是哪一个）；预测 = 结构 + 位置。不被扰动的行为事实定死一切（经典里结构与位置不可区分）；两个翻转记忆事实全同而不同（有回复时位置不是事实）；做标记的记忆被事实定死（扰动不可撤销时起点是事实）；一般判据：位置是事实 ⟺ 没有别的余下行为能做同样的事。线性时间是扰动不可撤销时的时间。两格、按最近使用排列的记忆：存了能读到、读过的受保护、没读的被挤掉，都是在任何历史之后成立的关系事实；读取改变以后的回答；快照不是事实。
- 第三十二轮（`49`）：随机的情形分出四样东西——运行之间的随机、运行之内的可复读、规律的扰动（平均掉已知回答之后）、信息；三枚硬币（留着的、新抛的、被推的）一一分开它们；Kolmogorov 的样本点恰是运行内可复读、运行间随机。个别化：把情形（时间、提问者、语境）写进问题，任何行为都有记录模型，只在不公共或被扰动时才需要；线性时间就是把反复提问个别化的下标；个别化与"藏回去"是一件事的两面；墙在于把个别化当作唯一的描述方式。"谁问"与"同时问"同形；名字对调时视角的全体相同而行为不同——你是哪个视角不是事实。一切情形的一条定理：结构 = 视角的全体（由事实决定），位置 = 此刻是哪种情形（不是事实）。
- 第三十三轮（`50`）：把第四十二到四十九轮收成底座的当前写法——原语与断言层、公理（T₀、T₁ = T₀ + (C)、理想化的完成 I）、定义（来源、行为与四种性质、事实与结构与位置、个别化）、按主题排列的已形式化定理、回到经典、判定了什么、失败的度量、对照四个倾向、开放与前沿、与此前写法的关系。
- 第三十四轮（`51`）：提问者在系统之内时，别人的提问就是我的历史，"谁问"与"之前问了什么"合一。定理：在至少两个提问者的网络里，公共 + 不干扰 ⟹ 不被扰动 ⟹ 有记录模型；逆否：在一个公共的世界里，扰动必然表现为干扰（我的读取改变你得到的回答）。共享的翻转记忆与私有的翻转记忆说明两个前提都不可少。读法：客观（公共 + 不干扰）排除一切扰动；共享记录由会改变被读者的提问产生，提问之间必然互相干扰（物理的触发器循环、ML 的测试集污染，只作启发）。
- 第三十五轮（`52`）：总结。得到的是一个诊断（一切回答都是记录，经典靠个别化维持）和一个原则，精确到定义与定理，并选出一个确切的公理系统（T₀、T₁、理想化的完成）。对四个倾向与三种形式化各有精确的对应陈述（划出合法的范围）；对 ML 与物理只在陈述问题的层面。形式上够成为公理体系，内容上形式内核已知（遗传可数集合、ω₁ 对实数不可达）；缺测量层自己的公理、一个方法、判定的来源。另：记录经过不随情形而变的通道仍是记录，经过一读就变的共享转述则不再是（`Network` §4）。
- 第三十六轮（`53`）：方法——时间不变（可随时重做）的评价只看见一个行为终将成为的样子；对不可逆的行为，事实本身随时间改变，会回到原处的行为事实不变；持续学习的评价面对真的取舍（可重做只看终局，看此刻就要按时间个别化、不可重做）。公理——把"记录"的定义用到数学世界自身：(U) 关于已有记录的陈述在补充新记录（强迫）之后真假不变；它在单个世界里写不出，于是记录化成为第二个原语（T₂：记录、记录的世界与记录化）。测试：排除 V = L；对一切记录化推出 (C)（待核验）；随机版本在第一层与可测性相关（待核验）；CH 不受影响（它不是关于记录的陈述）；稳定而不一定决定。平行：数学的记录是记录世界的终局事实。三条已知结果已核实：(U) 推出 (C)；随机强迫下的 Σ¹₃ 绝对性 ⟺ Δ¹₂ 可测（"不被记录化扰动"与"能问"在第一层合一）；一致性约为无穷多个强基数。采用为 T₂ 的公理，T₁ 保留为较弱的写法。
- 第三十七轮（`55`）：按你的意见，用集合论的语言重写底座：两类变量（集合、世界），关系 ∈、ε、≼；公理 M1 每个世界满足 ZFC，M2–M3 扩张（泛型扩张）且总能扩张，M4 可数核的绝对性；不假定融合（去掉 GLU₀）。定理：可数是持久的、每个集合在某个扩张中可数，所以只有可数是大小方面的全局事实；幂集、ℝ、样本空间是局部的；非主超滤、Vitali 集、ℝ 的良序在加入新实数后失去定义性质——选择给出看似全局、其实局部的对象；定律与 Borel 测度是全局的，随机点只在扩张中存在；CH 是局部的。用法：在一个世界里做就是 ZFC；判别全局与局部；换世界是通用的证明方法；概率以定律为基本对象。无穷：保留外延与良基，放弃"完成的无穷总体是全局对象"；Kolmogorov：保留有限与可数可加，放弃全局样本空间。T₀ 从公理变成定理（全局部分恰是可数核）。

## 3. 早期各轮的主要结论（第四至二十三轮）

### 第二十三轮的主要结论（概率过程）

1. **不加观察，所有过程都是同一个对象。** 每个状态走出去的总概率为 1 时，所有状态都是"以概率 1 回到自身"这一个对象：过程的身份来自观察。
2. **停止概率是对象的性质。** 以"停止"作为观察时，k 步内停止的概率由局部算法算出，所以同一个对象的状态停止概率相同，合并不改变它——证明它们相同，只需证明它们是同一个对象。
3. **对象比规律更细。** 两个状态在每个 k 步内停止的概率都相同，却不是同一个对象：一个走一步就定了结局，另一个要走两步。经典概率的规律忘掉了不确定性何时被消除，对象记得。
4. **对称迫使均匀分布。** n 个结点的循环对称下：选不出一个结点；"随机的一个结点"是整体的对象，每个权重 1/n；任何整体的概率都只能是这个均匀的。

### 第二十二轮的主要结论（计算的定义）

1. **推广计算的另一种方式。** Gandy 的机器原则（状态是带原子的有限集合、转移在置换下不变、整体由局部唯一地拼起、局部因果）就是原点处的 GLU。主流的推广换机器；这里改的是局部数据怎样粘合（π）。保守性锁住了"哪些 ℕ → ℕ 的函数可算"；随 π 变化的是"哪些任务能由局部机制完成"。
2. **局部算法只看得见对象。** 确定性局部算法的运行与解交换，所以同一个对象的结点永远分不开；所有结点是同一个对象时，选不出领袖。
3. **值决定看得见什么。** 只观察成员状态的集合时，"一个成员计一次"与"同一个成员计两次"分不开；观察权重时，一轮计数就分开。
4. **对象恰好是局部计算能分辨的东西。** 在有限的系统上，两个结点是同一个对象，当且仅当没有任何确定性局部算法能分开它们；一个"记住一切"的算法就够了——视图细化到某一轮停止，停止时的视图就是 Larsen–Skou 互模拟。种类中的同一，有了计算的意义。
5. **概率打破对称。** n 个匿名结点各掷硬币，只有 2 种结果让它们仍然相同，n 种结果选出唯一的领袖——随机算法以正的概率每轮成功，确定性算法永远不能。
6. **如实说明**：这些在分布式计算中都有对应的已知结果；新的是它们成为同一个公理体系的推论，且图灵可计算性是原点。"这是丘奇—图灵论题的另一种推广"是假设与研究计划。

### 第二十一轮的主要结论（作为扩展能做什么）

1. **什么算有意义。** 保守的扩展不增加集合论定理；有意义的先例（反基础公理、内集合论、强制法、带原子的集合）的意义在三处：让原来只能编码的东西成为对象；带来一种证明方法；它自己的问题有干净的答案。本体系再加一条：回答开头那四个倾向。
2. **局部何时成为整体，完整的答案。** 对任意上下文结构：局部的存在总能粘成整体，当且仅当可以为每个上下文取定一条进入它的箭头、与一切箭头相容。预序上是"每个连通分支有最小元"；有对称时只有平凡的群——只要有对称，就有处处有成员、却没有整体成员的对象。
3. **随机的选取不需要选择。** 值、名字、对称三者一起的种类构造出来了（不用选择）。在交换两只袜子的对称下：选不出一只袜子；但"随机的一只袜子"是一个整体的对象，每只权重 1/2、总和为 1；而且 1/2 是被对称迫使的。"下一刻"可以是一个分布，而不必是一个点——对应开头的绝对因果与目标拟合。
4. **如实的检查。** 成为对象、自己的问题有答案、回答开头，这三条已有；"方法"还弱——还缺一个能用来证明经典定理的方法，这是最需要的下一步。

### 第十九轮的主要结论（统一与判据）

1. **版本统一。** mathlib-free 部分与 mathlib 部分用同一个 Lean 版本：前者（`lean/`）是一个没有依赖的 Lake 包，后者（`lean-mathlib/`，原 `lean/mathlib`）经路径依赖引用它。两部分都按下面的命令完整构建过。
2. **锐的实例就是形状的拓展。** 一个构造（`Values`）在锐的回答处，与 `Shapes` §8 的反基础宇宙之间有一个保持并反映隶属的双射。"一个构造，W 是参数"不再只靠终对象的唯一性来论证。
3. **预序上的选择判据。** 在一个预序的上下文上，"每个整体对象只要在每个上下文里都有成员，就有整体的成员"，当且仅当每个上下文下都有一个沿箭头不变的根，也就是每个连通分支都有最小的上下文。
   - 充分性：在根上选成员，再搬到各处；选择只用来在各根之间挑选。
   - 必要性：造一个对象，其成员是以更低的上下文命名的原子；整体成员的名字给出根，不用选择。
   - `25 §5` 的读法在预序上成为定理。
4. **同一的关系形式，对每个值结构。** 两个结点是同一个对象，当且仅当有一个 Larsen–Skou 互模拟（一个等价关系，相关的结点给每个类的聚合值相同）联系它们。用等价关系，就不需要对权重另加条件。
5. **值随上下文。** 给值一个序（聚合保持它），随上下文只增不减的值又是完备的值结构；于是一个构造同时给出（W，一切形状，预序上下文）的种类。在这种表示里，原点仍是收缩，存在仍是局部的。同一是整体的，与 Kripke 的表示不同；对称不能放进值里（`36`）。

### 第十八轮的主要结论（带权的种类）

1. **一个构造，W 是参数。** 对任何完备的值结构（聚合与编号无关、单元素上是自身、可以分块），带基点的系统按"有共同的像"认同，给出一个种类：每个小系统恰有一个解，每个对象都是某个解的值，同一就是有共同的像。GLU 只用 `Quot.sound`，不用选择。
2. **两个实例。** 锐的回答时，有共同的像当且仅当有互模拟，所以它就是反基础宇宙。权重（[0, ∞] 带求和）时，就是带权的种类。
3. **影子是函子。** 值结构之间保持聚合的映射，诱导种类之间的映射，把解送到解。
4. **W 方向，原点是收缩。** 支撑是影子，它忘掉重数：一个成员计一次与计两次，是两个带权对象，影子相同。锐的对象按值坍缩后，每个成员计一次，嵌入带权的种类，权重恰为 0 或 1；再取影子是恒等。坍缩是必需的，因为"存在"幂等而求和不是。
5. `33 §4` 的表完整了：沿 𝒞 与 W，原点是收缩；沿 S，没有影子。

### 第十七轮的主要结论（名字、权重、选择的判据）

1. **名字是回答的一部分。** 带名字的系统上 GLU 照样成立；纯的系统中，对称被同一（互模拟）吸收。Russell 的袜子在种类里：一双袜子是整体的，也有成员，却没有一只袜子是整体的。这是"存在是局部的"的对称形态，与细化形态（`29`）并列。同一个对称下，权重可以是对称的（`Socks`），选取不能。
2. **存在是权重的影子。** 值结构之间保持聚合的映射把解送到解；"权重是否为零"就是这样一个影子，带权的解投下锐的解，影子忘掉重数。第四轮的"存在是计数的幂等影子"由此推广到权重与粘合。
3. **Kolmogorov 被局部化，形式化了。** 上下文是有限的问题集合，按包含排成有向结构：整体的权重由局部的权重唯一决定；相互独立的局部权重粘成乘积测度。两者 mathlib 都已有，这里只是按 GLU 读出。经典测度论，就是带权种类在有向上下文上的第一层 GLU。
4. **选择的判据：四种情形。** 一个整体的对象在每个上下文里都有成员时：
   - 有根：不用选择就有整体的成员；
   - 互不相交：恰好需要选择；
   - 两个上下文有共同的细化，或者有对称：可以没有整体的成员（两个反例都不用选择）。
   公理剖面本身就是证据。`25 §5` 的读法有了形式依据；一般的刻画仍开放。
5. **带上下文结构的反基础宇宙已经有了。** `Kinds` 的种类本来就允许一切形状，`25 §7` 第 1 条因此完成。
6. **公理体系收成一处**（`33`）：描述层（问、GLU₀、大小）加上对每个 π 的 GLU(π)。一阶地写，用解的函数符号，以互模拟（一个记录）代替对一切解的量化。GLU₀ 的条款 4 只在原点断言。
7. **原点的两种身份。** 沿上下文，经典原点是每个种类的收缩：取常对象、再只看一个上下文，是恒等。沿值，支撑是影子。沿形状则没有影子：没有保持隶属的映射能把一切形状送进良基的结构。拓展沿 W 与 𝒞 是加细，沿 S 是加对象。

### 第十六轮的主要结论（上下文种类的构造）

1. **GLU 在任意上下文结构上成立。** 上下文结构是一个小范畴；种类是带基点的系统，按沿箭头保持的互模拟认同。每个系统恰有一个解，对上下文自然；同一就是互模拟。只有一个上下文时，就是第十二轮构造的反基础宇宙。
2. **经典原点在里面**：常对象是整体的，两个常对象相等当且仅当作为普通系统互模拟。
3. **墙的第一层，形式化**：两个上下文有共同的细化时，一个对象可以在每个上下文里都有成员，却没有整体的成员——存在是局部的。只有一个上下文时，局部就是整体。
4. **纯集合承载不了对称**：在对称群上，同一轨道的对象互模拟，种类的每个对象都被固定。所以数得出、分不开的个体需要标签（原子）；"回答是什么"包括值与标签。修正了 `28` 对标签的排除。
5. **两种"没有全局上下文"**，对应上下文范畴的两类箭头：细化（连纯集合也受影响：真值与存在变成局部的）；对称（只在有标签时起作用：原子没有被不变的描述命名，选择失效）。

### 第十五轮的主要结论（π 是否完整，整体形式化）

1. **π =（S，𝒞）不完整，少了值 W。** 权重不只是真值上的态，还是局部数据本身的值（"y 以多大权重属于 x"）；以它为材料的对象有自己的同一（带权互模拟）与粘合（Kolmogorov 扩张）。π =（W，S，𝒞）。
2. **三个参数不是拼图**：它们是一个局部数据的三个方面——回答是什么、指向什么、在哪里给出；也正是第一轮的三个旋钮（Sharp 按第二轮拆成分级与随上下文）。同一、选择、排中律都是推论；大小是不变的墙。幂等的值就是真值，归入上下文（`Scheme` 中已证）。
3. **墙的第一层是种类之间的映射**：整体截面 Γ，从上下文种类到单点种类。它不满射，就是"局部一致而没有联合"。
4. **整体形式化**：GLU(π) = 种类 π 的宇宙是小的 π-系统之中的终对象；上下文是小范畴（细化是态射，对称是自同构）；参数之间的映射诱导种类之间的映射，经典是原点。第一阶段（统一接口）已在 Lean 中完成。

### 第十四轮的主要结论（拓展在哪里发生）

1. **IZF 不是拓展。** 它只是少断言：去掉选择与排中律。作为基础，它本身不断言任何墙外的对象存在；在形状上它和 ZFC 一样窄（保留 ∈-归纳）。直觉主义逻辑只是"上下文可以细化"这一个方向上的后果。
2. **拓展是一条公理模式 GLU(π)。** 种类为 π 的对象，恰好是小的 π-系统的唯一解。经典记录是原点实例（GLU₀）；其余每个实例都是正面的断言：循环的对象（AFA）、只在支撑中给出的个体、随上下文变化的真值、没有点的分布。
3. **形状参数上已形式化。** 良基的实例就是基础与外延；§8 构造的宇宙就是"一切图"的实例；两个实例不能共用一个隶属关系，所以拓展是**加种类**，旧的种类原样保留。
4. **仍然保守。** 每个种类都能由记录构造，每个种类都含有经典的像。经典集合论同时是描述一切局部数据的语言；墙，是描述只能粘成 π₀ 这一种对象。

### 第十三轮的主要结论（澄清）

1. **IZF 对 ZFC 不是保守扩张，而是更弱。** ZFC 证明 IZF 的一切；IZF 不证明排中律。能说的是：
   - IZF + 选择 = ZFC；
   - 二者等协调（Friedman 的双重否定翻译）；
   - 对 Π⁰₂ 算术语句，经典推理不带来新东西（待核验）。
2. **IZF = GLU₀ 去掉条款 4（非唯一的粘合），且不预设锐性。** 它只断言被局部数据唯一决定的粘合。排中律本身也是粘合断言（每个问题都在全局上下文里被定下），由条款 4 迫使。
3. **保守性在外层，IZF 在内层。** 公理体系本身对 ZFC 保守；在其中构造出的各个情况，内部都满足 IZF，差别在于选择与排中律保留多少。
4. **形式化本身就在确定的粘合之内。** 152 条定理里，只有 2 条用到选择；排中律恰在上下文不能再细化处成立，而它的双重否定处处成立（`Contexts`）。

### 第十二轮的主要结论（构造出来的拓展）

1. **形状的拓展被完整构造出来。** 带基点的图按互模拟认同：
   - 在其中，互模拟即相等，每个系统恰有一个解（AFA），小族可以粘合，Ω = {Ω} 存在；
   - 良基树嵌入其中，相等与隶属都被保持和反映。
   整个构造不用选择，因为它只推广了确定的粘合。
2. **对称：支撑就是上下文。** 从原子对中选取的函数，支撑必须命名除至多一个之外的所有原子，没有有限的上下文做得到。"数得出、分不开"与"没有全局上下文"是同一件事。
3. **参数收成两个：形状与上下文结构。**
   - 值作为真值，就是上下文：真值是"在哪些上下文中成立"；
   - 对称也是上下文结构；
   - 权重是真值上的态，不是宇宙的参数。
4. **家族的写法：IZF（确定的粘合）+ 形状 + 上下文结构。**
   - 上下文结构决定选择与锐性回来多少：单点、布尔代数都回来；有对称时只回来一部分；非布尔时都不回来。
   - 经典原点给出 IZF + 选择 = ZFC。

### 第十一轮的主要结论（公理体系）

1. **核心里只有一条关于粘合的公理。** GLU₀：记录恰好是小的、良基的局部数据的唯一粘合；小的族也有非唯一的粘合。
   另外两组公理分别说局部数据总能形成（问）、以及"小"有多大（大小，Russell 给的界）。三组合起来是 PZFC₀ 的重排，对 ZFC 保守。
2. **经典公理都是 GLU₀ 的条款。** 外延是唯一；配对、分离、替换是确定的存在；基础是形状（隶属良基 ⟺ 每个元素都是良基系统的解）；选择是非唯一的存在；排中律被唯一与非唯一的存在迫使。
   条款 1–3 合起来不用任何选择，Mostowski 坍缩由外延与替换推出；**经典里真正额外的承诺只有一个条款。**
3. **拓展是换 GLU₀ 的形容词。** 参数只有四个：形状、对称、值、上下文，并且彼此咬合。
   一个构造 U(π)——π-系统的解按 π-互模拟认同——在单参数处给出反基础宇宙、置换模型、布尔值宇宙、Heyting 值宇宙，每一个都含有经典原点的像。
4. **局部层就是概率的语言。** 记录的元素是被实现了的锐态；子集是事件，只在被实现处才是点集；标准测度论是权重的 GLU 在原点的形态。

### 第十轮的主要结论（形状）

1. **唯一性是一条原理。** 在一切图上，解唯一恰好等价于强外延（互模拟则相等）。在良基的结构上，外延就是强外延。
   所以外延公理是"按关系认同"在良基处的限制；离开良基，外延就不够了（两个自属元素满足外延，环 $x=\{x\}$ 却有两个解）。
2. **存在：良基处免费。** 良基的图由递归得到解，不用任何选择；解是单射当且仅当图是外延的（Mostowski）。
   一切图都恰有一个解，是 AFA 的内容；它以经典为原点，对良基集合保守（待核验）。**递归是解方程在良基处的特例。**
3. **参数的咬合。** 唯一处存在免费，选择公理的内容恰好是非唯一处的存在；在那里断言多少存在，按对称分级；
   非唯一处的存在加上外延，迫使二值（Diaconescu：形式化中只依赖 `propext`、`Quot.sound`，不依赖 `Classical.choice`）。
   **二值不是独立的假设。**

### 第八轮的主要结论（回到墙）

1. **墙是一条可描述性的边界。** 经典语言里，任务只有一种可描述的形式：沿全序时间，从过去到下一个的一个函数，作用在点上，用一个标量打分。不是这种形式的目标，就"无法描述"。
2. **墙的位置很小。** 四个成分对应从事件到点的五座桥：联合结果（Stone ⟺ BPI；Kolmogorov 的 Ω）、函数化（AC ⟺ 一致化）、
   线性排列（AC ⟺ 良序；基础公理）、标量可比（AC ⟺ Hartogs 三歧性；Hölder）、还原同一（外延 + 基础）。
   **"AC 是对测量存在的坚信"的精确形态：相信每族相容的测量问题都有联合结果，每种可能性都有确定的选取者。**
3. **拓展**：事件层（带权事件代数及其态射）在下，点层在上，桥可选。经典是桥全部打开处；事件层在 ZF 中可定义，所以保守。
   "子集只在某种意义上成立"——子集就是事件，只在桥 P 提供点的地方才是点集。
4. **拆掉桥后可描述的**：随机而无结果（Russell 的袜子：分布存在、联合结果不必存在）、依赖而无函数、时间而无全局时序、同一而无还原、比较而无标量（要求单标量就是要求桥 C）。
5. **CH、不可测集、Banach–Tarski 都在点层**；在事件层，连续统的测度代数是规范的（Carathéodory），CH 看不见。

### 第七轮的主要结论（架构）

1. **情况是内部宇宙，不是另加的公理。** 布尔值、Heyting 值（层）、可实现性、对称、反基础——这些宇宙都能在保守核心内定义，由参数定位。
   核心证明的是"某宇宙满足某某"，所以核心保持保守，而各种情况都能被谈论、被比较。
2. **经典是原点。** 平凡参数给出经典宇宙本身；每个情况都通过规范嵌入包含它的像。唯一真正离开保守性的方向，是参数的存在强度（大基数）。
3. **八种读法、六种参数**：粘合、分辨率、对称、分级回答、同一性、自反、选择、存在强度，各自到达一种"经典不适用"的结构性情形；它们由六种参数实现（场景、布尔代数、群与滤子、部分组合代数、方程系统、不可达基数）。构造可以复合，经典是单位元，所以参数空间是一个构造的范畴，而不是直积（`19`）。
4. **存活**：离开原点时，各构造用各自的尺子（投影层谱、联结词、否定性、秩的有界性、公理的使用、Lévy 层谱）保留经典真理，不存在单一的存活指数；共同的模式是**存活的是能被局部见证的**。
   **每种构造的第一个断点，恰好是它那条轴要放松的经典承诺**（全体实数已知、全局真值、无界判定、全局选择、还原到底、整个宇宙）——这是用独立的数据对架构做的一致性检验（`20`）。

### 第六轮的主要结论（体系）

1. **PZF₀ 对 ZF 保守，PZFC₀ = PZF₀ + AC 对 ZFC 保守**：原语是问题与回答，集合是"被完成的问题"（记录），原子是不被回答区分却彼此不同的个体。
   证明走模型扩张：带原子的扩张不改纯部分，可定义类的扩张不产生新记录，权重与值代数是可定义的。
2. **保守性的边界恰是 P4**：问题只谈论记录（谓词性，NBG 型）时保守；问题可以谈论问题（非谓词性，Morse–Kelley）时证明 Con(ZF)，不再保守。
3. **回收**：纯记录片段就是 ZF(C)；标准测度论在选择坐标 ≥ 可数选择处回收；
   集合论的概率读法——实数是随机变量、真值是概率——在保守核心之内可定义（Scott）。
4. **族**：选择、正则 Reg(W, Γ)、非谓词性、基础、对称、完成层级、逻辑，每个坐标是有序族；完美集性质与可测性是同一"缺陷为零"在 W 轴两端的形态。
5. **CH 的分解**：CH_C（基数权重饱和）有两条来路——正则或选择给出的标量；ZFC 的选择堵死前者，又不决定后者的值。

### 第四、五轮的主要结论

1. **每个开关背后都有一个层谱。** 缝 → acl/dcl 与 Borel 可归约性；选择 → 选择原理的格；可测 → 内外测度区间；
   P3 的两种读法 → 排中律与正则性在同一复杂度刻度上的两条截断线；两层 → 核的格。
2. **四条原理并不独立**：有限特征（紧致性）经 Lindström 定理选定了可辨性所用的语言。
3. **加细迫使值代数**：无差别 + 自洽在任何值代数中都成立，但结论取决于"和"——
   幂等 ⟹ 只有二值；ℕ ⟹ 无解（分数被迫出现）；截断且不可除 ⟹ 只有饱和解；可除的实数 ⟹ 唯一的 Lebesgue 权重。
   **二值不是原始的，是幂等或不可除值域的推论。**
4. **存在是计数的幂等影子**：集合论的"存在一个"是"有多少个"在 $n\mapsto[n>0]$ 下的像；两端由连续族相连。
5. **集合论位于事件代数 E 与权重合成 W 都幂等的角落**；Kolmogorov 是（布尔，+）。E 与 W 不是独立的两条轴（第五轮更正）：同一个由有限问题生成的权重，在正则事件上可加、在不正则事件上次可加——**正则就是可加性存活**，缺陷即 Carathéodory 缺陷。
6. **基数在 W 轴的幂等端，Lebesgue 在可消端**；基数运算有多幂等由选择公理逐级刻画：AC ⟺ 吸收平方 ⟹ 吸收加倍 ⟹ 吸收一点 ⟺ 无穷集都 Dedekind 无穷。
7. **标准测度论的值域是推出来的**：对称逼出 ℚ≥0，极限逼出 ℝ≥0；集合论的存在量词只要求"有没有"，停在幂等端。
