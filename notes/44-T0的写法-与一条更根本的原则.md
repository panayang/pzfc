## 1. T₀ 的写法

### 1.1 只有一类原语：记录

- T₀ 的对象都是**记录**：遗传可数的集合，满足 ZFC 去掉幂集、再加"每个集合都可数"（`43 §5`）。
- **来源不是另一类原语**：一个来源由它的**描述**给出，描述是记录；来源的**回答**不是 T₀ 的对象。
- 这正是测量优先的本体：**规律是对象，随机的回答不是。** 一个回答只有被记下，才成为对象。

### 1.2 一个来源由什么给出

以 0-1 回答的来源为例；一般的来源可以编码成它，已知可数生成的来源都可以这样编码（待核验）。

- **读取**：前 n 个回答的一种可能，也就是长度为 n 的 0-1 串。**不需要无穷序列作为原语。**
- **规律**：对每个 n，给每个长度为 n 的读取一个权重，总和为 1。
- **细化相容**：一个读取的权重，等于它的两个细化（后面接 0 或接 1）的权重之和。

有了这三样，就有了下面这些定义：

| 名称 | 定义 |
|---|---|
| 读取问题（层 n） | 长度为 n 的读取的一个集合 |
| 它的概率 | 其中读取的权重之和 |
| 距离 | 两个读取问题回答不同的概率（在共同的更细层上计算） |
| 可以问的问题 | 读取问题在这个距离下的极限，由一串读取问题表示 |
| 来源的记录 | 一个完整的回答序列，对每个足够必然的读取问题都回答"是" |
| 联合来源 | 读取成对的来源，两边的规律是它的两个边缘 |

### 1.3 T₀ 的公理

1. **记录**：ZFC 去掉幂集，再加"每个集合都可数"。
2. **来源**：一个来源是满足"总和为 1"与"细化相容"的一族权重（一份记录）。
3. **规律只关于读取**：来源的一切概率陈述，都是关于读取问题及其极限的陈述。
4. **记录化不是 T₀ 内的运算**：给来源补一份记录，是扩大记录的世界（`43 §9` 第 4 条）。

第 3 条是"可以问的问题"的落实：
- 一个问题有概率，当且仅当它是读取问题的极限；
- 放到点的集合上时，这恰好是可测的问题（`Askable.askable_iff`）。

### 1.4 已证明的（`Sources.lean`）

| 定理 | 内容 |
|---|---|
| `coin` | 公平的硬币是一个来源：长度为 n 的读取，权重各为 2⁻ⁿ |
| `lift_law` | **一个读取问题的概率与读的层次无关**：在第 n 层读，和在第 n + 1 层重新读，概率相同 |
| `isRecord_iff` | **记录恰是原子**：一个回答序列是来源的记录，当且仅当它的前缀的权重始终不低于某个正数 |
| `level_has_atom` | 每一层都有权重为正的读取：有限的部分总有记录 |
| `coin_no_record` | 公平的硬币没有记录：没有一个回答序列，能回答它所有必然的读取问题 |

读法：
- `lift_law` 是"统计能复读"的精确形态：同一个问题，粗读细读，规律不变。它也使"可以问的问题"（跨层次的极限）有意义。
- `isRecord_iff` 把"来源的记录"钉成一个可检验的条件，不需要点的集合：
  - 有原子，就有记录；
  - 没有原子，就没有记录。
- 与此相关的一个标准事实：**一个来源恰好是它的记录的混合，当且仅当它的权重全部落在原子上。** 连续的随机性不是它的记录的混合；Kolmogorov 把它放在点的集合上时，用的是别的来源的记录（`43 §3`）。这一条是标准的事实（由原子的定义与可数可加性得到），没有形式化。

**如实说明**：作为理论，T₀ 就是遗传可数集合的理论（约与 Z₂ 相当），它的定理都是这个理论的定理。新的不是定理，而是**分类**：
- 哪些是对象（记录、规律）；
- 哪些不是（随机的回答）；
- "来源的记录"作为一个定义，可能不存在。

## 2. (A)、(P) 从哪里来：一条原则

### 2.1 看它们在第一个非平凡的层次上说什么

最简单的"能从记录构成"的方式，是**分阶段构造**：从一份记录 a 出发，一步步定义出新的记录，阶段可以走到任何可数的长度。这样得到的记录的全体，已知叫 L[a]（相对于 a 的可构成宇宙）。

在这一层上（对应已知的 Σ¹₂ 集合），已知的结果是（Solovay、Mansfield，待核验）：
- **(P) 在这一层成立，当且仅当：对每一份记录 a，从 a 分阶段构造出的实数只有可数多个。**
- **(A) 在这一层成立，当且仅当：对每一份记录 a，硬币来源几乎每一个读数，都躲开一切能从 a 分阶段构造出的零概率检验**——也就是说，a 预测不了这个来源。

### 2.2 原则 (C)：分阶段会用完

> **(C) 从任何一份记录出发，分阶段的构造只做出可数多份记录。**

读法：
- 分阶段的构造，就是基础里的线性时间（`42 §4`）。
- (C) 说：从任何一份记录出发，**线性时间只够到达连续统的一个可数的部分**；连续统作为来源，永远不被线性时间用完。
- 反面是可构成宇宙 L 的公理"V = L"：一切都是从无出发、分阶段构造出来的——线性时间用完了一切。这时 L 里有一个 Σ¹₂ 的实数良序，(A)、(P) 都失败（`43 §6`）。

### 2.3 由 (C) 推出 (A)、(P)

1. **(C) ⟺ (P)**（这一层）：见 §2.1。
2. **(C) 加上规律的可数可加 ⟹ 记录预测不了来源**：
   - 从 a 分阶段构造出的零概率检验只有可数多个，因为它们都由可数多份记录给出；
   - 可数多个零概率的问题，并起来仍是零概率——这是规律自身的可数可加性。
   - 所以几乎每个读数都躲开它们（`Askable.listable_tests_escaped`）。
3. **记录预测不了来源 ⟹ (A)**（这一层）：见 §2.1。

反面也看得清楚（`Askable.all_records_formable`）：
- 如果一切记录都能构造出来，那么每一份记录 x 自己就是一个零概率的检验（"是 x"）；
- 每个读数都被它自己的检验抓住，没有一个读数躲得开。
- 这是"V = L"的测量读法：**线性时间用完一切时，没有随机性**——每个回答都是某个构造的记录。

所以，在这一层上，**一条原则 (C) 同时给出 (A) 与 (P)**：
- (P) 是 (C) 本身；
- (A) 是 (C) 与规律的可数可加性合在一起的结果。

### 2.4 它的强度与位置（已知，待核验）

- (C) 等价于：对每一份记录 a，ω₁ 在 L[a] 中不可达。它的一致性强度恰为一个不可达基数：
  - 由不可达基数的 Lévy 塌缩得到它的模型；
  - 反过来，它推出 ω₁ 在 L 中不可达。
- (C) 由"每个实数都有一个 sharp"推出，因此由一个可测基数推出。所以它与 ZFC 加大基数相容，不否定选择公理。
- (C) 在 L 中不成立，所以 **ZFC 证明不了 (C)**。

### 2.5 更高的层次（猜想）

- 更复杂的"能构成"，对应更强的分阶段构造：已知的做法是用带大基数的规范内模型代替 L[a]。
- 猜想的形式：
  - **(Cₙ)**：第 n 种构造从任何一份记录出发，只做出可数多份记录。
  - (Cₙ) 推出第 n + 1 层的 (A)、(P)。
- 全部 (Cₙ) 都应由投影决定性推出（待核验）。这一条只是按 §2.3 的模式外推，**没有证明**。

## 3. T₁ 的新写法

> **T₁ = T₀ + (C)**，以及更高层次的 (Cₙ)（猜想）。

- 一条原则代替两条：**分阶段会用完**——从任何记录出发，线性时间只到达连续统的可数部分。
- 在第一个非平凡的层次上，它判定了以下 ZFC 判定不了的问题（已知的集合论，待核验）：
  - 每个 Σ¹₂ 的实数集合都可测、都有 Baire 性质；
  - 每个不可数的 Σ¹₂ 集合都含完美子集——Cantor 形式的 CH 对这一层成立；
  - 实数没有 Σ¹₂ 的良序；
  - "V = L"不成立。
- 它与 ZFC + 一个可测基数相容：ZFC 仍是 T₀ 的理想化完成，选择公理留在理想化的那一侧。

**与开头四个倾向的关系**：
- **线性时间**：(C) 直接说它到不了连续统。
- **绝对因果**：在这一层，没有能构造的方式从"只差有限多位"的每一类中取出代表。
- **目标拟合**：在这一层，没有能构造的、大小居中的集合，配对这把尺子在这里只有两格；更细的尺子（信息、维数，`42 §8`）要到来源上去找。
- **还原论**：T₀ 的对象是记录，来源的回答不是对象，整体（联合来源）不由部分决定（`42 §10`）。

## 4. 形式化

| 文件 | 定理 | 公理 |
|---|---|---|
| `Sources.lean` | `coin`、`lift_law`、`isRecord_iff`、`level_has_atom`、`coin_no_record` | mathlib 的经典公理 |
| `Askable.lean` §4 | `listable_tests_escaped`：可数多个零概率检验，被几乎每个读数躲开，因而有读数躲开全部；`all_records_formable`：每个记录都是自己的零概率检验，每个读数都被某个检验抓住 | 同上 |

**如实说明**：
- 这些定理都简单。§2 的主要内容（(C) 与 (A)、(P) 的等价与蕴含）来自已知的集合论，没有形式化，列入待核验。
- 在 Lean 中形式化可构成宇宙超出了现在的范围。

## 5. 已知的与这里的

**已知的，只作指导**（待核验）：
- Solovay 对 Σ¹₂ 可测性的刻画（几乎每个实数在 L[a] 上随机）；
- Solovay、Mansfield 关于 Σ¹₂ 完美集性质的结果（对每个 a，ω₁^{L[a]} 可数）；
- 它们的一致性强度（不可达基数）；
- sharp 与可测基数；
- 投影决定性与更高层次的正则性。

**这里的**：
1. **T₀ 的分类**：
   - 一类原语（记录）；
   - 规律是对象，随机的回答不是；
   - 来源不以点为前提，由读取与细化相容给出；
   - "来源的记录"是一个定义，并且恰是原子（§1）。
2. **一条原则 (C)**：分阶段会用完。它是"线性时间到不了连续统"。
   - 在第一个非平凡的层次上，它同时给出 (A) 与 (P)：(P) 就是它；(A) 是它加上规律的可数可加性。
   - "V = L"是它的反面：线性时间用完一切，没有随机性（§2）。
3. **T₁ 的新写法**：T₀ + (C)。它判定一批 ZFC 判定不了的问题，与 ZFC + 大基数相容，并且与开头四个倾向一一对照（§3）。

## 6. 开放的问题

1. **更高的层次**：把 (Cₙ) 写准，并确认它们由什么推出（§2.5）。
2. **(C) 本身能否再往下推？** 它说"从一份记录出发的构造是可数的"。T₀ 已经有"每份记录可数"，(C) 把可数性从单份记录推广到"从一份记录出发能做出的一切"。两者之间是否有一条统一的"有限读取"原则？
3. **来源一侧的对应**：(C) 是关于记录的。来源一侧是否有对应的原则，比如"每个来源都不能被可数多个检验穷尽"？
4. 失败的度量、记录化与世界的扩张、自指：同 `43 §9`。
