# 50 · 底座的当前写法（第四十二到四十九轮收拢）

> **第三十七轮注**：公理体系已改用集合论的语言重写，见 `55`（世界、扩张、绝对、局部）。本篇的内容与之一致，但用语已被取代；对照表见 `55 §6`。

> **本篇是当前的主文件**，取代 `33`、`37` 作为公理体系的写法。它的评估（够不够、还缺什么）见 `52`；它是关于什么的（直白的说明与例子）见 `54`。`33`、`37` 的 GLU(π) 仍可作为加在任何底座上的保守的语言层（`41 §5`），但它不再是底座本身。
>
> 只用集合论的直白语言；每个定义都指向它的出处与形式化。

---

## 0. 一句话

> **经典基础假定一切回答都是记录——在再问、谁问、之前问了什么、同时问了什么这四种情形下都不变。这个底座不作这个假定。它只以记录为原语，把"一个对象的哪些回答是记录"当作可以陈述、可以度量的事情；经典是把一切情形都个别化进问题之后的理想化完成。**

## 1. 原语与断言层

- **唯一的原语：记录。** 记录就是遗传可数的集合。
- **断言层用经典逻辑。** 理由不是保守，而是同一个原则：数学的断言就是证明，而证明是公共的、可复读、不被扰动的记录（`46 §7`）。
- **不是记录的东西**——一个来源的单次回答、一个行为此刻的位置——不是对象。它们被记下之后，才成为对象（`44 §1.1`、`49 §5`）。

## 2. 公理

**T₀（弱底座）**
- **R（记录）**：ZFC 去掉幂集公理，再加"每个集合都可数"。
  - 读法：一份记录由可数多次有限的回答写成（`43 §5`）。
  - 这个理论与二阶算术 Z₂ 相当（待核验）。

除 R 之外，T₀ 的其余部分都是**定义**（§3），不是新的公理。

**T₁（强底座）= T₀ + (C)**
- **(C) 分阶段会用完**：对每一份记录 a，从 a 出发分阶段构造出的实数（L[a] 中的实数）只有可数多个，也就是它们构成一份记录。
  - 读法：从任何记录出发，线性时间只到得了连续统的一个可数部分；连续统作为来源，永远用不完（`44 §2`）。
- 更高层次的 (Cₙ) **不采用**：它们通向已知的内模型阶梯（投影决定性），只作对照（`45 §0.2`）。

**T₂（`53`）：记录化成为原语**
- 两类东西：记录；记录的世界，以及"由记录化而来"的关系。
- 公理：每个世界满足 T₀（W1）；总能记下任何来源的一份新读数（W2）；记录不消失（W3）；**(U) 记录不被之后的记录化扰动**——关于已有记录的陈述，在补充新记录之后真假不变。
- (U)（对一切记录化）推出 (C)，于是 T₂ 包含 T₁（已核实：Σ¹₃ 绝对性 ⟺ 每个集合都有 sharp）。
- (U) 的随机版本在第一层上与"能构成的就能问"等价（已核实：随机强迫下的 Σ¹₃ 绝对性 ⟺ 一切 Δ¹₂ 集合可测）。测量层的两条原则在这里合成了一条。
- 一致性强度约为无穷多个强基数。T₂ 已通过测试（`53 §3.1`）；T₁ 保留为较弱的写法。

**理想化的完成 I（回到 ZFC）**
- **个别化一切情形**：把时间、提问者、语境都写进问题（`49 §2`）。
- **一切来源都被完整记下**：不可数的总体也算记录；再加选择公理。
- 结果就是 ZFC：任何 ZFC 宇宙的遗传可数部分，都是 T₀ 的记录世界（`43 §5`）。
- 在 ZFC 加上一个可测基数中，(C) 成立。所以 **T₁ 与 ZFC + 大基数相容**，选择公理留在理想化的那一侧（`44 §2.4`）。

## 3. 定义（都在 T₀ 之内）

### 3.1 来源（`44`、`45`）

- **读取**：前 n 个回答的一种可能（有限串）。
- **来源**：对每个 n，给每个读取一个权重，总和为 1；一个读取的权重等于它各个细化的权重之和。**不以点为前提。**
- **可以问的问题**：读取问题在"回答不同的概率"这个距离下的极限。放到点的集合上时，恰是可测的问题（`Askable.askable_iff`）。
- **来源的记录**：对每个足够必然的读取问题都回答"是"的完整回答序列。它恰是**原子**（`Sources.isRecord_iff`），也恰是**两遍独立重读以正概率一致**的那部分（`Sources.record_iff_repeat`）。
- **来源的事实**：它必然的问题。

### 3.2 行为与提问的情形（`47`、`49`）

- **行为**：给定此前谁问了什么、现在谁来问、问什么，给出回答（或回答的规律）。
- **四种性质**：

  | 性质 | 回答不随什么变 |
  |---|---|
  | 可复读 | 再问 |
  | 公共 | 谁问 |
  | 不被扰动 | 之前问了什么；有随机性时指平均掉已知回答之后的规律（`49 §1`） |
  | 不依赖语境 | 同时问了什么 |

- **记录** = 四种都成立的回答。

### 3.3 事实、结构与位置（`48`、`49`）

- **视角**：对象在某一种情形下的所见——余下行为（历史）、某个提问者看到的行为（谁问）、某个语境中的回答（同时问）。
- **事实**：对一切视角都成立的性质。
- **结构**：视角的全体。**位置**：此刻是哪一种情形。
- **任务**：一组要维持的事实。**预测**：把每个回答都定死的任务（`47 §5`）。

### 3.4 个别化（`49 §2`）

- 把情形写进问题：(情形, 问题) 成为一个新的问题。
- 它与"把情形存进隐藏状态"（`47 §2`）是一件事的两面。

## 4. 定理（已形式化的，按主题）

**记录是什么**
- 记录恰是复读与复制分不开的来源；复读缺陷为 0 恰在记录上（`Records`）。
- 一族回答来自同一个整体对象 ⟺ 每个回答是跨语境的记录；整体对象唯一（`Records` §6）。**这就是 GLU**，它是"回答是记录"在语境这一面的形态。
- 来源的记录 = 原子 = 重读能以正概率复现全部回答（`Sources`）。
- 没有原子的来源没有记录；有限的部分总有记录（`Askable`、`Sources`）。
- 可以问 ⟺ 可测；对记录，一切问题都可以问（`Askable`）。

**提问的情形**
- 有记录模型 ⟺ 公共且不被扰动（`Circumstances` §1）。
- 每个行为都有隐藏状态模型；不被扰动 ⟺ 有状态不动的模型（§2）。
- 藏回扰动的最少隐藏状态数 = 余下行为的个数（§3）。
- 四种失败两两独立（§4；`Individuation` §1 的三枚硬币）。

**事实与结构**
- 事实全同 ⟺ 视角的全体相同（`Individuation.sameViewFacts_iff`；历史这一面是 `Circumstances.sameFacts_iff`）。
- 不被扰动 ⟹ 事实定死一切；会回到原处 ⟹ 位置不是事实；扰动不可撤销 ⟹ 起点是事实；一般判据（`Circumstances` §6）。
- 名字对调：视角的全体相同，行为不同（`Individuation` §3）。

**关系与任务**
- 关系可以是记录，而两端不是：同步的耦合没有记录，"相同"却必然；独立的耦合部分相同，"相同"的概率为 0（`Askable` §5）。
- 关系的任务不是预测（`Circumstances` §5）。
- 读取即更新的记忆：它的定义性质是几条关系的不变事实，快照不是事实（`Circumstances` §7）。
- 可以随时重做的评价只看见终局；对不可逆的行为，事实本身随时间改变；会回到原处的行为，事实不变（`Circumstances` §8，`53 §1`）。

**个别化**
- 个别化之后，任何行为都有记录模型；不个别化也有，当且仅当它公共且不被扰动（`Individuation` §2）。

**网络**（`51`）
- 在至少两个提问者的网络里：公共 + 不干扰 ⟹ 不被扰动 ⟹ 有记录模型；公共而被扰动 ⟹ 干扰（`Network`）。
- 记录经过不随情形而变的通道仍是记录；经过一读就变的共享转述，不再是接收者的记录（`Network` §4）。

**未形式化（来自已知的集合论，待核验）**
- (C) ⟹ 一切 Σ¹₂ 集合可测、有 Baire 性质与完美集性质；实数没有 Σ¹₂ 的良序；V ≠ L（`44 §2`）。

## 5. 怎样回到经典

| 经典 | 在底座里是什么 |
|---|---|
| Kolmogorov | 一族能被一起记下的来源，按时间个别化；样本空间 Ω 是它们的记录的全体（`43 §1`、`49 §2`） |
| 标准测度论 | 标准空间上来源的可以问的问题——恰是可测的问题（`43 §4`），在 T₀ 中照常可做（待核验：Z₂ 的范围） |
| ZFC | 理想化的完成 I：个别化一切情形，一切总体都算记录，再加选择公理（§2） |
| 图灵 | 以步数个别化的、做记录的过程（`49 §5`；未展开） |

## 6. 判定了什么

- **T₀**：没有新的判定。它是遗传可数集合理论的重新分类。CH 在 T₀ 中不能表述：它问的是理想化的总记录（`43 §5`）。
- **T₁**：判定一批 ZFC 判定不了的问题——Σ¹₂ 集合的正则性、实数没有 Σ¹₂ 良序、V ≠ L、Cantor 形式的 CH 对 Σ¹₂ 集合成立。
  - 它的一致性强度恰为一个不可达基数；
  - 它与 ZFC + 可测基数相容（`44 §2.4`）。
- **解释**：ZFC 判定不了的命题，是随位置而变的回答——换一个宇宙（谁问），或者做一次强迫（之前问了什么）。判定得了的，是不随它们而变的（`46 §7`、`49 §5`）。

## 7. 失败的度量（`00 §7` 的当前形态）

> 经典总能把失败藏回去（隐藏状态、个别化），所以失败只能相对于一类模型来测：**失败的程度 = 经典的描述必须虚构的量**（`47 §3`）。

| 情形 | 度量 | 经典（没有失败）时 |
|---|---|---|
| 再问（随机） | 复读缺陷；来源中原子之外的部分（`42 §10`、`45 §2.3`） | 0 |
| 之前问了什么 | 最少隐藏状态数 = 余下行为的个数（`47 §3`） | 1 |
| 谁问 | 视角的个数（`49 §3`） | 1 |
| 同时问了什么 | 同一个问题在各语境中的回答的个数（`43 §1`）；规律的情形用"相容的全局规律最多占多大权重"（已知，`45 §2.3`） | 1 |

## 8. 对照开头的四个倾向

| 倾向 | 在底座里 |
|---|---|
| **线性时间** | 把反复提问个别化的下标（`49 §2`）。它在扰动不可撤销时合法——这时位置由事实决定；在会回到原处的结构里，时间不是事实（`48 §2`）。它到不了连续统（`44`，(C)） |
| **绝对因果** | 预测 = 结构 + 位置（`48`）；关系的任务不是预测（`47`）；"是读取引起了改变"只在规律被改变时才是事实（`49 §1`） |
| **还原论** | 整体不由部分决定（耦合，`42 §10`）；关系可以是记录，而两端不是（`45 §3`）；事实看见结构（`48`） |
| **目标拟合** | 可信 = 公共的、可复读的记录，标量只是其中一种（`46 §6`）；评价 = 哪些事实被维持，按包含关系比较（`47 §5`） |

## 9. 开放与前沿

1. **提问者在系统之内**：已开始（`51`）——网络中公共使扰动成为干扰；记录转交的链、干扰的度量待做；自指（`11` 的 P4）未做。
2. 随机情形在更长历史上的形式化（mathlib）。
3. 有限分辨率是否应当是基本的（`46 §5` 第 7 条）。
4. 更高层次的 (Cₙ)：不采用，只作对照。
5. 文献核查（`99-待核验`），放在最后。

## 10. 与此前写法的关系

- **`24`–`40`（GLU(π)、种类）**：保守的语言层，可以加在任何底座上。它改的是"记录什么"，没有改"回答是不是记录"（`43 §2`），所以不是底座。
- **`41` 的选项 B**：没有动根，已放弃（`42 §0`）。
- **`42`–`49`**：本篇的来源。
