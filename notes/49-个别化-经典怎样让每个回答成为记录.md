## 0. 路线检查（清单第 17、18 条）

- **推动本轮的原则**：记录 = 在各种提问情形下都不变的回答。
- **处理的情形**：
  - 再问（随机），并把它与"之前问了什么"分开；
  - 谁问。
- **会拉着走的已知体系**：
  - 计算力学：随机过程的最小隐藏表示；
  - 量子基础中的序列测量与"时间上的无信号"；
  - 关系量子力学。

  只作对照。
- 本轮得到的主要观察不是某条定理，而是一个机制：**个别化**（§2）。它把 `46`–`48` 连成一件事。

## 1. 随机的情形：四样东西要分开

有随机性时，"被问两次得到不同回答"可以有几种不同的来源。用三枚硬币、各读两次来分（`Individuation.lean` §1，权重以 8 为分母）：

| 硬币 | 做法 | 随机 | 可复读 | 规律不被扰动 |
|---|---|---|---|---|
| **留着的** `kept` | 只抛一次，读就是看它 | 是 | **是** | 是 |
| **新抛的** `fresh` | 每读一次就重新抛 | 是 | **否** | 是 |
| **被推的** `pushed` | 读一次，就把它推向"正" | 是 | 否 | **否** |

- "规律不被扰动"的定义：**把第一次的回答平均掉之后**，第二次读的规律，与第一次不读（只等待）时相同。
- 必须平均掉第一次的回答，是因为有第四样东西：**信息**。
  - 留着的硬币，读到"正"之后，第二次一定是"正"。这不是硬币被改了，而是我们知道了。
  - 平均掉之后，规律没变——所以它不被扰动。

于是四样东西分开了：

1. **一次次运行之间的随机**：三枚都有。
2. **同一次运行之内的可复读**：只有留着的硬币有。**这正是 Kolmogorov 的样本点**：每次运行里是一份记录，各次运行之间随机。
3. **规律的扰动**：只有被推的硬币有。
4. **信息**：以已知的回答为条件，规律会变；这不是扰动。

还有一个值得记下的细节：
- 新抛的硬币"每读一次就重抛"，但只看各次读数的规律，它和一枚"自己每步都重抛"的硬币分不开。
- 所以"**是读取引起了改变**"在这里不是一个事实；只有当读取改变了（平均掉之后的）规律时——被推的硬币——它才是事实。

## 2. 个别化：经典的办法

再看新抛的硬币。Kolmogorov 怎样描述它？
- 他不说"同一个问题'抛'被问了两次"，而说：**第一次抛、第二次抛，是两个不同的问题** X₁、X₂。
- 每个只问一次，于是每个回答都是这次运行里的一份记录；两者的联合规律是乘积。
- 新抛的硬币由此变成了"留着的"一列硬币：**"再问"被消掉了，换成了一个下标。**

> **这个下标就是时间。** 线性时间在 Kolmogorov 的框架里的作用，就是把"同一个问题的反复提问"个别化成不同的问题，使每个回答都成为同一个样本点的一份记录。

这个办法对每一种情形都适用：
- **之前问了什么**：把历史写进问题。随机过程按时间编号，图灵机的格局按步数编号。
- **谁问**：把提问者写进问题——"对观察者 A 的 X""对观察者 B 的 X"。
- **同时问了什么**：把语境写进问题——每个（问题，语境）是一个新变量。
- **定理**（`individuate_record`）：**任何行为，把它的问题按情形（历史、提问者）个别化之后，都有记录模型。**
- **定理**（`individuation_needed`）：不个别化也有记录模型，当且仅当它公共且不被扰动。个别化恰在不是这样时才需要。

**个别化与 `47 §2` 的"藏回去"是一件事的两面**：
- 藏回去：把情形存进一个隐藏状态；
- 个别化：把情形写进问题。

两者都让"每个回答都是记录"重新成立。代价也是同一个量：需要区分的情形有多少——`47 §3` 中余下行为的个数，就是历史这一面需要的个别化的量。

所以，`42` 说的"一切回答都是记录"，在操作上的意思是：**经典的描述总把提问的情形个别化进问题里，直到每个回答都是一份记录。**
- 墙不在于个别化可以做（它总可以做），而在于它被当作**唯一**的描述方式。
- 个别化之后，"同一个问题再问"消失了，"谁在问"消失了，剩下的只有一个全局的样本点，和沿下标的预测。

## 3. 谁问

**形式上，"谁问"与"同时问了什么"同形**：都是回答所依赖的一个额外的下标。所以：
- **公共 ⟺ 各提问者的记录能粘成一份**：这就是 `43 §1` 的定理，把提问者当作语境；
- 个别化（按提问者编号）总能让它们各自成为记录。

**不同之处在于位置**（`Individuation.lean` §3）：
- 各得其名（`47 §4` 的 `nameB`）：两个提问者各自得到自己的名字。
- 把名字对调：每个提问者得到对方的名字。
- **两者让提问者们看到的是同样的两种视角，而两个行为不同**（`name_swap_same_views`）。
- 所以：**有哪些视角，是事实；"你是哪一个视角"，不是事实。** 这与 `48` 中"有哪些相位是事实、现在是哪个相位不是事实"同形。
- 另一方面，相对的回答之间可以有公共的关系："两个提问者得到的回答不同"对谁都成立（`47 §4`，`nameB_relation`）。

**没有处理的前沿**：
- 提问者本身也被问——一个提问者去问另一个提问者记下了什么。
- 这是"提问者在系统之内"（`46 §5`），物理中已知的不可能定理（Wigner 之友一类）都在这里。
- 我们还没有自己的原则性问题，只把它列为前沿，不去翻译那些结果。

## 4. 对一切情形的一条定理

`48` 的定理 1 与 §3 的例子，是同一条定理（`sameViewFacts_iff`，不依赖任何公理）：

> **一个对象在各种情形下的"所见"称为视角。两个对象通过视角的事实全同，当且仅当它们的视角的全体相同。**

- 情形取"之前问了什么"：视角是余下行为，得到 `48` 的定理 1（`invFact_is_viewFact`）。
- 情形取"谁问"：视角是每个提问者看到的行为，得到 §3。
- 情形取"同时问了什么"：视角是各语境中的回答。

读法：
- **结构 = 各种情形下的视角的全体**，它由事实决定；
- **位置 = 此刻是哪一种情形**：什么时候、谁、和什么一起。它不是事实。
- **经典 = 每一面都只有一个视角**，结构与位置不可区分。这正是个别化做到的：情形被写进问题之后，每个个别化了的问题只有一个视角。

## 5. 回到底座

在 T₀ 里（`44`、`47 §6`）：
- **对象**是一个行为或来源，由它的描述给出；描述是记录。
- **它的结构**——各种情形下的视角，以及视角之间的关系、它的规律——是记录，也就是它的事实。
- **它的位置**（此刻是什么时候、谁在问、和什么一起问）与**它的单次回答**，只有在被记下时才是记录。
- **经典的数学**把一切情形个别化进问题，于是每个回答都是同一个全局对象的一份记录：
  - Kolmogorov 按时间编号；
  - 图灵按步数编号；
  - 集合论把命题相对于模型来说（"在 V 中""在 V[G] 中"）。

这对开头的几堵墙意味着：
- **ML**：系统的评价是它的结构（关系的事实），不是它的位置（某个快照上的回答）。
- **物理**："预测结构还是演化"就是"结构还是位置"；演化 = 结构 + 位置。
- **集合论**：独立的命题，是随位置而变的回答——换一个宇宙（谁问），或者做一次强迫（之前问了什么）。

## 6. 形式化：`lean/Individuation.lean`

| 节 | 定理 | 内容 |
|---|---|---|
| §1 | `kept_repeatable`、`kept_undisturbed`、`kept_random` | 留着的硬币：随机、可复读、规律不被扰动 |
| | `fresh_not_repeatable`、`fresh_undisturbed`、`fresh_random` | 新抛的硬币：随机、不可复读、规律不被扰动 |
| | `pushed_disturbed`、`pushed_random` | 被推的硬币：规律被扰动 |
| §2 | `individuate_record` | 个别化之后，任何行为都有记录模型 |
| | `individuation_needed` | 不个别化也有记录模型 ⟺ 公共且不被扰动 |
| §3 | `sameViewFacts_iff` | 通过视角的事实全同 ⟺ 视角的全体相同（一切情形的一条定理） |
| | `invFact_is_viewFact` | 历史的情形就是 `48` 的定理 1 |
| | `name_swap_same_views` | 名字对调：视角的全体相同，行为不同——"你是哪个视角"不是事实 |

公理剖面：11 条不依赖任何公理；`kept_repeatable` 只依赖 `propext`，`name_swap_same_views` 只依赖 `Quot.sound`。

**如实说明**：
- 三枚硬币只是两次读取的算术；个别化的定理是平凡的；视角的定理是纯逻辑。
- 它们的作用，是让本篇的机制精确：
  - 随机、可复读、扰动、信息四样东西，可以一一分开；
  - 个别化总能让每个回答成为记录，而且只在不公共、被扰动时才需要；
  - 位置不是事实。

## 7. 已知的与这里的

**已知的，只作指导**：
- 随机过程的时间下标；
- 量子基础中"时间上的无信号"与序列测量；
- 计算力学的因果态；
- 观察者下标化的变量（关系量子力学一类的描述）；
- 上下文性中"按语境个别化就总有隐变量模型"。

**这里的**：
1. **随机情形的四样东西**：一次次运行之间的随机、一次运行之内的可复读、规律的扰动、信息。Kolmogorov 的样本点，恰是"运行内可复读、运行间随机"（§1）。
2. **个别化**：经典让每个回答成为记录，靠的是把提问的情形写进问题。线性时间就是把反复提问个别化的下标。墙在于把个别化当作唯一的描述方式（§2）。
3. **"谁问"与"同时问"同形**；有哪些视角是事实，你是哪个视角不是事实（§3）。
4. **一切情形的一条定理**：结构 = 视角的全体，由事实决定；位置 = 此刻是哪种情形，不是事实；经典 = 每一面只有一个视角（§4）。
5. **底座里的说法**：对象由结构给出，位置与单次回答只在被记下时才是对象（§5）。
