# 21 · 回到那堵墙：墙在哪里，针对性地拓展什么

> **第九轮注**：这里的五座桥不是五样东西，而是 GLU 在不同形状上的面；第一轮的三个旋钮是同一原理的三个参数。重想见 `22`。

> 这一篇取代第六、七轮的方向（见 §7）。不是统一一切公理，而是找出开头那堵墙在形式里的**具体位置**，只在那里动。

## 0. 偏离在哪里

公理的选择有无数种。第五到七轮越做越宽：六类内部宇宙、跨一切构造的存活原理——这是在给所有可能的基础画地图，是"大统一"，不是我们的目标。

偏离的起点：清单里的主目标被写成了"构造一个公理体系"，而不是"找出墙来自哪里，在那个位置拓展"。于是"能到达各种情况"被理解成了"把各种情况都列出来"。清单的主目标已改写（`自检清单`）。

## 1. 重读开头：墙的四个成分，和它的症状

开头那段博客给出了墙的成分：人类认知倾向于**线性时间、绝对因果、还原论、目标拟合**；
由此，一切框架都在"线性时间与绝对因果下，基于还原论，不断细化**对下一时刻 / 事件的预测**"。

症状是：撞墙之后"突破了这堵墙后你发现变得**无法描述**"。
没有数据集、没有 baseline、没有指标；而一旦要一个单标量指标，又把刚放弃的 reward 请了回来。

所以墙首先是一条**可描述性的边界**：在经典语言里，一个"任务"只有一种可描述的形式——

> 沿一个全序的时间，从过去到下一个的一个**函数**，作用在**点**（状态、结果、元素）上，用一个**标量**打分。

不是这种形式的目标（组织、维持关系、结构），在这个语言里没有位置，于是"无法描述"。

## 2. 墙在形式里的位置：从事件到点的桥

经典框架都用**点**来描述一切：Kolmogorov 的样本空间（所有测量的联合结果）、图灵机的格局序列、物理的状态、ZFC 的元素。
而实际能被测量、被问的，是**事件**（问题及其权重）。从事件走到点，需要几座桥。四个成分恰好是四座桥：

| 博客中的倾向 | 形式上的桥 | 它等价于的公理形式 |
|---|---|---|
| 绝对的状态（存在全局的联合结果） | **P**：每个一致的事件族都有联合的点（结果） | Stone 表示定理 ⟺ 布尔素理想定理（选择的弱形式）；Kolmogorov 的 Ω 对无穷乘积需要选择 |
| 绝对因果 | **U**：每个"可能性关系"都能细化为一个函数 | AC ⟺ 每个全关系包含一个函数（一致化） |
| 线性时间 | **W**：每个集合都能排成一列；构造按序数阶段进行 | AC ⟺ 良序定理；基础公理（序数阶段） |
| 目标拟合（单标量） | **C**：任意两者可比，且可比较的结构有标量表示 | AC ⟺ 基数三歧性（Hartogs）；标量表示 ⟸ 全序 + 阿基米德性（Hölder） |
| 还原论 | **R**：同一由成员决定，并可还原到底 | 外延公理 + 基础公理 |

"对下一时刻作出预测"正是这几座桥的合取：下一时刻是一个点（P），由过去的一个函数决定（U），过去沿一个良序排列（W），预测的好坏用一个标量衡量（C），状态由其组成部分决定（R）。

**墙因此不在整个 ZFC，而在一个很小的位置：选择型原理（以四种面目出现）加上外延与良基。**

你最初的直觉——"AC 可以视为我们对'测量'的存在的坚信"——在这里有了精确形态：
**AC（及其弱形式 BPI）就是相信：每一族相容的测量问题都有一个联合的结果，每一种可能性都有一个确定的选取者。**

## 3. 为什么"突破后无法描述"，以及那个小怪圈

在经典语言里，任务只能在点的层面陈述。一个目的不是逐点预测的系统，没有点层面的目标，于是没有可描述的任务、也没有指标。

博客里的小怪圈——要可测量就引入 reward，引入了又指责它只是拟合，拿掉了又被问"你的单标量是多少"——
是在桥 C 上来回：**每一次要求"描述"，要求的都是点层面、带标量的描述。** 每一步都对，因为在这个语言里只有这一种描述。

## 4. 针对性的拓展：事件在下，点在上，桥是可选的

**底层（事件层）**：带权事件代数——σ-完备布尔代数连同其上的可数可加态——以及它们之间的态射（保测同态、条件期望）。
命题就是事件，真的程度就是权重。这就是"用概率的语言表述逻辑结构"。
有限可加的事件层完全不需要选择；σ-可加性的某些性质需要可数选择，这本身就是一座最弱的桥。

**顶层（点层）**：点 = 事件代数的赋值（到 2 的 σ-同态）；点的集合；点集之间的函数。

**桥**：P、U、W、C、R 各自是一个选择型或外延型原理，都**可选、可分级**，经典在"全部打开"的那一端。

- **经典 = 事件层 + 全部的桥** = ZFC 加 Kolmogorov。这是"空间型"的特殊情形，点足够多（Loomis–Sikorski）。
- **保守**：事件层在 ZF 中可定义，所以这个拓展对 ZF(C) 保守（第六轮的要求保留）；经典是原点——桥全部打开处。
- 你最初说"'子集'是某种意义上的，与集合论是底层与顶层的关系"：子集就是**事件**；它们只在桥 P 提供了点的地方才是真正的点集。底层是事件层，顶层是点层。

## 5. 桥拆开之后，什么变得可描述

只陈述结构，不推测任何具体系统。

- **随机，而没有结果**（Russell 的袜子）：无穷多双袜子。每一双上的均匀分布，整族都存在，不需要选择；
  可是"从每双取一只"的联合结果——乘积空间中的一个点——可能不存在，于是 Kolmogorov 的样本空间是空的。
  事件层的描述（独立公平硬币的测度代数）照样存在。**测量的分布存在，而联合的结果不必存在。**
  （`lean/Socks.lean`：只从"存在一个与 Bool 的双射"——而不给出它——就能定义均匀权重，不用任何公理。）
- **依赖，而没有函数**：依赖是事件代数之间的态射（条件期望），不是点集之间的函数。
  "每个随机依赖都等于一个确定函数加独立噪声"是桥 U 的一个形态，在标准空间上成立，一般情形下是额外的承诺。
- **时间，而没有全局时序**：时间是事件代数沿细化的一个**有向系统**，一般只是偏序。
  它的极限（带相容态的正向极限代数）在事件层总是存在；而由点构成的路径空间需要桥 P 以及正则性。
  线性时间是其中"细化构成一条链"的特殊情形。
- **同一，而没有还原**：两个系统同一，当且仅当它们的带权事件代数同构——按关系认同，而不是按组成部分。
- **比较，而没有标量**：两个系统用带权事件代数之间的态射（细化、garbling）来比较，得到的是一个预序（Blackwell 的实验比较正是这个）。
  只有在桥 C 成立（全序且阿基米德）处才有标量。**要求单标量，就是要求桥 C。**

开头那两个核心问题，在这里有了可以陈述的形式（不是回答）：
- 物理"要预测演化还是结构"：演化属于点层（点沿良序时间的函数，需要 U、W、P）；结构属于事件层（有哪些区分、它们的权重、它们之间的态射）。事件层让"结构"成为可以预测的第一等对象。
- ML"放弃拟合指标之后如何度量"：在事件层度量——用细化 / 态射的预序比较，检查权重沿细化是否相容；标量只在可比较处出现。

## 6. ZFC 判定不了的，落在哪一层

- **CH** 问的是连续统的**点**有多少，是点层的问题。在事件层，连续统的测度代数是规范的：每个可分、无原子的概率代数都同构于 Lebesgue 的那一个（Carathéodory）。CH 在事件层看不见。
- **不可测集、Banach–Tarski**：它们是事件代数之外的点集，由桥（选择）造出——属于点层。
- **限制**：并非所有独立性都在点层。例如 P(ω)/fin 的自同构在 CH 与 PFA 下不同；但 P(ω)/fin 是用点的**全幂集**（ω 的全部子集）造出来的，已经用到了点层。
  由测量生成（可数生成）的事件代数是规范的。这一判断待核验。

所以对"ZFC 判定不了"的解释是：**不可判定性来自对点层——全幂集与各座桥——的承诺；在事件层，这些问题要么消失，要么有规范的答案。** 这是解释，不是判定。

## 7. 与前几轮的关系

**保留，并在此归位：**
- AC ⟺ 良序（第二轮）、AC ⟺ 可比较（第三轮）：桥 W、C。
- 缝与无差别（第三轮）：权重存在而选取不存在——正是 Russell 袜子的有限对称情形。
- 存在是计数的幂等影子（第四轮）：点层的"有一个结果"，是事件层权重在幂等端的像。
- 正则就是可加性存活（第五轮）：不可测集是事件代数之外的点集。
- CH 的分解（第六轮）：CH_C 与 CH_ℵ 都属于点层。
- 保守核心（第六轮）：事件层在 ZF 中可定义，拓展对 ZF(C) 保守。

**偏离，降为记录：** 第七轮的"各种内部宇宙 + 跨一切构造的存活"（`18`–`20`）。它不是错的，但不是这堵墙需要的。

**第一轮的全局粘合**在这里是第二层的桥：各上下文中的**态**相容，却没有联合的态（Vorob'ev 的无圈条件给出何时有）。
它与桥 P（联合的**结果**）是两层：一层关于点，一层关于权重。博客里的"绝对状态"可能同时包含两者。是否需要把它列为第六座桥，要看墙是否需要，暂不展开。

**范围**：这堵墙不包括对角线类的墙（Gödel、停机问题）；它们在任何基础里都会重现（`07`），不在这里的拓展范围之内。
