## 0. 路线检查

- **原则在推动的**：
  - 包络是我们选的，不是窗口给的。任何一条在窗口之下、斜率有界、转折有界的曲线都可以作包络。
  - 约去只需要一个停时，不需要一个固定的时刻。
- **会拉着走的**：无新工具。inf-卷积（下 Lipschitz 包络）只是一个构造。
- **结论先说**：
  1. **停时版的引理 E\***：把固定时刻 t₁ 换成首次到达深度 ℓ 的时刻，底部的估计消失，`116` 定理 1 中的 ℓ ≤ c′W^{3/4} 放宽为 ℓ ≤ ηW。
  2. **一切独立同分布的随机窗口**都可以对单个窗口序列直接证明（任何有界的分布），不再需要退火路线。
  3. **定理 2**（有界比值窗口）：只要在无穷多个长为 ΘW 个检查点的段上，窗口都在 [W, ΓW] 之中（W 是段上的最小窗口，Γ 固定），就刚性。**不需要任何关于窗口形状的假设。**
     - 证明：取窗口在斜率 C₀ = Γ/η² 之下的下 Lipschitz 包络，证明它的无接触段都短于 2η²W，然后光滑化。
  4. **剩下的前沿**：段内比值无界（在每个尺度上都有任意高的尖峰或平台）的窗口。
     - 这与"刚性对窗口单调"的猜想（`109`）是同一个问题。
     - 数值上，多尺度分段的窗口刚性（§3）。

## 1. 停时版的约去

**引理 E\*\***：设起点 z 的高度 ≤ ℓ，ℓ ≤ ηW（η ≤ 1/8）。令 σ := 首次深度 ≥ ℓ 的时刻，t₁ := Aℓ²/W 个检查点。则
> P_z(存活，末端 ∈ S) ≥ ε P_z(存活)，ε = c₂(1 − C/√A) e^{−cAη²} / (C₁(3 + C√A))。

*证明*：记 Σ(u) := 在 [0, u] 上的存活权重。
1. **σ 之前碰不到底部**：底部在深度 ≍ W ≫ ℓ 处，所以 σ 之前只有 κ 的杀死。
2. **停在上方的部分（Harris）**：
   - Σ(t₁) 是路径的减函数，{σ > t₁} = {在 [0, t₁] 上深度始终 < ℓ} 是增事件。由 Harris–FKG，
     > E[Σ(t₁); σ > t₁] ≤ E[Σ(t₁)] · P(σ > t₁) ≤ (C/√A)·E[Σ(t₁)]。
   - 最后一步：自由游走从离水平 ≤ 2ℓ 处出发，在 Aℓ²/W 个检查点内不越过它的概率 ≤ C/√A。
3. **分子**：
   - 在 σ 处深度 ∈ [ℓ, ℓ + 越过量]。由引理 2（`116`），此后的贡献 ≥ c₂ℓ/W · Λ(σ)。
   - 由于 σ ≤ t₁，Λ(σ) ≥ e^{−cAη²} Λ(t₁)：t₁ 只是块的一个 ≤ Aη² 的比例。
   - 又 Σ(σ) ≥ Σ(t₁)。所以
     > 分子 ≥ c₂ ℓ/W · e^{−cAη²} Λ(t₁) · E[Σ(t₁); σ ≤ t₁] ≥ c₂(1 − C/√A) e^{−cAη²} ℓ/W · Λ(t₁) · E[Σ(t₁)]。
4. **分母**：
   - σ ≤ t₁ 的部分：在 σ 处用引理 1（`116`），深度 + ℓ ≤ 2ℓ + 越过量，而越过量的条件期望 ≤ C√W ≤ Cℓ。
   - σ > t₁ 的部分：在 t₁ 处用引理 1 与引理 D。
   - 两部分合起来 ≤ C₁(3 + C√A) ℓ/W · Λ(t₁) · E[Σ(t₁)]。
5. **相除**：E[Σ(t₁)] 与 Λ(t₁) 约去。∎

**推论 1**：`116` 定理 1 对一切 ℓ ∈ [√W, ηW] 成立。

**推论 2**（一切独立同分布的随机窗口）：设 W_j = ω_j U_j，U_j 独立同分布，取值于 [u₀, Γu₀]，u₀ 为本质下确界。则几乎必然刚性。

*证明*：
- 以 u₀ω 为包络，令 F(x) = P(U − u₀ ≤ x u₀)，它对一切 x > 0 为正。
- 对任意固定的 ε > 0，取 ℓ = εW。一段 ε²W 个检查点中没有接触点的概率是 (1 − F(ε))^{ε²W}。
- 对块中 ≲ Θ/ε² 个段取并，再对块求和，都是可和的。所以对大的 W，（U）在尺度 εW 上成立，几乎必然。
- 块首取为 K 之后的第一个接触点，块末取为 2K 之前的最后一个接触点。由推论 1，刚性。∎

`113` 定理 1 的退火路线仍然成立，但已不必要。

## 2. 有界比值窗口的刚性

### 2.1 设定

- 一个**段**是 ⌈ΘW⌉ 个相邻的检查点，W 是段上的最小窗口。
- 在段上，W ≤ W_j ≤ ΓW。
- 检查点链同 `97`：间隔等于窗口，块的 X-时间 ≍ ΘW²。

### 2.2 下 Lipschitz 包络

取 C₀ := 1 + Γ/η²，并令
> ω̂_t := min_j ( W_j + C₀ |t − j| )（j 取遍段及其两侧的邻域）。

**引理 3**：
1. ω̂ ≤ W；ω̂ 是 C₀-Lipschitz 的；ω̂ ≥ W（段的最小窗口）。
2. **无接触段很短**：设 R 是一串相邻的检查点，其中每个 j 都满足 W_j > ω̂_j + ηW。则 |R| < 2η²W。

*证明*：
- **第 1 条**：前两点直接由定义得到；第三点因为每个 W_j ≥ W。
- **第 2 条**：
  - 对 t ∈ R，取达到最小值的 j\*。若 j\* ∈ R，则由 Lipschitz 性，
    > ω̂_t ≤ ω̂_{j\*} + C₀|t − j\*| < W_{j\*} − ηW + C₀|t − j\*| = ω̂_t − ηW，

    矛盾。所以 j\* ∉ R。
  - 取 t 为 R 的中点。则 ω̂_t = W_{j\*} + C₀|t − j\*| ≥ W + C₀|R|/2。
  - 另一方面 ω̂_t < W_t − ηW ≤ ΓW。
  - 所以 |R| < 2(Γ − 1)W/C₀ < 2η²W。∎

### 2.3 光滑化

令 ω̌ 为 ω̂ 在间距 δ_n = ηW/(2C₀) 的节点上的线性插值，再减去 ηW/2。则：
- ω̂ − ηW ≤ ω̌ ≤ ω̂ ≤ W_j：它在一切窗口之下；
- ω̌ ≥ (1 − η)W，所以管有足够的空间；
- 斜率 ≤ C₀；斜率在一个段上的全变差 ≤ 4ΘC₀²/η。

**接触**：W_j ≤ ω̂_j + ηW ⟹ W_j ≤ ω̌_j + 2ηW。由引理 3，（U）相对于 ω̌ 在尺度 ℓ = 2ηW 上成立（ℓ²/W = 4η²W ≥ 2η²W）。

**倾斜**：`97` 引理 7 的分段倾斜，参数在节点处改变。
- 连续部分的代价 ≲ exp(段长 × (C₀/W)² × W) = exp(ΘC₀²)；
- 各改变点的代价 ≲ exp(Γ · 斜率的全变差)。
- 两者都有界。

### 2.4 定理

**定理 2**（有界比值窗口）：若有无穷多个段，其上 W ≤ W_j ≤ ΓW（Γ 固定），则刚性。

*证明*：
- 在每个这样的段上取 ω̌ 为包络，η 取小，ℓ = 2ηW。
- 由推论 1，结合 §2.3 的倾斜，块首与块末取在接触点（接触点每 2η²W 个检查点内至少有一个）。
- 得到 Δ ≤ C′(Γ, η, Θ)。由 `109` 定理 6，刚性。∎

**读法**：
- `94 §4`、`108 §2` 以来的"不规则窗口"问题，在"段内比值有界"的范围里完全解决。
- 窗口的下包络可以在一切尺度上不规则：包络由窗口自己的 inf-卷积给出。
- 凸包定理、下包络定理、随机跳动、振荡窗口，都是定理 2 的特例。
- 这与 `109` 的一步收缩判据互补：
  - 后者处理窗口很小的瓶颈；
  - 定理 2 处理窗口在长段上比值有界的情形。

### 2.5 剩下的前沿

**比值无界**：在每个长为 ΘW 个检查点的段上，max W_j / min W_j → ∞。例如在一切尺度上出现任意高的尖峰或平台。

- 高的窗口只去掉约束，直观上不应破坏刚性。这正是 `109` 的单调性猜想："缩小窗口不产生新的隐藏参数"。
- **困难所在**：
  - 在间隔等于窗口的模型中，高窗口同时意味着长时间间隔。一个高度为 W′ ≫ W² 的尖峰，使路径在一个间隔内扩散超过 W。
  - 这有时帮助收缩（重置），有时不帮助（`109`：小窗口之后跟一个大窗口，一步直径 ≍ log W′）。
- **状态**：开放，列入 `118`。
