# 74 · 吸收问题：B 不判定世界的汇合；永不共存的集合

> 第四十七轮，第二个问题（`72 §6` 第 2 条；`71 §6`）。

---

## 0. 路线检查

- **原则在推动的**：
  - `71` 证明：在 ω 标准之下，同高的汇合一般不成立。
  - 遗留的问题是：在 B 的扩张关系下（宽度与高度的步骤），两个世界能否总在**某个**高度汇合？
- **会拉着走的**：强迫法中构造可数模型族的技术（选择泛型滤子、主泛型）。只用来构造 B 的模型。
- **四种情形**：本篇处理世界之间的"同时"：两个集合能否在同一个世界中并存。
- **是否回答 `00 §7`**：回答 B 在对象层面究竟承诺了多少全局性。

## 1. 问题的精确形式

- w ≼ w[c] 与 w ≼ w[d] 是两个宽度扩张。
- 问：是否有世界 u，使 w[c] ≼ u 且 w[d] ≼ u？这里的 ≼ 由 M2 的两种步骤生成。
- 回顾 B 的公理（`55 §2`）：M3a 只断言"对每个偏序，**有**一个泛型扩张"，并不要求一切泛型滤子都给出世界。

## 2. B 不证明汇合

**定理 1**（稀疏的模型）：
- 设外层有足够多的可数传递模型；这正是 `55 §8` 构造 B 的模型时所用的条件。
- 取任一世界 w，以及两个在 w 上 Cohen 的实数 c、d。它们甚至可以互为泛型。
- 则有 B 的一个模型，其中 w[c] 与 w[d] 都是世界，但**没有任何世界同时含有 c 与 d**。
- 所以在这个模型中，w[c] 与 w[d] 在任何高度都不能汇合。

*证明*：从 w 出发，只沿"不同时含有 c 与 d"的世界扩张。需要检验：
1. **M3a**。
   - 设 u 已含 c、不含 d，P ∈ u。
   - 使 u[G] 含 d 的泛型 G 只有很少：u 可数，名字只有可数多个；对每个名字 τ，使 τ^G = d 的 G 组成贫乏集。
   - 所以可以选一个 G 避开它们。
2. **M3b**。高度扩张不增加实数。
3. **M4**。沿用外层模型的泛型绝对性，同 `55 §8`。
4. **M1**。显然。∎

**推论**：在这个模型中，c 与 d 都是集合，各自在某个世界里，但**永不共存**。

## 3. 汇合与 B 相容

**定理 2**（有向的模型）：
- 设外层有：
  - 一条可数传递模型的高度链 N₀ ⊆ N₁ ⊆ …（每个是下一个的秩初段）；
  - 一个对它们都泛型的"主"坍缩滤子 K。
- 则有 B 的一个模型，其中任何两个世界都有共同的扩张。

*证明概要*：
- 取一切形如 N_i[K↾α] 的世界，以及它们之间的中间模型。
- 任何两个都含在某个 N_j[K↾β] 中。
- 坍缩的普遍性保证：每个世界上的每个偏序，都有泛型扩张落在族内（M3a）。∎

**所以 B 不判定汇合**：它与 B 相容，它的否定也与 B 相容。

## 4. 在"丰富"的解释中

若取一切可达的世界（外层中一切泛型都给出世界）：
- **同高**：汇合一般失败（`71`，Mostowski 型的例子）。
- **某个高度**：
  - 对小的强迫（如 Cohen），泛型性传到高度扩张上：设 N 是 w 的高度扩张，则 N 中 Cohen 强迫的稠密集都在 V_κ^N = w 中，所以 c 在 N 上仍是 Cohen 的，并且 w[c] ≼ N[c]。
  - 问题于是化为：N[c] 与 N[d] 能否在高度 o(N) 汇合？
    - 若编码高度的那个实数在 N 上是泛型的（按通常的构造，它就是），可以；
    - 若 c ⊕ d 编码了在任何这样的 N 上都不泛型的信息，则不能。
  - 所以这取决于外层宇宙中有哪些实数，是外层的性质，不是 B 的性质。

## 5. 为什么 B 不应加上汇合

- 若任何两个世界都有共同的扩张，世界就组成一个有向族。
- 它们的并是一个类，其中**任意有限多个集合都共存于一个世界**。这就是对象层面的全局宇宙，也就是 GLU₀。
- 所以：
  - B 不加汇合，正是在对象层面去掉 GLU₀；
  - 定理 1、2 说明这是一个真正的选择，不是一个被隐藏的定理。
- 这一点与 `71` 的理由互补：
  - `71`：在 ω 标准之下，同高汇合一般失败；
  - 本篇：即使允许任何高度，B 也不承诺汇合。

## 6. 读法：永不共存的集合

- 定理 1 的模型中，c 与 d 是"对象层面的互补"：每一个都存在，但永不同时存在。
- 这与语境性（`68`）形式相同，性质不同：

| | 值的层次（语境性） | 对象的层次（永不共存） |
|---|---|---|
| 什么不能并存 | 不同语境的样本作为共享记录 | 不同世界中的集合 |
| 由什么决定 | 定律（有限的，算术的），被强制 | B 不决定：有的模型中有，有的没有 |
| 是否可以度量 | 可以：η | 可以：汇合高度（`71`），或者根本不汇合 |

- B 在对象层面的承诺，因此是：
  - 每个世界是经典的；
  - 可数核是绝对的；
  - 可能性汇合（S4.2 的论证只用到 M3a，在两种模型中都成立）；
  - 哪些集合能共存，留作自由的结构。

## 7. 已知的与这里的

**已知的，只作指导**：
- 用可数传递模型与泛型滤子构造"多宇宙"模型的一般技术；
- Hamkins–Löwe 关于 .2 的论证只用到泛型扩张的存在。

**这里的**：
1. 汇合独立于 B（定理 1、2）。
2. "丰富解释中的吸收问题，是外层宇宙的性质"这一定位。
3. "不加汇合 = 在对象层面去掉 GLU₀"，以及"永不共存的集合"这一对象层面的互补。

**如实的判断**：
- 两个构造都是标准的。
- 新的是它们回答的问题：B 究竟承诺多少全局性。答案是：可数核与可能性的汇合；对象的共存不在承诺之内。
