# 45 · 路线的反思，与来源一侧

> 接 `44 §6`。你说：按这个继续做，注意动态反思路线本身。
> 所以本篇先反思路线（§0），再按反思的结论调整要做的事（§1–§3）。
>
> 形式化：`lean-mathlib/Sources.lean` §5：一个来源有记录，当且仅当重读能以正的概率复现它的全部回答。

## 0. 路线的反思

### 0.1 第二十五到二十七轮做成了什么

- **一个根**："一切回答都是记录"（`42`）。它统一了四个倾向、三个旋钮和三种形式化。
- **与 GLU 打通**：GLU = 回答是跨语境的记录，这是一条定理（`43 §1`）。
- **"子集"的两种意思**：可以问的问题，恰是可测的问题（`43 §4`）。
- **一条可以读懂、又不保守的原则**：(C) 分阶段会用完（`44 §2`）。它判定一批 ZFC 判定不了的问题，并且落在已知的规范界线上。

### 0.2 三处在漂移

**漂移一：形式系统退回了"记录优先"。**
- `42` 说来源是原语，记录是特殊的来源；`44 §1.1` 却说只有记录是原语，来源由记录描述。
- 这两种说法可以互相翻译：来源按规律认同，规律是记录；记录就是集中在一点的来源。所以这一步本身不算错。
- 但后果是：**到目前为止，测量优先只是一种读法，形式系统本身是经典的**（T₀ 就是遗传可数集合的理论）。
- 来源优先真正不同于经典的地方，不在单个来源上，而在**来源之间的关联**：
  - 两个规律相同的来源，与第三个来源的关联可以不同；
  - 整体不由部分决定（`42 §10`）。
  
  这一块 T₀ 还没有碰。

**漂移二：往上爬 (Cₙ) 会变成翻译。**
- 更高层次的 (Cₙ) 用的是带大基数的规范内模型，终点是投影决定性。这是已知的内模型理论，一步步写准它，就是把那套理论翻译成测量的话。
- **决定：不往上爬。**
  - (C) 在第一个非平凡层次上的形式，作为这条原则的代表保留；
  - 更高的层次记为"已知的阶梯"，只作对照（§1）。

**漂移三："测量失败的程度"被搁下了。**
- `00 §7` 的原话是：把"全局模型存在"降格为可以为假的命题，并测量它为假的程度。
- 第二十六轮只给了一个度量（复读缺陷），之后一直在记录一侧（实数集合的正则性）推进。
- 而"全局模型存在"首先是**来源一侧**的问题。

### 0.3 数学上新的东西很少，这要一直记着

- 到现在为止，新的是**原则、分类、读法**；定理本身要么简单，要么是已知的。
- 对一个基础的设计，这可以接受：原则是我们的，而且决定了取舍——例如 (C) 是从"线性时间到不了连续统"来的，不是因为它已知。
- 但要一直检查：**每一步是原则在推动，还是已知的体系在拉着走？** 漂移二就是后一种。

### 0.4 调整

1. 记录一侧收住：给出"记录可数"与 (C) 的统一读法（§1），不再往上。
2. 转到来源一侧（§2）：
   - 来源的记录与重读，给出定理；
   - "全局模型存在"的两种意思，以及各自的度量。
3. 下一步的重心，放在来源之间的关联（§3）。

## 1. 记录一侧收住："确定的总体是记录"

`44 §6` 的第 2 条问：T₀ 的"每份记录可数"与 (C)，能否统一成一条原则。可以写成一句读法：

> **(D) 从一份记录出发、以确定的方式得到的总体，包含在一份记录里；不包含在任何一份记录里的总体，来自来源。**

- "以确定的方式"取最弱的意思——一份记录的全部元素——就是 T₀ 的"每份记录可数"。
- 取"分阶段构造"，就是 (C)。
- 取更强的构造，就是已知的阶梯（带大基数的内模型，终点是投影决定性），这里不再往上走（§0.2）。

读法：
- **连续统不可数，是因为它不是一个确定的总体，而是一个来源的全部读数。** 它的"多"来自随机，不来自构造。
- 在"V = L"下，连续统是从无出发、分阶段构造出的确定的总体。这时没有随机性：每个读数都被它自己的检验抓住（`Askable.all_records_formable`）。
- 所以 (D) 把 Cantor 的"实数比自然数多"读成：**随机比构造多。**

**如实说明**：(D) 是一个统一的**读法**，不是新的公理——每一种"确定的方式"给出一个实例，实例是已知的。它的用处在于说明这些实例为什么是同一件事。

## 2. 来源一侧

### 2.1 记录就是重读能复现的回答：一条定理

`42 §2` 把记录定义为"再问一次一定得到同样回答"的回答。`44` 的来源不以点为前提，它的记录另有定义：对每个足够必然的读取问题都回答"是"的回答序列，也就是原子（`isRecord_iff`）。两个定义现在由一条定理接上（`Sources.record_iff_repeat`）：

> **一个来源有记录，当且仅当：独立地把它读两遍，两遍在前 n 个回答上一致的概率，对一切 n 都不低于某个正数。**
> 也就是说，**重读能以正的概率复现它的全部回答**。

- 证明的一半：记录的前缀权重有下界 c，于是两遍一致的概率至少是 c²。
- 另一半：若一致的概率始终不低于 L，则每一层都有权重不低于 L 的读取；这些读取按"有更深的重读取延伸"连成一条无穷的路（有限分叉的树），这条路就是一份记录。
- 例：公平的硬币，两遍在前 n 位一致的概率是 2⁻ⁿ，趋于 0，所以没有记录（与 `coin_no_record` 一致）。

这把根本的定义（记录 = 能复读）落实到了形式系统里：**来源的记录，正是它身上能被重读复现的那一部分。**

### 2.2 "全局模型存在"有两种意思

`00 §7` 要把"全局模型存在"降格为可以为假的命题。在来源一侧，它其实是两件事：

1. **全局规律存在**：各个语境中的局部规律，粘成一个联合的规律。这是来源一侧的 GLU。
2. **全局规律有记录**：这个联合的规律，能被重读复现（§2.1）。

经典的做法把两件事都藏了起来：
- 第 1 件由定义给出：Kolmogorov 从一个 Ω 出发，一切随机变量从一开始就在同一个联合规律里；
- 第 2 件由点的表示代替：把规律放在点的集合上，用的是**别的来源**的记录（`43 §3`）。
- 而点的表示本身，还需要点存在——这正是选择公理管的事（袜子）。

### 2.3 两种失败，各有度量

| 失败 | 它的度量 | 没有这种失败时 |
|---|---|---|
| 1. 局部规律粘不成全局规律 | 与局部规律相容的全局规律最多能占多大的权重（已知的概念，只作指导） | 这个权重为 1 |
| 2. 全局规律没有记录 | 原子的总权重，也就是来源中能被记录的部分。两遍完整重读一致的概率（`agree` 的极限）等于各原子权重的平方和（标准的事实，未形式化），它为正当且仅当有记录（§2.1） | 原子的总权重为 1：来源恰是它的记录的混合 |

### 2.4 例子

| 例子 | 全局规律 | 有记录 | 点的表示 |
|---|---|---|---|
| 一份记录 | 有 | 有 | 有 |
| 有限多个公平硬币 | 有 | 有（每个结果都是原子） | 有 |
| 无穷多个独立的公平硬币 | 有 | **没有** | 有（一切 0-1 序列，不用选择） |
| 没有选择公理时的无穷多双袜子 | 有 | 没有 | **可以没有** |
| 局部规律相容、却没有联合规律的族（Bell 型，已知） | **没有** | — | — |

这张表说明两种失败**彼此独立**。在经典的语言里，前两列被最后一列代替：有了点，就当作既有全局规律，又有记录。

## 3. 来源之间：关系可以是记录，而关系的两端不是

§0.2 说，来源优先真正不同于经典的地方在关联上。这里先给一个最简单、却已经不是经典读法的事实（`Askable.lean` §5）：

- 取一个没有原子的来源（例如无穷多个公平硬币），把它和自己**同步地**耦合：两遍读数总是相同。
  - 两个部分都是原来的来源（`sameCoupling_fst`）；
  - 联合的来源没有原子，所以**没有记录**（`sameCoupling_no_atoms`，与 `no_record` 合起来）；
  - 但"两遍相同"这个关系问题是**必然**的（`sameCoupling_agree_sure`）：问多少次都回答"是"——它是一份记录。
- 同一个来源，**独立地**耦合：两个部分完全一样，"两遍相同"的概率却是 0（`independent_agree_null`）。"两遍不同"成了必然的，也是一份记录。

读法：
- **关系可以是记录，而关系的两端不是记录。** 两端各自读不出一份记录，它们之间的关系却是一个能复读的事实。
- 部分相同，而整体上必然成立的事实相反。这是 `42 §10` 的"部分不决定整体"，这次是在没有记录的无穷情形。
- **一个来源的"事实"，就是它必然的问题**（概率为 0 或 1 的问题）。来源本身不必是记录，它的事实却是记录。
  - 大数定律是这样的例子："1 的频率是 1/2"对公平硬币是必然的——没有记录的来源，有一个能复读的事实。
  - 这也是 `42 §5` 中"规律是二阶的记录"的精确形态。

这回到开头那两个问题，只作启发：
- 物理的"预测演化还是结构"：个体的读数可以没有记录，而关系可以是记录。**被记下的首先是结构。**
- ML 的"放弃单一指标之后如何度量"：单个的得分可以不能复读，而比较（关系）可以是必然的事实。

## 4. 形式化

| 文件 | 定理 | 内容 |
|---|---|---|
| `Sources.lean` §5 | `record_iff_repeat` | 来源有记录，当且仅当两遍独立重读、在每一层一致的概率有正的下界 |
| | `agree`、`pre_succ`、`pre_step`、`pre_mono`、`pre_extend`、`heavy_of_agree`、`good_root`、`good_child`、`chain_coherent`、`pre_branch` | 证明用到的定义与引理：前缀的权重只减不增；一致的概率有下界时，每层有重的读取；好的串总有好的延伸；沿好的串得到一条路 |
| `Askable.lean` §5 | `sameCoupling_fst`、`sameCoupling_agree_sure`、`sameCoupling_no_atoms`、`independent_agree_null`、`measurable_dup` | 同步的耦合：部分不变，没有记录，"相同"必然；独立的耦合："相同"的概率为 0 |

**如实说明**：
- 这些都是初等的概率论，数学上不新。
- 它们的作用是把两件事钉住：
  - "记录 = 能复读"与"记录 = 原子"是同一个概念；
  - 关系可以是记录，而两端不是。

## 5. 已知的与这里的

**已知的，只作指导**：
- 原子与独立重读一致的概率（平方和）；
- 有限分叉的树上的无穷路（König）；
- 耦合；0-1 律与大数定律；
- 边缘问题与 Bell 型的族；
- 内模型的阶梯。

**这里的**：
1. **路线的反思**（§0）：
   - 三处漂移：形式系统退回记录优先；往上爬会变成翻译；失败的度量被搁下；
   - 调整：不往上爬，转到来源一侧。
2. **(D) 的统一读法**：确定的总体是记录，其余来自来源；"随机比构造多"（§1）。
3. **记录 = 能复读，成为定理**（§2.1）。
4. **"全局模型存在"的两种意思与各自的度量**：两种失败彼此独立，经典的语言用"有点"把它们一起代替了（§2.2–§2.4）。
5. **关系可以是记录，而两端不是**；来源的事实就是它必然的问题（§3）。

## 6. 下一步（按反思后的重心）

1. **把"来源的事实"作为 T₀ 的基本概念。**
   - 一个来源的事实，是它必然的问题。
   - 问：一个来源由它的事实决定到什么程度？两个来源事实相同而规律不同，是否可能？这是"按统计认同"（S2）与"按事实认同"的差别。
2. **关联的底座**：一族来源连同它们之间的耦合，作为 T₀ 的对象；在其中写出两种失败（§2.3）的定义与基本性质。
3. **失败的度量之间的关系**：两种失败彼此独立（§2.4），但度量之间可能有不等式。先不作断言。
4. **路线检查**：每做一步，先问两件事：
   - 它是来源一侧的原则在推动，还是已知的体系在拉着走？
   - 它对 `00 §7`（测量"全局模型存在"为假的程度）有没有贡献？
