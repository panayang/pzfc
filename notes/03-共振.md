# 03 · 共振：别的学科已经撞过这堵墙，而且留下了工具

> **第二轮注**：本表漏掉了三条主线——有限观测 → 拓扑即逻辑（Vickers）；不可区分 → 置换模型 / nominal 集合；对角线的形状取决于真值结构（Kripke、Łukasiewicz）。见 `05`–`08`。

> 你说希望联想到"其他很多我们并没有的知识，乃至人文社科方面的信念"。
> 这一篇按**同一个形式骨架**排列：每一条都是"局部数据无法粘合成全局对象"的一个实例。
> 标 **[形式]** 的是有严格数学对应的；标 **[类比]** 的只提供直觉，不承重。

---

## 1. 数学与逻辑里已经存在的"关掉旋钮"的工作

| 工作 | 关掉哪个旋钮 | 可借用的具体东西 |
|---|---|---|
| **无点拓扑 / locale 理论** [形式] | GLU（点是导出的，可以不存在） | 非空间 locale = 没有点但有丰富开集的空间。这是"结构存在而对象不存在"的最干净样板 |
| **Bohr topos**（Isham–Döring，Heunen–Landsman–Spitters）[形式] | GLU | Kochen–Specker 定理 = 内部谱 locale **没有点**。即：量子系统没有底层状态集，但有完整的逻辑结构 |
| **Aczel 反基础公理 (AFA)** [形式] | WF | 循环集合，同一性 = 互模拟。与 ZFC 等协调——**放弃还原论不需要付出协调性代价**，这点很重要 |
| **Markov 范畴**（Fritz）[形式] | Sharp/GLU | 无测度论的概率：条件独立、de Finetti 全部可做。`copy/delete` 的存在性 = 经典性 |
| **Effectus 理论**（Jacobs）[形式] | Sharp | 态与谓词的对偶作为原语——"概率即逻辑"的范畴化 |
| **Chu 空间 / 形式概念分析** [形式] | — | 对象 × 属性 × 矩阵的三元对称。点与性质完全对偶，没有哪一侧更基本 |
| **Domain 论 / Stone 对偶** [形式] | WF | 对象 = 有限观测的逆极限。这是 `01 §A7` 的现成技术 |
| **Gleason 定理** [形式] | — | **结构逼出态的形式**。这是"可解释公理体系"的真正标准 |
| **Solovay 模型** [形式] | Sharp + AC | "所有实数集可测"是协调的——不可测集是 AC 的产物，不是实在 |
| **布尔值模型 / 力迫** [形式] | Sharp | `01 §3` 整条路线；"独立性 = 非本征态"的严格载体 |

## 2. 物理里已经在做同一件事的人

- **Rovelli 关系量子力学** [形式]：状态是**相对于观察者**的。没有绝对状态 = 没有全局截面。
- **Hardy 的 causaloid** [形式]：不预设固定因果结构的操作框架。直接对应"不预设上下文复形的形状"。
- **构造子理论**（Deutsch–Marletto）[形式]：以"可能/不可能"为基本陈述，不以演化方程为基本陈述。`02 §6` 的现成形态。
- **因果集 / 形状动力学 / Barbour** [类比]：时间不是基本的。
- **Abramsky–Brandenburger 层论上下文性** [形式]：整个框架的技术核心，`src/` 实现的就是它。
- **热力学 & Lieb–Yngvason** [形式]：物理学最成功的理论之一**不预测轨道**，只预测不可能性；且从偏序严格导出标量。
  > 这一条我认为被严重低估：它同时是"预测什么"和"如何度量"两个问题的现成答案。

## 3. 统计与测量学：他们七十年前就承认了"信息量不是标量"

- **Blackwell 比较实验（1953）** [形式]：信息量是**偏序**，判据是 garbling。不可比是常态。
- **Rasch 模型 & specific objectivity** [形式]：合法指标 = 换探针不变的比较结构。**规范不变性的心理测量学形态。**
- **项目反应理论（IRT）** [形式]：能力与难度从**响应矩阵**联合估计——测量从交互中浮现，而非从任一侧读取。
  > IRT 的响应矩阵**就是一个概率 Chu 空间**。这条对应我认为是可以做实的，不只是类比。
- **构念效度 / nomological network**（Cronbach–Meehl）[形式]：构念由它在测量网络中的**位置**定义，没有独立定义。
  **这是关系主义在社会科学里的标准操作程序**，而且它是 1955 年的东西。
- **不精确概率 / 下上预期**（Walley）、**Dempster–Shafer**、**Choquet 积分** [形式]：
  非可加"测度"的成熟工具箱。这是 `01 §A5` 的现成载体。

> 对你朋友那句"人类间互评置信度低得离谱，IQ 也需要先排除一堆因素"：
> 心理测量学的结论不是"人类没有指标"，是"**指标的合法性是有范围的规范条件，不是有无问题**"。
> ML 评测辩论双方都在用"有/无标量"这个二值框架吵，而这个框架本身就是 Sharp 旋钮。

## 4. 社会科学与人文：他们有词汇，我们有公式

| 概念 | 形式骨架 | 说明 |
|---|---|---|
| **Arrow 不可能性 / Condorcet 循环** [形式] | 比较联络的非零曲率 | `00 §4`。ML 指标怪圈的精确对应物 |
| **Sen 的能力进路（capability approach）** [类比→可形式化] | 评价对象 = **可达功能集**，不是效用标量 | 直译到 ML：评价一个系统按它**能回答的问题族**，不按一个数。这就是 `02` 的证书格式 |
| **Goodhart / Campbell 定律** [形式] | 自然性方块不交换 | `02 §7` |
| **Kuhn 的不可通约性** [形式骨架清楚] | 范式 = 上下文；不可通约 = 无全局截面 | 通常被当成软的社会学主张。它和 Kochen–Specker 是**同一个形状**——这一点我认为很少被说出来 |
| **边界对象**（Star & Bowker, STS）[形式骨架清楚] | 有局部截面、无全局截面的预层 | 社会学早就命名了这个数学对象：在不同社群里含义不同却仍能协作的东西 |
| **Garfinkel 的索引性（indexicality）** [类比] | 意义不可去上下文化 | 民族方法学的核心主张就是 ¬GLU 在语言里的形态 |
| **维特根斯坦：语言游戏、遵守规则** [类比] | 意义 = 使用 = 响应预层 | 「意义即用法」就是「对象即其回答族」 |
| **巴赫金的复调（polyphony）** [类比] | 不存在全局叙述者截面 | 真理不可被单一声部穷尽，不是修辞，是结构断言 |
| **Geertz 深描** [类比] | 拒绝把局部意义压缩成全局变量 | |
| **龙树中观 / 缘起性空** [类比，但极贴切] | 无自性（svabhāva）= 无底层点 | 对象没有内在本质，只有关系中的生起。这是"无点本体"最古老的完整表述 |
| **因陀罗网** [类比，但技术上准确] | 每颗珠映一切珠 = 非良基方程组的解 | **这就是 Aczel 解引理的意象版**：循环互映的系统有唯一解（终余代数），不需要"底" |
| **二谛（俗谛/真谛）** [类比] | 经典极限 vs 上下文真值 | 俗谛 ≈ 障碍类为零那一片上的有效描述 |

> 我特意把龙树放进来，不是为了异域情调：
> **"没有自性、只有缘起"与"没有底层点集、只有响应预层"是同一个本体承诺**，
> 而西方基础数学花了一百年才被实验（Bell）推到这个位置。
> 这不构成论证，但它提示：**"对象优先于关系"这个直觉不是普遍的人类直觉，是一个特定传统的默认值**——
> 而我们把它写进了 ZFC 的第一条。

## 5. 一条横贯所有条目的观察

上面所有条目都可以归到同一句话：

> **一个领域一旦开始认真处理"测量"，它就会自发地发现自己需要放弃全局截面。**

- 物理：认真处理测量 → 量子力学 → 上下文性
- 心理测量：认真处理测量 → specific objectivity → 指标的规范依赖性
- 社会选择：认真处理聚合 → Arrow → 无全局序
- 统计：认真处理信息 → Blackwell → 偏序
- 社会学：认真处理跨社群协作 → 边界对象 → 有局部无全局
- 集合论：**还没有认真处理测量。**

最后这一行就是这个仓库存在的理由。

## 6. 反向的用处：这个框架能还给人文社科什么

这不该是单向借用。三个障碍不变量都是**领域无关**的：

- **Hodge 梯度占比**可以直接算在任何成对比较数据上：同行评议、面试评分、法官量刑、文学奖投票。
  它给出一个前所未有的东西：**"这场评审有多少比例是真的存在一个共同标准"**，可计算、可报告。
- **CF** 可以算在任何"顺序会影响回答"的问卷 / 访谈数据上。心理学的"问卷顺序效应"其实是 signalling，
  而残余的上下文性意味着**被试没有一个待读取的固定态度**——这是态度研究里一个真实的理论争议，而它现在可以被量化。
- **Blackwell 偏序**可以用来说"这个指标体系严格比那个更有信息量"，并附上 garbling 证书，
  而不是各自宣称自己的量表更好。

> 如果这套东西有一天要落地，我赌它先落在**评测与测量学**上，而不是落在物理或集合论上。
> 因为那里的痛点最急，数据最现成，而且**不需要先接受任何本体论主张就能开始用**。
