# 119 · 汇合高度的精确值

> 第六十六轮（`71 §6` 第 1 问、`95` 的汇合高度、`118 §2.2`）。

---

## 0. 路线检查

- **原则在推动的**：`71` 用汇合高度 amh 度量世界层次的"不能汇合"：
  - 下界是联合 Church–Kleene 序数 jck（`71` 定理 1）；
  - 上界是迭代像的高度（`95` 定理 2）。
  - 问题是它的精确值。
- **会拉着走的**：相对可构成性 L[A]、ZFC-高度。只用标准事实。
- **结论先说**：
  1. 对形如 w = L_α[A] 的世界（例如 w = L_α），
     > **amh(w[c], w[d]) = min{ β ≥ α : L_β[A, c, d] ⊨ ZFC }。**

     汇合高度就是 L[A, c ⊕ d] 在 α 处或之上的第一个 ZFC-高度（定理 1）。
  2. 同高汇合当且仅当 L_α[A][c ⊕ d] ⊨ ZFC（推论 1）。
  3. 若 ω₁^{c⊕d} ≥ α，汇合高度只依赖于 c ⊕ d（关于 A 的相对可构成度）：它就是 L[A, c ⊕ d] 的最小 ZFC-高度（推论 2）。
  4. 同一个世界上的两个 Cohen 实数，汇合高度在 ω₁ 中无界（推论 3）。
  5. jck 是一个很弱的下界：最小 ZFC-高度远在 ω₁^z 之上。

## 1. 设定

- w 是可数传递的 ZFC 模型，高度 α = o(w)，并且 w = L_α[A]，其中 A ⊆ α，A ∈ w。
  - 这包括 w = L_α，以及一切满足"V = L[A]，A 是序数集"的世界。
- c、d 是实数，w[c]、w[d] 是世界（ZFC 模型）。
- 例如 c、d 在 w 上泛型，w[c] = L_α[A, c]。

**汇合高度**（`71`）：amh(w[c], w[d]) 是同时包含 w[c] 与 w[d] 的传递 ZFC 模型 M（w[c] ∪ w[d] ⊆ M）的最小高度。

## 2. 定理

**定理 1**：amh(w[c], w[d]) = min{ β ≥ α : L_β[A, c, d] ⊨ ZFC }（若右边的集合非空；否则两者都不存在）。

*证明*：
- **（≥）**：设 M 是传递 ZFC 模型，w[c] ∪ w[d] ⊆ M，高度 β。
  - A ∈ w ⊆ M，并且 c ∈ w[c] ⊆ M，d ∈ w[d] ⊆ M。
  - 在 M 中构造 L[A, c, d]。它是 M 的内模型，满足 ZFC，并且等于 L_β[A, c, d]（相对可构成性是绝对的）。
  - 又 β ≥ α，因为 w ⊆ M。
- **（≤）**：设 β ≥ α，L_β[A, c, d] ⊨ ZFC。
  - 由于 α ≤ β 且 A 是参数，它包含 L_α[A] = w。
  - 它包含 c、d。对 w 中的名字 τ，τ^c 由 τ 与 c 通过绝对的递归算出，所以 w[c] ⊆ L_β[A, c, d]，对 d 同理。∎

**推论 1**（同高汇合的判据）：w[c]、w[d] 能同高汇合，当且仅当 L_α[A, c, d] ⊨ ZFC。
- 互为泛型的一对：L_α[A][c][d] ⊨ ZFC，所以 amh = α（`71` 定理 1 第 3 条）。
- Mostowski 型的一对：c ⊕ d 编码序型为 α 的良序，L_α[A, c, d] 把 α 看成可数的，不满足 ZFC，所以 amh > α。

**推论 2**：若 ω₁^{A∩ω ⊕ c ⊕ d} ≥ α（例如 A = ∅，c ⊕ d 计算出序型 ≥ α 的良序），则
> amh(w[c], w[d]) = zh(A, c ⊕ d) := min{ β : L_β[A, c ⊕ d] ⊨ ZFC }。

- 理由：L[A, z] 的一切 ZFC-高度都 > ω₁^z ≥ α（`71` 引理），所以"≥ α"的限制是空的。
- 所以此时汇合高度**只依赖于 c ⊕ d 的相对可构成度**，与原来的世界的高度 α 无关。

**推论 3**（无界性）：设 w = L_α 可数。对每个实数 z，有 w 上的 Cohen 实数 c、d，使 c ⊕ d ≥_T z。因此
> sup{ amh(w[c], w[d]) : c, d 在 w 上 Cohen } = ω₁。

*证明*：
- 取 c 在 L_α[z] 上 Cohen（L_α[z] 可数，这样的 c 存在），令 d := c XOR z。
- d 也在 w 上 Cohen：XOR 一个固定的实数是 Cohen 强迫的自同构，而这个自同构在 L_α[z] 中。
- c XOR d = z，所以 c ⊕ d ≥_T z。
- 由定理 1，amh ≥ zh(z)。而对任何可数序数 γ，取 z 编码一个序型为 γ 的良序，就有 zh(z) > ω₁^z > γ。∎

## 3. 读法

- `71` 说：世界层次上"差多少能汇合"是一个序数，不是 [0, 1] 中的数。现在它有了精确的形式：
  > **汇合高度 = 两个世界所含信息之和（c ⊕ d，连同 w 的参数 A）的第一个 ZFC-高度。**
- **障碍完全由信息之和决定**：
  - 两个世界各自都在高度 α 满足 ZFC；
  - 合起来的信息 c ⊕ d 可以编码 α 以上的良序，这时它们只能在 c ⊕ d 自己的 ZFC-高度处汇合。
- **jck 与 amh 的差距**：jck 只看可计算的良序（Π¹₁ 的信息）；amh 看的是"含有这些信息的最小 ZFC 宇宙"。
  - 例如对 z = 0，jck 是 ω₁^{CK}，而 amh 是最小的 ZFC 模型的高度 β₀，远在 ω₁^{CK} 之上（β₀ 之下有大量的可容许序数、稳定序数等）。
- **无界性（推论 3）**：
  - 同一个世界上的两个 Cohen 实数，各自都无害，合起来的代价却可以是任意大的可数序数。
  - 这是"世界层次的不能汇合是无穷的"（`71`）的精确形式：代价没有一致的界。
- **与上界的关系**：
  - 在有 Woodin 基数的丰富解释中，汇合总在迭代像的高度处发生（`95` 定理 2）；
  - 定理 1 说最小的汇合高度就是 zh；
  - 两者一致：迭代像包含 c ⊕ d，因而高于 zh。

## 4. 仍然开放的

1. **一般的世界**（夹逼见 `124 §2`）：若 w 不是 L_α[A] 的形式（例如不满足任何"V = L[A]"），定理 1 的（≥）方向仍给出 amh ≥ zh(c ⊕ d)。
   - 但包含整个 w 的模型可能需要更高：w 可能不是任何高度 ≥ α 的、含有 c、d 的模型的子集，除非它能被某个集合参数生成。
   - 精确值此时依赖于 w 的"可生成性"。
   - **猜想**：amh(w[c], w[d]) = min{ o(M) : M ⊇ w，c、d ∈ M，M ⊨ ZFC }，并且当 w 是某个 L_α[A] 的集合强迫扩张时，化为定理 1（由 Laver–Woodin 的基础模型可定义性）。
2. **ZFC-高度的结构**：zh(z) 作为 z 的函数（在相对可构成度上单调）的分布。这是经典的"间隙"理论的问题，不属于体系本身。

## 5. 已知的与这里的

**已知的**：
- 相对可构成性的绝对性；
- 内模型 L[A] 满足 ZFC；
- ω₁^z 与可容许序数；
- 对 Cohen 强迫的 XOR 自同构；
- Mostowski 型的不能汇合。
- 定理 1 本身是标准的论证。

**这里的**：
- 把 `71` 的汇合高度写成 ZFC-高度（定理 1）；
- 推论 2（与 α 无关的情形）；
- 推论 3（代价在 ω₁ 中无界）；
- 它在体系中的读法：障碍完全由信息之和决定。
