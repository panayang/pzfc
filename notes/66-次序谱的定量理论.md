# 66 · 次序谱的定量理论

> 第四十五轮，第二个问题（`64 §5` 第 2 条）。
>
> 形式化：`lean/Spectrum.lean`，13 条，不依赖 mathlib。

---

## 0. 路线检查

- **原则在推动的**：
  - 次序谱是行为的一个事实（`63 §3`）。
  - 这里要回答三个问题：
    - 它有多大？
    - 由什么决定？
    - 藏回去要付出多少？
- **会拉着走的**：
  - 自动机的状态数（Myhill–Nerode）；
  - 排列的计数与 Kendall 距离；
  - 信息论的熵。
  只用来度量，不引入新的对象。
- **四种情形**：只处理"之前问了什么"（次序）。"再问"在类之内允许改变；"谁问""同时问了什么"默认不变。

## 1. 设定

- 一个行为 b，一个历史 h，一组提问 l。
- **次序谱** Spec(b; h, l)：把 l 按各种次序问完之后，b 能变成的一切余下行为（`InSpectrum`）。
- 提问有类的映射 cls。**类间可交换**（`ClassCommute`）指：不同类的两次提问在未来上可交换。

## 2. 次序谱的指标集

**定理 1**（`spectrum_iff`、`realize_streams`、`residual_streams`）：设 b 类间可交换。
1. **此后的样子只依赖于每类之内的次序**：两个次序若在每类上的流相同，就留下相同的余下行为。
2. **每一组类内次序都能实现**：对 l 的每类部分各取一个重排 p_c，按 l 原来的日程读取这些重排，就得到 l 的一个重排，它的各类流恰好是 p_c。
3. 所以：
   - 次序谱恰好是"各类之内的重排组成的组"在映射 p ↦ residual(h ++ weave(cls(l), p)) 下的像；
   - 其中 weave 是 `65 §1` 定理 2 的读取。

**推论**：设 l 的 c 类部分有 N_c 种不同的排法（有重复的提问时，按多重集排列计数）。
- 一般地，|Spec(b; h, l)| ≤ ∏_c N_c。
- 若 l 中每个类至多出现一次，则次序谱只有一个成员（`spectrum_single_of_distinct`）。

## 3. 上界可以达到

- 定义**类历史行为**（`classHist`）：对每次提问，回答这一类到此为止的流。
- 性质：
  - 它类间可交换（`classHist_commute`）；
  - 它的余下行为决定每一类的流（`classHist_separates`）。
- 所以对它来说，不同的组给出不同的成员，|Spec| = ∏_c N_c。
- 结论：**定理 1 的界不能改进。**

## 4. 藏回去的代价

**定理 2**（`spectrum_states`）：实现 b 的任何模型，对次序谱的不同成员到达不同的状态。所以：

> 模型的状态数 ≥ 余下行为的个数 ≥ sup_{h,l} |Spec(b; h, l)|。

例子：
- 类历史行为只有一类、l 由 n 个不同的提问组成时，单是这一组提问，模型就需要 n! 个状态，即约 n·log₂ n 比特。
- 这就是"记住次序"的代价。

## 5. 随机的次序：次序熵

**定理 3**（由 `65 §1` 定理 2）：设 l 的次序在它的一切重排中均匀地随机选取（把重复的提问当作有标号的，逐次区分）。那么各类之内的次序是：
- **彼此独立**的；
- 每个都**均匀**分布。

*证明*：
- 由 `65` 定理 2，给定各类内次序的一个组 p，l 的具有这些流的重排，与"各类次数相符的日程"一一对应。
- 这样的日程的个数是多项式系数，与 p 无关。∎

**定义**：**次序熵** H(b; h, l) 是均匀随机次序下，余下行为（作为随机变量）的熵。

**推论**（b 类间可交换）：
1. 0 ≤ H ≤ log |Spec| ≤ Σ_c log N_c。
2. H = 0 当且仅当次序谱只有一个成员。
3. **可加性**：设 b 是**类分离**的，即 c 类的回答只依赖于 c 类的流（`65 §3`）。那么：
   - 余下行为与"各类的余下行为组成的组"一一对应；
   - 由定理 3，各分量彼此独立；
   - 所以 H(b; h, l) = Σ_c H(b_c; proj_c h, proj_c l)，其中 b_c 是 b 在 c 类上的部分。

   **次序敏感性在独立的类之间相加。**
4. 对只是类间可交换、并不类分离的行为，只有上界 H ≤ Σ_c log N_c。类历史行为达到这个上界。

## 6. 概率版本：次序敏感度

**设定**：
- 随机行为 (μ_l)，记号同 `65 §3`。
- 对 l 的两个重排 l₁、l₂，定义它们的**次序敏感度**

  δ(h; l₁, l₂) = sup_m d_TV(μ_{h l₁ m}, μ_{h l₂ m})，

  其中：
  - m 取遍一切后续提问序列；
  - 两边的回答按相同的提问一一对应之后再比较。
- 相邻两问的**交换缺陷**，是只对调这两问时的次序敏感度。

**定理 4**：
1. **三角不等式**：沿着任何一条由相邻交换组成的路，δ(h; l₁, l₂) ≤ 各步交换缺陷之和。
2. **按类的界**：设不同类的相邻交换缺陷为 0（迹可交换），同类的相邻交换缺陷不超过 ε。那么

   δ(h; l₁, l₂) ≤ ε · Σ_c τ_c(l₁, l₂)，

   其中 τ_c 是 l₁、l₂ 在 c 类上的流之间的 Kendall 距离，即次序相反的对的个数。

*证明*：
- 第 1 条：每一步交换改变的定律，在 m 上取上确界后，其和控制总的改变。
- 第 2 条，把 c 类流中一对相邻的元素对调，分两步：
  - 先用免费的交换把它们挪到相邻位置——二者之间只有其他类的字母；
  - 再做一次同类交换。
- 同类交换的总次数就是 Σ_c τ_c。∎

**读法**：
- 次序敏感度对"类之内的次序距离"是 Lipschitz 的，常数就是同类提问的交换缺陷。
- 它是 `63 §3`"次序谱落在余下行为之内"的定量形式。

## 7. 粗粒化

**定理 5**：对回答作任何粗粒化 f：
1. 可交换在粗粒化下保持（`futureCommute_coarse`）；
2. 次序谱只会变小：粗粒化之后的每个成员，都是原来某个成员的粗粒化（`spectrum_coarse`）。

**逆命题不成立**：
- 读取即更新的两格记忆依赖次序；
- 但忘掉回答的粗粒化处处可交换（`coarse_hides_order`）。

**读法**：
- 用一个与次序无关的指标去评价，看不出被评价者是否与次序无关。
- 反过来，指标若依赖次序，被评价者必定依赖次序。
- 这与 `53 §1`"可以随时重做的评价只看见终局"是同一类限度。

## 8. 读法：比较学习系统

对一个学习系统，把"用一批数据训练"当作提问，类就是可以交换次序的数据组（例如互不干扰的任务）。

| 量 | 意义 | 性质 |
|---|---|---|
| 次序谱的包含 | 一个系统能被次序带到的状态，是否包含另一个的 | 偏序，不压成一个数 |
| 次序熵 H | 随机打乱数据时，结果的不确定性 | 在类分离时按类相加；≤ Σ_c log N_c |
| 次序敏感度 δ | 两种次序给出的后续行为的最大差别 | ≤ ε · 类内的 Kendall 距离 |
| 状态数的下界 | 把次序依赖藏进一个状态要付出的代价 | ≥ |Spec| |

**要点**：只有同类数据的次序才起作用；不同的类（互不干扰的数据组）之间的次序是免费的，这是定理 1。

## 9. 已知的与这里的

**已知的，只作指导**：
- Myhill–Nerode：状态数 = 余下行为的个数；
- 排列的计数、Kendall 距离；
- 总变差距离的三角不等式。

**这里的**：
1. 次序谱的**精确指标集**（定理 1）：它是各类内重排组成的组的像，并且每一组都能实现。
2. **上界可以达到**（类历史行为）。
3. 随机次序下，**各类内的次序彼此独立**（定理 3）；由此，**次序熵对类分离的行为按类相加**。
4. **概率版本的按类的界**（定理 4）。

**如实的判断**：
- 每一条都初等。
- 价值在于：它们一起给出了次序依赖的一套度量——大小、熵、敏感度、代价——而且这套度量都只由"哪些提问可交换"与"类之内的交换缺陷"决定。
