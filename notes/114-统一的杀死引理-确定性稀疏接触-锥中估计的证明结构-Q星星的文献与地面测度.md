## 0. 路线检查

- **原则在推动的**：
  - 硬墙、软墙、随机窗口、确定性窗口，都只是"在包络之上以某个概率杀死"。把它们放进一个抽象的杀死机制，一个引理处理全部（§1）。
  - 锥的调和函数的误差对尺度可和（§2）。
- **会拉着走的**：Denisov–Wachtel 的方法；Mathias–Prikry 强迫的文献（Hrušák–Minami）。只作工具与核验。
- **结论先说**：
  1. **引理 S**（统一的杀死引理）：杀死机制满足两个尺度条件——上条件（KU）在尺度 ℓ，下条件（KL）在尺度 ℓ/C——就给出有界的块直径（§1.2）。
     - `113` 的软墙引理 A 是它的推论，对**任何**分布 F 成立（推论 A）。于是 `113` 定理 1（随机窗口几乎必然刚性）只依赖引理 S。
  2. **确定性的稀疏接触**：满足（KU）+（KL）的确定性窗口刚性（定理 2）。
     - 对振荡的例子 k(1 + ½|sin k^{0.7}|)，精确的有效层由零点处小数部分的分布决定。
     - 所以它化为一个数论问题：(nπ)^{10/7} 的小数部分在短区间中的等分布。
  3. **多链**：引理 W′ 的证明结构（§2）。
     - 锥的调和函数在 |y| ≥ A√g 处的相对误差是 (√g/|y|)³，对二进尺度可和；
     - 贴边的层用一维的 `97`；尖端附近是有限步；
     - 不需要 Denisov–Wachtel 的渐近结果，只用它的方法。
  4. **Q\*\***（§3）：
     - 文献中没有找到 M_F 与测度保持的直接结果（Hrušák–Minami 刻画的是加入最终不同实数与控制实数）；
     - 地面的 ν ∈ 𝒦 都不满足 Q_𝒦（命题 6），所以见证必须依赖 m。

## 1. 统一的杀死引理

### 1.1 设定

- 检查点链同 `97`，ω 是满足缓变假设 SV 的正则包络，W ≍ ω 在块上。
- 高度 h := D − ω_j（相对于包络）。
- **杀死机制**：在检查点 j，高度为 h 的路径以概率 κ_j(h) 被杀死。要求：
  - κ_j 对 h 不减；
  - h ≤ 0 时 κ_j = 0；
  - h > (Γ − 1)ω_j 时 κ_j = 1；
  - 底部 D < 1 处必然杀死。
- **实例**：
  - 确定性窗口 W_j ≥ ω_j：κ_j = 1{h > W_j − ω_j}；
  - 随机窗口的退火核：κ_j = F_j(h)（`113 §1.2`）。
- 核 M(x, y) = E_x[ ∏_j (1 − κ_j(h_j)) ; D_L = y ]，它是全正的。

### 1.2 两个尺度条件与引理 S

**（KU）**（尺度 ℓ）：对块中每个起点 s，以及每条在检查点 s, …, s + ⌈ℓ²/W⌉ 处高度都 ≥ ℓ 的路径，∏ (1 − κ_j(h_j)) ≤ 1 − c₀。

**（KL）**（尺度 ℓ′ = ℓ/C）：对块中每个起点 s，从高度 0 出发的自由游走满足
> E[ ∏_{j=s}^{s+⌈ℓ′²/W⌉} (1 − κ_j(h_j)) ] ≥ c₀。

**引理 S**：设 √W ≤ ℓ ≤ ηW，并且（KU）、（KL）在块及其时间倒转上成立。若 Θ ≥ Θ₀(Γ, C, c₀)，则 Δ(M_{块}) ≤ C′。C′ 只依赖于 SV 的常数、Γ、C、c₀、Θ。

*证明*：先用 `97` 引理 7 的分段倾斜使包络在共动坐标中静止（包络正则，似然比有界）。然后分四步。

**第 1 步（上界：包络之下深 δ 处）**：P_x(存活) ≤ C₁(δ + ℓ)/W · Λ，其中 Λ 是块的归一化（`97` 引理 8(b) 中的因子）。
- 取长为 ℓ²/(4W) 个检查点的段。在段起点高度 ≥ 2ℓ 的路径，以概率 ≥ p₁ 在整段中保持高度 ≥ ℓ（段内的涨落 ≲ ℓ/2）。由（KU），它在这一段内以概率 ≥ c₁ := c₀p₁ 被杀死。
- 在段起点处观察，得到一个步长 ≍ ℓ 的粗链。它每次位于 2ℓ 之上时，以 ≥ c₁ 的概率被杀死。
- 粗链在 2ℓ 之上的访问次数 N_n 满足反正弦律的界 P(N_n ≤ k) ≤ C√(k+1)/√n（起点在该水平时）。从深度 δ 出发时，另加"n 步内未到达"的概率 ≲ δ/(ℓ√n)。所以
  > P(存活 n 段) ≤ C(δ/ℓ + 1)/√n + Σ_k (1 − c₁)^k · C(√(k+1) − √k)/√n ≤ C(δ + ℓ)/(ℓ√n)。
- 换回检查点的单位（n ≍ TW/ℓ²），这就是硬墙位于 2ℓ 时的形式 C(δ + ℓ)/√(TW)。
- 加上底部的约束与块长，同 `97` 引理 8(b)，只是边界层 √g 换成 ℓ。

**第 2 步（下界：包络之下深 δ 处）**：P_x(存活，末端 ∈ S) ≥ c₂(δ + ℓ′)/W · Λ。
- δ ≥ ℓ′ 时：管放在包络之下，那里 κ = 0，同 `97` 的构造。
- δ < ℓ′ 时：
  - 由（KL），前 ⌈ℓ′²/W⌉ 个检查点的存活权重的期望 ≥ c₀；
  - 存活权重是路径的减函数，"末端深度 ≥ ℓ′"也是减事件。路径的分布是 MTP₂ 的，由 Harris–FKG 不等式，两者同时发生的权重 ≥ c₀ · c；
  - 此后从深度 ℓ′ 走管。

**第 3 步（包络之上高度 h > 0 处）**：令 τ 为首次到达高度 ≤ 0 的时刻，T₁ = ΘW²/2。
- **停在上方的部分**：在包络之上停留 T₁ 而存活，需要穿过约 ΘW²/ℓ² 个段而不被杀死（用第 1 步的机制）。所以 P_x(τ > T₁, 存活) ≤ e^{−c₃ΘW²/ℓ²}。
- **下来的部分**：
  - 在第一段之内直接下到包络之下的概率 ≥ e^{−C₄h²/ℓ²} ≥ e^{−C₄Γ²W²/ℓ²}；
  - 此后用第 2 步：P_x(τ ≤ T₁, 存活，末端 ∈ S) ≥ e^{−C₄Γ²W²/ℓ²} · c₂ℓ′/W · Λ。
- 取 Θ ≥ 2C₄Γ²/c₃ + (比较 ℓ′/W ≥ η′ 所需的常数)，停在上方的部分被下来的部分控制。于是：
  - P_x(存活) ≤ C·E_x[1{τ ≤ T₁，τ 时存活} · (ℓ + 越过量)/W] · Λ；
  - P_x(存活，末端 ∈ S) ≥ c·E_x[1{τ ≤ T₁，τ 时存活}] · ℓ′/W · Λ；
  - 越过量是 O(√W)，而 √W ≤ ℓ。

**第 4 步**：由第 1–3 步，对一切 x，进入比 ≥ c₂/(C·C₁)。
- 离开由倒转得到（假设在倒转上成立）；中段同 `97` 引理 10。
- 由三段夹逼，Δ ≤ C′。∎

**推论 A**（`113` 的软墙引理 A，对任何 F）：设 κ_j = F_j，F_j 不减，F_j(0) = 0。按
> (ℓ²/W)·F(ℓ) = A

定义 ℓ（若 F 有原子 p，则 ℓ = √(AW/p)）。则（KU）、（KL）成立，常数一致于 F 乘以 [¼, 1] 中的常数。

*证明*：
- **（KU）**：高度 ≥ ℓ 时 ∏(1 − F) ≤ exp(−(ℓ²/W)F(ℓ)) = e^{−A}。
- **（KL）**：由 Jensen，E∏(1 − F) ≥ exp(−E Σ F(h_j⁺))。自由游走在 ℓ′²/W 个检查点内的高度 ≲ ℓ′，而 F 不减，所以
  > E Σ F ≤ (ℓ′²/W)·F(ℓ′) ≤ (ℓ²/(C²W))·F(ℓ) = A/C²。
- 有原子时，ℓ′²/W < 1，（KL）是空的，下界回到 √g 的情形。∎

于是 `113` 定理 1（独立同分布的随机窗口几乎必然刚性）只依赖引理 S。

### 1.3 确定性的稀疏接触

**定理 2**：设确定性窗口满足 ω_j ≤ W_j ≤ Γω_j，并且在无穷多个块上，对某个 ℓ ∈ [√W, ηW]，下面两条成立：
- **（U）**：每 ⌈ℓ²/W⌉ 个相邻的检查点中，至少有一个满足 W_j ≤ ω_j + ℓ；
- **（KL）**：在尺度 ℓ/C 上成立（对块及其倒转）。

则刚性。

*证明*：（U）推出（KU）。高度 ≥ ℓ 的路径遇到 W_j ≤ ω_j + ℓ 的检查点时必然被杀死，所以 c₀ = 1。由引理 S 与 `109` 定理 6 得到结论。∎

- `112` 定理 2（凸包定理）是 ℓ = C√W 的情形：（KL）是空的。
- 定理 2 允许接触稀疏，只要"几乎接触"（在 ℓ 之内）的检查点足够稠密，并且从包络出发的路径不会在很短的时间内被大量杀死。

**振荡的例子** W_k = k(1 + ½|sin k^{0.7}|)：
- 零点 k₀(n) = (nπ)^{10/7}，间距 Z ≈ 4.5k^{0.3}。零点附近的超出量 ≈ 0.35k^{0.7}|k − k₀|。
- **粗的尺度**：ℓ ≍ W^{0.7} 时（U）成立（每个零点附近最近的检查点，超出量 ≤ 0.18W^{0.7}）。
  - 但在 ℓ/C 的尺度上，（KL）的时间内有 ≍ W^{0.1} 个零点，每个零点处可能以约 ½ 的概率被杀死，所以（KL）不在常数 C 下成立。
- **精确的层**：高度 u 的路径在一个零点处被杀死，当且仅当最近的检查点离 k₀ 小于 u/(0.35W^{0.7})。
  - 若小数部分 {k₀(n)} 等分布，杀死率就是 u/(0.18W^{0.7}) 每个零点，即每个检查点约 u/(0.8W)。
  - 这是线性软墙，ℓ ≍ W^{2/3}，与随机的情形相同。
- **所以这个例子化为**：{(nπ)^{10/7}} 在长度约 W^{0.033} 的 n-区间中的等分布（带差异界）。
  - 这是一个指数和的问题。它的区间太短，标准的 van der Corput 估计不直接适用。
  - 这里不再深入：它属于数论，不属于这套体系。

**判断**：
- 不规则窗口的刚性问题，现在精确地分成两部分：
  - 引理 S 覆盖的一切（包括一切随机窗口）；
  - 确定性窗口中"几乎接触的检查点的算术分布"。
- 后者是一个关于具体序列的数论问题，不是概率的缺口。

## 2. 多链：引理 W′ 的证明结构

记号同 `113 §2`：Y 是采样链，白化后第 k 步协方差为 g_k I（g_k ∈ [g/2, 2g]），三阶矩 ≤ Cg^{3/2}；锥 C 的开口为 α，p = π/α，h = r^p sin(pθ)。

**第 1 步（远离边与尖端时，近调和，误差可和）**：
- 在 { |y| ≥ A√g, d(y) ≥ A√g } 中，由 Taylor 展开与 Δh = 0：
  > |E h(y + ξ_k) − h(y)| ≤ C g^{3/2} |y|^{p−3} = C h(y) · (√g/|y|)³ / sin(pθ)。
- 再加上 d(y) ≥ A√g，即 sin(pθ) ≳ A√g/|y|，相对误差 ≤ C(√g/|y|)²/A。
- 在二进尺度 |y| ≍ 2^i√g 上，游走停留 ≍ 4^i 步。所以一个尺度上的累计相对误差 ≲ 4^i · (2^{−i})² · 2^{−i}/A ≲ 2^{−i}/A——这里用了修正函数 h̃ = h + O(g h |y|^{−2}) 吸收二阶项。
- 对 i 求和收敛。所以 h̃(Y) 在这个区域中是一个上下都差 (1 ± ε_A) 因子的鞅。

**第 2 步（贴边的层）**：在离边 < A√g、离尖端 ≥ A'√g 处，法向是一维的问题。
- 这是 `97` 引理 2–3 的情形（一维的检查点游走，步长不必同分布；`97` 处理的正是负二项步长随检查点改变的链）。
- 它给出：从离边 d 处出发，在被杀死之前到达离边 A√g 的概率 ≍ (d + √g)/(A√g)。

**第 3 步（尖端附近）**：在 |y| ≤ A′√g 中，有限多步内以正的概率离开到 |y| ≍ 2A′√g、θ 居中的位置。这只是有限维的局部极限定理。

**第 4 步（合起来）**：
- 从 x 出发，依次通过尖端的层、贴边的层、近调和区，每一步的概率都与 V 的相应因子同阶：
  - (|x| + √g)^{p−1} 来自近调和区；
  - (d + √g) 来自贴边的层。
- 由此得到引理 W′ 的第 1、2 条。第 3 条由 R² 尺度上 |Y|² 的上鞅与第 1 条得到。∎

**分级**：
- 结构完整，每一步的工具都已在体系中或是标准的。
- 没有写出的是第 1 步中修正函数 h̃ 的显式形式与常数的追踪。
- Denisov–Wachtel 的渐近结果不需要；只用"误差对尺度可和"这一点。

### 3.2 地面的测度不够

**命题 6**：若 ν ∈ 𝒦 ∩ v（地面的），则在 v[m] 中 H^v 是 ν-零测的。

*证明*：
- Σ_n ||ν_n||₂² < ∞，所以 ||ν_n||₂² → 0。
- 在 v 中，对大的 n 取 B_n 的二染色 χ_n，使 ν_n(χ_n = 0) ∈ [¼, ¾]。随机染色以正概率做到这一点（Hoeffding）。
- χ 在 v 中，所以对每个地面的 g，χ_n(g(n)) 沿 m 最终为常数（Mathias 实数的 Ramsey 性质）。
- 而在 ν 之下，沿 m 的这些颜色独立，并且每个颜色的概率都 ≥ ¼。所以"最终为常数"是 ν-零测的。∎

**读法**：Q_𝒦 的见证必须依赖 m。命题 5 又排除了"由 m 的有界元组定出支撑"的一类。剩下的只有依赖 m 的整个前段、元数无界的构造。
