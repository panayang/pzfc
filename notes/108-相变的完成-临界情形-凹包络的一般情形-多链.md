# 108 · 相变的完成：临界情形、一切凹包络、多链

> 第五十六轮，第二块（`98 §7` 与 `64 §2.3` 的剩余问题；`73` 的猜想）。
>
> **范围**：概率论（过程层）。

## 0. 路线检查

- **原则在推动的**：隐藏参数由迹的渐近几何决定（`73`）；相变在 ρ 上（`83`、`97`、`98`）。这里把"正则"这个限定尽量去掉。
- **会拉着走的**：凹函数的切线截距、Borel–Cantelli；多维随机游走的 Martin 边界（只作指导）。
- **结论先说**：
  1. **临界情形闭合**：`98` 的"严格凹"不需要。只要窗口有凹的包络，就足够（定理 1）。
  2. **一切凹包络**：对任何有凹包络（误差 O(√W)）的窗口，**刚性 ⟺ ρ → 0**（定理 2）。
     - 包括窗口平方与时间之比 W²/P 振荡的情形：只要它的下极限有限，就有无穷多个缓变的块。
  3. **多链**：
     - 比率层面的相变推广到任何连通的同步图（定理 3、4）；
     - 完全的刚性化为一个 (m−1) 维被杀死的游走，三段夹逼对维数不敏感；
     - 剩下的只是多面体窗口中的边界估计（§4）。
  4. **仍然开放的**：
     - 没有凹包络的不规则窗口（窗口在包络附近大幅跳动）；
     - 多链的边界估计。

## 1. 临界情形：不需要严格凹

**设定**：ω : [0, ∞) → [1, ∞) 不减、凹、倍增有界，|W_ℓ − ω(P_ℓ)| ≤ C₀√W_ℓ。令
> ρ(P) = ω(P)/P，b(P) = ω(P) − P ω′(P)（切线在 0 处的截距）。

凹性给出：
- b 不减，并且 b ≥ 0；
- ρ 不增，ρ′(P) = −b(P)/P²；
- 于是 ρ 收敛。若 ρ → 0，则 ρ(P) = ∫_P^∞ b(s)/s² ds。

**引理 1**（好的尺度）：设 ρ → 0 且 ω(P)/√P → ∞。则对每个 A，有任意大的 i，使
> b(2^{i−1}) ≥ A · 2^{i/2}，并且 b(2^i) ≤ 2 b(2^{i−1})（这一步 b 不倍增）。

*证明*：
1. **b/√P 无界**。若对 s ≥ s₀ 有 b(s) ≤ A√s，则 ρ(P) ≤ ∫_P^∞ A s^{−3/2} ds = 2A/√P，与 ω/√P → ∞ 矛盾。
2. **找到大的起点**。由第 1 步与 b 不减，有任意大的 i₀，使 b(2^{i₀}) ≥ 4A · 2^{i₀/2}。
3. **倍增必须停止**。若从 i₀ 起 b 每一步都倍增，则 b(2^i) ≥ 2^{i−i₀} b(2^{i₀})，与 b ≤ ω = o(P) 矛盾。设 i* > i₀ 是第一个不倍增的指标。
4. **检验 i***。b(2^{i*−1}) ≥ 2^{i*−1−i₀} · 4A · 2^{i₀/2} ≥ A · 2^{i*/2}。∎

**定理 1**（宽窗口，无严格凹）：设窗口有凹包络 ω（倍增有界、误差 O(√W)），ω/√P → ∞，ρ → 0。则相应的堆刚性。

*证明*：沿用 `98` 的全部结构，只改块的取法与引理 16、17 中用到严格凹的三处。
1. **先取终层 L，再取起层 K**。
   - 取 A 大，由引理 1 得好的指标 i：β := b(2^{i−1}) ≥ A·2^{i/2}，并且 b(2^i) ≤ 2β。
   - 取 P_L 为区间 [(2/3)·2^i, 2^i] 中的一个检查点：间隔 W_L ≪ P_L，所以存在。
   - 取 K 使 W_K ≈ 1/(6ρ_L)：窗口连续增长，相邻比趋于 1，所以这样的 K 存在。
   - 由 ω/√P → ∞，P_K ≲ 1/ρ_L² ≪ P_L，ΘW_K² ≪ P_L。所以 m_L = (W_L − W_K/2)/(P_L − P_{m₁}) ∈ [1/(8W_K), 1/(4W_K)]，t ≈ P_L。
2. **相对漂移的下界**（代替 `98 §5.2` 的 c_v m）。记 P = P_L。对 τ ∈ [0, P/4]，令 Q = P − τ ∈ [3P/4, P]。于是 2^{i−1} ≤ Q ≤ P ≤ 2^i，从而 b(Q) ≥ β，b(P) ≤ 2β。
   - 由 ρ′ = −b/P²：
     > ρ(P) − ρ(Q) = −∫_Q^P b(s)/s² ds ≥ −2β (1/Q − 1/P)。
   - 由 ω′(Q) = ρ(Q) − b(Q)/Q：
     > v(τ) = m − ω′(Q) = [ρ(P) − ρ(Q)] + b(Q)/Q + (m − ρ(P))
     > ≥ β (2/P − 1/Q) − |m − ρ(P)| ≥ (2/3) β/P − |m − ρ(P)|。
   - 误差：|m − ρ(P)| ≲ √W_L/P_L + 1/W_L ≪ 1/√P_L，因为 W_L ≫ √P_L，而 √(W_L/P_L) = √ρ_L → 0。
   - 所以 v(τ) ≥ β/(2P) =: v₀ ≥ A·2^{i/2}/(2P) ≥ A/(2√P)。
3. **相对漂移的上界**：ω′ 不增，所以 v(τ) ≤ v(0) = b(P)/P + (m − ρ(P)) ≤ 2β/P + o(v₀) ≤ 5 v₀。
   - 所以 `98` 引理 16 中的"慢后退"判别，以及似然比的界，都只需要 v_max ≤ 5v₀；
   - 层时间 τ₁ = A₁/v₀² ≤ 4A₁P/A² ≪ P/4（A² ≫ A₁）。
   - 层内的常数 Σ gΛ(λ′) ≤ τ₁ v_max² ≤ 25 A₁。这也更正了 `98` 原文中"≤ τ₁ m²"的写法：应当用 v，而不是 m。
4. **引理 17 中上界的间隔**（取 `98` 中的 ε = 1/4）：在 P_L − t/4 处，上界与平均路径的距离 ≥ ∫_{P_L−t/4}^{P_L} (m − ω′) ≥ v₀ t/4 ≥ A√t/8。更早的时刻由凹性更大。A 大时，这就是所需的 A′√t。
- 其余步骤（行的 Holley 与全正性、中段、角点公式）不用严格凹，不变。∎

**所以**：`98 §7` 的临界情形（例如 ω(P) ≍ P/log P）是刚性的。
- 此时 b(P) = P/log²P，好的尺度处处都是。
- 相对漂移 ≍ 1/log²P，层时间 ≍ log⁴P，远小于 P。

## 2. 一切凹包络

**定理 2**：设窗口有凹包络 ω（不减、倍增有界、|W_ℓ − ω(P_ℓ)| ≤ C₀√W_ℓ）。则
> 刚性 ⟺ ρ → 0。

凹性保证 ρ 单调，从而收敛；所以二分是穷尽的。

*证明*：
- **(⟸)** 分两种情形：
  - **liminf ω(P)²/P < ∞**：取 P 使 ω(P)² ≤ C P。在 X-时间 [P, (1 + ΘC)P] 这一块上：
    - 凹性给出 ω′(Q) ≤ ω(Q)/Q，所以 ω′(Q) ω(Q) ≤ ω(Q)²/Q ≤ C₀² C′（倍增有界）；
    - 这正是 `97` 的假设 SV 在这一块上的形式；而 `97` 的证明只用到一个块上的性质（引理 7–10 都是局部的）。
    - 这样的块有无穷多个，由 `78` 推论，刚性。
  - **ω(P)²/P → ∞**：定理 1。
- **(⟹)** liminf ρ > 0 时不刚性（`83` 定理 1，对任何窗口成立）。∎

**推论**：凡是由光滑的增长率给出的同步——多项式、对数修正、振荡的对数修正，只要包络是凹的——相变都恰在 ρ → 0 处。

**仍然开放的（不规则的窗口）**：
- 没有误差 O(√W) 的凹包络的窗口。例如在一个包络的常数倍之内随机地跳动（W_ℓ ∈ [ω, 2ω]），或者在大多数层上很小、在稀疏的层上很大。
- 困难只在上界：
  - 下界的估计（`97` 引理 3，`98` 的 Holley 与全正性）对任何窗口都成立；
  - 上界跳动时，`97` 的倾斜不能把它变成近乎固定的。
- 一个有用的观察：窗口为 1 的层是完全切口，于是这样的层无穷多时刚性（`69`）。有界的窗口无穷多次出现时，猜想刚性：瓶颈处的状态只有有限多个。但一般的证明需要瓶颈之间的"起点边界 Harnack"估计，没有写出。

## 3. 多链：比率层面的相变

**设定**（推广 `73`）：
- 堆分解为 m 条链 L₁, …, L_m；
- 同步由链之间的检查点给出：对链对 (a, b)，有一列检查点，要求在第 k 个检查点处，两条链的位置差 D^{ab}_k 落在一个窗口 [α^{ab}_k, β^{ab}_k] 中，窗口宽度记作 W^{ab}_k；
- **同步图**：以链为顶点，有无穷多个检查点的链对为边；
- 对每条边令 ρ^{ab}_k = W^{ab}_k / P^{ab}_k（窗口与已过的时间之比）。

**定理 3**（比率的唯一性）：设同步图连通，并且对每条边，liminf_k ρ^{ab}_k = 0。则每个中心的穷尽线性化的渐近比率（若存在）是 (1/m, …, 1/m)，即一切链以同样的速率推进。所以 R(τ) 至多一点。

*证明*：
- 对边 (a, b)，沿使 ρ^{ab} → 0 的检查点，位置差 = o(时间)，所以两条链的比例之差趋于 0。
- 图连通，所以一切比例相等。∎

**定理 4**（尺度不变时的比率多面体）：对每条边 (a, b)，设 liminf ρ^{ab} > 0，并且检查点的几何给出 a、b 的推进速度之比 λ^{ab} = r_a/r_b 的可行开区间 (ℓ^{ab}, u^{ab})，ℓ^{ab} < u^{ab}（同 `83` 定理 1 的第 1、2 步）。令
> Π = { r ∈ 单纯形的内部 : 对每条边，r_a / r_b ∈ (ℓ^{ab}, u^{ab}) }。

若 Π 非空，则 Π ⊆ S(τ)：Π 中每个比率都存活，并给出一个不同的极端中心线性化。所以 Π 的维数 ≥ 1 时不刚性，隐藏比率组成一个开多面体。

*证明*：
- 对 r ∈ Π，独立同分布的 r-日程在每条边的检查点处，余量都是线性的（区间是开的），而涨落是 √n 量级。检查点按几何级数分布（liminf ρ > 0）。
- 由 Borel–Cantelli，违反任何一个约束的次数几乎必然有限。边只有有限多条，所以永不被阻塞的概率为正。
- 由 `73` 定理 1 得到结论。∎

**读法**：
- 多链时，隐藏参数的个数 = 比率多面体 Π 的维数。它由尺度不变的同步边（liminf ρ > 0）的数目与它们的可行区间决定。
- 稠密同步的边（ρ → 0）把两端的链"焊"在一起，使比率相等（定理 3）；稀疏同步的边只把比率限制在一个区间里。
- **更一般的陈述**（定理 3 与 4 合起来）：
  - 把 ρ → 0 的边收缩，得到商图；
  - Π 是商图上由尺度不变的边给出的开多面体；
  - 隐藏比率的维数 = dim Π。

## 4. 多链的刚性：化到一个多维的边界问题

**化约**：
- 取一棵同步图的生成树，以树边上的位置差 D = (D^{e})_{e ∈ 树} ∈ ℤ^{m−1} 为状态。它是 X-时间中的独立同分布游走，协方差非退化，只在检查点处受约束：落在一个多面体窗口中。
- 中心线性化 ⟺ 这个被杀死的 (m−1) 维游走的正时空调和函数（同 `93` 定理 1）。

**已经对维数不敏感的部分**：
1. **判据**：`78` 定理 2（刚性 ⟺ Birkhoff 直径 → 0）与 `97` 引理 6（三段夹逼）都是关于非负矩阵的一般事实。
2. **中段**：`97` 引理 4、5（钉住终点的局部下界、沿直线的管）在 ℤ^{m−1} 中逐字成立：d 维的局部极限定理给出点概率 ≍ t^{−(m−1)/2}，Kolmogorov 不等式逐坐标使用。

**剩下的**：进入与离开（`97` 引理 8、9）的多维形式。
- 需要的是：在一个缓慢移动的多面体中被检查点杀死的游走，从任何起点出发、在存活的条件下，以正的比例进入内部。
- 一维时用的是：
  - 只在检查点监视的破产上界（`97` 引理 3）；
  - 移动的上界用倾斜处理（`97` 引理 7）；
  - 或者用全正性与 Holley（`98`）。
- 多维时：
  - **全正性不可用**：差之间共享链，增量负相关，联合核不是 MTP₂。
  - **破产上界可以逐面推广**：多面体的每个面是一个一维的约束。
  - **缺的是角落**：几个面相交处的"锥中存活"估计（Denisov–Wachtel 型的锥中游走的局部极限定理，其指数由锥的角度决定）。
- **判断**：
  - 当各条边的窗口尺度分离（一条边的窗口远大于另一条边的扩散尺度），角落退化为一维的问题，证明可以逐边进行；
  - 一般的尺度相当的情形需要锥中游走的估计，没有写出。

**关于 `73` 的猜想**（刚性 ⟺ |S(τ)| ≤ 1）：
- 两条链、窗口有凹包络：成立（定理 2 与 `83`）。
  - 此时 S(τ) 要么是空集（ρ → 0，刚性），要么是一个开区间（liminf ρ > 0，不刚性），从不恰是一点。
- 多链："|S| ≥ 2 ⟹ 不刚性"对一切堆成立（`73` 定理 1）。反方向化为本节的多维边界问题。
