## 0. 路线检查

- **原则在推动的**：
  - 消灭的层次（`107`）；
  - 隐藏参数由迹的渐近几何决定（`73`、`108`）。
- **会拉着走的**：Mathias 实数的 Ramsey 性质、Laver 性质、Birkhoff 收缩。只作工具。
- **结论先说**：
  1. **Q\*\***：化为一类实数。
     - v[r] 的实数按 Mathias 实数 m 分成"常数型"与"相异型"。常数型的全部零测（定理 1）。
     - 任何以地面函数为界的小集合，连地面实数都覆盖不了（定理 2）。所以覆盖必须用"快速"的区间。
     - Q\*\* ⟺ 相异型的实数不能被快速的小集合覆盖。开放。
  2. **多链**：三条链的路状同步有一个精确的分解。在尺度强分离时，由它化回两个一维问题并证明刚性（定理 3、4）。尺度相当时剩下 60° 角的边界估计。
  3. **不规则窗口**：一步核的直径有显式的公式，得到一个不需要任何包络的收缩判据（定理 5）。与局部正则的块合起来给出统一的充分条件（定理 6）。

## 1. Q\*\*：化为相异型的实数

设定同 `107 §3`：m 在 v 上 Mathias，r 在 v[m] 上随机，w = v[r]，w′ = v[m][r]。

### 1.1 常数型与相异型

对 x ∈ ℝ^{v[r]}，由 `107` 定理 1′ 的证明，x = f(r)，其中 f 是 v 中的 Borel 函数，在含 r 的紧集 K ∈ v 上连续。令 φ_n(s) := f(s)(n)（s ∈ K），它是 K 上的连续函数（在 v 中）。

在 v 中定义二染色：{i, j} 着色 1，当且仅当 φ_i = φ_j（在 K 上作为函数相等）。Mathias 实数对地面的二染色最终齐一（Ramsey 性质，已知），所以只有两种情形：
- **常数型**：对 m 中足够大的 i < j，φ_i = φ_j；
- **相异型**：对 m 中足够大的 i < j，φ_i ≠ φ_j。

**定理 1**：常数型的实数都在 EvConst(m) 中，因而全体零测。

*证明*：
- 常数型时，沿 m 最终 φ_{m_i} = φ，所以 f(r)(m_i) = φ(r) 是同一个比特。
- 这就是 f(r) 沿 m 最终为常数：f(r) ∈ EvConst(m)。它零测（`70` 定理 1，`Kill.lean`）。∎

所以：
> **Q\*\* ⟺ 相异型的实数（在 v[m][r] 中）不零测。**

- r 本身是相异型（φ_n(s) = s(n)）；
- 一切"沿 m 读出的独立比特"也是相异型，例如 r∘h（h ∈ v 单射）。

### 1.2 以地面函数为界的覆盖连地面实数都覆盖不了

标准形式（Bartoszyński）：每个零测集都包含于形如
> Σ(I, J) = { x : 有无穷多个 n，使 x↾I_n ∈ J_n }

的集合的并中，其中 I_n 是不交的区间，J_n ⊆ 2^{I_n}，并且可以要求 μ(J_n) ≤ 2^{−n}（合并相邻区间，取并集，即可做到）。

**定理 2**：设 (I_n, J_n) ∈ v[m][r]，μ(J_n) ≤ 2^{−n}，并且有 g ∈ v 使 I_n ⊆ [0, g(n))。则有 σ ∈ ℝ^v，σ ∉ Σ(I, J)。

*证明*：
1. **块与分布**。取 a_k = 3k。第 k 块的数据 D_k := (I_n, J_n)_{n ∈ [a_k, a_{k+1})}，它以 g 为界，是有限的对象。它是 r 的函数（给定 m），令 p_k 为它在 r′ ∈ P 上的分布，取整到有限的网格。p_k ∈ v[m]，以 v 中的函数为界。
2. **Laver 性质**：有 v 中的槽 S_k，|S_k| ≤ 2^k，p_k ∈ S_k。只保留"合法"的候选：它们给出的 J_n 满足 μ(J_n) ≤ 2^{−n}。
3. **在 v 中选 σ**。对均匀的 σ 与任一合法候选 p′，块 k 中命中次数的期望 ≤ Σ_{n ≥ a_k} 2^{−n} ≤ 2^{1−3k}。
   - 由 Markov 不等式与对 2^k 个候选的并，"某个候选的期望命中 > 2^{−k}"的概率 ≤ 2^{2k} · 2^{1−3k} = 2^{1−k}，可以求和。
   - 所以在 v 中有 σ，使对大的 k，一切候选的期望命中 ≤ 2^{−k}。
4. **结论**。真正的 p_k 是候选之一，所以 Σ_k E[块 k 中的命中] < ∞。"命中无穷多次"的 r′ 组成一个编码在 v[m] 中的零测集，r 避开它。∎

**推论**：
- v[m][r] 中覆盖 ℝ^v（更不用说 ℝ^{v[r]}）的零测集，必须用到**不以任何地面函数为界**的区间。
- EvConst(m) 正是这样的：它的区间由控制实数 m 给出。

### 1.3 剩下的问题

**Q\*\*（精确形式）**：是否有 v[m][r] 中的小集合 Σ(I, J)，区间快速（不以地面函数为界），覆盖一切相异型的 f(r)？

- **覆盖相异型实数的困难**：
  - 在快速的区间上与 f(r) 一致，需要知道 f 在那些位置上的表；
  - 相异型的表沿 m 两两不同；
  - Mathias 实数只能在沿 m 最终齐一的地方压缩地面信息（Ramsey），而相异型恰好是不齐一的那一边。
- **可能的方向**：
  - 对更高阶的染色（关于 j 元组的联合分布）用 Ramsey 性质，可知沿 m 的比特 f(r)(m_i) 的有限维联合分布最终与位置无关：一个渐近可交换的结构。
  - 由 de Finetti，它是独立同分布的混合。若混合参数不退化，这些比特"不可预测"，可能由此证明 Q\*\*。
  - 这一步没有完成。

## 2. 多链：路状同步的精确分解与尺度分离

**设定**：三条链 L₁、L₂、L₃，同步图是路 1 – 2 – 3。边 e₁ = (1,2) 的检查点处要求 D¹ = i₁ − i₂ ∈ 窗口₁，边 e₂ = (2,3) 的检查点处要求 D² = i₂ − i₃ ∈ 窗口₂。自由的过程每步以 ⅓ 的概率推进每条链。

**引理 3**（精确分解）：
- 令"是否推进链 1"的序列为 A（独立同分布的 Bernoulli(⅓)），令非 1 的步中"推进 2 还是 3"的序列为 B（独立的公平硬币）。A 与 B 独立。
- 令 U := i₁ − (i₂ + i₃)/2，它只依赖于 A；D² 作为"合并计数"（非 1 的步数）的函数，只依赖于 B。
- 并且 D¹ = U − D²/2。

*证明*：
- 三项分布等于"先分出链 1，再在其余中分 2 与 3"，所以 A 与 B 独立。
- 恒等式 i₁ − i₂ = [i₁ − (i₂ + i₃)/2] − (i₂ − i₃)/2 直接验证。∎

**读法**：
- 给定 (2,3) 的过程（即 B），边 e₁ 的约束是关于一维过程 U 的约束，障碍被 D²/2 扰动。
- U 相对于"合并"的时钟，正是 `97` 中的两链游走。

**定理 3**（尺度强分离下的刚性）：设在无穷多个块上：
1. 边 e₁ 的窗口满足 `97` 的缓变假设（窗口 ≍ W¹，块长 ΘW¹²）；
2. 边 e₂ 的窗口与检查点间隔都 ≤ C√W¹；
3. 边 e₂ 本身刚性，并且块内含有它的好块（例如它的窗口有凹包络且 ρ → 0，`108` 定理 2）。

则三链的堆刚性。

*证明*：设 M 为联合检查点链在一个块上的核。
1. **条件于 B**。
   - 由引理 3，给定 B，e₁ 的约束是 U 在一个被 D²/2 扰动的窗口中。
   - 在 e₁ 的检查点处，D² 被 e₂ 最近的检查点约束在 [1, W²] 中，再加上 ≤ C√W¹ 步的自由游走的偏离。
   - 所以除一个概率 ≤ ΘW¹ · exp(−c A² √W¹) 的事件外，扰动 ≤ A√W¹。这个概率远小于 `97` 中存活概率的量级 √W¹/W¹，可以并入误差。
2. **一维的估计一致成立**。
   - `97` 的引理 3–10 对障碍摆动 O(√W) 一致成立，而且给出的上下界是显式的：进入的存活 ≍ e(d¹) := (dist(d¹) + √W¹)/(√Θ W¹)，中段的点概率 ≍ 1/W¹。
   - 所以对每个给定的 B，U 部分的条件核满足 K₁(d¹, u¹ | B) ≍ e(d¹) e(u¹) Λ₁，常数与 B 无关。
3. **D² 部分**。
   - D² 在块上的核 K₂ 是边 e₂ 的核之积。块内含有 e₂ 的好块，直径 ≤ C*，并且 Δ(AB) ≤ Δ(B)，所以 Δ(K₂) ≤ C*。
   - 于是 K₂(d², u²) ≍ a₂(d²) b₂(u²) Λ₂，畸变 ≤ e^{C*}。
4. **合起来**：M((d¹,d²), (u¹,u²)) = E_B[ K₁(d¹, u¹ | B) ; D² 从 d² 到 u² ] ≍ e(d¹) e(u¹) Λ₁ · K₂(d², u²)。
   - 所以 M 在有界畸变内是乘积形式，交叉比有界。
   - 由 `78` 定理 2 与推论（它们对任何非负矩阵成立），刚性。∎

**定理 4**（路状多链的层级分离）：对 m 条链的路 L₁ – L₂ – ⋯ – L_m，若在无穷多个块上，各边的窗口按层级强分离（W^{(i+1)} ≤ C √W^{(i)}），并且每条边都满足定理 3 中相应的条件，则刚性。
- 证明是定理 3 的递归：每次分出一端的链，其余合并。树状的同步图同理：逐次分出叶子。

**剩下的（尺度相当）**：
- 若 W² 与 W¹ 同阶，扰动 D²/2 与窗口同阶，第 1 步失效。
- 此时 (D¹, D²) 是一个协方差为 [[⅔, −⅓], [−⅓, ⅔]] 的二维游走，窗口是一个矩形。去相关之后，矩形的角是 **60°** 的楔形：路状同步中，两条差共享中间的链。
  - 星状同步中角是 120°。
- 需要的是 60°（或 120°）楔形中被检查点杀死的游走的进入估计（边界 Harnack 型），没有写出。

## 3. 不规则窗口：一步直径与收缩判据

**一步直径**（`94` 定理 1 用于单个核 q_k）：
> Δ_k := Δ(q_k) = log [ p(W_k) · p(W_{k+1}) / ( p(1) · p(W_k + W_{k+1} − 1) ) ]，

其中 p 是负二项(W_{k+1}, ½) 的概率质量函数（由全正性，直径就是四个角点的交叉比）。

数值：

| (W_k, W_{k+1}) | (1, 任意) | (2, 2) | (2, 100) | (2, 10⁴) | (4, 4) | (8, 8) | (16, 16) | (32, 32) | (64, 64) | (128, 128) |
|---|---|---|---|---|---|---|---|---|---|---|
| Δ_k | 0 | 0.12 | 3.24 | 7.82 | 0.94 | 3.41 | 9.31 | 22.1 | 48.7 | 102.9 |

- 窗口为 1 时直径为 0：完全切口。
- 两个窗口都等于 W 时，Δ_k ≈ 0.8W。
- 小窗口后面跟一个大窗口 W′ 时，Δ_k ≍ log W′。

**定理 5**（一步收缩判据）：若
> Σ_k exp(−Δ_k / 2) = ∞，

则堆刚性，对任何窗口序列都成立。

*证明*：
- Birkhoff 的收缩不等式：tanh(Δ(AB)/4) ≤ tanh(Δ(A)/4) · tanh(Δ(B)/4)。
- 所以 tanh(Δ(M_{K→L})/4) ≤ ∏_{k=K}^{L−1} tanh(Δ_k/4)。
- 而 1 − tanh(x/4) ≥ e^{−x/2}（x ≥ 0），所以 Σ_k (1 − tanh(Δ_k/4)) = ∞，乘积趋于 0。由 `78` 定理 2，刚性。∎

**推论**：
1. 相邻两个窗口都 ≤ B 的层无穷多次出现（"双瓶颈"）时，刚性：这些层的 Δ_k ≤ C(B)。
2. 若对无穷多个 k 有 max(W_k, W_{k+1}) ≤ c log k（c 足够小，使 e^{−Δ_k/2} ≥ 1/k），则刚性。窗口可以在其余各处任意大、任意不规则。

**定理 6**（统一的充分条件）：若存在互不重叠的层区间 [K_j, L_j)，使
> Σ_j exp(−Δ(M_{K_j → L_j}) / 2) = ∞，

则刚性。
- 这些区间可以是单步（定理 5）、`97` 的缓变块、`98`/`108` 的宽窗口块，或它们的混合。
- 证明同定理 5。

**读法**：
- 不规则的窗口只要在足够多的地方"局部地"可以控制——要么窗口小（瓶颈），要么在一段上有凹包络——就刚性。
- **仍然开放的**：
  - 窗口处处大、并且在任何一段上都没有凹包络的情形，例如在 [ω, 2ω] 中无规律地跳动，而且 ρ → 0；
  - 此时上界的跳动是唯一的障碍（`108 §2`）。
- **猜想**：刚性对窗口是单调的：缩小窗口不产生新的隐藏参数。若成立，一切 ρ → 0 的窗口（在某个凹包络之下）都刚性。

|---|---|---|
