# 46 · 回到墙：工具的困境是这样的吗？够不够？盲区在哪里

> **第三十轮注**：§9 的第 1、2 步已在 `47` 中做了确定性的情形：四种提问情形的定义与独立性，藏回去的代价，任务与预测。

> 你的问题：回到原本的目标和那几堵墙本身。深层的数学工具困境是我们说的这样吗？我们给出的工具够用吗，还是又有盲区？极其仔细地想一遍再推进。
>
> 本篇以思考为主。形式化只有一个小例子：`lean/Records.lean` §7，3 条。

---

## 0. 路线检查（自检清单第 17 条）

- 第二十五到二十八轮一直在一个诊断上推进："一切回答都是记录"。这一轮不先推进，先检查这个诊断本身。
- 检查的办法：逐堵墙问——**它缺的究竟是什么数学工具**；再拿我们的工具去对。

## 1. 逐堵墙：真正缺的是什么

### 1.1 ML：放弃自回归与 reward 之后，没有指标

博客里的系统是"时间感知的、非自回归的、无 reward 的记忆组织架构"。它的几个特征，逐个问缺什么：

- **读取即更新。** 系统被问一次，自己就变了。经典的数学能表示它：把"至今的全部历史"当作隐藏状态，下一个回答就是这个状态的函数。**但这样一表示，它就被写成了"由过去预测下一刻"的形式——正是被放弃的自回归。** 表示能力不缺，缺的是一种不把它写成预测的描述方式。
- **时间感知而非自回归。** 时间在这里是**内容**（记忆项之间的先后、间隔、节律），不是**下标**（第几步的预测）。经典工具里，时间几乎总是下标。
- **评价。** 要可信，就得有一个大家都能重复得到的结果；惯例上这被等同于一个标量。第 1 轮已经看到了这一点的一半（`00 §3`）：读取即更新时，所有时刻的观测不在同一个语境里，单一的全局评价没有依据。
- **任务。** 数学里的"任务"几乎只有三种：计算一个函数、预测、优化一个量。"组织记忆"不是其中任何一种。

### 1.2 物理：理论与实验的循环；要预测什么

- **循环**：触发器由理论决定哪些事件被记下，理论又由被记下的数据启发。**哪些记录被做出来，取决于提问者（理论）。** 数据不是"发生过的一切"的中立总记录，而是提问者做出来的记录。
- **关系主义**：状态相对于观察者；不同观察者的记录未必能合成一份公共的记录。
- **要预测什么**：经典工具只有"一个全局状态随时间演化"这一种形式。

### 1.3 Kolmogorov、ZFC、图灵

- **Kolmogorov**：
  - 一个 Ω 记下一切，这是公共、不被扰动、可重复的总记录；
  - 时间通过"信息沿一条线增长"（过滤）进入；
  - 预测就是"给定过去，下一刻的条件期望"。
- **ZFC**：
  - 集合是公共的、不变的完成记录；
  - 一切命题在唯一的宇宙里有定值；
  - 选择公理：一切选取都能一起记下。
- **图灵**：纸带是公共的、只因机器自己的一步而改变的记录；计算就是从输入到输出的函数。

### 1.4 四个倾向

线性时间、绝对因果、还原论、目标拟合，合起来是"对下一时刻作出预测"。**博客还有一句我们没有细读："不断细化、更精确地"预测**——细化到底，就能得到确定的个体回答，这本身也是信念的一部分。

## 2. 拿我们的工具去对

| 墙缺的东西 | 我们的工具 | 覆盖 |
|---|---|---|
| 不以全局样本空间为前提的概率 | 来源、可以问的问题、来源的记录（`43`、`44`） | 有 |
| 不可测、选择、CH 的来源 | 可以问 = 可测；(C) 分阶段会用完；T₁（`43`、`44`） | 有（数学一侧） |
| 整体不由部分决定 | 耦合；关系可以是记录而两端不是（`45 §3`） | 有，静态的 |
| 局部与整体何时粘得起来 | GLU = 跨语境的记录（`43 §1`）；两种失败（`45 §2`） | 部分：只对规律固定的情形 |
| **读取即更新** | 无。来源的规律是固定的，被问不会改变它 | **没有** |
| **记录是谁的**（观察者、提问者） | 无。一切记录默认是公共的 | **没有** |
| **提问者本身在系统之内** | 无 | **没有** |
| **任务不是预测** | "事实 = 必然的问题"（`45 §3`）是一个种子 | 几乎没有 |
| **时间作为内容** | "关系可以是记录"是一个种子 | 几乎没有 |
| 不以标量评价 | 尺寸不止一把尺子（`42 §8`）；关系是记录 | 部分 |

结论先说：**不够。** 我们只处理了墙的一个方面，而对 ML 与物理两堵墙来说，这恰恰不是最要紧的方面。

## 3. 诊断要修正：记录是在一切提问情形下都不变的回答

`42 §2` 只问了一个问题："再问一次，会得到什么？"。其实一次提问总有它的**情形**，至少有四种：

| 情形 | 回答在这个情形下不变，就是 |
|---|---|
| **再问**：同一个问题再问一次 | 可复读 |
| **谁问**：换一个提问者 | 公共的 |
| **之前问了什么**：提问的历史不同 | 不被扰动的 |
| **同时问了什么**：一起问的别的问题不同 | 不依赖语境的 |

> **修正后的诊断：经典的记录，是在这四种情形下都不变的回答。经典基础的共同前提，是一切回答都是这样的记录。**

逐一对照：
- **Kolmogorov 的 Ω**：四种都不变。谁来读、何时读、和什么一起读，读到的都是同一个 ω 的值。
- **ZFC 的集合**：四种都不变——公共的、永不改变的完成记录。
- **图灵的纸带**：公共的；只因机器自己的一步而改变，而那一步又是纸带的函数。
- **四个倾向**：
  - 线性时间：只剩"之前问了什么"这一种情形，而且只是一条线上的位置；
  - 绝对因果：回答是历史的函数；
  - 还原论：整体的回答由部分不依赖语境的回答拼成；
  - 目标拟合：谁来评价都读同一把尺子（公共的）。

**我们做到哪里**：
- 第二十五到二十八轮的"来源"，只放开了**再问**：单次回答可以不同，但规律对其余三种情形都不变。
- 第二十六轮的 GLU 定理处理了**同时问**的一半。
- **谁问**与**之前问了什么**，完全没有碰。

而 ML 的墙（读取即更新）正是"之前问了什么"，物理的墙（关系主义、触发器）正是"谁问"与"之前问了什么"。第 1 轮其实已经看到了读取即更新（`00 §3`），后面的轮次在形式化时把它丢了——这是一个路径依赖造成的盲区。

## 4. 一个关键的细节：经典总能把失败藏回去

- 放开"之前问了什么"，经典的数学并不会束手无策：把全部历史当作隐藏状态，任何行为都有一个全局模型。
- 放开"谁问"也一样：把提问者当作状态的一部分即可。
- 所以，如果不限定模型的种类，"全局模型存在"**总是真的**，`00 §7` 要测量的东西就消失了。

由此得到两点：
1. **"全局模型为假的程度"只能相对于一类模型来测量。**
   - 例如：相对于"不被扰动的模型"（回答只依赖问题和一份事先取定的记录），一个行为离它有多远；
   - 或者：相对于"公共的模型"（回答不依赖提问者），离它有多远。
   
   第 1 轮的"扰动的比例"、第二十六轮的"复读缺陷"，都是这种相对的度量的特例。
2. **经典把失败藏回去的方式，正是把一切写成预测。**
   - 把历史变成隐藏状态之后，唯一剩下的问题就是"由这个状态预测下一个回答"。
   - 所以博客说的"突破之后无法描述"，更准确的说法是：**经典的语言能描述它，但只能把它描述成一个很复杂的预测问题**；它自己的结构——什么被维持、什么关系不变——在这种描述里不是主角。

## 5. 盲区的清单

按上面的检查，盲区有这些，按对墙的要紧程度排：

1. **之前问了什么（扰动）。** 被问会改变被问者。影响 ML（读取即更新）、物理（测量的反作用、触发器）、计算（交互式的计算）。
2. **谁问（公共性）。** 记录属于谁？不同的提问者能否得到能合在一起的记录？影响物理（关系主义）、ML（系统内部的记录与外部评价者的记录）。
3. **提问者在系统之内。** 记忆读自己，理论与实验在同一个世界里。这是前两条的极端情形；它牵涉自指，只列出，不作断言。
4. **任务的形式。** 数学的任务只有计算、预测、优化。"维持""组织"没有形式。
5. **时间作为内容。** 时间是被记下的关系（先后、间隔），不只是提问的下标。
6. **问题的同一性。** 要谈"再问同一个问题"，先要知道两次问的是不是同一个问题。在会变化的系统里、在不同的提问者之间，这本身可能是相对的。
7. **细化。** "不断细化、更精确"：我们的"可以问"用任意精细的读取来定义，它仍在这个信念之内。
   - 但已经有一半的回答：细化能把**规律**确定到任意精度，却不能把**个体回答**确定下来（没有原子的来源没有记录，`44`）。
   - 有限分辨率是否应当是基本的，没有想。

## 6. 由修正后的诊断直接得到的一个结论：可信的评价是什么

- **"可信"要求的，是公共的、可复读的记录**：换一个人做，再做一次，得到同样的结果。
- 一个标量只是满足这个要求的一种形式。**博客里的小怪圈，就在于把"公共的、可复读的记录"等同于"一个标量"。** 拿掉 reward 之后要求"给我一个数"，要的其实是一份公共的、可复读的记录，只是默认它只能是一个数。
- 对一个**以"被问时怎样改变"来定义**的系统，某一时刻的回答不是记录（它取决于之前问了什么）；而**跨历史不变的关系**可以是记录。
- 最小的例子（`Records.lean` §7）：一个每读一次就翻转的记忆。
  - 再问一次，回答不同，所以回答不是记录（`flip_not_repeatable`）；
  - 在某一时刻"评测"它，结果取决于之前读了几次，两种结果都会出现（`flip_depends_on_history`）；
  - 但"相邻两次回答不同"在任何历史的任何时刻都成立（`flip_relation`）：它是一份公共的、可复读的记录，而且正是这个系统的定义性质。

需要如实补充一点：
- 人造系统可以保存快照再恢复，所以同一段交互可以重做。
- 因此问题不在于"不能重复"，而在于**评价的对象**：
  - 快照上的一组回答，给出的是一个语境里的记录；
  - 一个持续学习的系统，由它在各种历史下怎样改变来定义。它的记录是**跨历史的不变量与关系**。
- 用快照上的标量去评价它，就是用一个语境里的记录，去代替一个本来就不是单一语境的对象。第 1 轮说的"单一全局指标在结构上不适用"（`00 §3`），在这里有了更准确的说法。

## 7. 对数学一侧的检验

修正后的诊断也应当解释 ZFC 的那一堵墙。

- **ZFC 判定不了的命题，恰是在"谁问"与"之前问了什么"两种情形下都会变的回答：**
  - 换一个宇宙（提问者），CH 的真假可以不同——它不是公共的；
  - 强迫法加入新的记录（之前问了什么），CH 可以被翻过来又翻回去——它会被扰动。
- **判定得了的**，是两种情形下都不变的回答：
  - 算术命题；
  - 在大基数下，投影层次的命题，它们在强迫法下不变（已知，待核验）。
- T₁ 的 (C)（`44`），就是让第一个非平凡层次上的回答变成这种不变的记录。
- 所以集合论的独立性，与 ML、物理的墙，是同一个诊断的不同情形：**回答随提问的情形而变，而经典的语言默认它不变。**

**为什么断言层可以是经典的**：
- 数学的断言就是证明，而证明正是公共的、可复读、不被扰动的记录：谁来检查、何时检查、和什么一起检查，结论都一样。
- 所以底座的断言层保持经典，不是保守，而是由同一个原则得出的：**数学自己的产物是记录；它所谈论的对象不必是。**

## 8. 结论

1. **深层的困境，比我们说的更宽。** "一切回答都是记录"是对的，但"记录"包含四种不变性：再问、谁问、之前问了什么、同时问了什么。
2. **我们的工具不够。**
   - 我们只放开了"再问"，以及"同时问"的一半；
   - ML 与物理的墙主要在"之前问了什么"与"谁问"。
   - 第 1 轮看到过前者，后来丢了。
3. **经典总能把失败藏回去**（把历史或提问者变成隐藏状态），藏回去的方式就是把一切写成预测。所以 `00 §7` 的度量只能相对于一类模型来定义。
4. **一个立刻可用的结论**：
   - 可信 = 公共的、可复读的记录；标量只是其中一种。
   - 对由"被问时怎样改变"来定义的系统，它的记录是跨历史的不变量与关系。
5. **同一个诊断也解释了 ZFC 的独立性**：独立的命题，是随"谁问"（宇宙）与"之前问了什么"（强迫法）而变的回答。
6. **断言层保持经典有了理由**：证明本身就是公共的、可复读的记录。

## 9. 怎样推进

按原则的顺序，而不是按已有体系的顺序：

1. **把提问的情形放进底座。**
   - 一个"行为"：对每个提问者、每段提问历史、每组一起问的问题，给出回答的规律。它的描述是记录，属于 T₀。
   - 定义四种不变性。然后：
     - 记录 = 四种都不变；
     - 来源 = 规律四种都不变，个体回答可以变——即前几轮的对象；
     - 被扰动的、相对的，是新放开的两类。
2. **事实与任务。**
   - 事实 = 在一切情形下都必然的问题，包括跨历史的关系，例如 `flip_relation`。
   - 任务 = 要维持的一组事实；评价 = 哪些事实被维持，按包含关系比较，不压成一个数。
3. **相对于模型类的失败度量。** 对"不被扰动""公共""不依赖语境"三类模型，各定义一个行为到它的距离；证明经典的模型类恰是三者的交，而三种失败彼此独立（给出例子）。
4. **用墙检验**：一个读取即更新的记忆；两个提问者的记录能否合并；数学一侧（宇宙与强迫法），只作对照。
5. **最后才回到 T₀、T₁**，看这些概念在底座里的位置。

## 10. 风险（写在这里，以便每一步对照）

- **大统一**：四种情形可能又变成"一切框架的地图"（第五到七轮的偏离）。守住：只用这四种，它们来自对一次提问的分析；没有必要，不再加。
- **翻译**：扰动、语境、相对的记录，在量子基础里都有成熟的形式（信号、上下文性、关系量子力学、Wigner 之友一类的不可能定理），交互式计算、时序逻辑里的不变量也是已知的。它们只作指导；我们要做的是原则的推论——什么是可信的记录，任务与评价是什么。
- **分层**：这些工具首先是描述系统的语言；底座（T₀、T₁）是数学对象的理论。二者的连接——在数学里，"谁问"是宇宙，"之前问了什么"是强迫法——要写准，不能只停在比喻上。

## 11. 已知的与这里的

**已知的，只作指导**：
- 信号与无信号；上下文性；带测量依赖的隐变量模型；
- 关系量子力学与 Wigner 之友一类的结果；
- 交互式计算；时序逻辑中的不变性质；
- 集合论中强迫法下的绝对性。

**这里的**：
1. 四种提问情形的诊断，以及我们的工具只覆盖了其中之一的检查；
2. 经典总能把失败藏回去，而藏回去的方式就是预测——所以失败只能相对于模型类度量；
3. 可信 = 公共的、可复读的记录，标量只是一种；以改变来定义的系统，记录是跨历史的不变量；
4. 独立性是随提问情形而变的回答；
5. 断言层保持经典的理由：证明是记录。
