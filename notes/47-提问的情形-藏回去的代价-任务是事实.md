## 0. 路线检查（清单第 17、18 条）

- **推动这一轮的是原则**：记录 = 在四种提问情形下都不变的回答（`46 §3`）。
- **这一轮处理的情形**：谁问、之前问了什么（确定性的行为）。同时问了什么已在 `43 §1`；再问（随机）已在 `42`–`45`，这里只说明它与"之前问了什么"的关系。
- **会拉着走的已知体系**：
  - 自动机的最小状态数（Myhill–Nerode）；
  - 时序逻辑中的不变性质；
  - 量子基础中的信号与上下文性。

  它们只作对照，见 §8。

## 1. 行为，与提问的情形

**行为**：给定一段历史——此前依次是谁问了什么——以及现在谁来问、问什么，给出回答。

| 性质 | 定义 | 放开它，就是 |
|---|---|---|
| **公共的** | 换一个提问者，回答不变 | 谁问 |
| **不被扰动的** | 换一段历史，回答不变 | 之前问了什么 |
| **不依赖语境的** | 与哪些问题一起问，回答不变 | 同时问了什么（`43 §1`） |
| **可复读的** | 再问一次，回答不变 | 再问 |

**一个区分**：
- 对确定性的行为，"再问一次"就是一段特殊的历史——刚问过同一个问题。所以确定性的行为再问得到不同的回答，**必定**是被扰动了。例如每读一次就翻转的记忆。
- "再问"与"之前问了什么"只在有随机性时才分得开：
  - **随机**：规律不随历史变，单次回答变（`42`–`45` 的来源）；
  - **扰动**：规律本身随历史变。
- 所以前几轮的"来源"是这样一类行为：**不被扰动、公共、不依赖语境，只是不可复读。**

## 2. 经典的模型，与"藏回去"

- **记录模型**：一份答案表，谁来读、什么时候读，都读同一份。
- **定理 1**（`record_iff`）：一个行为有记录模型，当且仅当它既是公共的，又是不被扰动的。
- **隐藏状态模型**：状态、起点、一次提问怎样改变状态、从状态读出回答。
- **定理 2**（`historyModel_realizes`）：**每个行为都有隐藏状态模型**——把全部历史存进状态即可。这就是 `46 §4` 说的"经典总能把失败藏回去"。
- **定理 3**（`undisturbed_iff_static`）：一个行为不被扰动，当且仅当有一个从不改变状态的模型给出它。

所以，"存在一个全局模型"要看是哪一类：
- 存在隐藏状态模型：总是真的；
- 存在状态不动的模型：当且仅当不被扰动；
- 存在记录模型：当且仅当公共且不被扰动。

## 3. 藏回去的代价，就是失败的度量

`46 §4` 说，失败只能相对于一类模型来测量。这里给出一种自然的测法：**要把失败藏回去，经典的描述至少得虚构多少隐藏的记录。**

**对"之前问了什么"**：
- 一个行为在一段历史之后**还会做什么**，称为它在那里的**余下行为**。
- **定理 4**（`residual_realized`）：任何隐藏状态模型，都要为每一个余下行为准备一个状态。所以模型的状态数，至少是余下行为的个数。
- **定理 5**（`residualModel_realizes`）：以余下行为本身作状态的模型给出这个行为，而且正好用这么多状态。
- **定理 6**（`undisturbed_iff_one_residual`）：不被扰动，当且仅当只有一个余下行为——就是行为本身。
- 所以：**余下行为的个数，就是藏回扰动所需的最少隐藏状态数**；它的对数是需要虚构的隐藏记录的位数。
  - 不被扰动：1 个状态，0 位；
  - 翻转的记忆：至少 2 个状态，1 位（`flipB_two_states`）；
  - 回答依赖全部历史、没有重复的行为：状态数无穷——这正是"由过去预测下一刻"要用的全部记忆。

**对其余三种情形**，同样的测法：

| 情形 | 藏回去要虚构的 | 经典（为零）时 |
|---|---|---|
| 之前问了什么 | 余下行为的个数（隐藏状态） | 1 个 |
| 谁问 | 不同提问者得到的行为有多少种（要存下的视角） | 1 种 |
| 同时问了什么 | 同一个问题在不同语境中的回答有多少种 | 1 种（`43 §1` 的定理） |
| 再问（随机） | 复读缺陷（`42 §10`）；来源一侧，原子之外的部分（`45 §2.3`） | 0 |

**读法**：经典的描述靠虚构隐藏记录把一切失败藏回去；**失败的程度，就是它必须虚构的量**。这正是 `00 §7` 要的"测量全局模型为假的程度"：不是问"有没有全局模型"（总有），而是问"为了有，要虚构多少"。

## 4. 四种失败彼此独立

| 例子 | 可复读 | 公共 | 不被扰动 | 不依赖语境 |
|---|---|---|---|---|
| 一份记录 | 是 | 是 | 是 | 是 |
| 独立的公平硬币（来源） | **否** | 是 | 是 | 是 |
| 做标记的记忆 `markB`：问第一个问题会留下标记，第二个问题问"有没有标记" | 是（`markB_repeatable`） | 是（`markB_public`） | **否**（`markB_disturbed`） | 是 |
| 各得其名 `nameB`：两个提问者各自得到自己的名字 | 是（`nameB_repeatable`） | **否**（`nameB_relative`） | 是（`nameB_undisturbed`） | 是 |
| 同一个问题在两个语境中回答不同 | 是 | 是 | 是 | **否**（`43 §1`） |
| 翻转的记忆 `flipB` | **否**（`flipB_not_repeatable`） | 是（`flipB_public`） | **否**（`flipB_disturbed`） | 是 |

第二到第五行，每行只放开一种情形，所以四种失败互不蕴含。
- 做标记的记忆说明，扰动不必让同一个问题再问时变样：它改变的是**另一个**问题的回答。
- 翻转的记忆同时放开了两种：对确定性的行为，再问得到不同的回答，必定是被扰动了（§1）。

`nameB` 还说明了一点：**相对的回答之间，可以有公共的关系**。两个提问者得到的回答不同，这件事本身在任何历史中都成立，对谁都一样（`nameB_relation`）。这与 `45 §3`"关系可以是记录，而两端不是"同形，只是这里两端是相对的，不是随机的。

## 5. 任务是事实；预测是一种特殊的任务

`46 §5` 的盲区之一：数学的任务只有计算、预测、优化。用本篇的语言：

- **任务**：对行为的一个要求，也就是一组要被维持的事实。
- **预测**：一个把每个回答都定死的任务——满足它的行为只有一个（`IsPrediction`；`exact_is_prediction`）。
- **关系的任务不是预测**："相邻两次回答不同"在一切历史中成立，翻转的记忆满足它；反向起始的翻转记忆也满足它，而两者不同（`flipB_task`、`flipB'_task`、`flipTask_not_prediction`）。

读法：
- **自回归的训练，是把任务写成预测**：训练历史上的每一个下一回答都被定死。
- **"组织记忆"一类的任务，是关系的事实**：
  - 存过的东西之后取得回来；
  - 相关的问题回答一致；
  - 某种先后关系被保持。

  它们约束回答之间的关系，却不定死每个回答。
- **评价就是看哪些事实被维持。**
  - 两个系统按所维持的事实的包含关系比较，这是一个偏序。
  - 要压成一个数，就得给事实加权，而加权没有规范的选法——这就是 reward 回来的地方。
- **事实与怎样藏回去无关**：
  - 事实是对行为本身的陈述，不管用哪个隐藏状态模型去描述它，事实都一样；
  - 而"内部状态是什么"依赖于所选的模型。
  
  所以**事实是可信的**：它是公共的、可复读的记录（`46 §6`）。

对物理的那个问题，只作启发：
- "预测演化"是定死回答的任务；
- "预测结构"是关系的事实。
- 后者不要求一个全局状态沿时间演化，只要求关系在一切情形下成立。

## 6. 数学一侧，与 T₀、T₁ 的位置

**对照**（已知，只作检验）：
- 在数学里，"谁问"是**宇宙**（模型），"之前问了什么"是**强迫法**（加入新的记录）。
- ZFC 判定不了的命题，是在这两种情形下会变的回答；判定得了的，是不变的——算术命题，以及在大基数下投影层次的命题（`46 §7`）。
- T₁ 的 (C)（`44`）让第一个非平凡层次上的回答成为不变的。

**T₀ 中的位置**：
- 一个行为的**描述**，是一份记录：问题、回答、历史都是有限或可数的数据，所以它是遗传可数的，属于 T₀。
- 本篇的一切定义——公共、不被扰动、余下行为、任务、预测——都是关于这些描述的陈述，所以 T₀ 就够用。
- 行为的单次回答**不是**对象；事实**是**。
- 底座不需要新的原语。需要的是**分类**：一个对象是记录，还是一个行为的描述；它的事实在哪些情形下不变。

**这说明了什么**：
- 前几轮担心"形式系统退回了记录优先"（`45 §0.2`）。现在看，这不是问题：
  - 断言层是记录（证明），对象的描述也是记录；
  - 不是记录的，是**被描述的东西的回答**，它们本来就不该是对象。
- 测量优先落在**哪些东西算事实**上，而不在原语上。

| 节 | 定理 | 内容 |
|---|---|---|

| §2 | `historyModel_realizes`、`foldl_snoc` | 每个行为都有隐藏状态模型（状态 = 历史） |

| | `undisturbed_iff_one_residual` | 不被扰动 ⟺ 只有一个余下行为 |
| §4 | `markB_public`、`markB_disturbed`、`markB_repeatable` | 公共、可复读，却被扰动 |
| | `nameB_undisturbed`、`nameB_repeatable`、`nameB_relative`、`nameB_relation` | 不被扰动、可复读，却是相对的；相对的回答之间有公共的关系 |

**如实说明**：
- 这些都是初等的。§3 就是自动机里的最小状态数定理（Myhill–Nerode）在"行为"上的形态。
- 它们的作用，是把 `46` 的诊断变成确定的定义与判据：
  - 哪一类全局模型存在；
  - 藏回去的代价；
  - 任务与预测的区别。

## 8. 已知的与这里的

**已知的，只作指导**：
- 最小状态数（Myhill–Nerode）；
- 随机过程的最小隐藏表示与"统计复杂度"（计算力学）——那是随机情形下"藏回去的代价"的对应；
- 时序逻辑中的"始终成立"的性质；
- 量子基础中的信号、上下文性与关系量子力学；
- 集合论中的绝对性。

**这里的**：
1. **四种提问情形的定义**，以及它们两两独立：每种失败都有只放开它一种的例子（§1、§4）。
2. **"存在全局模型"按模型类分开**：隐藏状态模型总有；状态不动的模型 ⟺ 不被扰动；记录模型 ⟺ 公共且不被扰动（§2）。
3. **失败的程度 = 藏回去必须虚构的量**。这是 `00 §7` 的一个可以计算的形态（§3）。
4. **任务是事实，预测是定死回答的任务**；评价按事实的包含关系比较；事实与怎样藏回去无关，所以是可信的记录（§5）。
5. **T₀ 不需要新的原语**：测量优先落在"哪些东西算事实"上（§6）。

## 9. 下一步

1. **随机的情形**：把"再问"与"之前问了什么"在有随机性时分开。
   - 规律随历史变的程度——扰动；
   - 单次回答的变动——随机。
   
   这时"藏回去的代价"就是随机过程的最小隐藏表示，要避免把计算力学翻译过来：只取它作为度量的对照，问题仍由我们的原则提出。
2. **事实的结构**：一个行为的全部事实构成什么样的结构？
   - 两个行为事实相同而不同，是否可能？这对应 `45 §6` 的"来源由它的事实决定到什么程度"。
   - 预测的任务，在事实的结构里处于什么位置？
3. **用墙检验**：写一个"读取即更新"的记忆，它的定义性质是几个关系的事实，并且它的每个快照评分都依赖历史。要比翻转的记忆更像真的记忆。
4. **路线检查照常**：每一步先问，是原则在推动，还是已知的体系在拉着走；以及对 `00 §7` 的贡献。
